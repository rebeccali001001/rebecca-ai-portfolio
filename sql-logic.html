01

CASE WHEN

CASE works like a simple IF / ELSE expression. It returns a result based on a condition.

SELECT order_id, quantity,
CASE
    WHEN quantity >= 100 THEN 'Large'
    WHEN quantity >= 50 THEN 'Medium'
    ELSE 'Small'
END AS order_size
FROM sales_orders;

SQL checks the WHEN conditions in order and returns the matching THEN value.

02

COALESCE

COALESCE returns the first value that is not NULL.

SELECT COALESCE(delivery_date, 'Not delivered')
FROM sales_orders;

This lets a query show a useful fallback when a value is missing.

03

NULLIF

NULLIF returns NULL when two values are equal.

SELECT NULLIF(quantity_mt, 0)
FROM sales_orders;
04

How to Think About SQL Logic

CASE classifies values. COALESCE supplies a fallback. NULLIF turns a matching value into NULL.
