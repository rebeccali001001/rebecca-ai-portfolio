Build

The process of turning source code into a form that can be run, packaged, tested, or deployed.

01

What is it?

Build is the process of turning source code into a form that can be run, packaged, tested, or deployed.

A build can compile code, bundle files, process assets, include dependencies, and create a consistent output from a set of source files.

Simple Definition：
Build turns source code into a usable software artifact.

02

Think of it like...

Think of a build like preparing a recipe for serving.

Source code is the ingredients and instructions. The build combines and prepares them into something that can run.

Product manager translation

A build makes the same source code produce a known, repeatable output.

07

Do Not Confuse

Build

Transforms source code into an output.

Deploy

Places the output into an environment where it can run.

Build = Prepare Output
Deploy = Run Output Somewhere

What to Remember

Build turns source code into a known output.

The output can be tested, packaged, or deployed.

A repeatable build helps teams produce consistent software artifacts.
