14 · Pseudo Elements

Style a virtual part of an element.

01 · What is it?

Style a virtual part of an element.

02 · Think of it like...

They are small pieces the browser lets CSS add or target.

03 · Basic Syntax

.quote::before { content: "“"; }
p::first-letter { font-size: 2em; }

04 · Visual Model

14 · Pseudo Elements

Read the code from the target, through the CSS rule, to the visible result in the browser.

05 · How it works

::before and ::after need content to appear, even when it is an empty string.

06 · Key Properties

::before::after::first-letter::first-line::selectioncontent

07 · Example

.quote::before { content: "“"; }
p::first-letter { font-size: 2em; }

Change one value at a time in DevTools to see what the browser recalculates.

08 · Common Patterns

Keep a small, reusable rule close to the component it styles. Prefer clear class names and values that support responsive layouts.

09 · Common Mistakes

Putting essential meaning only in generated content; it may not be available to assistive technology.

10 · When to use

Use pseudo elements whenever this is the clearest way to express a visual decision in CSS.
