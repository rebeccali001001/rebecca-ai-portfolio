PART III · HTTP & APIs

DELETE

An HTTP method commonly used to remove a resource.

01 · What is it?

What is it?

DELETE is an HTTP method commonly used to remove an existing resource.

Simple Definition： DELETE asks the system to remove something.

02 · Think of it like...

Think of it like...

Think of DELETE as removing one record from a system.

Existing Resource
→
DELETE
→
Resource Removed
03 · What does it do?

What does it do?

DELETE can be used to remove:

A Record
A File
A Saved Item
A Resource
A Temporary Object
04 · Where is it used?

Where is it used?

DELETE requests can appear in:

Admin Systems
Content Management
Saved Items
User Records
Temporary Data
API Resource Management
05 · Example

Example

DELETE /api/orders/1001

Request removal of order 1001.

Client→DELETE /api/orders/1001→Backend→Check Rules→Remove Resource→Response

The backend may still apply validation and business rules before deletion is allowed.

06 · How it connects

How it connects

Client→DELETE→Endpoint→Backend→Business Logic→Database→Response

DELETE requests often still pass through backend rules before data is removed.

07 · Do Not Confuse

Do Not Confuse

DELETE

Requests removal of a resource from the system.

Remove from Screen

May only hide something in the user interface.

Hidden UI
does not always mean
Deleted Data
08 · Topic Glossary

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
DELETE删除An HTTP method commonly used to remove a resource.通常用于删除资源的 HTTP 方法。
Resource资源The data or object being removed.DELETE 请求希望删除的数据或业务对象。
Endpoint接口地址The address identifying the resource to remove.用来标识需要删除哪个资源的 API 地址。
Delete Operation删除操作An operation that removes data or a resource.从系统中移除数据或业务对象的操作。
Validation校验Checking whether deletion is allowed.删除前检查是否满足系统要求。
Business Logic业务逻辑Rules that may decide whether deletion is allowed.用来判断某条数据是否允许删除的业务规则。
Database数据库The system where the resource may be stored.被删除资源可能实际保存的系统。
Response响应The result returned after a delete request.DELETE 请求处理完成后返回的结果。
Soft Delete软删除Marking data as deleted without physically removing it.不真正移除数据，而是通过状态标记为已删除。
Hard Delete物理删除Permanently removing the stored data.将数据从存储中真正删除。
09 · What to Remember

What to Remember

DELETE is commonly used to remove a resource.

A DELETE request may still require validation and business rules.

Removing something from the screen is not always the same as deleting the data.
