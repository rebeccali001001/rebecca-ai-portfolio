12 · IDs & Classes

Give elements reusable groups or a specific page identity.

What is it?

id and class are global attributes used by HTML, CSS, and JavaScript. Think of it like: a unique badge versus a shared category label.

Basic Syntax

<div id="profile" class="card active">…</div>

id vs class

An ID should normally be unique on a page. A class is reusable and an element may have multiple classes. CSS can select #profile or .card; JavaScript can select either.

Common Mistakes

Do not duplicate IDs or encode a whole styling system in IDs. Prefer classes for reusable visual and state patterns.

Quick Reference

id="profile" unique identifier · class="card active" reusable groups · CSS .card · JS document.querySelector().
