MODULE 05 · DATABASE & SQL

SQL

SQL is the standard language used to define, query, insert, update, and manage data in relational databases.

01 · What is it?

SQL is a language for working with structured data in relational databases.

It gives an application a consistent way to describe database structures, ask for rows, add records, change values, remove data, and control groups of related changes.

02 · Think of it like...

Think of SQL as speaking clearly to a very organized librarian.

You name the collection, describe what you want, and state any rules for choosing it. The database finds the matching records or applies the requested change.

03 · What does it do?

SQL lets software work with both the shape of data and the data itself.

Define StructureCreate tables, columns, and constraints.
Query DataFind rows that match a condition.
Insert DataAdd new records to a table.
Update DataChange values in existing records.
Delete DataRemove records that are no longer needed.
Manage TransactionsKeep related changes consistent.

04 · Where is it used?

SQL appears anywhere a system needs reliable, structured access to relational data.

Web ApplicationsUsers, orders, and settings.
Backend ServicesRead and write application data.
ReportsGroup and summarize business data.
Data OperationsMove or repair structured records.
Database ToolsInspect and manage schemas.

05 · Example

A backend can use SQL to find active customers, then return the result through an API.

Read existing data

SELECT id, name
FROM customers
WHERE status = 'active'
ORDER BY name;

Meaning: return the IDs and names of active customers, ordered by name.

Change existing data

UPDATE customers
SET status = 'inactive'
WHERE id = 42;

Meaning: change the status of customer 42.

07 · Do Not Confuse

SQL

A language used to work with relational database data.

Database

The system that stores and organizes the data.

SQL vs NoSQL

SQL commonly describes relational systems; NoSQL is a broader family of non-relational approaches.

SQL is how software communicates with a relational database; it is not the database itself.

09 · What to Remember

SQL is the standard language used to work with relational database data.

It can define structures, query rows, insert records, update values, and delete data.

In an application, backend code usually sends SQL to the database and returns the result through an API.
