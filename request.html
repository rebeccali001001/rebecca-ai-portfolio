PART III · HTTP & APIs

Request

A message sent from one system to ask another system for data or an action.

01 · What is it?

What is it?

A request is a message sent from a client to another system.

It asks for data, sends information, or asks the system to perform an action.

Simple Definition: A request tells another system what you want.

02 · Think of it like...

Think of it like...

Think of a request as placing an order.

You tell the system:

What you want

Where you want it

Any information needed to process it

03 · What does it do?

What does it do?

A request can ask a system to:

Read Data
Create Data
Update Data
Delete Data
Search Data
Trigger an Action
04 · Where is it used?

Where is it used?

Requests are used between:

Browser and Server
Frontend and Backend
Mobile App and API
Service and Service
System and External API
05 · Example

Example

Use:

GET /api/orders/1001

Meaning: Request order 1001.

Second example:

POST /api/orders

Request Body:

{
  "customer_id": 2001,
  "quantity": 10
}

Meaning: Request creation of a new order.

06 · How it connects

How it connects

Client→Method→Endpoint→Request→Backend→Response

A request combines several pieces of information to tell the receiving system what should happen.

07 · Do Not Confuse

Do Not Confuse

Request

Asks for data or an action.

Response

Returns the result.

Request = Ask

Response = Answer

08 · Topic Glossary

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Request请求A message sent to ask another system for data or an action.向另一个系统请求数据或执行操作的信息。
Client客户端The side that usually sends a request.通常负责发送请求的一端。
Server服务器The side that usually receives and processes a request.通常接收并处理请求的一端。
MethodHTTP 方法The action the request wants to perform.表示请求希望执行什么操作的方法。
Endpoint接口地址The address the request is sent to.请求发送到的具体 API 地址。
Header请求头Extra information sent with the request.随请求一起发送的附加信息。
Body请求体The main data carried inside the request.请求中真正携带的主要数据。
Query Parameter查询参数A value added to the URL to control or filter a request.加在 URL 中用来筛选或控制请求的参数。
Path Parameter路径参数A value placed inside the URL path.放在 URL 路径中标识具体资源的参数。
Response响应The result returned after the request is processed.请求处理完成后返回的数据或结果。
09 · What to Remember

What to Remember

A request tells another system what you want.

A request may include a method, endpoint, headers, parameters, and body.

A request is followed by a response.
