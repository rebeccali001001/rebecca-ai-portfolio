Source Code

Human-readable instructions written by developers that define how software behaves.

01

What is it?

Source code is human-readable instructions written by developers that define how software behaves.

02

Think of it like...

Think of source code as a recipe for software.

The recipe describes the steps, decisions, and rules that a computer follows to produce a result.

03

What does it do?

Define behavior

Describe what the software should do.

Process input

Receive and work with information.

Apply rules

Make decisions and carry out logic.

Produce output

Return a result, action, or response.

04

Where is it used?

Web applications

Build pages, interactions, and browser behavior.

Backend services

Handle requests, rules, data, and integrations.

Mobile and desktop apps

Power features users run on their devices.

Scripts and tools

Automate tasks and support development work.

05

Example

A small function can express one rule in source code:

function calculateTotal(price, quantity) {
  return price * quantity;
}

The source code defines how the total is calculated when the function is used.

07

Do Not Confuse

Source code ≠ machine code

Source code is written for people to read; machine code is the lower-level form a computer executes.

Source code ≠ repository

Source code is the instructions; a repository stores source code and its history.

Source code ≠ documentation

Source code defines behavior; documentation explains how to understand or use it.

09

What to Remember

Source code is the human-readable set of instructions that defines software behavior.

Developers write and review it; build tools turn it into a form that can run.
