Database & SQL Glossary

05 · DATABASE & SQL

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Database数据库A system used to store and organize application data.用来保存和组织应用数据的系统。
DBMS数据库管理系统Software that manages databases and access to their data.负责管理数据库、处理读写请求并控制访问权限的软件。
Index索引A structure that helps a database find rows faster.帮助数据库更快找到数据行的辅助结构。
Relational Database关系型数据库A database that stores data in tables and connects related records.把数据放在表里，并把相关记录连接起来的数据库。
PostgreSQLPostgreSQLAn open-source relational database management system.一个开源的关系型数据库管理系统。
MySQLMySQLA popular relational database management system.一种常用的关系型数据库管理系统。
Table表A structure that stores related data in rows and columns.按行和列保存相关数据的结构。
Row行One complete record in a database table.数据库表中的一条完整记录。
Column列One type of information stored in every row.每一行都保存的一种信息类型。
Schema模式 / 结构The blueprint that defines how database data and objects are organized.规定数据库如何组织表、字段和关系的蓝图。
Primary Key主键A value that uniquely identifies a record.唯一标识一条记录的值。
Foreign Key外键A field that points to a record in another table.指向另一张表中记录的字段。
Relationship关系A connection between records in different tables.不同数据表中的记录之间的关联。
Constraint约束A rule that controls which data is allowed.规定哪些数据可以被保存的规则。
Transaction事务A group of database operations treated as one unit.作为一个整体执行的一组数据库操作。
NULL空值A marker for a missing or unknown value.表示缺少或未知数据的标记。
Normalization规范化Organizing relational data to reduce unnecessary duplication.整理关系型数据，减少不必要的重复。
Migration迁移A controlled change to a database schema or stored data.有计划地改变数据库结构或搬移数据。
SQL结构化查询语言A language used to read and change relational database data.用来查询和修改关系型数据库数据的语言。
One-to-Many一对多One record is related to many records.一条记录对应很多条记录。
