Functional Tests for AI Systems

Functional tests verify that an AI feature completes the intended job, not merely that the model returns plausible text.

Detail

Build a small, versioned set of representative tasks with explicit assertions. Test the happy path, missing inputs, malformed tool arguments, empty retrieval, retries, and human handoff.

Test layerExample assertionEvidence
Output contractValid JSON and required fieldsSchema validation result
Tool behaviorCorrect tool, arguments, and permission pathTrace + tool fixture
Workflow outcomeCorrect routing or business actionEnd-state assertion
RecoveryRetry, fallback, or escalation is triggeredFailure-path trace

Sample

A document agent receives a real invoice fixture, extracts required fields, refuses an unsupported format, and routes low confidence to review.

Test rhythm

Run smoke tests on every change; run the full scenario set before a deployment decision.
