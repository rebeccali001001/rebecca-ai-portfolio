13 · Data Attributes

Store small custom values on an element for scripts or integration hooks.

What is it?

Attributes beginning with data- hold custom, non-visible data. Think of it like: a note attached to an element for code to read later.

Basic Syntax

<button data-user-id="123" data-state="ready">Open</button>

element.dataset.userId

How it works

HTML names values with kebab case, such as data-user-id. JavaScript exposes them through element.dataset.userId in camel case.

Common Mistakes

Do not invent unrelated custom attributes such as user-id; prefer data-user-id. Do not place private or security-sensitive information in HTML.

Quick Reference

data-* custom data · dataset JavaScript interface · use attributes for small element-specific values.
