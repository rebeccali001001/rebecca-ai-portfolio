The Core Ideas That Start AI

This module introduces the basic ideas behind artificial intelligence, machine learning, and deep learning, and shows how different learning approaches fit together.

Start with the big picture before going deeper into models.

The Big Picture · taxonomy

AI is broad; learning is one way to build it

ARTIFICIAL INTELLIGENCEThe broad field of machines performing tasks that appear intelligent
↓ MACHINE LEARNINGSystems learn patterns from data rather than relying only on fixed rules
├── Supervised LearningLearn from examples with labels
├── Unsupervised LearningFind patterns without labels
├── Reinforcement LearningLearn through actions, feedback, and rewards
└── Deep LearningAn important machine-learning approach that often uses neural networks with many layers
Knowledge Structure

A · BROADEST IDEA

Artificial Intelligence

Machine Learning

A way for machines to learn patterns from data.

B · WAYS OF LEARNING

Supervised Learning

Learns from examples with labels.

Unsupervised Learning

Looks for patterns without labels.

Reinforcement Learning

Learns through actions, feedback, and rewards.

C · MAJOR APPROACH

Deep Learning

A machine-learning approach based on multi-layer neural networks.
