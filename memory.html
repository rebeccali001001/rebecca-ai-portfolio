How Does AI Memory Work?

Memory lets an AI system keep useful information outside the current request, retrieve what matters, and bring it back into context when needed.

Start here: Memory is not Context. Context is what the model can see now; Memory is what the surrounding system may store and retrieve later.

The Big Picture

From archive to answer

The model does not need every stored item. A memory architecture selects relevant information before the current run.

Long-Term MemoryStored facts, events, and preferences → Retrieve Relevant MemorySearch, rank, filter, and select → Context WindowCurrent working information → LLMUses visible context to respond

Memory retrieval is usually an application or system step around the model, not a magical expansion of the model’s context.

Key Distinctions

Do not collapse these layers

Stored vs visibleMemory ≠ ContextStored information only helps after it is selected and supplied to the current run.
Runtime vs learningMemory ≠ TrainingRuntime memory can preserve information without changing model parameters.
Selection vs capacityRetrieval ≠ Unlimited ContextRetrieval helps choose useful information; it does not remove context limits.
