# Article skills

This project has two reusable article skills:

- technical_writer/SKILL.md (article-technical-writer) — plans and drafts practical technical articles from a topic or prompt.
- qa/SKILL.md (article-qa) — checks evidence, structure, links, duplication, visuals, and publish readiness.

The writing skill is intentionally source-disciplined: missing facts stay as TODO items. The QA skill is a gate before an article moves from draft to review or published.
