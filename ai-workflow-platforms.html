What these platforms do

MODEL CONNECTION

Connect a workflow to one or more model providers.

PROMPT / FLOW DESIGN

Arrange prompts, branches, variables, and steps.

RAG / KNOWLEDGE

Bring documents or knowledge sources into the flow.

TOOLS / API

Call approved tools, APIs, or external services.

APP / WORKFLOW OUTPUT

Expose the result as a chatbot, app, API, or repeatable workflow.

Major platforms

These products overlap, but their center of gravity and user experience differ.

Dify

WHAT IT IS

A platform for building AI applications and workflows.

MAIN STYLE

Visual orchestration with app, prompt, knowledge, and model features.

TYPICAL USER

Product teams, builders, and developers who want a fast path to an AI app.

COMMON USE CASE

RAG apps, chatbots, internal assistants, and workflow-backed AI products.

Flowise

WHAT IT IS

A visual builder for LLM chains, agents, and data-connected flows.

MAIN STYLE

Node-based composition of models, memory, retrievers, and tools.

TYPICAL USER

Developers and technical builders who prefer visual experimentation.

COMMON USE CASE

Prototyping RAG pipelines, agents, and tool-using AI flows.

Coze

WHAT IT IS

A visual platform for creating and publishing AI bots and apps.

MAIN STYLE

Productized, low-code bot building with plugins, knowledge, and workflows.

TYPICAL USER

Creators, teams, and non-specialists building shareable AI experiences.

COMMON USE CASE

Chatbots, content helpers, knowledge bots, and lightweight AI apps.

These platforms usually compose a flow through visual nodes or configuration. The canvas makes the sequence and handoffs easier to see; the underlying systems still need permissions, testing, and monitoring.

How the layers differ

AI WORKFLOW PLATFORM

Often visual / low-code.

Connects models, prompts, RAG, tools, and app outputs. Examples: Dify / Flowise / Coze.

AGENT FRAMEWORK

Typically a code-first development layer.

Provides primitives and control for building custom agent behavior. Examples: LangGraph / Agents SDK.

AI WORKFLOW PLATFORM

AI-centered flows: model · prompt · RAG · agent.

AUTOMATION PLATFORM

App / business-centered flows: trigger · CRM · email · spreadsheet · database.

The boundary is not fixed: the two categories are showing clear overlap as automation products add AI and AI platforms add integrations.

Typical use cases

Q&A / RAG app

Answer questions from a controlled knowledge source.

AI chatbot

Package a conversational experience for users.

Document workflow

Extract, classify, summarize, or route documents.

Agent prototype

Try a tool-using or multi-step agent idea.

Internal AI tool

Give a team a focused assistant for recurring work.

AI-powered form / workflow

Turn structured input into a useful next action.

How to think about choosing

Want visual AI app building→ AI Workflow Platform
Want code-level agent control→ Agent Framework
Want business-system automation→ Automation Platform

Remember this

AI workflow platforms provide visual or low-code ways to combine models, prompts, knowledge, and tools into AI applications.
