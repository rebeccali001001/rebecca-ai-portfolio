02

Big Picture

User→Browser→Web Page→HTML + CSS + JavaScript→DOM→Event→Backend / API

The browser creates the visible page locally, while events can connect that page to services outside the browser.

03

Core Concepts

Frontend

The part of a product that users see and interact with.

Browser

Software that loads web resources and renders a web page.

Web Page

The document and interface presented in a browser window.

HTML

The structure and meaning of content on a page.

CSS

The visual presentation, layout, and responsive behavior of a page.

JavaScript

The behavior and logic that make a page interactive.

DOM

The browser's structured representation of the page that scripts can read and change.

Event

A signal that something happened, such as a click, input, or page load.

Event Listener

Code that waits for an event and runs a response when it occurs.
