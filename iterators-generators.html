15 · Iterators & Generators

Iterators and generators let Python process values one at a time.

This is useful when:

processing large datareading filesstreaming resultsavoiding loading everything into memory

1. Iterable

An iterable is something Python can loop over.

Common examples:

list
tuple
string
dict
set
range
products = ["Copper", "Aluminum"]

for product in products:
    print(product)

2. iter()

iter() creates an iterator from an iterable.

products = ["Copper", "Aluminum", "Nickel"]

iterator = iter(products)

3. next()

next() gets the next value from an iterator.

products = ["Copper", "Aluminum", "Nickel"]

iterator = iter(products)

print(next(iterator))
print(next(iterator))
print(next(iterator))

Output

Copper
Aluminum
Nickel

4. StopIteration

When there are no more values, next() raises:

StopIteration

The second call has no value left.

5. for Loop Uses Iteration

A for loop automatically gets values one at a time.

for product in products:
    print(product)

You normally do not need to manually call:

iter()
next()

6. Generator

A generator produces values one at a time instead of creating all values immediately.

Generators commonly use:

yield

7. yield

yield returns one value and pauses the function.

def numbers():
    yield 1
    yield 2
    yield 3

for number in numbers():
    print(number)

Output

1
2
3

8. return vs yield

return

def get_number():
    return 1

The function finishes.

yield

def get_numbers():
    yield 1
    yield 2
    yield 3

The generator can continue producing more values.

9. Generator with Loop

def generate_numbers(limit):

    for number in range(limit):
        yield number

for number in generate_numbers(3):
    print(number)

Output

0
1
2

10. Generator Expression

Similar to list comprehension, but uses parentheses.

List:

numbers = [x * 2 for x in range(5)]

Generator:

numbers = (x * 2 for x in range(5))

11. List vs Generator

List:

Creates all values immediately

Uses more memory

Can access items by index

Generator:

Produces values one at a time

Uses less memory

Designed for iteration

12. Practical Generator Example

def valid_orders(orders):

    for order in orders:

        if order["status"] == "Completed":
            yield order

for order in valid_orders(orders):
    print(order["id"])

Output

1001
