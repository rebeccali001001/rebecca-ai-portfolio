MODULE 05 · DATABASE & SQL

Relationship

A relationship describes how records in one table are logically connected to records in another table.

01 · What is it?

A relationship describes how records in one table are logically connected to records in another table.

For example, one customer can be connected to many orders. The relationship lets software work with those records as connected parts of one business story.

Simple Definition: A relationship explains which records belong together across tables.

02 · Think of it like...

Think of a relationship like a label that connects a person to the things they own.

A customer record does not need to repeat every order detail. Each order keeps its own record, while a shared identifier shows which customer it belongs to.

Customers

id · 42

name · Mina

→

Orders

03 · What does it do?

A relationship helps a database:

Connect Records

Link related records across tables.

Reduce Duplication

Store shared facts once instead of repeating them.

Support Queries

Combine related data when an application needs it.

Protect Consistency

Keep links meaningful and valid.

04 · Where is it used?

Relationships appear wherever one piece of business data depends on another.

Commerce

Customers connect to orders.

Content

Authors connect to posts.

Education

Students connect to courses.

Support

Customers connect to tickets.

05 · Example

Tables

customers
id | name
42 | Mina

orders
id  | customer_id | total
9001| 42          | 49.00

Query the relationship

SELECT customers.name, orders.total
FROM customers
JOIN orders
  ON orders.customer_id = customers.id
WHERE orders.id = 9001;

The query follows the relationship to return Mina’s order total.

06 · How it connects

Table A→Primary Key→Foreign Key→Relationship→Query Result

The relationship is the logical connection; keys and queries are common ways to represent and use it.

07 · Do Not Confuse

Relationship

The logical connection between related records.

Foreign Key

A column that stores a reference to a record in another table.

JOIN

A SQL operation that reads related rows together.

Relationship = the connection · Foreign key = a stored reference · JOIN = a query operation

09 · What to Remember

A relationship explains how records in different tables belong together.

Keys store references, and SQL queries can use those references to read connected data.

A clear relationship keeps data organized without repeating every fact.
