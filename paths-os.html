PYTHON · LANGUAGE & SYNTAX

18 · Paths & OS

Python often needs to work with:

  • files
  • folders
  • file paths
  • environment variables
  • the current working directory

The most common tools are:

pathlib
os

For new Python code, pathlib is usually easier to read for file paths.

1. File Path

A file path tells Python where a file is located.

data/orders.csv

data folder
↓
orders.csv

/Users/rebecca/project/data/orders.csv

C:\Users\Rebecca\project\data\orders.csv

2. pathlib.Path

Path represents a file or folder path.

from pathlib import Path

file_path = Path("data/orders.csv")

3. Build a Path

Use / with Path to combine folders and file names.

from pathlib import Path

folder = Path("data")
file_path = folder / "orders.csv"

Result conceptually:

data/orders.csv

4. Current Working Directory

The current working directory is the folder Python is currently running from.

from pathlib import Path

current_folder = Path.cwd()
print(current_folder)

/Users/rebecca/project

5. home()

Returns the current user's home folder.

from pathlib import Path

home = Path.home()
print(home)

/Users/rebecca

6. exists()

Checks whether a file or folder exists.

from pathlib import Path

file_path = Path("orders.csv")

if file_path.exists():
    print("File exists")

7. is_file()

Checks whether a path points to a file.

file_path = Path("orders.csv")
print(file_path.is_file())

8. is_dir()

Checks whether a path points to a folder.

folder = Path("data")
print(folder.is_dir())

9. mkdir()

Creates a folder.

from pathlib import Path

folder = Path("output")
folder.mkdir()

folder.mkdir(
    parents=True,
    exist_ok=True
)

parents=True creates missing parent folders.

exist_ok=True does not fail if the folder already exists.

10. name

Gets the file name.

file_path = Path("data/orders.csv")
print(file_path.name)
orders.csv

11. stem

Gets the file name without the extension.

print(file_path.stem)
orders

12. suffix

Gets the file extension.

print(file_path.suffix)
.csv

13. parent

Gets the parent folder.

print(file_path.parent)
data

14. glob()

Finds files matching a pattern.

from pathlib import Path

folder = Path("data")
files = folder.glob("*.csv")
for file in files:
    print(file)

Find all .csv files in the data folder.

15. rglob()

Searches matching files inside a folder and its subfolders.

files = folder.rglob("*.csv")

16. os Module

import os

The os module provides operating-system related tools.

  • environment variables
  • current working directory
  • path information
  • process configuration

17. os.getcwd()

import os
current_folder = os.getcwd()
print(current_folder)

Returns the current working directory.

18. Environment Variables

Environment variables store configuration outside the Python source code.

API_KEY
DATABASE_URL
ENVIRONMENT
PORT

import os
api_key = os.getenv("API_KEY")

19. os.getenv()

Syntax:

os.getenv("VARIABLE_NAME")

environment = os.getenv("ENVIRONMENT")

environment = os.getenv("ENVIRONMENT", "development")

If ENVIRONMENT does not exist, use: development

20. Why Environment Variables Matter

Use them for:

  • API keys
  • database URLs
  • environment settings
  • configuration

Do not place secrets directly into public source code.

api_key = "real-secret-key"

api_key = os.getenv("API_KEY")

21. Practical Path Example

from pathlib import Path

base_folder = Path.cwd()
input_file = base_folder / "data" / "orders.csv"
output_folder = base_folder / "output"
output_folder.mkdir(parents=True, exist_ok=True)
output_file = output_folder / "result.csv"

Project
├── data
│   └── orders.csv
└── output
    └── result.csv
