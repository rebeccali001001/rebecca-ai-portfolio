06 · Images & Media

Embed images, audio, and video with useful alternatives and controls.

What is it?

Media elements bring external visual or audio resources into a document. Think of it like: placing a labeled frame or player in a page.

Basic Syntax

<img src="team.jpg" alt="Three teammates in a meeting" width="800" height="450">
<video controls poster="cover.jpg"><source src="intro.mp4" type="video/mp4"></video>

Key Attributes / Syntax

img uses src and meaningful alt; set width and height to help reserve space. Use picture and source for responsive image choices. audio and video can use controls, autoplay, and poster.

Common Mistakes

Do not omit useful alt text or write “image of” before a description. Decorative images can use an empty alt="". Do not rely on autoplay for essential information.

When to use it

Use media when it adds content, not merely decoration. Related: Accessibility.

Quick Reference

img image · picture responsive sources · audio/video media players.
