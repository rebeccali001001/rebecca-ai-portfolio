What is Reinforcement Learning?

Reinforcement learning trains an agent to choose actions by learning from rewards and consequences.

What is it?

Reinforcement learning is a machine-learning method where an agent learns by interacting with an environment.

Agent

the decision-making system

Environment

the world it interacts with

Action

what the agent chooses to do

Reward

feedback about the result

Goal: learn a policy that produces better long-term reward.

Think of it like...

Learning a game by playing it

You try a move.
The game gives you a result.
Good decisions may lead to rewards.
Bad decisions may lead to poor outcomes.
Over many attempts, you learn which actions tend to work better.

How it works

1Environment
2Agent observes state
3Choose action
4Environment changes
5Receive reward
6Update behavior
7Repeat

Real-world examples

Game Playing

State: Current board

Action: Choose move

Reward: Win / lose / score

Robot Learning

State: Robot position

Action: Move

Reward: Progress toward goal

Recommendation / Decision Systems

State: Current context

Action: Choose an option

Reward: Measured outcome

Reinforcement learning can be used in some recommendation and decision systems; not all recommendation systems are reinforcement learning.

What it is NOT

Reinforcement Learning ≠ Supervised Learning

Supervised: Correct answer supplied for examples.

RL: Feedback comes from interaction and rewards.

Reinforcement Learning ≠ Unsupervised Learning

Unsupervised: Finds structure in unlabeled data.

RL: Learns actions through rewards.

Reward ≠ Correct Answer

Reward: A feedback signal.

Correct answer: A specific target label.
