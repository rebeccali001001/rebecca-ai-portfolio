05 · DATABASE & SQL

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Database数据库A system used to store and organize application data.用来保存和组织应用数据的系统。
Table表A structure that stores related data in rows and columns.按行和列保存相关数据的结构。
Primary Key主键A value that uniquely identifies a record.唯一标识一条记录的值。
Foreign Key外键A field that points to a record in another table.指向另一张表中记录的字段。
Relationship关系A connection between records in different tables.不同数据表中的记录之间的关联。
Normalization规范化Organizing relational data to reduce unnecessary duplication.整理关系型数据，减少不必要的重复。
Migration迁移A controlled change to a database schema or stored data.有计划地改变数据库结构或搬移数据。
SQL结构化查询语言A language used to read and change relational database data.用来查询和修改关系型数据库数据的语言。
