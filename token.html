03 · Tokens, Context & Inference

What is a token?

A token is a small unit of text that an AI model reads and processes. It can be a whole word, part of a word, punctuation, or a space.

Definition

A token is one piece produced by a model’s tokenizer before the model processes the text.

In plain language

An AI model does not receive your sentence as one solid thought. It receives a row of smaller pieces. The pieces are not always whole words: a long word, emoji, or punctuation may be split differently by different tokenizers.

whole wordword partpunctuationspace

Key points

  • More text usually means more tokens to process.
  • Input and output tokens both use the request budget.
  • Token counts affect context capacity, cost, and processing time.

Sample: the coffee order

The order “one oat latte” can be pictured as small pieces: [one] [oat] [latte]. Real tokenizers may split the pieces differently, but the idea is the same: a larger request is assembled from smaller units.

1 · inputOne oat latteA human-sized sentence.
2 · pieces[one] [oat] [latte]Small units the model reads.
3 · meaningMake a drinkThe pieces work together in context.

Where it matters

Token counts matter when you trim prompts, choose a context window, estimate API spend, or diagnose why a long conversation becomes slower.

request load = input tokens + output tokens
