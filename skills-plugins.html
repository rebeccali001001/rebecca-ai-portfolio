What Are Skills and Plugins?

Skills and plugins are packaged capabilities that extend what an AI system can do.

They may combine instructions, tools, resources, configuration, and workflow logic into a reusable capability.

A skill packages capability. A tool performs a specific action.

Think of it like...

A smartphone app.

The phone → AI system

Individual device functions → Tools

Installed app → Skill / Plugin

An app may combine

camera · location · network · storage

into one useful capability.

This analogy is for understanding only. Different AI platforms define “skill” and “plugin” differently.

One simple example

“Prepare a daily sales report.”

Skill / Plugin may contain

  1. Read sales database
  2. Calculate totals
  3. Generate summary
  4. Create chart
  5. Send report

Underlying tools may include

Database Query

Calculator

File Creation

Email

One packaged skill can orchestrate multiple tools.

Skill / Plugin vs Tool

TOOL

A specific external capability

search_web()
query_database()
send_email()

SKILL / PLUGIN

A packaged higher-level capability

May combine instructions, multiple tools, workflow, and resources.

CORE DIFFERENCE

Tool = individual action
Skill / Plugin = reusable packaged capability

Skill / Plugin vs MCP

SKILL / PLUGIN

Defines a usable capability or workflow.

MCP

Defines a standardized way for AI applications to connect to external tools and resources.

SKILL
↓may use

MCP

Skill / Plugin describes capability packaging. MCP describes connection standardization.

Skill / Plugin vs Agent

AGENT

Decides what actions to take toward a goal.

Agent → decides

SKILL / PLUGIN

Provides a capability the agent may use.

Skill → provides reusable capability

Platform terminology

Different platforms may use terms such as:

Skill · Plugin · Extension · Action · App · Tool Package

The exact implementation varies by platform. These names are not a strict universal taxonomy.

What it is NOT

Skill / Plugin ≠ Model

The model generates or selects outputs; the package adds reusable capability around it.

Skill / Plugin ≠ Tool

A package may use tools, but a tool is one specific action.

Skill / Plugin ≠ MCP

A package describes capability; MCP standardizes connections.

Skill / Plugin ≠ Agent

An agent decides what to do; a skill provides something it can use.
