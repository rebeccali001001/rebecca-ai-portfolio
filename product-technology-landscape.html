19 · Product Technology Landscape

Product Technology Landscape

Different technologies solve different parts of a product, from building the interface to running backend logic, storing data, and connecting external services.

01 · Main technology stack

A product is made of layers

These are common names you may see when people describe how a product is built.

FRONTENDReactNext.js · Vue · Nuxt · Svelte
↓
BACKENDNode.jsPython · FastAPI · Django · Express
↓
DATAPostgreSQLMySQL · MongoDB · Redis · Vector Database
↓
PRODUCT SERVICESPaymentsEmail · Analytics · Monitoring · Maps · Search

02 · Keep the vocabulary clear

Architecture vs technology vs platform

The layer is the job. The technology is the tool. The platform is where that tool is hosted or managed.

ARCHITECTURE LAYERFrontend→TECHNOLOGYReact→PLATFORMVercel / Cloudflare
ARCHITECTURE LAYERDatabase→TECHNOLOGYPostgreSQL→PLATFORMSupabase / managed database provider

↓

04 · Backend technologies

What runs product logic behind the interface

JAVASCRIPT / TYPESCRIPT→ Node.js→ Express / NestJS
PYTHON→ FastAPI / Django→ Flask

Keep the levels separate. JavaScript and Python are languages. Node.js is a runtime. Express, NestJS, FastAPI, Django, and Flask are backend frameworks.
