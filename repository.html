PART VIII · DEVELOPMENT & GIT

Repository

A managed location that stores a software project's code, files, and version history.

01 · What is it?

What is it?

A repository is a managed location used to store a project's source code and related files.

With Git, a repository also contains version history showing how the project changed over time.

Simple Definition: A repository is the home of a software project's code and history.

02 · Think of it like...

Think of it like...

Think of a repository as a project folder with memory.

It stores the files, but it also remembers how those files changed.

Project Files+Version History→Repository

07 · Do Not Confuse

Do Not Confuse

Repository

The project and its version-controlled files.

GitHub

A platform that can host Git repositories online.

Repository = Project Storage + History
GitHub = Hosting / Collaboration Platform
