Backend Glossary

Simple English and Chinese explanations for the concepts that make backend systems work.

04 · BACKEND

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Backend后端The part of software that processes requests, data, and business rules.负责处理请求、数据和业务规则的软件部分。
Server服务器A system that receives requests and provides data or services.接收请求并提供数据或服务的一端。
PythonPythonA programming language often used for backend services.常用于构建后端服务的一种编程语言。
Framework框架A reusable structure and set of tools for building software.帮助开发者组织和构建软件的一套结构与工具。
FastAPIFastAPIA Python web framework for building APIs.用 Python 构建 API 的 Web 框架。
Route路由A rule that connects a request path and method to backend code.把请求地址和方法连接到后端代码的规则。
Function函数A reusable block of code that performs a specific task.执行某项具体任务、可以重复使用的一段代码。
Parameter参数A named value supplied to a function or request.传给函数或请求的一个有名字的值。
Validation校验Checking whether incoming data follows required rules.检查输入数据是否符合系统要求。
Business Logic业务逻辑Rules that decide how the system handles business actions.决定系统如何处理业务操作的一组规则。
Service服务A component that coordinates application or business operations.协调完成某类应用或业务操作的软件组件。
Repository / DAO数据访问层A component that reads and writes stored data.负责读取和保存数据的组件。
Dependency依赖Software or configuration another component needs.当前组件运行所需要的其他软件或配置。
Package软件包A bundle of reusable code.一组可以安装和复用的代码。
Environment Variable环境变量A named value supplied by the runtime environment.由运行环境提供的一个命名值。
Configuration配置Settings that control software behavior.控制软件如何运行的一组设置。
Exception异常An event raised when a program cannot continue normally.程序无法正常继续执行时产生的事件。
Error Handling错误处理Detecting failures and responding safely.发现错误并安全、清晰地做出响应。
Logging日志记录Recording events and context while software runs.记录软件运行时发生的事件和相关信息。
External API外部 APIAn API provided by another system or company.由其他系统或公司提供的接口。
Middleware中间件Code that runs between a request and its handler.在请求到达最终处理函数之前运行的代码。
Background Job后台任务A task that runs outside the immediate request-response flow.不阻塞当前请求、在后台继续执行的任务。

Backend in one line

Requests enter through routes, backend code applies rules, and the system returns a result.
