01

Data vs Database Structure

Data Modification uses INSERT, UPDATE, and DELETE to change rows. Database Definition uses CREATE, ALTER, and DROP to change database structure.

DML means Data Manipulation Language. DDL means Data Definition Language.

02

CREATE TABLE

CREATE TABLE creates a new table and defines its columns.

CREATE TABLE customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100) NOT NULL,
    country VARCHAR(50),
    customer_type VARCHAR(30)
);
PartMeaning
CREATE TABLECreates a new table.
customersTable name.
customer_idColumn name.
INTData type.

04

Keys and Constraints

A PRIMARY KEY uniquely identifies each row. It should identify one row and is commonly used in relationships.

customer_id INT PRIMARY KEY
status VARCHAR(20) DEFAULT 'Pending'
ConstraintPurpose
PRIMARY KEYUniquely identifies a row.
NOT NULLRequires a value.
UNIQUEPrevents duplicate values.
DEFAULTSupplies a value when none is provided.
FOREIGN KEYConnects related tables.

A constraint is a rule that helps keep table data valid.

05

FOREIGN KEY

A foreign key connects related tables. This is the structure that later makes a JOIN between customers and orders meaningful.

CREATE TABLE sales_orders (
    order_id VARCHAR(20) PRIMARY KEY,
    customer_id INT,
    metal VARCHAR(30),
    quantity_mt DECIMAL(10,2),
    FOREIGN KEY (customer_id)
        REFERENCES customers(customer_id)
);

customers.customer_id
↑
sales_orders.customer_id

06

ALTER TABLE

ALTER TABLE changes the structure of an existing table.

ALTER TABLE sales_orders
ADD COLUMN delivery_date DATE;

ALTER TABLE sales_orders
DROP COLUMN delivery_date;
07

DROP and TRUNCATE

DROP TABLE is a structural operation and can be destructive.

DROP TABLE temporary_orders;
TRUNCATE TABLE temporary_orders;
DELETE

Removes rows.

TRUNCATE TABLE

Removes all rows while keeping the table structure.

DROP TABLE

Removes the table itself.

Exact behavior can vary by database system.

09

Putting It Together

CREATE TABLE customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100) NOT NULL
);

CREATE TABLE sales_orders (
    order_id VARCHAR(20) PRIMARY KEY,
    customer_id INT,
    metal VARCHAR(30),
    quantity_mt DECIMAL(10,2),
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);

Table definition creates the keys and relationship. Later, a JOIN can use that relationship to combine customer and order data.
