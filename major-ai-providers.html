Major AI Providers

The AI market is built by many companies, each with different model families, products, business models, and deployment strategies.

The provider stack

Different Provider Strategies

These categories overlap; they are not a strict taxonomy.

CLOUD-FIRSTHosted models, APIs, managed scale.
OPEN-WEIGHT ECOSYSTEMWeights, partners, local runtimes.
CONSUMER PRODUCT + APIAn app plus developer access.
ENTERPRISE / CLOUDSecurity, governance, integrations.

Provider vs Model vs Product

OpenAI = company
GPT = model family
ChatGPT = AI product
Codex = coding product / agent
Anthropic = company · Claude = model family + branded product · Claude Code = coding product

Brand names can overlap layers. Ask which layer the name refers to.
