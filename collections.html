03 · Collections

Collections store multiple values inside one variable.

1. list

A list stores multiple values in order.

Syntax

items = [value1, value2, value3]

Example

products = ["Copper", "Aluminum", "Nickel"]

Common scenarios

  • product list
  • order list
  • customer list
  • API results

2. Read a List Item

products = ["Copper", "Aluminum", "Nickel"]\n\nprint(products[0])

Copper

Python starts counting from 0.

3. Change a List Item

products[0] = "Gold"

Result:

["Gold", "Aluminum", "Nickel"]

4. append()

Adds a new item to the end of a list.

products.append("Zinc")

5. remove()

Removes a specific value.

products.remove("Nickel")

6. len()

Returns the number of items.

products = ["Copper", "Aluminum", "Nickel"]\n\nprint(len(products))

3

7. tuple

A tuple is similar to a list, but is usually used for values that should not change.

Syntax

coordinates = (10, 20)

Example

rgb = (255, 255, 255)

8. dict

A dictionary stores data as:

key → value

Syntax

data = {\n    "key": "value"\n}

Example

order = {\n    "order_id": 1001,\n    "customer": "Apple",\n    "product": "Copper",\n    "quantity": 10\n}

Common scenarios

  • API response
  • order information
  • customer information
  • configuration

9. Read Dictionary Value

print(order["customer"])

Apple

10. Add or Change Dictionary Value

order["status"] = "Pending"

The first example adds a new key.

order["quantity"] = 20

The second updates an existing key.
