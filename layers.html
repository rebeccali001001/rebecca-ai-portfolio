What are Layers in a Neural Network?

A layer is a stage in a neural network that transforms information before passing it to the next stage.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A layer is one stage of computation inside a neural network.

Common descriptions include an input layer, hidden layers, and an output layer. Modern architectures can use more specialized and repeated structures than a simple traditional three-layer diagram.

Think of it like...

Think of a layer like one station on an assembly line.

Each station receives something, changes it, then passes the result forward.

How it works

Each layer uses learned parameters to transform its input into a new representation.

1 · InputReceive informationRaw data or an earlier representation arrives.
2 · TransformApply learned computationWeights, biases, and operations change the signal.
3 · Pass forwardSend a representationThe result becomes input for the next layer.
4 · RepeatBuild more structureMore layers refine or reorganize the representation.
5 · OutputProduce a predictionThe final stage produces task-specific output.
Input ↓ Layer 1 Transformation ↓ Layer 2 Transformation ↓ More Layers ↓ Output

Real-world examples

Image recognition

Early processing: edges and simple signals

Later layers: shapes, patterns, and higher-level representations

Output: a prediction such as “cat” or “car”

Text processing

Input: token representations

Repeated transformations: layers combine and refine context

Output: contextual representations for prediction or classification

What it is NOT

Layer ≠ Neuron

Layer: a stage containing or applying many computational units.

Neuron: one unit within a layer.

Layer ≠ Parameter

Layer: a computation and its structure.

Parameter: a learned value used by that computation.

More Layers ≠ Always Better

Depth can help represent complex patterns, but can also increase cost and optimization challenges.
