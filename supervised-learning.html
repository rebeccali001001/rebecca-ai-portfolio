What is Supervised Learning?

Supervised Learning teaches a model to make predictions from examples that include the correct answers.

What is it?

Supervised Learning is a Machine Learning method that learns from labeled examples.

Each example pairs an input with a target answer, such as a photo and its label or a house and its sale price. The trained model uses learned patterns to predict answers for new inputs.

Think of it like...

Think of it like practicing with an answer key.

A teacher shows many questions together with their correct answers. Over time, the learner notices useful patterns and can try a new question. The answer key is the analogy for labeled training data.

How it works

The model compares its predictions with known answers during training, then applies what it learned to new data.

1 · CollectGather examplesBring together inputs and trustworthy target answers.
2 · TrainFind patternsThe model adjusts internal values to reduce prediction errors.
3 · ValidateTest new examplesUse held-out data to check whether patterns generalize.
4 · PredictScore a new inputThe model returns a class, number, probability, or ranking.
5 · MonitorReview performanceCheck errors and data changes after deployment.

What it is NOT

Supervised Learning ≠ Machine Learning

Supervised Learning: One learning setup that uses labeled examples.

Machine Learning: The broader field, including unsupervised and reinforcement learning.

Supervised Learning ≠ Rule-based programming

Supervised Learning: Learns patterns from examples.

Rule-based programming: Uses rules explicitly written by people.

Supervised Learning ≠ Guaranteed correctness

Supervised Learning: Makes predictions that can be wrong.

Reliable use: Requires representative labels, evaluation, and appropriate human review.
