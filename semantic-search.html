What is Semantic Search?

Semantic search tries to find information based on meaning rather than only exact matching words.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Semantic search retrieves results based on semantic similarity or meaning.

For example, “employee vacation allowance” can match “annual leave entitlement” even when the exact words differ. Semantic search describes the search goal or behavior; vector search is one common technical method that can support it.

Think of it like...

Think of it like asking a librarian for books about “cars” and also getting relevant material titled “automobiles.”

The librarian understands that the topics are related instead of checking only whether the same word appears on the cover.

How it works

1 · QueryRead the requestThe system receives the user's words.
2 · Represent meaningEncode the queryThe query is represented in a form that captures useful meaning.
3 · CompareCheck indexed contentThe system compares the query with stored documents or records.
4 · RankOrder relevant matchesMore relevant results are placed higher.
5 · ReturnShow the matchesResults go to the user or a downstream AI step.

Real-world examples

Everyday example · Help center

Query: “I forgot my password”

System: finds “Resetting your account credentials”

Output: a relevant article without an exact phrase match

Business example · HR search

Query: “employee vacation allowance”

System: finds “annual leave entitlement” in the HR policy

Output: the policy section that answers the question

What it is NOT

Semantic Search ≠ Keyword Search

Semantic search: looks for related meaning.

Keyword search: primarily looks for matching words or phrases.

Semantic Search ≠ Vector Search

Semantic search: describes the goal of finding meaning-related results.

Vector search: is one technical method that can support that goal.

Semantic Search ≠ RAG

Semantic search: finds relevant results.

RAG: retrieves information and supplies it to a generative model before an answer is produced.

Related concepts

Query → Meaning representation → Similarity / relevance → Ranked results → Retrieval or answer
