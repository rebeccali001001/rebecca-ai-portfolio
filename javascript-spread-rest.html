13 · Spread & Rest

The same ... syntax can expand values or collect remaining values.

What is it?

Spread & Rest

Think of it like...

Spread opens a suitcase; rest packs leftovers into one.

Basic Syntax

Spread opens a suitcase; rest packs leftovers into one.

How it works

JavaScript evaluates this feature when the code reaches it. The result can be stored, returned, displayed, or used to decide what happens next.

Simple Example

all_items = [*a, *b]
const allItems = [...a, ...b];

Real Web Example

// Spread & Rest in a web page
console.log("Spread & Rest is running");

Common Syntax

copy and merge

Common Mistakes

Do not confuse a similar-looking syntax with the same behavior. Read errors carefully and test with a small value first.

Python Comparison

Python

all_items = [*a, *b]

JavaScript

const allItems = [...a, ...b];

When to use

Use Spread & Rest when it makes the intent of your code clearer and smaller.
