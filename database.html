MODULE 05 · DATABASE & SQL

Database

A structured place where an application stores, organizes, updates, and retrieves persistent data.

01 What is it?

A database is a structured place where an application stores, organizes, updates, and retrieves persistent data.

It keeps information available after the original request or session has finished.

Simple Definition: A database is where software keeps data it needs to remember.

02 Think of it like...

Think of a database as an organized storage room.

Different types of information have clear places, so software can find and change the right item.

Database
│
├─ Users├─ Orders├─ Products├─ Payments└─ Inventory

03 What does it do?

A database allows software to:

Store Data
Read Data
Update Data
Delete Data
Search Data

Databases are used in almost every application that needs to remember information.

07 Do Not Confuse

Database

Stores and manages data.

SQL

A language used to work with relational database data.

Database = Where the data lives·SQL = How you work with the data

08 Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Database数据库A system used to store and organize application data.用来保存和组织应用数据的系统。
Data数据Information stored or processed by software.软件保存或处理的信息。
Table表A structure that stores one type of data in rows and columns.数据库中按行和列保存某一类数据的结构。
Row行One complete record in a database table.数据表中的一条完整记录。
Column列One type of information stored in a table.数据表中保存某一类信息的字段。
Record记录A collection of related data about one item.描述一个对象的一组完整数据。
Query查询A request to read or change database data.向数据库发出的查询或数据操作指令。
SQL结构化查询语言A language used to work with relational databases.用来查询和修改关系型数据库数据的语言。

Write写入Saving or changing data in a database.向数据库保存或修改数据。
Transaction事务A group of database operations treated as one unit.作为一个整体执行的一组数据库操作。

09 What to Remember

A database stores application data persistently.

Software can read, add, change, and remove data from a database.

SQL is commonly used to work with relational databases.
