PART II · FRONTEND & BROWSER

Button

A control users click to trigger an action.

01 · What is it?

A button is an interactive element that users click to start an action.

The action may submit a form, open a menu, save data, or trigger JavaScript.

Simple Definition: A button starts an action when the user clicks it.

02 · Think of it like...

Think of a button as a switch.

The user activates it, and the system responds.

User→Button→Action

03 · What does it do?

Buttons can:

Submit Forms
Save Data
Open Menus
Close Dialogs
Start Searches
Trigger JavaScript

04 · Where is it used?

Buttons appear throughout user interfaces.

Save
Submit
Search
Delete
Approve
Cancel

05 · Example

<button id="save-button">Save</button>

button.addEventListener("click", saveData);
button

creates the clickable element.

click

is the event.

saveData

is the function that runs.

06 · How it connects

User→Button→Click Event→JavaScript→Action

For data saving

Button→JavaScript→API Request→Backend→Response

07 · Do Not Confuse

Button

Usually triggers an action.

Link

Usually moves the user to another page or resource.

Button = Action
Link = Navigation

09 · What to Remember

A button is used to trigger an action.

Buttons often work with events and JavaScript.

A button can start a larger software flow.
