What is Pre-training?

Pre-training is the broad training stage where a model learns general patterns from a large dataset.

What is it?

Pre-training is the initial, broad training stage for a model.

For a language model, this often means learning to predict missing or next tokens across a large collection of text. The result is a base model that can later be instructed, fine-tuned, or connected to external information.

Think of it like...

Think of it like general education before job training. A person studies many subjects first; later, a focused course can teach a narrower role.

How it works

1 · CollectPrepare broad dataThe training pipeline selects, filters, and tokenizes a large dataset.
2 · PredictLearn from an objectiveThe model predicts tokens or another training target.
3 · UpdateAdjust parametersOptimization changes the model after each batch of examples.
4 · FinishSave a base modelThe trained model becomes a reusable starting point for later adaptation.

Real-world examples

Everyday example · Language completion

Input: a partial sentence

AI / System: learns from many examples of what tends to follow

Output: a likely continuation

Business example · General assistant base

Input: broad language data

AI / System: learns general language patterns before product instructions

Output: a base model ready for adaptation

What it is NOT

Pre-training ≠ Fine-tuning

Pre-training: broad learning before a specific product task

Fine-tuning: later training on narrower data or behavior

Pre-training ≠ Prompting

Pre-training: changes model parameters

Prompting: supplies instructions at use time

Pre-training ≠ Memorizing a database

Pre-training: learns statistical patterns from data

A database: stores retrievable records with explicit lookup behavior

Related concepts
