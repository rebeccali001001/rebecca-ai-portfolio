01 · The idea

What is Workflow Discovery?

Workflow discovery is the process of understanding how work is done today before deciding where AI should help.

  • who does the work
  • what inputs they receive
  • what decisions they make
  • what tools they use
  • what output they produce
  • where delays or errors happen
Start with the workflow, not the model.
02 · A useful mental model

Think of it like...

Map the Journey Before Building a Shortcut

04 · See it in the real world

Real-world examples

Example 01 · Invoice Review

Current workflow

Employee receives invoice → checks fields → compares policy → enters ERP → escalates exceptions

Discovery: Find which steps are repetitive and which require judgment.

Example 02 · Customer Support

Observe

Ticket arrives → agent searches policy → writes response → escalates unusual cases

AI opportunity: search + draft assistance.

Example 03 · Trading Operations

Observe

Trade confirmation → validation → settlement checks → exception handling

AI opportunity: document extraction or anomaly detection.

05 · Keep the boundary clear

What it is not

≠ Prompt Writing

Workflow Discovery: Understand the business process.

Prompt Writing: Define instructions for a model.

≠ Choosing a Model

Model selection: Comes later.

Workflow discovery: Defines the real problem first.

≠ Process Automation

Discovery: Understand the workflow.

Automation: Changes or executes the workflow.
