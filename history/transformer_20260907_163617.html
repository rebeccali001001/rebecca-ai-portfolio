What is a Transformer?

A Transformer is a neural-network architecture that uses attention to connect relevant tokens, building a context-aware representation before producing an output.

What is it?

A Transformer is a way to process a sequence by letting each token compare itself with other tokens that may help explain its meaning. Its layers repeatedly refine those relationships into representations that a model can use for prediction, classification, translation, or other tasks.

In one line: tokens + attention + layers → a useful contextual representation.

Think of it like...

Imagine reading a sentence and deciding which words deserve your attention. In “The trader closed the position because it was risky,” you look back at the surrounding clues to work out what “it” refers to. A Transformer does a mathematical version of that scan: each token checks the other tokens for useful signals, then carries forward a better-informed meaning.

How it works

The flow is a sequence of small transformations. Attention is the connection-making step; the layers repeat and refine it.

01 · TokensSplit the inputText, code, or another sequence becomes manageable pieces.
02 · AttentionCompare cluesEach token weighs which other tokens are useful right now.
03 · LayersRefine patternsRepeated blocks transform the signals and relationships.
04 · ContextBuild meaningEach token gets a contextual representation shaped by the sequence.
05 · OutputUse the resultA task head or language model turns it into a prediction or response.

Real-world examples

  • Language models: relate words and punctuation while predicting the next token.
  • Translation: connect words across a sentence so meaning can move between languages.
  • Document understanding: link a clause to the heading, table, or evidence that gives it context.
  • Vision and multimodal systems: relate image patches, text tokens, or both when the task needs cross-modal context.

What it is NOT

Transformer≠LLM: an LLM is one application built with a language model; a Transformer is an architecture that can support many tasks and modalities.
Transformer≠Chatbot: a chatbot is a product or interface. It may use a Transformer, plus prompts, safety rules, retrieval, tools, and a user experience.
Attention≠Human attention: model attention is a learned calculation over token relationships, not awareness, focus, or understanding like a person’s.

Related concepts

LLMA language model that commonly uses Transformer blocks to predict and generate text.TokenA piece of text or other input that a model processes as a unit.Context WindowThe amount of input and generated context available during a model call.

Remember this

A Transformer builds meaning by letting tokens exchange information through attention, repeating that work across layers, and producing context-aware representations for a task.
