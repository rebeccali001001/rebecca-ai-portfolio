What is RAG?

RAG lets an AI system retrieve useful information before it generates an answer.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Retrieval-augmented generation combines document retrieval with model generation.

At query time, the system finds relevant information and places it in the model’s context. The model then generates an answer using that context, often with citations or a source link.

Think of it like...

Think of it like taking an exam with an open book. The model has learned general patterns, but it can look up the relevant pages before answering a specific question.

How it works

1 · QuestionReceive the requestA user asks for information.
2 · SearchFind candidatesThe system searches indexed documents.
3 · RetrieveSelect useful passagesRelevant chunks and metadata are chosen.
4 · ContextProvide evidenceThe passages are added to the model input.
5 · AnswerGenerate and citeThe response uses the retrieved context.

Real-world examples

Everyday example · Travel rules

Input: “Can I bring this battery on a flight?”

AI / System: retrieves the airline’s current policy

Output: an answer based on that policy

Business example · HR policy

Input: “How many annual leave days do I receive?”

AI / System: searches the approved HR documents

Output: a current answer with a source

What it is NOT

RAG ≠ Fine-tuning

RAG: retrieves external information at query time.

Fine-tuning: changes model behavior through additional training.

RAG ≠ Search Engine

Search: finds candidate information.

RAG: combines retrieval with context and generation.

Retrieved text ≠ Guaranteed truth

Retrieved text: is evidence selected by a system.

Reliable answer: still needs source quality and validation.
