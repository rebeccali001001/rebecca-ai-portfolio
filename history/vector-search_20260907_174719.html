What is Vector Search?

Vector search finds items that are close in a numerical meaning space.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Vector search compares an input vector with stored vectors and returns nearby results.

The vectors usually come from an embedding model. A similarity or distance measure ranks candidates, so the system can find related content even when the wording is different.

Think of it like...

Think of it like a library organized by meaning instead of alphabetically. A question about refunds can lead you to a passage about returning money, even if the words do not match exactly.

How it works

1 · IndexPrepare contentDocuments are split and converted into vectors.
2 · StoreKeep vectorsVectors and useful metadata are stored.
3 · QueryEmbed the requestThe new question becomes a vector too.
4 · RankCompare distanceNearby candidates receive higher scores.
5 · ReturnSend resultsThe application uses the top results for display or RAG.

Real-world examples

Everyday example · Recipe search

Input: “quick vegetarian dinner”

AI / System: searches recipe vectors by meaning

Output: related recipes

Business example · Support search

Input: a customer’s question

AI / System: ranks similar support articles

Output: relevant articles for an answer or agent

What it is NOT

Vector search ≠ Keyword search

Vector search: compares learned representations.

Keyword search: matches words or text patterns.

Vector search ≠ Embedding

Vector search: finds nearby stored vectors.

Embedding: creates the vector representation.

Nearest ≠ Relevant in every case

Nearest: ranks by a chosen distance measure.

Relevant: depends on task, data, and evaluation.
