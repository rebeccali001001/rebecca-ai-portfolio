What is KV Cache?

KV Cache stores reusable attention information from tokens the model has already processed.

The short version: save earlier work, so the model can keep moving.
On this pageWhat is it?Think of it like...How it worksExamplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

KV Cache is a temporary cache used during Transformer inference.

When the model generates text token by token, it can reuse key and value representations from earlier tokens instead of recomputing all of them every time.
Faster generationLess repeated work for each new token.
A memory trade-offThe saved information lives in memory while the request is running.

How it works

KV means Key / Value. These are names for attention information—not something you need to calculate by hand.

01 · InputPrompt tokensWords already in the conversation.
02 · ComputeTransformer processes themAttention connects the tokens.
03 · SaveKeys + Values are storedReusable information is cached.
04 · GenerateGenerate next tokenThe model chooses what comes next.
05 · ReuseReuse cached K/VEarlier work is available.
06 · RepeatProcess only new tokenThe cycle continues.

Key idea: the model still looks at earlier context—but it does not rebuild the same attention information from scratch each time.

Real-world examples

Simple example · A sentence

The model is generating:

Theweathertodayissunny...

Without KV Cache: more earlier attention information must be computed again.

With KV Cache: earlier tokens' K/V are already cached and can be reused.

AI example · Long-context assistant

A chatbot or coding assistant may continue from a long conversation or large codebase.

Longer context can create a larger KV Cache, which means more memory is needed while the request is active.

What it is NOT

KV Cache ≠ Memory

KV Cache: temporary inference cache.

Memory: information intentionally stored and retrieved across interactions.

KV Cache ≠ Context Window

Context Window: how much information is available.

KV Cache: cached computation associated with processed context during generation.

KV Cache ≠ Model Parameters

Parameters: learned during training.

KV Cache: created dynamically during inference.
