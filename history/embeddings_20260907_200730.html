01

What is it?

An embedding turns text, images, or other content into a list of numbers called a vector.

Items with similar meaning or features usually end up closer together in this vector space.

Embeddings make it possible for software to compare meaning mathematically.

02

Think of it like...

Map of Meaning

Think of embeddings like putting ideas on a map.

dogpuppypetairplanecloser = more similar

“dog”, “puppy”, and “pet” may appear close together. “airplane” would usually be farther away.

This “distance” is not real-world space—it is mathematical similarity.

04

Real-world examples

01

Semantic Search

Input: “holiday allowance”

System: compares its embedding with document embeddings

Output: finds “annual leave policy” even when exact words differ

02

Recommendations

Input: a product or piece of content

Embedding: represents its features

Output: finds similar products or content

03

Image Search

Input: an image

Embedding: represents visual features

Output: finds visually or semantically similar images

05

What it is NOT

Embedding ≠ Token

Embedding: a numerical representation

Token: a unit of text processed by a model

Embedding ≠ Vector Database

Embedding: the vector itself

Vector Database: stores and searches vectors

Embedding ≠ Keyword

Embedding: captures semantic similarity

Keyword: matches explicit words or terms

Embedding ≠ Meaning itself

Embedding: a learned numerical representation

Meaning: the underlying concept represented
