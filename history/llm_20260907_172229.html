What is an LLM?

A Large Language Model (LLM) predicts the next token from the context it can see, then repeats that small decision to generate language.

What is it?

A Large Language Model (LLM) is a model trained to predict and generate language.

It is a neural network trained on large collections of text and code. It processes text as tokens and repeatedly predicts what token is likely to come next based on the context it can see.

Think of it like...

Think of an LLM like an extremely advanced autocomplete system.

It looks at the tokens already present and predicts what token should come next. Then it repeats this process again and again.

Each token is like adding one tile to a sentence.

How it works

At a high level, the model follows this loop:

Input → Tokens → Transformer → Next-token prediction → Repeat → Output

01Input tokensYour text is split into small pieces called tokens.
02Transformer processingThe Transformer looks at how the tokens relate to each other.
03Predict next tokenThe model chooses a likely next token.
04RepeatThe new token is added, and the process starts again.
05OutputThe completed token sequence becomes readable text.

Real-world examples

Example 1 · Writing

Input: “Write a polite email to reschedule tomorrow’s meeting.”

LLM: Processes the prompt and predicts tokens one by one.

Output: A new email draft.

Example 2 · Summarization

Input: A long article.

LLM: Processes the text and generates a shorter representation.

Output: A summary.

Example 3 · Coding

Input: “Write a Python function that removes duplicate values.”

Output: Generated code.

What it is NOT

An LLM is one component in a broader AI product. These distinctions prevent common category mistakes.

LLM ≠ ChatGPT

LLM: The underlying language model.

ChatGPT: A product that uses models plus an interface and other system components.

LLM ≠ AI

LLM: One kind of AI system focused on language.

AI: A broad field that includes many other approaches.

LLM ≠ Search Engine

LLM: Generates likely language.

Search engine: Retrieves and ranks documents.
