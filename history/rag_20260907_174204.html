What is RAG?

RAG lets an AI retrieve relevant information before generating an answer.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Retrieval-Augmented Generation is a workflow that retrieves external information and gives it to a model as context before generation.

RAG is useful when knowledge changes or must remain outside model weights. Retrieval improves access to evidence, but the model and sources still need evaluation.

Think of it like...

Think of taking an open-book exam. The relevant pages are on the desk, but the student can still misunderstand a page or fail when the right page is missing.

How it works

A question becomes a search request, useful passages enter context, and the model generates an answer from the question plus evidence.

1 · QuestionReceive the requestA user asks for information or help.
2 · SearchFind candidatesThe system uses keywords, vectors, metadata, or a mix.
3 · RetrieveSelect passagesRelevant documents and permissions are checked.
4 · ContextPlace evidence beside the promptSelected passages enter the model's context.
5 · GenerateWrite the answerThe model responds using the available context.

Real-world examples

Everyday example · Holiday policy

Input: How many leave days do I get?

System: The system searches the current HR policy

Output: An answer based on the policy

AI product example · File chat

Input: A question about a document

System: The product retrieves relevant chunks

Output: A response with source context

Business example · Shipment claim

Input: What documents are needed?

System: The system retrieves the current claim policy

Output: A cited answer or safe fallback

What it is NOT

RAG ≠ Fine-tuning

RAG: Retrieves external information at query time

Fine-tuning: Changes model behavior through additional training

RAG ≠ Search engine

RAG: Combines retrieval with generation

Search engine: Primarily returns existing results

RAG ≠ Grounding

RAG: A retrieval-plus-generation workflow

Grounding: The broader evidence and trust contract

Related concepts

Question → Embedding / search → Retrieval → LLM → Answer
Vector search is one possible retrieval method. Grounding adds source and trust rules.
