01 · The idea

What is it?

Vector Search finds content with similar meaning by comparing embeddings.

First, content is represented as vectors. Then a query is also converted into a vector. The system compares the query vector with stored vectors and returns the closest matches.

That means it can find semantic similarity even when exact words are different.

02 · A mental model

Think of it like...

Think of vector search like finding the nearest places on a map. Embeddings place ideas on a map of meaning.

“Which stored points are closest to this new point?”

05 · Keep the terms straight

What it is NOT

Vector Search ≠ Keyword Search

Vector Search: matches semantic similarity.

Keyword Search: matches words or terms.

Vector Search ≠ Embedding

Embedding: the vector representation.

Vector Search: the process of comparing vectors.

Vector Search ≠ RAG

Vector Search: one retrieval technique.

RAG: a larger workflow that may use vector search before generation.
