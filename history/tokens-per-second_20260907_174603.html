What is Tokens per Second?

Tokens per second measures how quickly a model generates output tokens after generation begins.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Tokens per second measures how quickly a model generates output tokens after generation begins.

It is a throughput measure for generation, not a complete measure of user experience. A system can generate quickly but still have high time to first token because of queueing, a long prompt, retrieval, or other setup work.

Think of it like...

Think of it like a printer’s pages-per-minute rate. It tells you the steady output speed, but not how long the printer takes to warm up or receive the document.

This is a learning analogy. The real system uses mathematical models and software controls.

How it works

1 · PrepareLoad the requestThe system receives and tokenizes the prompt.
2 · StartRun the first passThe model processes the input and begins generation.
3 · GenerateProduce tokensEach next token is calculated and returned.
4 · MeasureCount the streamThe system divides generated tokens by generation time.
5 · CompareUse the right workloadTeams compare speed with quality, context, memory, and concurrency.

Real-world examples

Everyday example · Drafting

Input: A short prompt and a paragraph request

AI / System: Generates output at a measured rate

Output: A response that streams smoothly or slowly

Business example · Batch summaries

Input: Many documents to summarize

AI / System: Measures generation throughput under load

Output: A capacity estimate for a processing queue

What it is NOT

Tokens per Second ≠ Latency

Tokens per Second: Tokens per second measures generation rate.

Latency: Latency measures waiting time across the full path.

Tokens per Second ≠ Words per Second

Tokens per Second: Tokens and words are different units.

Words per Second: A token may be part of a word or punctuation.

High speed ≠ Good system

High speed: Speed is one operational measure.

Good system: Quality, cost, safety, and stability still need evidence.
