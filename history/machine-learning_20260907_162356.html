01 · AI Foundations · Topic 02

What is Machine Learning?

Machine Learning is a way to build systems that learn patterns from examples and use those patterns to make predictions or decisions.

01 · What is it?

Machine learning learns a pattern from examples

Instead of writing every rule by hand, we provide examples and a learning algorithm finds relationships that help with a task. The result is a model that can turn a new input into a prediction, classification, ranking, or recommendation.

In plain language: show a computer many examples, let it find a repeatable pattern, then test whether it works on an example it has not seen before.

02 · Think of it like...

A coach improving from practice

Imagine a kitchen helper learning from labeled recipe cards. Each card shows what went in, what happened, and what “good” looked like. After enough practice, the helper can make a useful suggestion for a new order—but it still needs a check when the situation is unfamiliar.

The examples are the practice set; the learned pattern is the coach’s skill; the new order is the real-world test.

03 · How it works

From examples to a checked prediction

ExamplesCollect the signalInputs, labels, and outcomes become training data.
TrainingFind patternsThe model adjusts its internal parameters to reduce errors.
New inputApply the patternA new request goes through the learned model.
EvaluationCheck the resultUnseen examples reveal whether it generalizes safely.
04 · Real-world examples

Where it is used

  • Spam filtering: classify incoming messages.
  • Forecasting: estimate demand or risk.
  • Recommendations: rank items a person may want.
  • Quality checks: spot defects or unusual behavior.
05 · What it is NOT

Pattern learning is not the same as understanding

Machine learning≠

A guarantee of truth: a model can be confidently wrong when its data or assumptions fail.

Machine learning≠

Handwritten rules for every case: the model learns statistical relationships from examples.

Machine learning≠

Human-level common sense: strong performance on one task does not mean general intelligence.

Machine learning≠

Automatic success in production: monitoring, evaluation, and human fallback still matter.

06 · Related concepts

Useful neighbors

  • Artificial Intelligence — the broader field of systems that perform tasks associated with intelligence.
  • Deep Learning — machine learning built with multi-layer neural networks.
  • Foundation Models — broadly trained models adapted to many downstream tasks.
  • Evaluation — tests and evidence used to judge whether a model is useful and safe.
07 · Remember this

Examples shape the model

Machine learning learns from examples, then applies learned patterns to new inputs. Good results depend on representative data, a clear target, honest evaluation, and a safe response when the model is uncertain.
