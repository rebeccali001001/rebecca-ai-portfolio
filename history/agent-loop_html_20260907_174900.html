What is Agent Loop?

An agent loop repeats decision, action, observation, and stopping checks until a task is complete or blocked.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

An agent loop is the control cycle that lets an agent continue working after each model or tool result.

The loop normally has a goal, a model decision, optional tool execution, an observation, and a stopping condition. Limits on time, steps, cost, and permissions keep the loop bounded.

Think of it like...

Think of it like a person following a checklist that can change after every result. They look at the latest information, choose the next step, and stop when the job is done or a supervisor is needed.

How it works

1 · GoalState the taskThe loop starts with an objective and constraints.
2 · DecideChoose the next actionThe model proposes an answer, question, or tool call.
3 · ActExecute an allowed stepThe application validates and performs the action.
4 · ObserveRead the new stateThe result is added to the working context.
5 · Stop or repeatCheck the boundaryThe loop finishes or continues under step, time, and risk limits.

Real-world examples

Everyday example · Plan a route

Input: a destination and travel time

AI / System: checks a route, sees a delay, and searches another

Output: an updated route or a question

Business example · Ticket triage

Input: a support issue

AI / System: looks up an account, checks policy, and routes the case

Output: a response or escalation

What it is NOT

Agent Loop ≠ One Prompt

Agent Loop: multiple decisions and observations over time

One prompt: one model request with no required control cycle

Agent Loop ≠ Workflow

Agent Loop: can choose the next step dynamically

Workflow: usually follows predefined transitions

Agent Loop ≠ Infinite Autonomy

Agent Loop: must have stopping and permission limits

Unbounded autonomy: unsafe behavior without a controlled boundary

Related concepts

Goal ↓ Decide ↓ Tool or response ↓ Observe ↺ continue or stop
