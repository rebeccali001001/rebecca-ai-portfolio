THE CONTROL CYCLE

What is an
Agent Loop?

An agent loop is the repeated cycle an AI agent uses to decide, act, observe the result, and continue until a task is complete.

Decide→Act→Observe→Decide Again

01 / THE IDEA

What is it?

An agent is not a single model call. It is a control loop that keeps responding to what just happened.

A normal LLM call maps an input to an output. An agent loop keeps a goal in view, takes a step, reads the result, and uses that new information to choose what happens next.

02 / A USEFUL MENTAL MODEL

Think of it like… navigation

Think of an agent loop like driving with navigation.

You do not decide the entire trip once and then stop thinking. You look at the route, take an action, observe where you are, adjust, and continue. An agent loop works the same way.

05 / BOUNDARIES

What it is NOT

Agent Loop ≠ Single Prompt

Single Prompt: one model call.

Agent Loop: multiple decisions and actions over time.

Agent Loop ≠ Fixed Workflow

Fixed Workflow: a predetermined sequence.

Agent Loop: the next step may depend on current results.

Agent Loop ≠ Infinite Loop

Agent Loop: stops when a goal or stopping condition is reached.

Infinite Loop: continues without useful termination.
