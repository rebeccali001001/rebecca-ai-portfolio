What is Tool Calling?

Tool calling lets a model request a defined function so an application can perform an action.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Tool calling is a structured way for a model to ask an application to use a tool.

The application defines the tool name and input schema, validates the model's request, executes the function when allowed, and returns the result. The model does not directly access the database, browser, or service.

Think of it like...

Think of it like an assistant deciding when to use a calculator, browser, database, or another tool. The assistant can ask for the tool, but a supervisor still checks the request before it runs.

How it works

The model chooses from declared tools, while the application remains in control of execution.

1 · DefineDescribe a toolGive the tool a name, purpose, and input schema.
2 · DecideRequest a functionThe model returns a structured tool call when useful.
3 · ValidateCheck the requestThe application checks types, permissions, and risk.
4 · ExecuteRun the toolThe application calls the approved service.
5 · ReturnSend back the resultThe model can use the result in its next response.

Real-world examples

Everyday example · Calculator

Input: “What is 18% of 240?”

System: Requests a calculator tool

Output: The computed result in the reply

AI product example · Calendar

Input: “Find a free time tomorrow.”

System: Calls a calendar search after permission checks

Output: Available time slots

Business example · Order lookup

Input: A customer asks about an order

System: Calls an order service with a validated ID

Output: Current status for the response

What it is NOT

Tool Calling ≠ Tool Execution

Tool Calling: The model's structured request to use a function.

Tool Execution: The application's controlled act of running it.

Tool Calling ≠ Agent

Tool Calling: One interface for requesting an action.

Agent: A larger system that may plan, call tools, observe results, and continue.

Tool Calling ≠ Permission

Tool Calling: Describes what the model wants to do.

Permission: A separate application decision about what is allowed.

Related concepts

Model → Tool call → Validation → Tool execution → Tool result
Agents use tool calling inside an Agent Loop. MCP is one protocol for exposing tools and data.
