What is a System Prompt?

A system prompt is a high-priority instruction that sets the role, rules, and boundaries for an AI feature.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A system prompt tells an AI feature how it should behave before it receives a user request.

It can define role, output rules, safety limits, tool instructions, and how to handle uncertainty. It guides a model, but application code and permissions still enforce important controls.

Think of it like...

Think of it like an operating brief given to a worker before the shift begins. It explains the job, the boundaries, and what to do when the answer is uncertain.

How it works

1 · RoleSet the purposeDescribe the assistant’s job and audience.
2 · RulesDefine behaviorState allowed formats, tone, and decision boundaries.
3 · ContextProvide inputsAdd user requests, evidence, and tool results.
4 · GenerateProduce a responseThe model predicts an answer using the full input.
5 · CheckValidate the resultThe application checks schema, permissions, and policy.

Real-world examples

Everyday example · Study helper

Input: a student question

System: explains simply and states uncertainty

Output: a clear answer with a next question

Business example · Support assistant

Input: a customer issue

System: uses approved policy and escalates exceptions

Output: a consistent reply or handoff

What it is NOT

System prompt ≠ User prompt

System prompt: sets feature-level behavior and boundaries

User prompt: gives the current request

System prompt ≠ Access control

System prompt: instructs the model

Access control: must be enforced by the application and tools

System prompt ≠ Guaranteed obedience

System prompt: a behavioral instruction

Guarantee: requires validation, testing, and runtime controls

Related concepts

System instructions+User request+Evidence / tools↓Validated output
