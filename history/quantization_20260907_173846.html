What is Quantization?

Quantization stores model values with fewer bits so the model can use less memory.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Quantization stores model values with fewer bits so the model can use less memory.

The conversion reduces numerical precision in selected values. It can make a model smaller or faster, but the trade-off depends on the method, hardware, and task quality.

Think of it like...

Think of compressing a large model so it takes less memory while trying to preserve most of its ability. Smaller storage can come with some loss of detail.

How it works

1 · ModelStart with weightsA trained model contains numerical values.
2 · ConvertUse fewer bitsQuantization represents selected values with lower precision.
3 · PackStore the smaller modelThe resulting files use less memory or bandwidth.
4 · RunLoad on hardwareA runtime uses a compatible quantized format.
5 · EvaluateCheck the trade-offMeasure quality, speed, memory, and task failures.

Real-world examples

Everyday example · Laptop model

Input: a model too large for memory

AI / System: uses a smaller quantized format

Output: a model that can run locally

AI product example · Edge device

Input: a vision or language model

AI / System: trades some precision for device fit

Output: lower memory use and usable inference

What it is NOT

Quantization ≠ Every kind of compression

quantization: reduces numerical precision in model values

other compression: may remove structure, encode files, or use another method

Quantization ≠ Fine-tuning

quantization: changes numerical representation for serving

fine-tuning: changes learned behavior through training

Smaller ≠ Always better

smaller model: uses fewer resources

quality: may change and must be measured
