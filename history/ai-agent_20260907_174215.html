What is an AI Agent?

An AI agent is a system that uses a model, tools, and a control loop to work toward a goal.

What is it?

An AI agent is a system that can decide and take actions toward a goal.

It usually combines a model with instructions, tools, a loop for checking results, and limits that keep actions safe. The model does not become the whole agent by itself.

Think of it like...

Think of it like giving an AI worker a goal and a toolbox.

The worker decides whether to use a calculator, browser, database, or another tool. The toolbox enables action; rules and a supervisor define what is allowed.

How it works

1 · GoalReceive an objectiveThe system turns a request into a bounded task.
2 · PlanChoose a next stepThe model proposes what information or action is needed.
3 · ToolCall an allowed toolThe runtime checks permissions and arguments.
4 · ObserveRead the resultThe tool result becomes new context for the task.
5 · FinishAnswer or hand offThe system stops when evidence or a human says it should.

Real-world examples

Everyday example · Travel helper

Input: “Find a weekend train and add it to my plan.”

System: Searches schedules, compares choices, and asks before committing.

Output: A recommendation or a confirmed plan.

Business example · Support triage

Input: A customer issue.

System: Reads the case, checks policy, and routes it.

Output: A draft reply or an escalation.

What it is NOT

Agent ≠ LLM

Agent: A system with tools, instructions, and a control loop.

LLM: The reasoning and language model inside it.

Agent ≠ Chatbot

Agent: Can take bounded actions through tools.

Chatbot: Primarily communicates with a user.

Agent ≠ Workflow

Agent: Can choose what to do next.

Workflow: Usually follows a predefined sequence.

Related concepts

LLM + Instructions + Tools + Memory + Agent Loop = AI Agent
