What is Pre-training?

Pre-training is the broad first phase where a model learns language patterns from a large, diverse corpus before it is adapted to a specific use case.

What is it?

Pre-training is the first broad training stage where a model learns general patterns from large amounts of data.

For language models, this often involves predicting missing or next tokens again and again across a very large dataset.

The output is a base model that can later be prompted, fine-tuned, or otherwise adapted.

Think of it like...

Think of pre-training like giving a student a very large general education before choosing a profession.

The student reads many kinds of material and repeatedly practices predicting what comes next. Over time, broad language patterns are learned.

How it works

The model repeats a prediction-and-update loop across enormous numbers of examples.

1 · Training dataCollect a very large dataset.
2 · TokenizationConvert text into tokens.
3 · Prediction taskPredict a missing or next token.
4 · CompareMeasure the prediction error.
5 · Update parametersAdjust model parameters slightly.
6 · RepeatRepeat across enormous examples.
7 · Base modelProduce a broadly capable pre-trained model.

Data → Tokens → Prediction → Error → Parameter update → Repeat → Base Model

Real-world examples

Example 1 · Next-token prediction

Input: “The trader closed the position because it was ___”

Model: Predicts likely next tokens.

Training: Compares the prediction with training data and updates parameters.

Example 2 · General language learning

Training data: Books, articles, code, and other text sources.

Result: A model that learns broad patterns before any single application is chosen.

What it is NOT

  • Pre-training ≠ Fine-tuning
    Pre-training is broad initial training; fine-tuning is later additional training for narrower behavior.
  • Pre-training ≠ Prompting
    Pre-training changes the model through training; prompting provides instructions at runtime without retraining it.
  • Pre-training ≠ RAG
    Pre-training builds learned capability before deployment; RAG retrieves external information at runtime.
  • Pre-training ≠ Storing a Database
    Pre-training encodes statistical patterns into parameters; a database stores explicit retrievable records.
