What is a Foundation Model?

A foundation model is a broadly trained AI model that can be reused or adapted for many different tasks.

What is it?

A foundation model is a broadly trained AI model that can be reused or adapted for many different tasks.

Instead of training a separate model from scratch for every task, developers can start with one broadly capable model and use prompting, retrieval, fine-tuning, or tools to make it useful for a specific application.

Think of it like...

Think of a foundation model like a person who has completed a broad general education.

They already know many basic skills. Later, they can receive additional instructions or specialized training for a particular job.

How it works

A foundation model is created through broad training, then adapted into many kinds of applications.

1 · Large and varied dataStart broadTraining uses broad datasets such as text, images, code, or other modalities.
2 · Pre-trainingLearn general patternsThe model learns reusable relationships and capabilities from that data.
3 · Foundation ModelCreate the baseOne broadly capable model becomes a starting point for many downstream uses.
4 · AdaptationShape the capabilityPrompting, fine-tuning, retrieval, and tools can adapt the base model for a task.
5 · Many applicationsSupport different jobsThe same model may support chat, coding, search, summarization, vision, or other tasks.

Real-world examples

Language foundation model
Broadly trained on text and code; adapted for chat, summarization, coding, and translation.
Vision foundation model
Broadly trained on large image datasets; used for image understanding, classification, retrieval, and editing.
Multimodal foundation model
Learns from more than one modality; supports text-and-image understanding, document analysis, and assistants.

What it is NOT

Foundation Model ≠ LLMCategory vs. language focusA foundation model is a broad category. An LLM is a foundation model focused primarily on language.
Foundation Model ≠ Finished AI ProductUnderlying model vs. productA product adds an interface, instructions, data, tools, workflow, and other components.
Foundation Model ≠ Fine-tuned ModelStarting point vs. specializationFine-tuning further trains a broad starting model for narrower behavior or tasks.
Foundation Model ≠ Generative AIReuse vs. generationFoundation model describes broad reusability; generative AI describes the ability to create new content.

Related concepts

Deep Learning → Pre-training → Foundation Model → Adaptation → Many downstream applications

Deep Learning
A family of methods used to learn patterns from data.
Pre-training
The broad learning stage that builds reusable capability.
Fine-tuning
Further training for narrower behavior or a domain.
LLM
A language-focused foundation model.
RAG
A retrieval technique for adding relevant external context.
Generative AI
AI systems that generate new content.
