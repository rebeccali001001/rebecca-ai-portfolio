What is an Agent Loop?

An agent loop is the repeated cycle an AI system uses to decide, act, inspect the result, and continue or stop.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

An agent loop is a control cycle that turns a goal into a sequence of bounded actions.

A model may propose the next step, but the application should validate tool calls, permissions, timeouts, step limits, and the condition for stopping.

Think of it like...

Think of it like a worker following a checklist that can change after each inspection. They do one safe step, look at the result, and decide whether to continue, correct, ask, or finish.

How it works

1 · GoalDefine the outcomeState what success means and what is out of bounds.
2 · DecideChoose next actionThe model proposes a response or tool call.
3 · ValidateCheck permissionThe runtime checks arguments, policy, and limits.
4 · ExecuteRun the actionThe tool returns an observation or an error.
5 · StopContinue or finishEvidence, a limit, or a handoff ends the cycle.

Real-world examples

Everyday example · Calendar helper

Input: “Find a time next week.”

System: checks availability, proposes a slot, and waits before booking

Output: a draft invite or a confirmation request

Business example · Code change

Input: a failing test

System: reads code, edits a file, runs a restricted test, and inspects output

Output: a verified patch or a clear blocker

What it is NOT

Agent loop ≠ Infinite autonomy

Agent loop: a bounded cycle with limits and stopping conditions

Infinite autonomy: an unsafe idea without a clear end state

Agent loop ≠ One model response

Agent loop: can include several actions and observations

One response: a single generation step

Agent loop ≠ Unchecked tool access

Agent loop: validates allowed actions

Unchecked access: lets a proposal become a side effect without controls
