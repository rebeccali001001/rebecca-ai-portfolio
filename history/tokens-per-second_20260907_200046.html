What are Tokens per Second?

Tokens per Second (tokens/s) measures how quickly a model generates output tokens.

30tokens / second
On this pageWhat is it?Think of it like...How it worksExamplesWhat it is NOTRelatedRememberVideo

What is it?

If a model generates 30 tokens per second, it produces about 30 output tokens each second during generation.

Importanttokens ≠ words. So, don’t read 30 tokens/s as 30 words/s.

Think of it like...

Think of tokens per second like the printing speed of a printer. Once printing begins, a faster printer produces more pieces of output each second. Similarly, a faster model generates more tokens each second.

What it is NOT

Tokens per Second ≠ Latency

Tokens/sec: generation speed.

Latency: waiting time for response.

Tokens per Second ≠ Words per Second

Tokens: model units.

Words: human language units.

Higher speed ≠ Better model

Speed: performance metric.

Quality: depends on capability, task, training, and more.
