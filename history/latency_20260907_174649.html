What is Latency?

Latency is the time a user or system waits for an AI response or response stage.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Latency is the elapsed time between an event and the result you are measuring.

For an AI request, teams may measure time to first token, time to first useful result, or total response time. These measures answer different user-experience questions.

Think of it like...

Think of it like waiting at a café. Time until someone acknowledges your order is different from time until the full drink is ready.

How it works

1 · RequestSend the inputThe user or system starts an AI operation.
2 · QueueWait for capacityThe request may wait for a worker, GPU, or network connection.
3 · PrefillProcess the inputThe system reads the prompt and context.
4 · First resultMeasure first responseTime to first token or first useful output becomes visible.
5 · CompleteMeasure total timeThe full response finishes and can be used.

Real-world examples

Everyday example · Chat reply

Input: a short question

AI / System: measures time until the answer starts

Output: a fast or slow first response

Business example · Document workflow

Input: an uploaded invoice

AI / System: measures processing time to a validated result

Output: a completed record or exception

What it is NOT

Latency ≠ Tokens per Second

Latency: time spent waiting for a stage or result

Tokens per Second: output generation throughput

Latency ≠ Context Window

Latency: a time measurement

Context Window: a token capacity

Latency ≠ Quality

Latency: how quickly a result arrives

Quality: how correct or useful the result is

Related concepts

Request ↓ Queue + prefill ↓ Time to first token ↓ Decode ↓ Total latency
