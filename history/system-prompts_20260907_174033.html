What is a System Prompt?

A system prompt is a high-priority instruction that sets an AI feature's role, rules, and boundaries.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A system prompt is an instruction given to a model before the user's request.

It can define the task, tone, allowed actions, output rules, and what to do when information is missing. It guides behavior but does not make the model infallible.

Think of it like...

Think of it like a staff brief before a shift. It tells the worker what job to do, which rules matter, and when to ask for help.

How it works

The application combines system instructions with the user's input before inference.

1 · RoleSet the jobDefine what the feature is meant to do.
2 · RulesSet boundariesState allowed sources, actions, tone, and limits.
3 · User inputReceive the requestA user supplies a task inside those boundaries.
4 · ModelGenerate a responseThe model uses the combined context.
5 · CheckApply safeguardsThe application validates output and handles uncertainty.

Real-world examples

Everyday example · Tutor

Input: A learner asks a question

System: The system prompt sets a patient teaching style

Output: A simple explanation

AI product example · Support bot

Input: A customer request

System: The prompt requires approved policy sources

Output: A bounded reply or handoff

Business example · Data assistant

Input: A reporting question

System: The prompt restricts fields and output format

Output: A reviewable answer

What it is NOT

System Prompt ≠ User Prompt

System Prompt: High-priority application instruction

User Prompt: The request supplied by the user

System Prompt ≠ Fine-tuning

System Prompt: Runtime instructions

Fine-tuning: Additional model training

System Prompt ≠ Safety Guarantee

System Prompt: A behavior guide

Safety Guarantee: A real system still needs validation and controls

Related concepts

System instructions + User input → Context → Model output
System prompts are one part of a product's instruction and control layer.
