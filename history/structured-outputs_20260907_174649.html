What are Structured Outputs?

Structured outputs make an AI response follow a defined shape that software can validate and use.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A structured output is an AI response that follows a defined format, such as a JSON object with required fields.

The format gives downstream software a contract to validate. A valid shape does not guarantee that every value is correct, so content checks and failure handling still matter.

Think of it like...

Think of it like asking a form-filler to complete labeled boxes instead of writing a free-form note. The boxes make the result easier to check and pass to the next system.

How it works

1 · SchemaDefine the shapeList fields, types, required values, and allowed options.
2 · InputProvide the requestInclude the user task and any supporting context.
3 · GenerateFill the structureThe model produces a candidate object.
4 · ValidateCheck the contractThe application checks syntax, types, and required fields.
5 · HandleRepair or rejectRetry safely, ask for clarification, or escalate when invalid.

Real-world examples

Everyday example · Packing list

Input: a trip description

System: returns items grouped by category

Output: a predictable list for a mobile app

Business example · Invoice extraction

Input: an invoice image

System: extracts supplier, date, and amount

Output: validated fields or a review task

What it is NOT

Structured output ≠ Correct answer

Structured output: follows a format

Correct answer: requires evidence and content validation

JSON ≠ Structured output by itself

Structured output: uses an agreed and validated contract

JSON: only one possible serialization format

Schema ≠ Business rule

Schema: describes shape and types

Business rule: checks whether the value makes sense for the workflow
