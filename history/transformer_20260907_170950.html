What is a Transformer?

A Transformer is a neural-network architecture that uses attention to connect information across tokens.

What is it?

A Transformer is a neural-network architecture that uses attention to connect information across tokens.

Instead of processing each token in isolation, it allows tokens to use information from other relevant tokens in the sequence. Its layers refine these relationships for prediction, translation, and other tasks.

Transformer ≠ LLM. A Transformer is an internal architecture; an LLM is a language model that often uses it.

Think of it like...

“The trader closed the position because it was risky.” When you read “it,” you look at the context and infer that it refers to the position.

Transformer attention does a mathematical version of this association: each token checks which other tokens provide useful signals.

Attention is not human attention. It is a numerical calculation.

How it works

1 · TokensInput is split into tokens.
2 · AttentionEach token checks which other tokens are relevant.
3 · Combine informationRelevant signals are weighted and combined.
4 · LayersThe process repeats across many Transformer blocks.
5 · Output representationThe model now has context-aware representations.
6 · PredictionAn LLM can use these representations to predict the next token.

Real-world examples

Example 1 · Pronoun reference

Sentence: “The trader closed the position because it was risky.”

Transformer: Connects “it” with “position”.

Result: Better contextual understanding.

Example 2 · Translation

Input: A full sentence.

Transformer: Connects words that depend on each other.

Output: A translation that uses sentence context.

Example 3 · LLM generation

Input: A prompt.

Transformer: Processes relationships across all visible tokens.

Output: Context used for next-token prediction.

What it is NOT

Transformer≠LLM: an architecture vs. a language model often built using Transformer layers.
Transformer≠Chatbot: an internal architecture vs. a user-facing application.
Attention≠Human attention: a mathematical mechanism assigning weights vs. a cognitive process.
