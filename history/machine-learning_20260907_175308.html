What is Machine Learning?

Machine Learning is a way for computers to learn patterns from examples instead of receiving every rule by hand.

What is it?

Machine Learning is a way for computers to learn patterns from data and use those patterns to make predictions or decisions.

During training, an algorithm adjusts model parameters to reduce errors on examples. During use, the trained model applies those learned patterns to new inputs.

Think of it like...

Think of it like learning to sort fruit by seeing many labeled examples. You do not write a rule for every apple; you show examples, and the learner gradually picks up useful patterns.

How it works

1 · ExamplesCollect training dataThe system receives inputs, labels, or useful outcomes.
2 · LearnAdjust model parametersTraining changes internal values to reduce error.
3 · ValidateTest on new examplesA separate set checks whether the pattern generalizes.
4 · UseMake a predictionThe trained model produces a result for new input.

Real-world examples

Everyday example · Spam filtering

Input: an incoming email

AI / System: scores patterns learned from labeled messages

Output: spam or inbox

Business example · Demand forecast

Input: sales and calendar data

AI / System: learns relationships from past outcomes

Output: a forecast for planning

What it is NOT

Machine Learning ≠ AI

Machine Learning: one approach within the broader AI field

AI: the wider field, including rules, learning, and other methods

Machine Learning ≠ Deep Learning

Machine Learning: includes many algorithms and model types

Deep Learning: a subset that uses multi-layer neural networks

Machine Learning ≠ Fixed-rule programming

Machine Learning: learns patterns from examples

Fixed rules: people specify the conditions and actions directly

Related concepts

Artificial Intelligence ↓ Machine Learning ↓ Training data + model ↓ Prediction or decision
