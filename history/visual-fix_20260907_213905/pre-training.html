What is it?

Pre-training is the broad initial training stage that teaches a model general patterns from large amounts of data.

For a language model, this often means predicting missing or next tokens repeatedly. The result is a base model that can later be adapted.

Think of it like...

Think of it like a general education before specialist training. A student studies many subjects before choosing one job.

How it works

Large datasets become training examples. Prediction errors update parameters until a base model emerges.

1 · Training dataCollect broad materialText, code, images, or other data provide examples.
2 · TokenizationMake unitsLanguage is converted into tokens the model can process.
3 · PredictionGuess the next partThe model predicts a missing or next token.
4 · ErrorCompare with targetThe prediction is measured against the training example.
5 · UpdateAdjust parametersThe model changes internal values and repeats the loop.
6 · Base modelFinish the broad stageThe result can be prompted or adapted for applications.

What it is NOT

Pre-training ≠ Fine-tuning

Pre-training: Broad initial training

Fine-tuning: Later targeted training

Pre-training ≠ Prompting

Pre-training: Changes model parameters through training

Prompting: Changes runtime instructions

Pre-training ≠ RAG

Pre-training: Builds learned capability before deployment

RAG: Retrieves outside information at query time

Related concepts

Broad data → Pre-training → Base model → Adaptation
A base model is a result of pre-training, not a synonym for every AI model.
