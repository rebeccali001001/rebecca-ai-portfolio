Core Concepts

Three layers make an AI call usable.

01
System PromptHidden or application-level instructions that define behavior and rules.
02
Structured OutputA predictable output format such as JSON or a fixed schema.
03
Failure HandlingThe logic used when an AI call fails, returns invalid output, or cannot safely complete the task.
One Request, Three Layers

Same LLM. Different system design. Different application behavior.

User

“Check this invoice and return the result.”

System PromptYou are an invoice review assistant.
Structured Output
{
  "status": "...",
  "issues": [...]
}
Failure Handling

If required fields are missing, return an error status instead of inventing data.
