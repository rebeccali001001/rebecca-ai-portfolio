What is an Agent Loop?

An agent loop is a repeated cycle of deciding, acting, observing, and deciding again.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

An agent loop is the control cycle that lets an AI system take a step, observe the result, and choose what to do next.

The loop normally includes a goal, model decision, action, observation, and stop condition. Limits and validation keep the loop from continuing blindly.

Think of it like...

Think of it like checking a route after every turn.

A navigation system follows a route, observes the road, and updates the next turn when conditions change. An agent loop follows a similar sequence with tools and system state.

How it works

1 · GoalSet the objectiveDefine the task and stopping rules.
2 · DecideSelect an actionThe model chooses from available actions.
3 · ActCall a toolThe system executes an allowed action.
4 · ObserveRead the resultTool output becomes new context.
5 · StopFinish or repeatThe system completes, asks, or continues.

Real-world examples

Everyday example · Web research

Input: a question needing several sources

AI / System: searches, reads results, and refines the query

Output: a sourced answer or a request for clarification

Business example · Ticket handling

Input: a support ticket

AI / System: checks records, proposes an action, and validates it

Output: a response, update, or human handoff

What it is NOT

Agent Loop ≠ One Model Call

Agent loop: can repeat decisions and actions.

One model call: produces one response from one input.

Agent Loop ≠ Infinite Loop

Agent loop: needs limits and a stop condition.

Infinite loop: continues without reaching a safe end.

Agent Loop ≠ Human Reasoning

Agent loop: is a programmed system pattern.

Human reasoning: is not reproduced exactly by this loop.
