What is Context Window?

What is it?

A context window is the amount of tokenized information a model can use in one operation.

It can include system instructions, the user message, conversation history, retrieved documents, and space reserved for the answer. It is working space for a request, not automatically permanent memory.

Think of it like...

Think of it like the size of a working desk. A larger desk holds more papers at once, but it is still not a permanent filing cabinet.

This is a learning analogy. The real system uses mathematical models and software controls.

How it works

1 · GatherCollect materialThe application assembles instructions, messages, and optional retrieved text.
2 · TokenizeCount the unitsAll material becomes tokens.
3 · FitSelect what can enterThe system truncates, summarizes, or retrieves only what fits.
4 · InferProcess the sequenceThe model uses the available tokens to produce an output.
5 · ManageKeep headroomThe application leaves space for the answer and handles overflow.

Real-world examples

Everyday example · Long conversation

Input: Recent messages and a new question

AI / System: Keeps the useful history within the limit

Output: An answer based on the visible conversation

Business example · Policy assistant

Input: A question plus current policy excerpts

AI / System: Places instructions and retrieved text on the working desk

Output: An answer grounded in the supplied policy

What it is NOT

Context Window ≠ Memory

Context Window: Context is available for the current operation.

Memory: Memory stores or retrieves information across operations.

Context Window ≠ Training data

Context Window: Context is supplied at use time.

Training data: Training data shaped the model earlier.

Bigger context ≠ Perfect recall

Bigger context: A larger window allows more tokens.

Perfect recall: The model can still miss, misread, or give less attention to details.
