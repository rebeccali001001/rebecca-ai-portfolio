What are Failure Modes?

Failure modes are the recurring ways an AI system can produce an incorrect, unsafe, incomplete, or unusable result.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A failure mode is a recognizable way a system can fail under a certain input, condition, or interaction.

Cataloging failure modes helps teams design tests, monitoring, recovery, and human review. It also separates model errors from retrieval, tool, integration, data, and workflow errors.

Think of it like...

Think of it like a pre-flight checklist. Naming the ways a journey can go wrong helps the crew notice risk before the same problem appears in production.

How it works

1 · ObserveCollect real failuresCapture examples from tests, pilots, logs, and user reports.
2 · ClassifyName the failure patternSeparate hallucination, missing evidence, tool error, timeout, and other causes.
3 · PrioritizeEstimate impact and frequencyFocus controls on failures that matter most.
4 · ControlAdd a responseUse validation, fallback, monitoring, or human review.

Real-world examples

Everyday example · Wrong date

Input: “Book Friday” across time zones

AI / System: interprets the date without clarifying

Output: an incorrect event or clarification need

Business example · Unsupported policy answer

Input: a question outside retrieved sources

AI / System: generates a confident answer anyway

Output: a false claim instead of a handoff

What it is NOT

Failure Modes ≠ Random Bugs

Failure Modes: recurring patterns with a cause or condition

Random bug: an isolated defect that may need a different fix

Failure Modes ≠ Model Errors Only

Failure Modes: include integration, data, tool, and workflow failures

Model error: one possible source

Failure Modes ≠ Test Cases

Failure Modes: describe how the system can fail

Test cases: inputs used to reveal or guard against those failures

Related concepts

Input ↓ Failure condition ↓ Observed failure mode ↓ Control + test + monitor
