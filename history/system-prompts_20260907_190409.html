What is a
System Prompt?

A system prompt is a set of instructions that defines how an AI model should behave inside an application.

01 / 085 min readPrompting fundamentals
01 — The short answer

What is it?

A system prompt may define:

RoleRulesBoundariesToneAllowed behaviorOutput expectations
↳

Usually, users do not re-enter these rules every time. They are provided to the model by the application.

02 — Make it familiar

Think of it like...

Think of a system prompt like the employee handbook given to a worker before customers arrive.

05 — Important limits

What it is NOT

↔

System Prompt ≠
User Prompt

System Prompt: application-level instructions.

User Prompt: the current user request.

⌁

System Prompt ≠
Model Training

System Prompt: changes runtime instructions.

Training: changes learned model parameters.

!

System Prompt ≠
Guaranteed Control

System Prompt: influences behavior.

It does not mathematically guarantee that every output will follow every rule.
