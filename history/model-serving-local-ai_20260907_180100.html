Model Serving & Local AI

Understand what makes a model runnable, efficient, and usable on a real device.

Chapter introduction

From model files to a usable runtime

This chapter separates the runtime that starts a model, the representation that helps it fit, and the limits that shape the real experience.

Why this matters

What this chapter helps you understand

A model that exists is not automatically a model that can serve requests. Local AI requires fit across memory, speed, context, hardware, and workload.

Concept map

Three decisions behind local AI

Model files\n↓\nOllama or another runtime\n↓\nQuantization trade-off\n↓\nMemory / speed / context limits\n↓\nUsable local system

Ollama is a runtime and manager. Quantization changes numerical representation. Runtime Constraints describe the operating limits.
