05 · Embeddings, RAG & Vector Search

How AI Finds Information Before Answering

This chapter explains how an AI system can search for relevant information before asking a language model to generate an answer.

You will learn how meaning is represented as vectors, how relevant information is retrieved, and how RAG gives a model useful external context.

02 · The Big Picture

Question → Search → Retrieve → LLM → Answer

When the model needs facts it may not reliably know, a retrieval pipeline finds useful source material first.

04 · One Question, Step by Step

“How many annual leave days do employees receive?”

01 · QueryThe user asks a question.
02 · EmbeddingThe question is converted into a vector.
03 · SearchThe system finds semantically similar document chunks.
04 · RetrievalRelevant HR policy text is returned.
05 · RAGThe retrieved text is added to the LLM context.
06 · AnswerThe LLM answers using the provided policy.
07 · GroundingThe answer can point back to the source.
