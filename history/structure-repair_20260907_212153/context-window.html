What is a Context Window?

A context window is the amount of information a model can work with during one request or conversation state.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

The context window is the model’s working space.

It contains the tokens currently available to the model, which may include system instructions, user messages, uploaded content, retrieved information, tool results, and generated text.

Context size is usually measured in tokens.

Think of it like...

Working Desk

Think of the context window like a desk. Everything the AI needs for the current task must fit on the desk. A larger desk can hold more documents at the same time.

If the desk is full, some information must be removed, summarized, or retrieved again.

Real-world examples

Example 1 · Long conversation

A user has a very long chat.

As more messages are added, more context is used.

Example 2 · Large document

Input: A long PDF or document.

System: The text must fit into the available context or be split/retrieved selectively.

Output: Answer based on the visible context.

Example 3 · Coding Agent

Instructions + repository files + tool results + chat history can all consume context.

What it is NOT

Context Window ≠ Memory

Context Window: The information available for the current model operation.

Memory: Information stored or retrieved across interactions.

Context Window ≠ Model Knowledge

Context Window: Information supplied now.

Model Knowledge: Patterns learned during training.

Context Window ≠ Maximum Answer Length

Context Window: Covers available input plus generated tokens according to the model/API design.

Output limit: May be separately constrained.
