What is it?

Pre-training is the broad first stage where a model learns general patterns from large amounts of data.

For a language model, pre-training often teaches the model to predict missing or next tokens across a large corpus. It creates a general starting point that can later be prompted, evaluated, or adapted.

Think of it like...

Think of it like general education before a first job. A student learns language and broad subjects first, then can learn a specialized role more efficiently.

This is a learning analogy. The real system uses mathematical models and software controls.

How it works

1 · PrepareCollect and process dataThe training corpus is filtered, tokenized, and arranged for learning.
2 · PredictRun a broad objectiveThe model predicts tokens or another training target.
3 · MeasureCompute the lossThe system measures how far the prediction is from the target.
4 · UpdateChange parametersOptimization adjusts the model to reduce the loss.
5 · RepeatBuild general abilityThe cycle runs over many batches and training steps.

Real-world examples

Everyday example · Language pattern

Input: Many sentences

AI / System: Learns regularities such as likely word order

Output: A base model that can continue text

Business example · General assistant

Input: Broad training followed by an application prompt

AI / System: Uses the base model as a starting point

Output: A model ready for task-specific controls

What it is NOT

Pre-training ≠ Fine-tuning

Pre-training: Pre-training builds broad capability.

Fine-tuning: Fine-tuning is additional narrower training.

Pre-training ≠ Prompting

Pre-training: Pre-training changes model parameters.

Prompting: Prompting changes the input at use time.

Pre-training ≠ Memorizing a database

Pre-training: The model learns distributed patterns.

Memorizing a database: It is not a guaranteed, queryable record of every training item.
