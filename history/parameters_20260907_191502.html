What are Parameters?

Parameters are the learned numerical values inside a model.

What is it?

Parameters are numerical values that a model adjusts during training.

Together, they shape how the model transforms input and scores possible outputs. A parameter count describes scale, but it does not by itself guarantee quality, truthfulness, or speed.

Think of it like...

Think of parameters like the settings inside a large mixing desk. Training adjusts many tiny controls so the system responds differently to different patterns.

How it works

1 · InitializeStart with valuesThe model begins with values that do not yet encode the target skill.
2 · TrainCompare predictions with targetsThe system measures error on many examples.
3 · UpdateAdjust the valuesOptimization changes parameters to reduce future error.
4 · UseApply the learned settingsThe trained model uses its parameters on new inputs.

Real-world examples

Everyday example · Next-word prediction

Input: “The weather is”

AI / System: uses learned values to score continuations

Output: a ranked set of next tokens

Business example · Ticket routing

Input: a support ticket

AI / System: uses learned values to score categories

Output: a predicted route or queue

What it is NOT

Parameters ≠ Training data

Parameters: learned numerical values in the model

Training data: examples used to adjust those values

Parameters ≠ Model size on disk

Parameters: count of learned values

File size: also depends on numeric precision, format, and metadata

Parameters ≠ Quality

Parameters: one measure of model scale

Quality: depends on data, training, architecture, evaluation, and task fit
