What are Parameters?

Parameters are the learned numbers inside a model. Together, they shape how the model turns input tokens into a prediction.

What is it?

A parameter is a numerical value that a model adjusts during training. Billions of these values work together across many layers to capture useful patterns, such as which words tend to fit together or which visual features often appear in an image.

Training changes the parameters; using the finished model reads them to make predictions.

Think of it like...

Imagine a control panel with millions of tiny knobs. After practicing on many examples, the model keeps the knob settings that help it make better guesses. The settings are not written instructions; they are the model’s learned tendencies.

How it works

The basic loop is: examples → training updates → parameters → new input → prediction.

1 · ExamplesShow patternsTraining examples give the model a task and an expected answer.
2 · Training updatesMeasure the missThe system checks the prediction and calculates how it could improve.
3 · ParametersAdjust the numbersAn optimization step nudges many weights and biases.
4 · New inputRead the promptLater, a prompt is converted into tokens and passed through the model.
5 · PredictionChoose what fitsThe model uses its learned settings to score possible next outputs.

Real-world examples

  • Model selection: compare a small local model with a larger hosted model for quality, cost, privacy, and speed.
  • Hardware planning: estimate memory and serving requirements before putting a model into production.
  • Fine-tuning: make a focused set of updates so a base model behaves better for a particular task or style.

What it is NOT

  • Parameters ≠ knowledge database
    They encode statistical relationships; they are not a searchable table of facts.
  • More parameters ≠ always better
    Quality also depends on data, training, task fit, evaluation, latency, and cost.
  • Parameters ≠ tokens
    Tokens are pieces of input or output text; parameters are learned values inside the model.

Related concepts

LLM
A language model whose learned parameters help predict text.Machine Learning

Updating a model for a narrower task or behavior.

Remember this

Parameters are the model’s learned numerical settings. Parameter count tells you something about capacity and resource needs, but it does not tell you everything about usefulness.
