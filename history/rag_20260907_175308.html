What is RAG?

RAG lets an AI system retrieve relevant information before generating an answer.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Retrieval-Augmented Generation combines information retrieval with model generation.

A RAG system finds relevant content at query time, adds selected evidence to the model’s context, and asks the model to generate an answer from that context.

Think of it like...

Think of it like taking an exam with an open book. The model is not limited to what it learned earlier; before answering, it can look up relevant pages.

How it works

1 · QuestionReceive the requestThe system receives a question and any filters or permissions.
2 · SearchFind relevant contentThe query is embedded or otherwise used to retrieve candidate chunks.
3 · SelectBuild evidence contextThe system ranks, filters, and formats the useful sources.
4 · GenerateAsk the model to answerThe model uses the selected evidence and instructions.
5 · CheckCite or verifyThe application checks support, access, and answer quality.

Real-world examples

Everyday example · Holiday policy

Input: “How many annual leave days do employees receive?”

AI / System: searches the current HR policy and supplies the relevant passage

Output: an answer based on the current policy

Business example · Operations assistant

Input: a question about a settlement rule

AI / System: retrieves the current policy with source metadata

Output: a grounded answer or review flag

What it is NOT

RAG ≠ Fine-tuning

RAG: retrieves external information at query time

Fine-tuning: changes model behavior through additional training

RAG ≠ Search Engine

RAG: combines retrieval with generation and application controls

Search: retrieves or ranks existing information

RAG ≠ Guaranteed Truth

RAG: gives the model selected evidence

Truth: still depends on source quality, retrieval, reasoning, and checks
