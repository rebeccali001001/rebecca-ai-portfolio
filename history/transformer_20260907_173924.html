What is it?

A Transformer is a neural-network architecture that processes relationships between tokens.

Its attention mechanism lets the model weigh which parts of the input are useful when producing each representation or output token.

Think of it like...

Think of it like a reading group where every word can look around the table and decide which other words matter for the current task.

How it works

Tokens are embedded, processed through attention and feed-forward layers, and turned into output scores.

1 · TokensSplit the inputText becomes token IDs and vectors.
2 · AttentionCompare contextEach position weighs information from relevant positions.
3 · Layer stackTransform representationsRepeated attention and feed-forward layers refine the signal.
4 · Output scoresPredict optionsA final layer scores possible next tokens or labels.
5 · DecodeProduce outputThe system selects output tokens or task results.

Real-world examples

Everyday example · Pronoun resolution

Input: A sentence with it or they

System: Attention weighs nearby words and references

Output: A more likely continuation

AI product example · Translation

Input: A sentence in one language

System: Transformer layers map relationships across tokens

Output: Translated text

Business example · Classification

Input: A support ticket

System: The architecture processes the ticket sequence

Output: A category label

What it is NOT

Transformer ≠ LLM

Transformer: An architecture

LLM: A language model often built with that architecture

Transformer ≠ Attention

Transformer: A full architecture with several components

Attention: One important mechanism inside it

Transformer ≠ ChatGPT

Transformer: A model architecture

ChatGPT: A product can use Transformer-based models plus other systems

Related concepts

Tokens → Embeddings → Attention + layers → Output scores
The Transformer is a design pattern for neural networks, not a single product.
