What are Structured Outputs?

Structured outputs make a model return data in a defined shape instead of free-form text.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Structured outputs are model responses that follow a specified schema or format.

The schema may require fields, types, and allowed values. The application can parse the result more reliably, while still checking whether the values are correct.

Think of it like...

Think of it like a form with labeled boxes. The form makes the answer easier to pass to the next person, but it cannot make an incorrect value true.

How it works

The application describes a schema, the model fills it, and the system validates the result.

1 · SchemaDefine the shapeList required fields, types, and allowed values.
2 · PromptDescribe the taskTell the model what to extract or create.
3 · GenerationFill the fieldsThe model returns a structured candidate.
4 · ValidationCheck the shapeThe application checks syntax and schema rules.
5 · ReviewCheck meaningA person or rule verifies important values.

Real-world examples

Everyday example · Trip plan

Input: A travel request

Output: Structured trip data

AI product example · Extraction

Input: An invoice

System: The model maps text to a schema

Output: Fields ready for review

Business example · Ticket routing

Input: A support message

System: The model returns category, priority, and reason

Output: Data for a workflow

What it is NOT

Structured Outputs ≠ Correct Answers

Structured Outputs: A response with a defined shape

Correct Answers: A response whose values are accurate

Structured Outputs ≠ Plain Text

Structured Outputs: Fields and types follow a schema

Plain Text: Free-form prose

Structured Outputs ≠ Database

Structured Outputs: A model response format

Database: A system that stores and queries records

Related concepts

Prompt → Model → Schema validation → Workflow
Structured output is a contract for shape, not a substitute for evaluation.
