What is Embeddings?

An embedding is a numerical representation that places content in a space where useful similarities can be compared.

What is it?

An embedding is a vector of numbers produced by an embedding model for text, images, audio, or other data.

Content with related patterns may be placed closer together in that vector space. The vector is a representation for comparison or retrieval; it is not a complete answer by itself.

Think of it like...

Think of it like putting every idea on a map of meaning. Similar ideas tend to be placed in nearby neighborhoods, even when they use different words.

How it works

1 · InputProvide contentA document chunk, query, image, or other item enters the system.
2 · EmbedMap it to a vectorAn embedding model converts the item into numerical coordinates.
3 · CompareMeasure similarityThe system compares vectors with a distance or similarity function.
4 · RetrieveUse nearby itemsA search or ranking step returns useful candidates for the application.

Real-world examples

Everyday example · Policy question

Input: “Can I cancel after the vessel sails?”

AI / System: embeds the query and policy chunks

Output: a nearby chunk about post-departure cancellation

Business example · Knowledge search

Input: a support question

AI / System: finds semantically related internal documents

Output: ranked evidence for an assistant

What it is NOT

Embedding ≠ Token

Embedding: a numerical representation of an input

Token: a unit processed by a model

Embedding ≠ Vector Database

Embedding: the vector representation

Vector Database: a system that stores and searches vectors

Embedding ≠ Answer

Embedding: a signal for similarity

Answer: generated or selected content that still needs checking

Related concepts

Text or image ↓ Embedding model ↓ Vector ↓ Similarity comparison ↓ Retrieval
