What are Tokens per Second?

Tokens per second measures how quickly a model generates output tokens during decoding.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Tokens per second is a throughput measure for generated tokens over time.

It is usually measured after generation starts. It does not include every part of the user experience, such as queueing or time to first token, and it depends on model, hardware, context, and settings.

Think of it like...

Think of it like the speed of writing after the first word has appeared. A fast writing rate is useful, but it does not tell you how long you waited before the writer began.

How it works

1 · PromptSend the requestThe system receives input and prepares the context.
2 · PrefillProcess input tokensThe model reads the prompt before generating output.
3 · DecodeGenerate output tokensThe model predicts and emits tokens one by one.
4 · MeasureCount output over timeThe benchmark reports a rate under stated conditions.

Real-world examples

Everyday example · Chat reply

Input: a short prompt

AI / System: generates 40 output tokens at 20 tokens per second

Output: about two seconds of decode time

Business example · Batch summaries

Input: many documents

AI / System: measures output throughput under load

Output: capacity for a target queue

What it is NOT

Tokens per Second ≠ Latency

Tokens per Second: generation throughput

Latency: time to first or complete result

Tokens per Second ≠ Token count

Tokens per Second: tokens generated per unit time

Token count: how many units are generated

Tokens per Second ≠ Quality

Tokens per Second: a performance metric

Quality: a separate measure of correctness or usefulness
