What is an AI Agent?

An AI agent is a system that uses a model, instructions, tools, and a control loop to work toward a goal.

What is it?

An AI agent is a software system that can decide what step to take next while working toward a goal.

A typical agent combines a model with instructions, tools, state or memory, permissions, and stopping conditions. The model helps select or explain actions; surrounding software controls what can actually happen.

Think of it like...

Think of it like giving an AI worker a goal and a toolbox. The worker can choose a tool, inspect the result, and continue, but the toolbox and permissions define the safe boundary.

How it works

1 · GoalReceive the objectiveThe system gets a task, constraints, and success condition.
2 · PlanChoose the next stepThe model proposes a response, question, or tool call.
3 · ActUse an allowed toolThe application validates and executes the selected action.
4 · ObserveRead the resultThe tool result becomes new context for the next decision.
5 · StopFinish or escalateThe loop ends when the goal is met, blocked, or unsafe.

Real-world examples

Everyday example · Travel planning

Input: a request to compare train options

AI / System: searches schedules and checks constraints

Output: a plan with links and trade-offs

Business example · Document workflow

Input: a request to process an invoice

AI / System: reads the document, checks fields, and routes exceptions

Output: a completed record or human review

What it is NOT

Agent ≠ LLM

LLM: the reasoning and language model

Agent: a system using models, tools, instructions, and a control loop

Agent ≠ Chatbot

Chatbot: primarily communicates with a person

Agent: can take actions and use tools toward a goal

Agent ≠ Workflow

Workflow: usually follows predefined steps

Agent: can dynamically choose the next action within limits

Related concepts

Goal + Model + Instructions + Tools + Agent Loop = AI Agent
