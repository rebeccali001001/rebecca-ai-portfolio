What is System Prompt?

A system prompt is application-provided instruction context that sets an AI system’s role, rules, and boundaries.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A system prompt is instruction context supplied by the application, usually before the user’s message.

It can define the task, important terms, decision rules, tool behavior, output requirements, and failure path. It guides the model, but permissions and validation still belong in software around it.

Think of it like...

Think of it like a job brief handed to a new front-desk teammate. It explains the role, house rules, and when to call a supervisor, but it does not unlock doors or approve refunds by itself.

How it works

1 · RoleState the jobExplain what the system is responsible for.
2 · RulesSet priorities and limitsDescribe what it must do, avoid, or ask about.
3 · ToolsDefine allowed actionsExplain when a tool may be used and what inputs it needs.
4 · OutputSpecify the result shapeState the required format and fields.
5 · FailureDefine the safe exitSay when to abstain, ask, retry, or hand off.

Real-world examples

Everyday example · Writing helper

Input: a request to rewrite a message

AI / System: applies tone and length instructions

Output: a draft with the requested style

Business example · Support drafting

Input: a customer question and policy excerpt

AI / System: uses only supplied evidence and flags uncertainty

Output: a draft plus review fields

What it is NOT

System Prompt ≠ Application Code

System Prompt: instructions that guide model behavior

Application code: enforces permissions, validation, and business rules

System Prompt ≠ User Prompt

System Prompt: product-level instructions and boundaries

User Prompt: the current user request

System Prompt ≠ Security Boundary

System Prompt: can state a safety rule

Security boundary: must be enforced by access controls and trusted code

Related concepts

Application ↓ System Prompt ↓ User input + tools ↓ Validated output
