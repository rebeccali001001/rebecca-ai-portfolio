What are Functional Tests?

Functional tests check whether an AI feature does the job it is meant to do.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A functional test checks whether an AI system produces an acceptable result for a defined task.

The test uses a representative input, a clear expected behavior, and pass criteria. It can check an answer, tool call, citation, routing decision, or safe fallback—not only a text match.

Think of it like...

Think of it like checking a vending machine with a known order. Put in the same coin and button press, then verify that the right item, price, and error message appear.

How it works

1 · DefineChoose a taskDescribe the user goal and important boundaries.
2 · PrepareWrite a test caseProvide input, context, tools, and expected behavior.
3 · RunExecute the workflowCall the same system a user would call.
4 · JudgeCheck the resultUse assertions, rules, graders, or human review.
5 · TrackCompare over timeRecord regressions, edge cases, and release decisions.

Real-world examples

Everyday example · Travel helper

Input: A request with a budget and dates

System: Returns the required fields and respects the budget

Output: A usable plan or a clear clarification

Business example · Support routing

Input: A known customer case

System: Classifies and routes the case correctly

Output: Correct queue, priority, and audit trail

What it is NOT

Functional Test ≠ Demo

Functional test: repeatable check against pass criteria

Demo: a selected example that may not cover failures

Functional Test ≠ Model Benchmark

Functional test: checks a complete product behavior

Model benchmark: measures a model on a benchmark task

Functional Test ≠ One Perfect Answer

Functional test: can allow several acceptable outputs

One exact answer: is not always the right criterion for generated text

Related concepts

Task → Test case → System run → Pass / fail evidence
Failure modes reveal what to test; deployment readiness uses test evidence with other release signals.
