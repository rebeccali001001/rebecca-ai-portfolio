What is it?

A token is a small unit of text that an AI model reads and processes.

A token may be a whole word, part of a word, punctuation, or another text unit depending on the tokenizer. Models count tokens for context limits, cost, and processing speed.

Think of it like...

Think of it like cutting a sentence into small LEGO pieces. The model processes these pieces rather than reading a sentence exactly the way a person sees words.

This is a learning analogy. The real system uses mathematical models and software controls.

How it works

1 · TextReceive a stringThe user or application provides text.
2 · TokenizerSplit into unitsA tokenizer maps the text to token pieces.
3 · IDsAssign numbersEach token becomes an ID the model can process.
4 · ModelProcess the sequenceThe model uses token representations and context.
5 · DecodeTurn IDs into textGenerated token IDs are converted back into readable output.

Real-world examples

Everyday example · Short sentence

Input: “ChatGPT is useful.”

AI / System: The tokenizer splits it into token pieces

Output: The model processes token IDs

Business example · Context budget

Input: A long support case

AI / System: Counts input and output tokens

Output: A prompt that fits, is truncated, or needs summarization

What it is NOT

Token ≠ Word

Token: A word may be one token or several.

Word: Token boundaries depend on the tokenizer.

Token ≠ Character

Token: A token is not simply one letter.

Character: It may contain characters, parts of words, spaces, or punctuation.

Token ≠ Meaning

Token: A token is a processing unit.

Meaning: Meaning comes from patterns across tokens and context.
