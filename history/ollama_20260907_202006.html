What is Ollama?

Ollama is software that helps you download, run, and manage AI models locally.

On this pageWhat is it?Think of it like...How it worksExamplesWhat it is NOTRelated conceptsRemember thisVideo
01 · The short answer

What is it?

Ollama provides a runtime around AI models.

It can download model packages, load models, run inference, expose a local API, and manage model versions or configurations.

Downloadmodel packages
Loadmodel files
Runinference
Exposea local API
Manageversions & config

The models can be:

LlamaQwenDeepSeekMistralMore

Ollama is not any of these models. It is the software that runs them.

02 · A beginner-friendly mental model

Think of it like...

Think of Ollama like a media player.

AI modelThe movie file

The model file / weights: the learned data that contains what the model knows.

OllamaThe media player

The software that loads the file and plays it. Ollama loads and runs the model.

05 · Clear up the common confusion

What it is NOT

Ollama ≠ LLM

Ollama: runs and manages models.

LLM: the actual language model.

Ollama ≠ Model Weights

Ollama: runtime software.

Model weights: the learned numerical data of the model.

Ollama ≠ AI Agent

Ollama: provides model inference.

Agent: a larger system with a model, tools, and a control loop.

Ollama ≠ ChatGPT

Ollama: a local model runtime.

ChatGPT: a complete AI product and service.
