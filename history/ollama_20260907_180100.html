What is Ollama?

Ollama is software for running and managing AI models locally.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Ollama is a local model runtime and management tool.

It helps download, configure, start, and interact with supported models on a local machine. Ollama is not the language model itself; it is the software layer that runs and manages models.

Think of it like...

Think of it like a local model launcher and manager. It helps you install and run the engine, but the engine—the model weights—are a separate thing.

How it works

1 · ChooseSelect a modelA user or application chooses a compatible local model.
2 · PrepareDownload and configure itThe runtime obtains model files and runtime settings.
3 · RunStart a local serviceOllama loads the model and exposes a local interface.
4 · RequestSend a prompt or API callAn application uses the local endpoint to generate a result.

Real-world examples

Everyday example · Private notes

Input: a short note on a laptop

AI / System: a local model processes the prompt without a hosted request

Output: a summary or rewrite

AI product example · Local prototype

Input: a prompt from a test app

AI / System: Ollama serves a selected model over a local API

Output: a response for development

What it is NOT

Ollama ≠ LLM

Ollama: runs and manages models

LLM: the actual language model

Ollama ≠ Cloud AI service

Ollama: software running on a local machine

Cloud service: remote infrastructure accessed over a network

Ollama ≠ Privacy Guarantee

Ollama: can keep a request local when configured that way

Privacy: also depends on logs, files, network, and the surrounding application
