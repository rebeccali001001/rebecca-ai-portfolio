What is an AI Agent?

An AI agent is a system that uses a model, tools, instructions, and a control loop to work toward a goal.

What is it?

An AI agent is a system that can decide and take bounded actions toward a goal.

An agent usually combines a model with instructions, tools, memory or state, permissions, and a loop that decides whether to continue. The model proposes actions; the surrounding application controls what may happen.

Think of it like...

Think of it like giving an AI worker a goal and a toolbox. The worker chooses which tool to use, but the workplace still decides which tools are allowed and when the job must stop.

How it works

An agent repeats a bounded decision cycle until it finishes, needs help, or reaches a limit.

1 · GoalReceive the taskThe user or application defines an outcome.
2 · PlanChoose a next stepThe model proposes what information or action is needed.
3 · ToolRequest an actionThe agent selects an allowed tool with structured inputs.
4 · ObserveRead the resultThe application returns tool output or an error.
5 · Continue or stopFinish safelyThe loop continues, asks for help, or returns a result.

Real-world examples

Everyday example · Travel planning

Input: “Find a train that arrives before noon.”

System: Searches schedules and compares options

Output: A shortlist for confirmation

AI product example · Coding assistant

Input: A bug report

System: Reads files, edits code, and runs tests

Output: A proposed change and test result

Business example · Operations helper

Input: A delayed shipment case

System: Checks records and approved procedures

Output: A draft action or human handoff

What it is NOT

Agent ≠ LLM

Agent: A system with a model, tools, instructions, and a control loop.

LLM: The language model component that generates or scores text.

Agent ≠ Chatbot

Agent: Can take bounded actions through tools.

Chatbot: Primarily communicates with a person.

Agent ≠ Workflow

Agent: Can choose the next allowed action dynamically.

Workflow: Usually follows predefined steps and branches.

Related concepts

Goal + LLM + Tools + Memory or state + Agent loop → Bounded action
Tool Calling is the action interface. The Agent Loop controls repeated decisions and stopping.
