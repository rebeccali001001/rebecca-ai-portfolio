What is a Context Window?

What is it?

A context window is the amount of tokenized information a model can use in one operation.

It may include the user message, system instructions, retrieved documents, conversation history, and the answer being generated.

Think of it like...

Think of it like the size of a working desk. A larger desk holds more papers at once, but it is still not a permanent filing cabinet.

How it works

The application assembles context, stays within the token limit, and sends it to the model for inference.

1 · InputGather materialThe system collects instructions, messages, and optional retrieved text.
2 · TokenizeCount unitsAll material becomes tokens.
3 · Fit the windowSelect contextThe application truncates, summarizes, or retrieves only what fits.
4 · InferenceProcess the sequenceThe model uses the available tokens to produce an output.
5 · OutputReturn the answerThe generated tokens also consume part of the operation budget.

Real-world examples

Everyday example · Long chat

Input: A conversation with many turns

System: The system keeps useful history within the limit

Output: A reply based on selected context

Business example · Policy answer

Input: A question plus policy passages

System: The application puts current evidence on the working desk

Output: An answer using the available policy context

AI product example · File analysis

Input: A large document

System: The product chunks or summarizes the file before inference

Output: A response about selected content

What it is NOT

Context Window ≠ Memory

Context Window: Current information available for one operation

Memory: Information stored or retrieved across interactions

Context Window ≠ Model parameters

Context Window: Temporary input and output tokens

Model parameters: Learned values inside the model

Larger context ≠ Always better

Larger context: Can hold more information

Always better: May increase cost, latency, or noise

Related concepts

Messages + Instructions + Retrieved context → Context Window → Inference
Memory can supply context, but the context window is the current working space.
