What is it?

A token is a small unit of text that an AI model reads and processes.

A token may be a whole word, part of a word, punctuation, or another text unit depending on the tokenizer.

Think of it like...

Think of cutting a sentence into small LEGO pieces. The model processes these pieces, not text exactly as a human sees words.

How it works

Text is tokenized before the model processes it. Generated text is built by producing more tokens.

1 · TextReceive the sentenceA user provides words, punctuation, or symbols.
2 · TokenizerSplit into unitsThe tokenizer maps text to token pieces or IDs.
3 · ModelProcess tokensThe model uses token representations as input.
4 · Next tokenPredict a continuationA language model scores possible next tokens.
5 · OutputDecode the sequenceTokens are converted back into readable text.

Everyday example · Emoji

Business example · Cost estimate

Input: A long support transcript

System: The system counts input and output tokens

Output: A usage and cost estimate

What it is NOT

Token ≠ Word

Token: A model-processing unit

Word: A word may be one token or several tokens

Token ≠ Character

Token: A tokenizer-defined unit

Character: A token is not simply one letter

Token ≠ Context Window

Token: One unit in a sequence

Context Window: The context window is the total token budget available

Related concepts

Text → Tokenizer → Tokens → Model processing
Token count affects context limits, latency, and often usage cost.
