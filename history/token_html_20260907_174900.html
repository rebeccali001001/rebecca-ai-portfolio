What is it?

A token is a small unit of text that an AI model reads and processes.

A token may be a whole word, part of a word, punctuation, or another text unit depending on the tokenizer. Token counts affect context limits, input cost, and generation speed.

Think of it like...

Think of it like cutting a sentence into small LEGO pieces. The model processes these pieces rather than reading the whole sentence exactly the way a person sees words.

How it works

1 · TextReceive a stringThe system starts with human-readable text.
2 · TokenizerSplit into piecesA tokenizer maps the text into model-specific token units.
3 · IDsConvert pieces to numbersEach token becomes an ID the model can process.
4 · ModelUse the token sequenceThe model reads the sequence as part of its context.

Real-world examples

Everyday example · Short sentence

Input: “ChatGPT is useful.”

AI / System: splits text into several tokens

Output: a token sequence for the model

Business example · Document cost

Input: a long policy

AI / System: counts tokens before sending the request

Output: a context and cost estimate

What it is NOT

Token ≠ Word

Token: a model-specific unit of text

Word: a human language unit that may be one or many tokens

Token ≠ Character

Token: may contain several characters or part of a word

Character: one letter, number, symbol, or code point

Token ≠ Meaning

Token: an input unit used by the model

Meaning: comes from patterns across many tokens and context
