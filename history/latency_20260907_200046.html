What is Latency?

Latency is the amount of time you wait for an AI system to respond.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Latency measures delay.

In an AI application, that delay can come from more than the model itself.

Request transmissionPrompt processingModel inferenceTool callsRetrievalOutput generation

Latency is the time across the part of the system you are measuring. It is not the same thing as Tokens per Second.

Think of it like...

Think of latency like waiting for food at a restaurant.

You place the order. Then time passes before the food arrives.

Different stages can add delay:

Taking the orderCookingGetting ingredientsServing

AI works the same way: several small waits can add up to the total time you feel.

How it works

1User requestYou send a message.
2Network / APIThe request travels to the system.
3Prompt processingThe system reads your prompt and context.
4Inference startsThe model begins working.
5First tokenOutput starts to appear.
6Remaining tokensThe answer continues generating.
7Complete responseThe full answer is ready.

Time to First Token

How long before output starts.

Total Latency

How long before the complete response is finished.

Real-world examples

Example 1 · Chatbot

Click Send → wait 1.5 seconds → first word appears

This waiting time contributes to perceived latency.

Example 2 · Agent

User request → LLM → search tool → database → LLM

Tool calls may add additional latency.

Example 3 · Local model

A large model on slower hardware may take longer to start or generate.

What it is NOT

Latency ≠ Tokens per Second

Latency: how long you wait.

Tokens per Second: how fast tokens are generated after generation is underway.

Latency ≠ Model Quality

A faster model is not automatically a better model.

Latency ≠ Only Model Inference

Network, RAG, tool calls, queues, and other components may also add latency.
