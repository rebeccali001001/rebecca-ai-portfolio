What is Tool Calling?

Tool calling lets a model request a defined function with structured arguments so an application can perform an action.

Detail

The application validates the arguments, executes the tool, and returns the result to the model. The model does not directly access the system.

Model proposes; application controls execution.

Sample

A model requests `get_trade_price(symbol, date)`; the application checks permissions before calling the pricing service.
