A coffee-order robot

Imagine a café robot handling: “Please make one oat latte, no sugar, for table six.” The same order makes all five ideas visible.

TokenCut the orderThe sentence is split into small readable pieces.
ContextUse the order boardInstructions, table number, and current order must fit together.
KV cacheKeep the ticket nearbyAlready-read details stay handy while the answer is prepared.
LatencyMeasure first responseHow long until the robot says, “Got it”?
Tokens / secondMeasure answer flowAfter starting, how quickly can it write the rest?

The practical takeaway: a request can fit but still feel slow; caching can help repeated work but cannot enlarge the context window; a high output speed does not erase the wait before the first token.
