What is an AI Agent?

An AI agent is a system that uses a model, tools, and a control loop to work toward a goal.

What is it?

An AI agent is a system that can decide and take actions toward a goal.

It usually combines a model with instructions, tools, permissions, memory or context, and a loop that checks results. The application—not the model alone—must enforce limits and safety rules.

Think of it like...

Think of it like giving an AI worker a goal and a toolbox. The worker chooses which tool to use, checks what happened, and continues only while the task still needs work.

How it works

1 · GoalReceive the taskThe system defines the desired outcome and boundaries.
2 · DecidePlan the next stepA model proposes a response or tool call.
3 · ToolTake an allowed actionThe runtime validates and executes the selected tool.
4 · ObserveRead the resultThe output becomes evidence for the next decision.
5 · FinishAnswer or stopThe loop ends at success, a limit, or a safe handoff.

Real-world examples

Everyday example · Trip planning

Input: a destination and travel dates

System: checks approved travel tools and constraints

Output: an itinerary with sources and a confirmation step

Business example · Coding assistant

Input: a bug report

System: reads files, proposes a patch, and runs allowed tests

Output: a reviewed change or an honest blocker

What it is NOT

Agent ≠ LLM

Agent: a system with a goal, tools, instructions, and a control loop

LLM: a language model that generates or scores tokens

Agent ≠ Chatbot

Agent: can use tools and take bounded actions

Chatbot: mainly communicates with a person

Agent ≠ Workflow

Agent: can choose the next step dynamically within limits

Workflow: usually follows predefined steps

Related concepts

Goal+LLM+Tools+Memory / context+Agent loop=Agent
