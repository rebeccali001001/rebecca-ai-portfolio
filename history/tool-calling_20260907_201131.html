06 · Agents, Tools & MCP · Topic 02

What is Tool Calling?

Tool Calling lets an AI model request an external tool when it needs information or an action it cannot perform by itself.

→ The model decides which capability it needs — and what arguments to send.
+

+
01 · The idea

What is it?

An LLM mainly generates model output. Tool Calling gives it a way to ask an application to do something outside the model.

The model does not magically gain permissions. The application checks the request, runs the tool, and sends the result back.

It can’t know everythingReal-time databases and weather change.
It can’t do everythingCode, email, and files need external systems.
It can ask for helpWith a named tool and structured arguments.

05 · Clear up the terms

What it is NOT

≠ Tool

Tool Calling: the mechanism for requesting a tool.

Tool: the capability that performs the action.

≠ Agent

Tool Calling: one capability.

Agent: a larger system that may call tools repeatedly in a loop.

≠ API

API: an external interface.

Tool Calling: the model/application mechanism that may invoke it.
