What are Parameters?

Parameters are the learned numerical settings that shape how a model responds to input.

On this pageWhat is it?Think of it like...How it worksExamplesWhat it is NOTRelatedRememberVideo

1. What is it?

Parameters are the learned numerical values inside an AI model.

During training, these values are adjusted so the model becomes better at its task.

Large models may contain millions or billions of parameters.

2. Think of it like...

Think of parameters like millions of tiny knobs inside a machine.

Training slowly turns these knobs. After training, their settings influence how the model responds to new inputs.

The knobs do not store complete sentences or facts directly.

4. Real-world examples

Example 1 · Language model

Input: “The sky is”

Parameters: Learned patterns make some next tokens more likely than others.

Output: A possible continuation such as “blue”.

Example 2 · Image model

Input: An image.

Parameters: Learned visual relationships help detect edges, shapes, and objects.

Output: An object label.

Example 3 · Fine-tuning

Before: Base parameter settings.

During fine-tuning: Some parameters or adapters are updated.

After: The model behaves more consistently for a target task.

5. What it is NOT

  • Parameters ≠ Tokens
    Parameters are learned values inside the model. Tokens are units of input and output processed by the model.
  • Parameters ≠ Knowledge Database
    Parameters encode learned statistical relationships. A database stores explicit retrievable records.
  • More Parameters ≠ Always Better
    More parameters can increase capacity. A better model also depends on architecture, training data, training quality, and task fit.
