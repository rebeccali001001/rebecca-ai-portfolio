01 / START HERE

What is it?

Functional tests check whether an AI feature works correctly for expected user tasks.

They may test:

input handlingoutput formattool useretrievalbusiness ruleserror handling

The question is simple:

“Does the system do what it is supposed to do?”
02 / A USEFUL MENTAL MODEL

Think of it like... Driving Test

Think of functional testing like a driving test.

Knowing how a car engine works is not enough. You must check whether the driver can:

startturnstopfollow ruleshandle common situations

AI functional testing is similar. You test the real behavior of the complete system.

05 / CLEAR UP THE CONFUSION

What it is NOT

≠ Benchmark

Functional Tests check whether a specific application works for a defined task.

Benchmark measures model performance on a standardized dataset or test.

≠ Unit Tests

Unit Tests usually test a small deterministic code component.

Functional Tests can test the behavior of a complete AI workflow.

≠ Human Opinion Only

Use explicit pass/fail criteria where possible. Human review may be part of evaluation, but should not be the only method for every case.
