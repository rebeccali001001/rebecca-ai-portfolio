What is Context Window?

A context window is the amount of tokenized information a model can use in one request.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A context window is the maximum amount of tokenized input and output that a model can handle for one operation.

It may include system instructions, conversation history, retrieved documents, tool results, and the new answer. A larger context window does not guarantee that every detail will receive equal attention.

Think of it like...

Think of it like the size of a working desk. You can use the papers on the desk together; when the desk is full, something must be removed, summarized, or moved to storage.

How it works

1 · CollectGather request contextInstructions, history, documents, and the new question are assembled.
2 · TokenizeCount the unitsThe system converts all content into tokens.
3 · FitCheck the limitThe request must fit within the model’s input and output budget.
4 · GenerateUse the available contextThe model produces an answer from the information in the current window.

Real-world examples

Everyday example · Long conversation

Input: many earlier messages

AI / System: keeps selected history in the current window

Output: a response using the visible context

Business example · Policy assistant

Input: a question plus policy excerpts

AI / System: fits only the relevant sections

Output: an answer based on the supplied context

What it is NOT

Context Window ≠ Memory

Context Window: information available for the current model operation

Memory: information stored or retrieved across interactions

Context Window ≠ Model knowledge

Context Window: current input and generated output budget

Model knowledge: patterns learned during training

Context Window ≠ File storage

Context Window: temporary working space for a request

File storage: persistent data that must be retrieved or supplied

Related concepts

Instructions + history + Retrieved documents ↓ Context Window ↓ Inference
