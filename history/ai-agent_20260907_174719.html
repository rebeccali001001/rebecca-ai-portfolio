What is an AI Agent?

An AI agent is a system that uses a model, tools, and a control loop to pursue a goal.

What is it?

An AI agent is a software system that can choose actions to make progress toward a goal.

It usually combines a language or reasoning model with instructions, tools, state or memory, and a loop that observes results. The model proposes decisions; tools perform the real-world actions.

Think of it like...

Think of it like giving an AI worker a goal and a toolbox. The worker decides which tool to use, checks what happened, and continues until the job is done or needs a person.

How it works

1 · GoalReceive the taskInstructions define the desired outcome and limits.
2 · DecidePlan a next stepThe model selects an action based on the current state.
3 · ToolExecute an actionA tool reads data or changes something.
4 · ObserveRead the resultThe system adds the result to the next decision.
5 · ContinueFinish or hand offThe loop stops at success, a limit, or a human review.

Real-world examples

Everyday example · Trip planner

Input: “Plan a two-day trip within my budget.”

AI / System: searches options and checks constraints

Output: an itinerary and questions for missing details

Business example · Support triage

Input: a customer issue

AI / System: reads the record, searches policy, and drafts an update

Output: a proposed action or escalation

What it is NOT

Agent ≠ LLM

LLM: the language or reasoning model.

Agent: a system around a model with tools and a control loop.

Agent ≠ Chatbot

Chatbot: primarily communicates with a user.

Agent: can take bounded actions through tools.

Agent ≠ Workflow

Workflow: usually follows predefined steps.

Agent: can dynamically choose the next step within limits.

Related concepts

Goal + instructions\n+ LLM\n+ Tools\n+ Memory or state\n+ Agent loop\n= AI agent
