What is Generative AI?

Generative AI creates new content such as text, images, audio, video, or code from an input or instruction.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Generative AI is a class of AI systems that produces new content.

The output is generated from patterns learned during training and shaped by the current input, instructions, context, and system controls. Generated content still needs evaluation when accuracy or safety matters.

Think of it like...

Think of it like a musician who has studied many songs and can compose a new piece from a brief. The new piece is not a copied recording, but it is shaped by learned patterns and the direction you give.

How it works

1 · InputProvide a prompt or sourceA user gives text, an image, audio, code, or other context.
2 · RepresentTurn input into model unitsThe system converts the request into a form the model can process.
3 · GeneratePredict or construct contentThe model produces output step by step or through iterative refinement.
4 · CheckReview the resultA person or system checks quality, policy, format, and factual support.

Real-world examples

Everyday example · Image creation

Input: a text description of a room

AI / System: generates visual content from learned patterns

Output: a new image

Business example · Drafting a report

Input: notes and a report outline

AI / System: generates a first draft in a chosen format

Output: a reviewable report draft

What it is NOT

Generative AI ≠ AI

Generative AI: one area focused on creating content

AI: the broader field, including prediction, classification, and control

Generative AI ≠ Search

Generative AI: constructs a new response

Search: retrieves existing documents or pages

Generative AI ≠ Human creativity

Generative AI: recombines learned patterns under an input

Human creativity: includes human goals, experience, judgment, and responsibility
