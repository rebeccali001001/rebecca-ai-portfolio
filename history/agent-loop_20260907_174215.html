What is an Agent Loop?

An agent loop is the repeated cycle an AI system uses to move from a goal toward a result.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

An agent loop is a control cycle that lets an AI system observe a task, choose a next step, act, and check the result.

It repeats only while the task is unfinished and the system is allowed to continue. A useful loop has limits, permissions, timeouts, and a clear stop condition.

Think of it like...

Think of it like a person following a checklist while cooking.

You check what is needed, do one step, taste the result, and decide whether to continue. The checklist has a stopping point, so “keep trying” is not the plan.

How it works

1 · GoalReceive the taskA user or workflow states the desired outcome.
2 · ObserveRead the current stateThe system gathers messages, tool results, or files.
3 · DecideChoose the next actionThe model proposes a step within the allowed plan.
4 · ActUse a tool or respondThe runtime validates and executes the action.
5 · CheckContinue or stopEvidence decides whether to repeat, hand off, or finish.

Real-world examples

Everyday example · Trip planning

Input: “Find a train that arrives before 9.”

System: Checks schedules, compares options, and verifies the time.

Output: A suitable option or a request for more details.

Business example · Coding task

Input: A bug report.

System: Reads files, proposes a patch, runs tests, and inspects results.

Output: A verified change or a clear handoff.

What it is NOT

Agent loop ≠ LLM

Agent loop: The control process around the model.

LLM: The language model that proposes text or actions.

Agent loop ≠ Workflow

Agent loop: Can choose the next step from the current state.

Workflow: Usually follows predefined steps.

Continue ≠ Success

Continue: The system still has an allowed next step.

Success: Evidence shows the goal was met.

Related concepts

Goal → Observe → Decide → Tool / response → Result
An agent combines this loop with a model, instructions, tools, memory, and permissions.
