What is Vector Search?

Vector search finds items whose embeddings are close to a query embedding.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Vector search compares numerical vectors to find content that is similar in the chosen representation space.

It is useful when related content may use different words. Practical systems often combine vector similarity with keyword search, metadata filters, permissions, and reranking.

Think of it like...

Think of it like a library organized by meaning instead of alphabetically. A question about changing a booking can sit near documents about amendments, even if the wording is different.

How it works

1 · EmbedRepresent the queryAn embedding model maps the query into a vector.
2 · IndexPrepare stored vectorsDocuments or other items are embedded and stored for search.
3 · CompareFind nearby vectorsThe system searches for the closest candidates.
4 · FilterApply constraintsMetadata, access rules, and freshness limits remove invalid results.
5 · RankReturn useful evidenceThe application orders candidates for retrieval or generation.

Real-world examples

Everyday example · Find a recipe

Input: “quick vegetarian dinner”

AI / System: searches nearby recipe vectors

Output: a ranked set of related recipes

Business example · Support search

Input: a customer issue in new wording

AI / System: combines semantic similarity with product filters

Output: relevant cases or policy passages

What it is NOT

Vector Search ≠ Keyword Search

Vector Search: compares learned numerical representations

Keyword Search: matches terms or text signals

Vector Search ≠ Embedding

Vector Search: the search operation and index

Embedding: the vector representation used by that operation

Vector Search ≠ RAG

Vector Search: one retrieval method

RAG: a larger pattern that retrieves evidence and generates an answer
