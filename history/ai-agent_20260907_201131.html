06 · Agents, Tools & MCP · Topic 01

What is an
AI Agent?

An AI agent is a system that can use a model, tools, and a control loop to work toward a goal.

Model+Instructions+Tools+State / Memory+Control Loop

01 · The idea

What is it?

Normal model callinput → model → output
An agentgoal → decide → use tool → observe result → decide again → finish

The key difference: it can use the current result to decide what to do next.

02 · A mental model

Think of it like…

AI worker + toolbox

Give a worker a goal, instructions, a toolbox, a workspace, and permission to take several steps.

GoalInstructionsToolboxWorkspacePermission

The model is the worker’s reasoning engine. The tools are what let the system act.

04 · In practice

Real-world examples

EXAMPLE 01 · CODING AGENT

“Fix this bug.”

Agent: reads files → runs tests → edits code → checks result

Output: a code change.

EXAMPLE 02 · RESEARCH AGENT

“Compare three AI products.”

Agent: searches sources → reads pages → extracts facts → organizes result

EXAMPLE 03 · BUSINESS WORKFLOW

“Can this invoice be approved?”

Agent: reads invoice → queries policy → checks fields → returns result or escalates

05 · Clear up the confusion

What it is NOT

Agent ≠ LLM

LLM: generates or reasons over information.

Agent: a system around a model that can use tools and take multiple steps.

Agent ≠ Chatbot

Chatbot: primarily communicates with the user.

Agent: can execute actions and interact with external systems.

Agent ≠ Workflow

Workflow: usually follows predetermined steps.

Agent: can choose the next action dynamically.

Agent ≠ Tool

Tool: performs one capability.

Agent: chooses when and how to use tools.
