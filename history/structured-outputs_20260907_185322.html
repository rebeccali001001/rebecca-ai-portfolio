01 / THE IDEA

What is it?

A response that follows a specified shape — so an application knows what to expect.

JSONfixed fieldsschemaenum values
02 / THE ANALOGY

Think of it like...

Asking someone to fill in a form instead of writing a free-form paragraph.

FREE-FORM ANSWER
“Rebecca's invoice looks okay...”
STRUCTURED OUTPUT
StatusApproved
Amount1000
CurrencyUSD

For software, the second answer is easier to process.

05 / BOUNDARIES

What it is NOT

≠ Plain Text

Structured Output follows a defined shape.

Plain Text is free-form language.

≠ Correct Output

Valid structure means the format is correct.

Correct answer means the content is accurate.

≠ Database

Structured Output is a response format.

Database stores and queries data.
