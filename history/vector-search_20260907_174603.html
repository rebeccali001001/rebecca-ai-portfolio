What is Vector Search?

Vector search finds items whose numerical representations are close to a query representation.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Vector search compares a query vector with stored vectors and returns the closest matches.

The comparison may use cosine similarity, distance, or another metric. It is useful when related wording or meaning matters more than exact keyword overlap.

Think of it like...

Think of it like a library organized by meaning instead of alphabetically. A question about “post-departure cancellation” can find a policy section that uses different words.

How it works

1 · IndexRepresent the itemsStored documents or records become vectors.
2 · QueryRepresent the questionThe current request becomes a vector in the same space.
3 · CompareMeasure closenessThe search calculates similarity or distance.
4 · RankOrder candidatesThe closest items are returned with metadata.
5 · UseRetrieve or filterA later system decides what evidence is useful.

Real-world examples

Everyday example · Recipe finder

Input: “quick vegetarian dinner”

System: Searches recipe vectors

Output: Recipes with related meaning

Business example · Support search

Input: A customer question

System: Finds related help-center passages

Output: Evidence for a support answer

What it is NOT

Vector Search ≠ Keyword Search

Vector search: Compares representations and similarity.

Keyword search: Matches terms or lexical signals.

Vector Search ≠ Embedding

Vector search: Finds nearby stored items.

Embedding: Creates the vectors being compared.

Nearest ≠ Correct

Nearest result: A ranked candidate.

Correct evidence: Still needs filters, permissions, and review.
