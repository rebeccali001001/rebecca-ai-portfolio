What is Vector Search?

Vector search finds items that are close to a query in embedding space.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Vector search compares a query vector with stored vectors and returns the nearest candidates.

It can match related meaning even when exact words differ. Filters, keyword signals, reranking, permissions, and freshness checks may still be needed.

Think of it like...

Think of a library organized by meaning instead of alphabetically. A request brings back nearby shelves, then a librarian checks which books really fit.

How it works

The system embeds the query, searches an index, and returns candidates for the next step.

1 · QueryReceive the requestA user asks a question or describes an item.
2 · EmbedCreate a query vectorAn embedding model maps the request into numbers.
3 · SearchFind nearby vectorsThe index returns nearest candidates.
4 · FilterApply constraintsMetadata, permissions, and freshness narrow the set.
5 · UseRetrieve or rankA downstream system uses the candidates.

What it is NOT

Vector Search ≠ Keyword Search

Vector Search: Compares vector similarity

Keyword Search: Matches words or terms

Vector Search ≠ Embedding

Vector Search: The lookup process

Embedding: The numerical representation used by lookup

Vector Search ≠ Correct Retrieval

Vector Search: Returns nearby candidates

Correct Retrieval: Candidates still need filtering and evaluation

Related concepts

Query → Embedding → Vector index → Filter / rerank → Candidate set
Vector search often supports retrieval in a RAG pipeline.
