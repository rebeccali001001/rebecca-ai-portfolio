What are Embeddings?

An embedding is a numerical representation that places an item in a space where similarity can be compared.

What is it?

An embedding is a vector of numbers that represents features or meaning in a form a machine can compare.

An embedding model converts text, images, audio, or other inputs into vectors. Similar items may be close together, depending on the model and task.

Think of it like...

Think of putting every idea on a map of meaning. Similar topics appear near one another, even when they use different words.

How it works

An embedding model converts an input into a vector, then another system compares vectors.

1 · InputReceive an itemText, image, audio, or another object enters the system.
2 · Embedding modelEncode featuresA trained model maps the item to numbers.
3 · VectorStore the representationThe vector can be indexed with metadata.
4 · CompareMeasure similarityThe system compares a query vector with candidates.
5 · UseSelect or rankA downstream workflow retrieves, groups, or recommends items.

What it is NOT

Embedding ≠ Token

Embedding: A numerical representation of an item

Token: A unit processed in a model sequence

Embedding ≠ Vector Database

Embedding: The vector itself

Vector Database: A system that stores and searches vectors

Embedding ≠ Truth Score

Embedding: A similarity representation

Truth Score: A close vector is not proof that content is true

Related concepts
