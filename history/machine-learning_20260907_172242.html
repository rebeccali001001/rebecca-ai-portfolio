What is Machine Learning?

Machine Learning is a way for computers to learn patterns from examples instead of being given every rule by hand.

What is it?

Machine Learning is a way for computers to learn patterns from examples instead of being given every rule by hand.

The learned model can use those patterns to classify, predict, rank, or recommend something for new inputs.

Think of it like...

Think of Machine Learning like teaching someone with examples instead of giving them a rulebook.

Show many examples of: “This is spam.” “This is not spam.” After enough practice, the learner tries to classify a new message.

ExamplesShow labeled messages.
Learn patternNotice repeated signals.
New exampleTry an unseen message.
PredictionSpam or not spam.

How it works

Training and using the trained model are two different stages.

1 · Training DataGive examplesProvide inputs, labels, and outcomes.
2 · TrainingReduce mistakesThe model adjusts internal parameters.
3 · Learned ModelProduce a modelTraining leaves behind learned patterns.
4 · New InputTry something newGive the model an input it has not seen.
5 · PredictionReturn a resultApply learned patterns to the input.
6 · EvaluationCompare resultsCheck predictions against expected results.

Real-world examples

Everyday example · Spam filter

Input: A new email.

Machine Learning: Uses patterns learned from previous spam and non-spam emails.

Output: Spam or not spam.

Everyday / Product example · Recommendation

Input: What a user watched, clicked, or purchased.

Machine Learning: Finds patterns similar to previous behavior.

Output: A ranked list of recommended items.

Business example · Demand forecasting

Input: Historical sales and related data.

Machine Learning: Finds patterns in past demand.

Output: A demand forecast.

What it is NOT

Machine Learning ≠ Artificial Intelligence

Machine Learning: One approach within AI that learns patterns from data.

Artificial Intelligence: The broader field of making systems perform intelligence-related tasks.

Machine Learning ≠ Deep Learning

Machine Learning: Includes many methods such as decision trees, linear models, and neural networks.

Deep Learning: A type of Machine Learning based on multi-layer neural networks.

Machine Learning ≠ Fixed-rule programming

Machine Learning: Learns patterns from examples.

Fixed-rule programming: A developer explicitly writes the rules the software follows.
