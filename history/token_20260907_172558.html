What is a token?

A token is a small unit of text that an AI model reads and processes.

What is it?

A token is a small unit of text used by a model.

Depending on the tokenizer, a token can be a whole word, part of a word, punctuation mark, or another text fragment. Models count tokens rather than words exactly as people see them.

Think of it like...

Think of cutting a sentence into small LEGO pieces. The model processes those pieces and uses them to build the next response.

A longer or less common word may be split into several pieces.

How it works

1 · InputTextA message, document, or prompt arrives.
2 · SplitTokenizerThe tokenizer breaks text into pieces.
3 · RepresentToken IDsEach piece is mapped to a number.
4 · ProcessModelThe model uses the token sequence.
5 · OutputNew tokensGenerated tokens are decoded into text.

Real-world examples

Everyday example

Text: “ChatGPT is useful.”

System: Splits the sentence into tokens.

Output: The model processes token IDs, not the sentence as one indivisible object.

Business example

Input: A long support ticket.

System: Counts tokens before sending it to a model.

Output: The application can reject, trim, or summarize text that is too long.

What it is NOT

Token ≠ Word

Word: A unit people use in language.

Token: A tokenizer's unit. One word may become one token or several.

Token ≠ Character

Character: One letter, symbol, or code point.

Token: May contain several characters or only part of a word.

Token ≠ Meaning

Token: A processing unit.

Meaning: Depends on the sequence and the model's learned representations.
