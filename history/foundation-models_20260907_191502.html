What are Foundation Models?

A Foundation Model is broadly trained on diverse data and can be adapted for many downstream tasks.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A Foundation Model is a model trained broadly on large and varied data so it can support many later tasks.

It provides a reusable starting point. An application may prompt it, connect tools or retrieval, fine-tune it, or combine it with other software for a specific job.

Think of it like...

Think of it like a well-stocked general workshop. It has many materials and basic skills already available, so a craftsperson can configure it for different projects instead of building every tool from zero.

How it works

1 · Pre-trainLearn broad patternsThe model learns from a large and varied training collection.
2 · RepresentBuild reusable capabilityIts parameters capture patterns useful across many tasks.
3 · AdaptAdd task instructions or dataAn application narrows the behavior with prompts, tools, retrieval, or fine-tuning.
4 · DeployUse in a productThe adapted system generates or predicts within a defined workflow.

Real-world examples

Everyday example · Writing helper

Input: a request to rewrite a message

AI / System: uses broad language ability plus instructions

Output: a clearer draft

Business example · Support assistant

Input: a customer question and policy context

AI / System: uses a foundation model with retrieval and rules

Output: a grounded draft answer

What it is NOT

Foundation Model ≠ LLM

Foundation Model: a broad model category across modalities and tasks

LLM: a foundation model specialized for language

Foundation Model ≠ ChatGPT

Foundation Model: a model used as a reusable capability

ChatGPT: a product that combines models with interface and product systems

Foundation Model ≠ Fine-tuning

Foundation Model: the broadly trained starting model

Fine-tuning: one possible way to adapt that model
