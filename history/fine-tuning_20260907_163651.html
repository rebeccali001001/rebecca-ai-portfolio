What is Fine-tuning?

Fine-tuning is additional training that adapts a capable base model to follow a focused task, format, style, or domain behavior more consistently.

What is it?

A base model learns broad language patterns during pre-training. Fine-tuning continues that training with a smaller, carefully chosen set of examples that show the behavior you want.

The result is a model that is more likely to respond in a particular way without repeating the same instructions in every prompt. It can improve consistency, but it does not automatically make the model current, correct, or safe.

Fine-tuning changes learned behavior; it is not a live knowledge update.

Think of it like…

Think of a person who completes general education before receiving professional training. School builds broad reading and reasoning skills; an apprenticeship then uses coached practice to build habits for one role.

Fine-tuning is that focused apprenticeship for a model: the examples demonstrate how a specialist should handle recurring situations.

How it works

A typical workflow moves from a reusable model to a measurable specialized behavior:

01 · StartBase modelChoose a pre-trained checkpoint with the right general capability.
02 · PrepareCurated examplesCollect representative inputs paired with high-quality target outputs.
03 · UpdateAdditional updatesTrain on those examples so selected parameters or adapters shift.
04 · SpecializeSpecialized behaviorExpect more consistent format, tone, or task handling.
05 · CheckEvaluationTest quality, edge cases, regressions, and safety before release.

Real-world examples

Fine-tuning is most useful when the desired behavior is stable, repeatable, and clear enough to demonstrate in examples.

Support triage

Classify incoming tickets into a known set of queues and return the same JSON shape every time.

Writing style

Draft internal updates in a consistent voice, structure, and level of detail.

Domain workflow

Apply a specialist’s labeling conventions to documents or requests that follow a recurring pattern.

What it is NOT

Fine-tuning≠Prompting

Prompting changes the instructions supplied at runtime. Fine-tuning changes the model’s learned parameters or adapter behavior through additional training.

Fine-tuning≠RAG

RAG retrieves external context at runtime. Fine-tuning is a training change; use retrieval when answers need current or source-specific facts.

Fine-tuning≠Guaranteed truth

More consistent behavior does not guarantee factual accuracy. Evaluation, grounding, monitoring, and human review still matter.

Related concepts

LLM ↗

The language model that predicts and generates text.

Pre-training ↗

The broad learning phase that creates a reusable base model.

RAG ↗

A runtime pattern for retrieving relevant external information.

Evaluation ↗

The tests and evidence used to decide whether behavior is ready.

Remember this

Fine-tuning is specialist training after general education: teach a stable behavior with representative examples, then evaluate it. It can make a model more consistent, but it cannot promise fresh facts or guaranteed truth.
