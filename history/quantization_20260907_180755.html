What is Quantization?

Quantization stores model values with lower numerical precision to reduce memory or improve runtime efficiency.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Quantization converts numerical values into a lower-precision representation.

For model serving, this can reduce file size and memory use and may improve speed. The trade-off is that lower precision can change model behavior or quality, so the chosen format must be evaluated for the target task.

Think of it like...

Think of it like compressing a large model so it takes less memory while trying to preserve most of its ability. The smaller package can be easier to carry, but some detail may be lost.

How it works

1 · StartLoad model valuesThe original model contains numerical weights at a chosen precision.
2 · ConvertMap to lower precisionWeights are represented with fewer bits or a more compact format.
3 · RunLoad the quantized modelThe runtime uses the smaller representation for inference.
4 · EvaluateMeasure the trade-offTeams compare quality, memory, speed, and task failures.

Real-world examples

Everyday example · Laptop assistant

Input: a quantized local model

AI / System: uses less memory during a short chat

Output: a response on hardware that could not load the full model

Business example · Edge deployment

Input: a target device with limited RAM

AI / System: chooses a quantization level after testing

Output: a workable local inference service

What it is NOT

Quantization ≠ Any Model Compression

Quantization: reduces numerical precision of values

Other compression: may prune, distill, or encode the model in different ways

Quantization ≠ Free Speed

Quantization: a memory and numeric representation choice

Speed: depends on hardware kernels, runtime, batch, and workload

Quantization ≠ No Quality Change

Quantization: aims to preserve useful behavior with fewer bits

Quality: must be measured because some tasks can degrade

Related concepts

Full-precision model ↓ Lower-precision weights ↓ Smaller memory footprint ↓ Local inference
