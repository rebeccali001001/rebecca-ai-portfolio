What is Structured Outputs?

Structured output means asking an AI system to return data in a defined shape that software can check and use.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Structured output is a response that follows a specified schema, such as JSON fields with known types.

A schema makes the interface easier to validate and integrate, but a well-formed response can still contain wrong or unsupported values.

Think of it like...

Think of it like a form with labeled boxes. The form makes the answer easier to process, but someone still has to check whether the information in each box is correct.

How it works

1 · DefineChoose a schemaName the fields, types, allowed values, and required fields.
2 · PromptExplain the expected shapeThe model receives the task and output contract.
3 · GenerateReturn structured dataThe system produces values in the requested format.
4 · ValidateCheck syntax and meaningSoftware verifies the shape, values, evidence, and business rules.
5 · RecoverHandle invalid resultsThe application retries, repairs, or escalates when needed.

Real-world examples

Everyday example · Trip plan

Input: a request for three activities

AI / System: returns an array with name, time, and location

Output: data that a calendar UI can display

Business example · Invoice extraction

Input: an invoice document

AI / System: returns vendor, date, total, and review flag

Output: validated fields for a workflow

What it is NOT

Structured Outputs ≠ Correct Outputs

Structured Outputs: a predictable response shape

Correct Outputs: values that are accurate and supported

Structured Outputs ≠ Plain Text

Structured Outputs: fields have a defined contract

Plain Text: flexible content without a machine-checked shape

Structured Outputs ≠ Database Schema

Structured Outputs: a response interface at one system boundary

Database schema: persistent storage design with its own constraints
