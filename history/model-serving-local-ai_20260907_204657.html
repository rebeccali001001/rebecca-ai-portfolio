07 · Model Serving & Local AI

How AI Models Run on Real Hardware

This chapter explains how an AI model is loaded, served, and used on local or remote hardware.

You will learn what Ollama does, why quantization matters, and what hardware and runtime limits affect model performance.

Chapter Introduction

From downloaded weights to a working response

A model file is only the starting point. Serving is the chain that turns weights into tokens, and tokens into something an application can use.

The important idea: serving is a system, not a single download. Each layer changes what the next layer can do.

Core Concepts

Three ideas to keep in mind

OllamaSoftware for downloading, running, and managing AI models locally.
QuantizationReducing numerical precision so a model uses less memory and compute.
Runtime ConstraintsThe real hardware and memory limits that affect whether and how a model can run.
One Local Model Request

What happens when you ask: “Explain RAG.”

Step 1Ollama loads the selected local model.
Step 2The prompt becomes tokens.
Step 3The model processes the context in memory.
Step 4Inference generates output tokens.
Step 5The application displays the response.
