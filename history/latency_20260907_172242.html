03 · Tokens, Context & Inference

What is Latency?

Latency is the time a user waits for an AI system to respond. For a streaming model, it has more than one useful clock.

Topic detail

Measure time to first token (TTFT), the gaps between later tokens, and end-to-end time to finish. Queueing, network travel, prompt processing, model compute, tool calls, and validation can all contribute.

A quick first token does not guarantee a quick completed answer.

Why it matters

Latency changes whether a workflow feels interactive, tolerable, or too slow. Optimize the measure that matches the job: first signal for a chat UI, completion time for a batch action, or the full loop for an agent.

user wait = queue + network + prompt work + generation + tools + post-processing

Sample

A support assistant emits a first token after 0.8 seconds, continues streaming for 2.4 seconds, and finishes after 4.1 seconds. Those are different signals, not contradictory measurements.

0.8 sfirst signal / TTFT
3.2 sstreaming underway
4.1 scomplete response

Easy analogy

Like checkout, latency includes the line before service and the time to finish the purchase. Reaching the cashier quickly is helpful, but it is not the same as leaving the store quickly.
