What is a Failure Mode?

A failure mode is a specific way an AI system can produce the wrong, incomplete, unsafe, or unusable result.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A failure mode describes how something can go wrong.

Common AI failure modes may include:

hallucinationwrong retrievalmissing contextinvalid structured outputtool failureincorrect classificationstale informationoverconfident answer

Identifying failure modes helps teams decide what to test and what safeguards to add.

Think of it like...

Think of failure modes like the different ways a car can fail.

Run out of fuelNo energy to continue.
Flat tireA part cannot do its job.
OverheatThe system becomes unsafe.
Lose battery powerThe support system stops.

These are different failure modes. AI systems also fail in different ways.

Real-world examples

Example 1 · Hallucination

Question: “What is the policy limit?”

Failure: Model invents a number not found in the source.

Example 2 · Retrieval Failure

Question: “How many annual leave days?”

Failure: System retrieves an outdated HR policy.

Example 3 · Structured Output Failure

Expected: Valid JSON.

Failure: Model returns free-form text.

Example 4 · Tool Failure

Agent: Calls a database.

Failure: Database request fails or returns incomplete data.

What it is NOT

Failure Mode ≠ Failure Handling

Failure Mode: How the system can fail.

Failure Handling: What the system should do when failure happens.

Failure Mode ≠ Bug Only

Bug: A software defect.

Failure Mode: Can come from data, model behavior, retrieval, tools, prompts, or system design.

Failure Mode ≠ Hallucination

Hallucination: One specific failure mode.

Failure Modes: The broader set of ways an AI system may fail.
