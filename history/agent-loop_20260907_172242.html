The Agent Loop

An agent is a bounded control loop: the model proposes the next step, the application decides what is allowed, and evidence from each action feeds the next decision.

Detail

Observe task
Plan next step
Validate tool
Execute action
Inspect / stop

The loop needs a maximum step count, explicit tool permissions, timeout handling, and a final answer contract. “Keep going” is not a stopping policy.

Sample

For a coding task, the loop reads a file, proposes a patch, runs a restricted test, inspects the output, and stops when the acceptance checks pass.

Model proposes; runtime enforces.

Design checks

  • Can every tool call be replayed?
  • What happens after a timeout?
  • Which actions require approval?
  • What evidence ends the loop?
