What is Generative AI?

Generative AI is AI that creates new content based on patterns learned from data.

What is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Generative AI is AI that creates new content based on patterns learned from data.

The content may be text, code, images, audio, video, or other structured outputs.

Traditional predictive AIChooses or predicts an answerFor example, deciding whether an email is spam.
Generative AICreates a new outputFor example, writing a new email from a prompt.

Think of it like...

Think of Generative AI like a creative assistant that has studied many examples.

You give it a prompt. It uses patterns it learned during training to create a new draft. The draft may be text, an image, music, code, or video.

It does not simply copy one stored example; it generates a new output from learned patterns. That does not mean every output is guaranteed to be completely original.

How it works

The core idea is simple: learn patterns → receive a prompt → generate new content.

1 · TrainingLearn patternsThe model learns patterns from large amounts of data.
2 · Prompt / InputReceive an instructionA user gives an instruction, question, or example.
3 · Model ProcessingUse learned patternsThe model predicts what should come next based on the prompt.
4 · GenerateCreate step by stepIt creates new text, pixels, audio, code, or video.
5 · OutputReturn the resultThe generated content is returned to the user or application.

Different generative models create different types of content, but the general idea is similar.

Real-world examples

Each example makes the input and the newly generated output visible.

Text generationInput: “Write a short email asking to reschedule a meeting.”Uses learned language patterns → output: a new email draft.
Image generationInput: “A small robot reading a book in a library.”Creates visual content from the prompt → output: a newly generated image.
Code generationInput: “Write a Python function that sorts a list.”Uses code patterns → output: generated Python code.
Video generationInput: a text or image promptCreates moving visual content → output: a generated video clip.

What it is NOT

These comparisons separate Generative AI from related ideas.

Generative AI ≠ Artificial IntelligenceGenerative AI is one category of AIArtificial Intelligence is the broad field; Generative AI focuses on creating new content.
Generative AI ≠ LLMGenerative AI is broader than language modelsIt includes text, image, audio, video, and other systems. Many LLMs are used for Generative AI.
Generative AI ≠ Search EngineIt creates a new outputA search engine finds and retrieves existing content.
Generative AI ≠ CopyingIt generates from learned patternsCopying reproduces an existing item directly; generation can produce a new output without guaranteeing complete originality.
