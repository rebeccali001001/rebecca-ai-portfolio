What is it?

A Transformer is a neural-network architecture that uses attention to connect information across tokens.

Transformer layers turn a sequence into context-aware representations. Modern LLMs commonly use Transformer blocks to process language, then use the resulting representations for next-token prediction or other tasks.

Think of it like...

Think of a reading group marking a sentence together. When one word is ambiguous, the readers look at the other relevant words before deciding what it means. Transformer attention is a mathematical way to weight those relationships.

This is a learning analogy. The real system uses mathematical models and software controls.

How it works

1 · TokensRepresent the inputText becomes a sequence of token representations.
2 · CompareCalculate attentionEach position scores which other positions may be useful.
3 · CombineMix relevant signalsThe model combines information using those scores.
4 · RepeatPass through blocksMany layers refine the context-aware representations.
5 · PredictSupport a taskAn LLM uses the result to score the next token or another output.

Real-world examples

Everyday example · Pronoun reference

Input: “The trader closed the position because it was risky.”

AI / System: Connects “it” with useful context

Output: A better next-token prediction

Business example · Translation

Input: A sentence in one language

AI / System: Uses relationships across the sequence

Output: A translation that keeps sentence context

What it is NOT

Transformer ≠ LLM

Transformer: A Transformer is an architecture.

LLM: An LLM is a language model that often uses Transformer layers.

Attention ≠ Human attention

Attention: Transformer attention is a numerical weighting step.

Human attention: Human attention is a cognitive process.

Transformer ≠ Chatbot

Transformer: A Transformer runs inside a model.

Chatbot: A chatbot is a user-facing application.
