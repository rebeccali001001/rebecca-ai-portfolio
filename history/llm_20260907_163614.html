02 · LLMs & Transformers · Topic 01

What is an LLM?

A Large Language Model (LLM) predicts the next token from the context it can see, then repeats that small decision to generate language.

What is it?

An LLM is a neural network trained on large collections of text and code. During use, it reads an input as tokens, estimates what token should come next, and turns those predictions into an answer, draft, summary, or program.

An LLM is a language-pattern engine. The quality of its output depends on its training, its context, and how the surrounding application checks the result.

Think of it like...

Imagine a writer completing a sentence one small tile at a time. Before choosing the next tile, the writer looks back at the words already on the page and picks a likely continuation. An LLM does this with tokens and learned patterns, so each new choice becomes part of the context for the next one.

How it works

The generation loop is a sequence of small predictions. A Transformer helps the model weigh relationships between tokens so it can use the surrounding context.

01Input tokensYour prompt and any supplied context are split into tokens.
02Transformer processingThe model compares token relationships and builds a contextual representation.
03Predict next tokenIt scores possible continuations and selects or samples one.
04RepeatThe new token is added to the context, and the loop runs again.
05OutputThe token sequence is decoded into text you can read or use.

Real-world examples

Customer supportDraft a reply from a question, policy, and conversation history.
Writing and codingTurn an outline into prose or translate a plain-language request into code.
SummarizationCondense a long document into key points, actions, or a structured record.

What it is NOT

An LLM is one component in a broader AI product. These distinctions prevent common category mistakes.

LLM≠ChatGPT

An LLM is the model; ChatGPT is an application that wraps a model with an interface, instructions, safety systems, and other product features.

LLM≠AI

An LLM is one kind of AI system. AI also includes vision, recommendation, robotics, rules, search, and many other approaches.

LLM≠Search engine

An LLM generates a likely continuation. A search engine retrieves and ranks documents; an LLM may still need retrieval or citations for current facts.

Related concepts

Next layerTransformerThe architecture that helps process relationships between tokens. Smallest unitTokenA piece of text the model reads and predicts. Working spaceContext WindowThe amount of input and generated text available at once. Broader familyGenerative AISystems that create new text, images, audio, code, or other outputs.

Remember this

An LLM generates language by predicting one token at a time from context. That simple loop can support powerful products, but it does not guarantee truth, current knowledge, or independent judgment.
