What is an LLM?

An LLM is a language model trained to predict and generate text from tokens.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A Large Language Model is a model that learns patterns in language and uses them to predict likely next tokens.

It can summarize, translate, answer, classify, or generate text, but it does not automatically know that an output is true. Its behavior depends on training, context, instructions, tools, and evaluation.

Think of it like...

Think of it like an extremely well-read autocomplete system. It has learned many patterns in language, but it still needs the right context and checks when the answer matters.

How it works

1 · InputRead tokensThe prompt and available context are converted into tokens.
2 · ProcessUse the TransformerAttention and neural-network layers process relationships between tokens.
3 · PredictScore possible next tokensThe model estimates which continuations fit the context.
4 · RepeatGenerate a responseSelected tokens are added one by one until the system stops.

Real-world examples

Everyday example · Message rewrite

Input: a rough sentence

AI / System: predicts a clearer continuation in a chosen tone

Output: a revised sentence

Business example · Support summary

Input: a customer conversation

AI / System: processes the supplied context and instructions

Output: a concise summary with open issues

What it is NOT

LLM ≠ ChatGPT

LLM: a type of language model

ChatGPT: a product that uses models plus interface and other systems

LLM ≠ AI

LLM: one model type

AI: the broader field of intelligent computer systems

LLM ≠ Search Engine

LLM: generates text from learned patterns and current context

Search engine: retrieves existing information from an index
