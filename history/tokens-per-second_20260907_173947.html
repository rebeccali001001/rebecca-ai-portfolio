What are Tokens per Second?

Tokens per second measures how quickly a system generates output tokens.

What is it?

Tokens per second measures how quickly a system generates output tokens.

It is a throughput measure. It does not by itself describe answer quality, total latency, or how quickly the first token appears.

Think of it like...

Think of it like typing speed. A fast typist may still pause before starting and may take longer on a very long document.

How it works

After the first token, the model generates more tokens in sequence. The rate depends on the model, hardware, context, and workload.

1 · PromptSend the inputThe request and context enter the serving system.
2 · PrefillProcess the promptThe model reads the input before generation.
3 · DecodeGenerate tokensThe model produces output one token at a time.
4 · MeasureCount output speedTokens are divided by generation time.
5 · CompareUse a consistent testTeams compare the same conditions and settings.

System: Hardware and quantization affect decode speed

What it is NOT

Tokens per Second ≠ Latency

Tokens per Second: Generation throughput

Latency: Time to first or complete result

Tokens per Second ≠ Token count

Tokens per Second: Tokens generated per unit time

Token count: How many units are generated

Tokens per Second ≠ Quality

Tokens per Second: A performance metric

Quality: A quality metric needs separate evaluation

Related concepts
