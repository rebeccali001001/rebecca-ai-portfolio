What are Functional Tests?

Functional tests check whether an AI system completes the task it is supposed to complete.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

A functional test checks whether a system produces the required behavior for a defined input.

For AI applications, a test can check answer content, tool selection, structured fields, citations, routing, refusal behavior, or a human-review path. It needs representative cases and clear pass criteria.

Think of it like...

Think of it like testing each button on a vending machine. Press a known button, check the item and change, then test invalid choices and the safe fallback.

How it works

A simple view of the path from input to output.

1 · DefineWrite expected behaviorTurn the workflow requirement into a clear pass or fail rule.
2 · PrepareCreate test casesInclude normal, boundary, invalid, and adversarial inputs.
3 · RunExecute the systemCapture output, tool calls, errors, and timing.
4 · JudgeCompare with the requirementUse rules, graders, or human review.
5 · TrackWatch changesKeep results so regressions are visible after updates.

Real-world examples

Everyday example · Calendar helper

Input: “Move my 3 pm meeting to Friday”

AI / System: checks permission, tool call, and confirmation

Output: the correct change or a safe clarification

Business example · Invoice pipeline

Input: an invoice with missing data

AI / System: checks extraction, validation, and routing

Output: fields plus a review flag

What it is NOT

Functional Tests ≠ Quality in every dimension

Functional Tests: They check defined task behavior.

Quality in every dimension: They do not by themselves cover latency, cost, safety, or long-term reliability.

Functional Tests ≠ One successful demo

Functional Tests: A demo shows one path.

One successful demo: Tests cover representative normal and unusual cases.

Functional Tests ≠ Fixed unit tests only

Functional Tests: AI outputs can vary with context.

Fixed unit tests only: Criteria must be behavior-aware and reproducible.

Related concepts

Functional tests connect a real workflow requirement to repeatable evidence that the system behaved as expected. They are one part of evaluation and deployment readiness.
