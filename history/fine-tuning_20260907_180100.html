What is Fine-tuning?

Fine-tuning is additional training that adapts a pre-trained model for a narrower task, style, or behavior.

On this pageWhat is it?Think of it like...How it worksReal-world examplesWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Fine-tuning updates some or all model parameters using a focused dataset after pre-training.

It can make a model more consistent for a task, format, domain, or style. It does not automatically add a reliable, up-to-date knowledge source, and it can reduce general behavior if done poorly.

Think of it like...

Think of it like giving someone specialized training after general education. They keep broad skills but practice a narrower job with examples from that job.

How it works

1 · StartChoose a base modelA broadly trained model provides general capability.
2 · PrepareCreate focused examplesExamples show the desired inputs, outputs, format, or behavior.
3 · TrainUpdate parametersThe model learns from the focused dataset.
4 · EvaluateCheck the trade-offsTests confirm whether the target behavior improved without harmful regressions.

Real-world examples

Everyday example · Consistent tone

Input: a draft message

AI / System: uses examples of a preferred writing style

Output: a more consistent rewrite

Business example · Structured extraction

Input: an invoice image or text

AI / System: learns a domain-specific output format from examples

Output: fields in a predictable schema

What it is NOT

Fine-tuning ≠ RAG

Fine-tuning: changes model behavior through additional training

RAG: retrieves external information at query time

Fine-tuning ≠ Prompting

Fine-tuning: changes parameters

Prompting: changes the input instructions without retraining

Fine-tuning ≠ Updating a live database

Fine-tuning: creates a new model version from training examples

A database update: changes records that a system can retrieve

Related concepts

Base model ↓ Focused examples ↓ Fine-tuning ↓ Specialized behavior
