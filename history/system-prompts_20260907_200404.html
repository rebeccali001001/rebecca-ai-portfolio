01 — The short answer

What is it?

A system prompt is a set of instructions sent by an application to guide the model's behavior.

It can define a role, rules, boundaries, tone, or output format. It guides a response at runtime but does not retrain the model.

RoleRulesBoundariesToneOutput formatReview needs
↳

Users usually do not enter these instructions each time. The application adds them before the current request.

02 — Make it familiar

Think of it like...

Think of a system prompt like a workplace handbook placed at a service desk before the first customer arrives.

Customerasks a specific question.
Handbooksets the rules for handling requests.
System Promptguides the AI application for this run.

This analogy covers instructions and boundaries. It does not mean the model is a person or that the rules guarantee every response.

05 — Important limits

What it is NOT

↔

System Prompt ≠ User Prompt

System prompt: application-level guidance that sets general behavior.

User prompt: the request for the current turn.

⌁

System Prompt ≠ Model Training

System prompt: runtime instructions added to an input.

Model training: changes learned parameters across training data and updates.

!

System Prompt ≠ Guaranteed Control

System prompt: guides and constrains likely behavior.

Guaranteed control: certainty that every output follows every rule, which a prompt alone cannot provide.
