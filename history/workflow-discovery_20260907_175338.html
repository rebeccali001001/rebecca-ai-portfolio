Workflow Discovery

Find the real work before choosing the AI.

Definition

Workflow discovery is the disciplined process of learning how a task moves today: who starts it, which systems are touched, where decisions happen, what exceptions appear, and what “done” means.

In plain English

Follow one real case from beginning to end. Listen for the handoffs, workarounds, repeated copying, and moments where a person has to stop and ask for help.

Key points

  • Observe the path: map steps, roles, systems, and wait time.
  • Capture exceptions: the unusual cases often define the safe boundary.
  • Name the owner: someone must confirm whether the workflow improved.
  • Start with evidence: use real examples, not only wish-list language.

Application

Use discovery before building a support assistant, document workflow, approval agent, or recommendation system. It helps separate a painful, repeatable job from a broad request such as “add AI to operations.”

The output is a shared workflow map and a shortlist of candidate steps for a safe pilot.

Sample · trace one lunch order

At a busy lunch counter, follow one order from the queue to the customer. Notice when staff retype the order, wait for an ingredient check, ask a manager to approve a substitution, and file the receipt. Those observations show where an assistant might help—and where a person must stay in control.
