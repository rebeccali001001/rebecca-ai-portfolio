01

print()

print() displays information in the terminal or console.

Common scenarios

  • check a value
  • show a result
  • debug simple code
  • display text

Syntax

print(value)

Example

print("Hello")

Output:
Hello

Another example

price = 8500
print(price)

Python prints the value stored in price.

02

Comments

Use # to write notes in Python code.

Python ignores comments when the program runs.

Common scenarios

  • explain code
  • leave notes
  • temporarily disable a line while testing

Syntax

# comment

Example

price = 8500  # copper price

# copper price is only a note.

It does not affect the program.

03

Variables

A variable stores a value so you can use it later.

Syntax

variable_name = value

Example

customer = "Apple"
quantity = 10
price = 8500

Three values are stored in three variables.

Common scenarios

  • customer name
  • quantity
  • price
  • order ID
  • status
  • calculation results
04

Assignment =

= assigns a value to a variable.

Example

quantity = 10

Meaning:

Store the value 10 in quantity.

Important: = means assignment.

It does NOT mean “is equal to” in a comparison.

Comparison uses:

==
05

Reassigning Variables

A variable can be given a new value.

quantity = 10
quantity = 20

After the second line:

quantity

contains:

20
06

Multiple Variables

price = 8500
quantity = 10
total = price * quantity

total stores the calculation result.

07

Variable Naming

Good examples

customer_name = "Apple"
order_id = 1001
total_amount = 85000

Avoid

x = "Apple"
a = 1001
abc = 85000

Clear names make code easier to understand.

Rules

  • use letters, numbers, and underscore
  • do not start with a number
  • spaces are not allowed
  • Python keywords cannot be used as variable names
08

Basic Input

input() reads text entered by a user.

Syntax

input("message")

Example

name = input("Enter your name: ")
print(name)

The user's input is stored in name.

Important: input() returns text by default.
