Development & Cloud Platforms

Modern products are often built by combining specialized platforms for code, deployment, backend services, data, and cloud infrastructure.

Beginner platform landscape

Where the platforms fit

DEVELOPER PLATFORM
GitHub · GitLab · BitbucketManage code and collaboration.
↓
WEB / CLOUD PLATFORM
Cloudflare · Vercel · Netlify · Render · RailwayDeploy websites, apps, and services.
↓
BACKEND / DATA PLATFORM
Supabase · Firebase · other managed backend servicesDatabase, auth, storage, and backend capabilities.
↓
MAJOR CLOUD
AWS · Azure · Google CloudProvide broad computing infrastructure.

These categories overlap.

What problem does each category solve?
DEVELOPER PLATFORMS

Manage code and collaboration.

WEB & CLOUD PLATFORMS

Deploy websites / apps / services.

BACKEND & DATA PLATFORMS

Provide database, auth, storage, backend capabilities.

MAJOR CLOUD PLATFORMS

Provide broad computing infrastructure.
