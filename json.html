JSON

A common text format for representing and exchanging structured data.

01

What is it?

JSON is a common text format for representing structured data.

It organizes information using names and values.

JSON is a simple way to structure data.

02

Think of it like...

Think of JSON as a labeled package of information.

Each value has a name.

{
  "name": "Order 1001",
  "status": "Created",
  "amount": 500
}
Label→Value
status→Created
amount→500
03

What does it do?

JSON helps software systems exchange structured data.

It can represent:

Text
Numbers
True / False Values
Lists
Objects
04

Where is it used?

JSON is commonly used in:

API Requests
API Responses
Configuration
Data Files
System Integration
05

Example

Example Response

Do Not Confuse

JSON

A data format.

Database

A system used to store and manage data.

JSON describes data.

A database stores data.
