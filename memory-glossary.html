Memory Glossary

A plain-language guide to the terms used when an AI system stores information, retrieves it, and uses it in a later response.

GlossaryWorking MemoryShort-Term MemoryLong-Term MemoryConversation MemorySemantic MemoryEpisodic MemoryUser MemoryVector Memory

Working Memory

Information actively used while solving the current task.

It is close to the idea of a model’s current working space. In an AI application, it may include the current request, intermediate results, and task state.

Short-Term Memory

Recent information kept for a limited time or interaction.

A recent chat summary or a temporary task variable can act as short-term memory.

Long-Term Memory

Information retained so it can be used across future sessions or tasks.

It may be stored in a database, file store, vector database, or provider-managed memory service. Long-term does not mean permanent or always correct.

Conversation Memory

Past messages, summaries, or facts used to maintain conversational continuity.

A system may keep the full conversation, a summary, selected facts, or a combination.

Semantic Memory

General facts and meanings, not tied to one particular event.

Example: “The user prefers concise explanations.”

Episodic Memory

A specific past event or experience.

Example: “In the previous support case, the user chose the annual plan.”

User Memory

Information associated with a person, account, or team and used for continuity or personalization.

Good systems make user memory visible, editable, permission-aware, and subject to retention rules.

Vector Memory

Stored content or representations that can be found through similarity search.

Vector memory often uses embeddings and a vector database. The retrieved source still needs to be placed into context before the model can use it.
