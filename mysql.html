MODULE 05 · DATABASE & SQL

MySQL

MySQL is a widely used relational database management system that stores and manages structured data using SQL.

01 · What is it?

MySQL is a relational database management system, or DBMS, for storing and managing structured data with SQL.

It organizes data into related tables and lets an application create, read, update, and delete records.

02 · Think of it like…

Think of MySQL as a well-organized set of filing cabinets.

Each table is a cabinet for one kind of record. Rows are individual files, columns describe each file, and SQL is the language used to find or change them.

03 · What does it do?

MySQL gives software a structured place to keep data and a reliable way to work with it.

StoreSave records in tables.
QueryFind records with SQL.
UpdateChange existing data.
RelateConnect data across tables.

04 · Where is it used?

MySQL is common in web applications and business systems that need structured, relational data.

User accountsProfiles, settings, and account status.
OrdersCustomers, products, payments, and order states.
Content platformsPosts, comments, categories, and publishing data.
Business systemsInventory, reporting, and operational records.

05 · Example

Find a customer’s recent orders

An application can ask MySQL to join customer and order data, filter by customer, and return the newest results.

SELECT orders.id, orders.created_at, orders.total
FROM orders
JOIN customers ON customers.id = orders.customer_id
WHERE customers.email = 'alex@example.com'
ORDER BY orders.created_at DESC;

The application receives structured rows and can use them to render an order history.

06 · How it connects

Frontend→API→Backend→SQL Query→MySQL→Response

The backend applies business rules, sends SQL to MySQL, and turns the returned data into a response for the frontend.

07 · Do Not Confuse

MySQL

A database system that stores and manages relational data.

SQL

A language used to work with relational database data.

Table

A structure inside a database that organizes records in rows and columns.

09 · What to Remember

  • MySQL stores structured data in related tables.
  • Applications use SQL to read, add, update, and organize that data.
  • MySQL is the database system; SQL is the language used to work with it.
