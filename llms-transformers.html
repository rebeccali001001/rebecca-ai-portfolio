Key distinctions

Related does not mean interchangeable

Boundary 01
Foundation Model ≠ LLM

An LLM is one language-focused family within the broader foundation-model category.

Boundary 02
Parameter ≠ Token

Parameters are learned internal values; tokens are units of input or output.

Boundary 03
Multimodal Model ≠ LLM

Some multimodal models use language, but not every multimodal model is an LLM.
