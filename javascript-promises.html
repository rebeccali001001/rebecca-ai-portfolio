23 · Promises

A Promise represents a result that will arrive later or fail.

What is it?

Promises

Think of it like...

A delivery tracking card: pending, fulfilled, or rejected.

Basic Syntax

A delivery tracking card: pending, fulfilled, or rejected.

How it works

JavaScript evaluates this feature when the code reaches it. The result can be stored, returned, displayed, or used to decide what happens next.

Simple Example

# similar to a future
fetch("/api/users").then(showUsers).catch(showError);

Real Web Example

// Promises in a web page
console.log("Promises is running");

Common Syntax

then, catch, finally

Common Mistakes

Do not confuse a similar-looking syntax with the same behavior. Read errors carefully and test with a small value first.

Python Comparison

Python

# similar to a future
fetch("/api/users").then(showUsers).catch(showError);

JavaScript

# similar to a future
fetch("/api/users").then(showUsers).catch(showError);

When to use

Use Promises when it makes the intent of your code clearer and smaller.
