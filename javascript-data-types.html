02 · Data Types

Values have different kinds: text, numbers, true/false, and objects.

What is it?

Data Types

Think of it like...

typeof value

Basic Syntax

typeof value

How it works

JavaScript evaluates this feature when the code reaches it. The result can be stored, returned, displayed, or used to decide what happens next.

Simple Example

name = "Rebecca"
const name = "Rebecca";

Real Web Example

// Data Types in a web page
console.log("Data Types is running");

Common Syntax

primitive vs object

Common Mistakes

Do not confuse a similar-looking syntax with the same behavior. Read errors carefully and test with a small value first.

Python Comparison

Python

name = "Rebecca"

JavaScript

const name = "Rebecca";

When to use

Use Data Types when it makes the intent of your code clearer and smaller.
