Parameter

A named input that allows a function, route, or operation to receive data.

On this pageWhat is it?Think of it like...What does it do?Where is it used?ExampleHow it connectsDo Not ConfuseTopic GlossaryWhat to Remember
01 · What is it?

What is it?

A parameter defines a value that code expects to receive.

Parameters allow the same logic to work with different input values.

Simple Definition: A parameter is an input a function or route expects.

02 · Think of it like...

Think of it like...

Think of a form with blank fields.

The structure defines what information is needed. The actual values can change each time.

Form structure
├─ Name field
├─ Amount field
└─ ID field

Values change each time the form is used.

05 · Example

Example

Function:
def get_order(order_id):
    ...

Parameter:
order_id

Call:
get_order(1001)

Argument:
1001
order_id is the named input in the function definition.
1001 is the actual value passed into it.
The same function can work with another order ID.
06 · How it connects

How it connects

Input→Parameter→Function→Logic→Result

The parameter gives a function or route a named place to receive input.

07 · Do Not Confuse

Do Not Confuse

Parameter

The named input in the definition.

Argument

The actual value supplied when calling it.

Parameter: order_id · Argument: 1001

08 · Topic Glossary

Topic Glossary

English Term中文Simple English中文小白理解
Parameter参数A named input expected by code.函数或接口定义时预先声明需要接收的输入。
Argument实参The actual value passed to a parameter.真正调用函数时传进去的具体数据。
Input输入Data provided to an operation.提供给函数或系统处理的数据。
Path Parameter路径参数A value placed inside a URL path.URL 路径中用来标识具体资源的参数。
Query Parameter查询参数A value added to a URL query string.URL 后面用于筛选或控制请求的参数。
Default Value默认值A value used when no other value is supplied.没有传入新值时自动使用的预设值。

What to Remember
