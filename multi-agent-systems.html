What is a Multi-Agent System?

A multi-agent system uses more than one agent to divide, coordinate, or collaborate on a task.

On this page What is it? Think of it like... How it works Real-world examples What it is NOT Related concepts Remember this Video

What is it?

A multi-agent system contains multiple agents that interact while working toward one or more goals.

Agents may have specialized roles, delegate tasks, work in parallel, review one another, or coordinate through shared state. More agents does not automatically mean better.

Think of it like...

Think of it like a project team.

A researcher finds useful information, a writer turns it into a draft, and a reviewer checks the result. Each person has a different role, and they exchange information to complete one deliverable.

How it works

1 · Goal Set the objective Define the shared task and constraints.
2 · Assign Choose roles A coordinator or shared task connects the work.
3 · Work Run agents Agents solve parts of the task, sometimes in parallel.
4 · Exchange Share results Agents pass messages, artifacts, or state to one another.
5 · Review Coordinate output The system combines, checks, and returns the result.

Some systems use decentralized coordination instead of one central coordinator.

Real-world examples

Everyday example · Research and writing

Input: a request for a short report

AI / System: research, writing, and review agents collaborate

Output: a checked draft with sources

Business example · Software development

Input: a feature request

AI / System: planning, coding, testing, and review roles exchange work

Output: a proposed change with test evidence

What it is NOT

Multi-Agent System ≠ One Agent with Many Tools

Multi-agent system: has multiple interacting agent roles or loops.

One agent with tools: has one decision-maker using several capabilities.

Multi-Agent System ≠ Multiple LLM Calls

Multi-agent system: coordinates distinct roles or agents.

Multiple LLM calls: may simply be a sequence without agent interaction.

More Agents ≠ Better Performance

More agents: can add coordination cost, errors, and latency.

Better performance: depends on task fit, communication, and evaluation.
