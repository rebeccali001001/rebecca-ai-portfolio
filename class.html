Class

A reusable name used to group and identify HTML elements.

01 · What is it?

What is it?

A class is a name assigned to one or more HTML elements.

It is commonly used by CSS and JavaScript to work with groups of elements.

Simple Definition: A class is a reusable label for elements.

02 · Think of it like...

Think of it like...

Think of a class as a category label.

Many different items can share the same label.

Class: button ├─ Save Button ├─ Submit Button └─ Delete Button
03 · What does it do?

What does it do?

A class can help:

Apply Shared Styles
Find Elements
Group Elements
Control UI States
Reuse Page Patterns
04 · Where is it used?

Where is it used?

Classes are commonly used in:

HTML
CSS
JavaScript
HTML:

<button class="primary-button">Save</button>

CSS:

.primary-button {
  font-weight: bold;
}

JavaScript:

document.querySelector(".primary-button");
05 · Example

Example

<div class="card active">
  Order 1001
</div>
card
can provide the normal card style.
active
can represent the current state.
One element can have multiple classes.

07 · Do Not Confuse

Class ≠ ID

Class

Can be reused on many elements.

ID

Should identify one specific element on a page.

Class = reusableID = specific
