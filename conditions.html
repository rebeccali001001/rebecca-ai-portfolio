05 · Conditions

Conditions let Python run different code depending on whether something is True or False.

On This PageSimple flowifIndentationelseelifMultiple conditionsNone and valuesNested ifConditional expression

Simple flow

Condition ↓ True? ↓ Run this code
price = 8500

if price > 8000:
    print("High price")

High price

1. if

if runs code only when a condition is True.

Syntax

if condition:
    code

Example

quantity = 20

if quantity > 10:
    print("Large order")

The message is printed only when quantity > 10.

Common scenarios

  • check price
  • check quantity
  • check status
  • check whether data exists
  • validate user input

2. Indentation

Python uses indentation to show which code belongs to an if block.

Correct

if price > 8000:
    print("High price")

Incorrect

if price > 8000:
print("High price")

The line inside the condition must be indented.

3. else

else runs when the if condition is False.

quantity = 5

if quantity >= 10:
    print("Large order")
else:
    print("Small order")

Small order

4. elif

elif checks another condition when the previous condition is False.

if condition1:
    code
elif condition2:
    code
else:
    code
quantity = 60

if quantity >= 100:
    print("Large")
elif quantity >= 50:
    print("Medium")
else:
    print("Small")

Medium

5–7. Multiple conditions

Multiple Conditions with and

Use and when both conditions must be True.

product = "Copper"
quantity = 20

if product == "Copper" and quantity > 10:
    print("Matched")

Matched

Multiple Conditions with or

Use or when at least one condition must be True.

product = "Copper"

if product == "Copper" or product == "Aluminum":
    print("Supported product")

not

not reverses a condition.

is_completed = False

if not is_completed:
    print("Still pending")

8–9. Check values

Check None

if delivery_date is None:
    print("No delivery date")

This checks whether delivery_date has no value.

Check a Value Exists

customer = "Apple"

if customer:
    print("Customer exists")

Non-empty strings are treated as True.

Common examples that are treated as False:

""
0
[]
{}
None
False

10. Nested if

An if statement can be placed inside another if.

product = "Copper"
quantity = 20

if product == "Copper":
    if quantity > 10:
        print("Large Copper order")

Do not overuse nested conditions.

11. Conditional Expression

Also called: ternary expression

A short way to write a simple if / else.

value_if_true if condition else value_if_false
quantity = 20

size = "Large" if quantity >= 10 else "Small"

Large

Use this only for simple conditions.
