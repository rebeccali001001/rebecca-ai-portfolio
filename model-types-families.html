Model Types & Families

AI models can be grouped in different ways: by provider, by model family, by modality, or by what they are designed to do.

Two dimensions, one landscape

Provider / family tells you who builds related models. Model type / capability tells you what information or tasks they handle.

Family ≠ one fixed model. A family can contain different generations, sizes, tiers, or specialized variants.

Types by purpose

Another lens is what a model is optimized to help accomplish.

General-purpose

Broad everyday tasks.

Reasoning

Harder, multi-step problem solving.

Coding

Software work and code transformations.

Embedding

Vectors for search and retrieval.

Image generation

Create or edit visual outputs.

Video generation

Create or transform moving images.

Speech

Transcribe, synthesize, or converse.

One model may belong to several capability categories. This is not a strict mutually exclusive taxonomy.

Foundation model vs LLM vs multimodal model

TermBeginner meaning
Foundation modelA broad model trained for reuse across many tasks.
LLMA language-focused category of foundation model.
Multimodal modelA model that works with multiple information modalities.

Remember: Not every foundation model is an LLM. Not every multimodal model should simply be called an LLM.
