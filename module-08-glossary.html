MODULE 08 · GLOSSARY

Development & Git Glossary

Simple English and Chinese explanations for the concepts that move software from code to release.

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Source Code源代码Human-readable instructions written by developers.开发人员编写和修改的程序代码。
Repository代码仓库A managed location containing project files and history.保存项目文件并管理版本历史的位置。
GitGitA tool used to track changes in source code.用来管理和记录代码版本变化的工具。
GitHubGitHubAn online platform for hosting Git repositories.用于托管 Git 仓库并支持团队协作的在线平台。
Commit提交A recorded set of code changes.一次保存下来的代码修改记录。
Branch分支An independent line of development.可以独立开发的一条代码版本线。
Main主分支The primary shared code line in a repository.代码仓库中通常代表主要成果的共享代码线。
Pull Request合并请求A request to merge changes into another branch.请求把一个分支的代码修改合入另一个分支。
Code Review代码审查Checking proposed code changes before they are merged.代码合并前检查别人提交的修改。
Merge合并Combining changes from different branches.把不同分支的代码修改组合起来。
Conflict冲突A situation where Git cannot automatically combine changes.Git 无法自动判断不同代码修改应该如何合并的情况。
Version版本A specific state of software at a point in time.软件在某个时间点的确定状态。
Release发布版本A version of software prepared for users or deployment.已经准备好用于上线或交付的软件版本。
Build构建Turning source code into a form that can be run or deployed.把源代码处理成可以运行或部署的软件版本。
Dependency依赖Software or code that another program needs.程序运行需要的其他代码、软件包或组件。
Package软件包Bundled code prepared for installation or use.打包好、可以安装或使用的代码集合。
Environment环境A set of systems, settings, and resources where software runs.软件运行所依赖的一组系统、配置和资源。
