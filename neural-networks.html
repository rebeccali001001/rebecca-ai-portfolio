What is a Neural Network?

A neural network is a machine-learning model made of connected layers that transform input into output.

What is it?

A neural network contains connected computational units whose learned parameters transform information through layers.

Neural networks were historically inspired in part by biological neurons, but modern artificial neural networks are mathematical systems, not digital brains.

Think of it like...

A series of adjustable filters.

Input passesthrough several filters.
Each filter transformsthe information.
Training adjuststhose filters so the final output becomes more useful.

How it works

1 · InputReceive data
2 · First LayerTransform signals
3 · Hidden LayersBuild representations
4 · Output LayerProduce a result
5 · PredictionReturn an estimate
6 · Training FeedbackAdjust parameters

Real-world examples

Image Classification

Maps visual patterns in an image to a label such as “cat,” “road,” or “defect.”

Text Classification

Maps text patterns to categories such as topic, sentiment, or spam.

Price Prediction

Maps relevant features to an estimated price or other numeric value.

What it is NOT

Neural Network ≠ Human Brain

It is a mathematical model that learns numerical transformations, not a biological mind.

Neural Network ≠ Deep Learning

Deep learning usually uses neural networks with many layers; the terms are related but not identical.

Neural Network ≠ One Neuron

A network connects many computational units and layers, rather than being a single unit.
