PART I · HOW SOFTWARE WORKS

Client

The side of a software system that sends requests and receives responses.

01

What is it?

A client is the side of a software system that interacts with a server.

It usually sends requests and receives responses.

A client asks a server for data or actions.

02

Think of it like...

Think of a client as a customer at a service counter.

The customer asks for something.

The service staff processes the request and returns a result.

07

Do Not Confuse

Client ≠ Server

Client

Usually sends requests and receives results.

Server

Usually receives requests and processes them.

Client asks.

Server processes.

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Client客户端The side of a system that sends requests to a server.系统中向服务器发送请求的一端。
Server服务器A system that receives requests and provides data or services.接收请求并提供数据或服务的一端。
Request请求A message asking another system for data or an action.向另一个系统发送的取数或执行操作请求。
Response响应A message returned after a request is processed.请求处理完成后返回的数据或结果。
Browser浏览器Software that loads and runs web pages.用来打开、显示并运行网页的软件。
Mobile App移动应用An application designed for mobile devices.为手机或其他移动设备设计的应用程序。
User用户A person or system that uses software.使用软件的人或其他系统。
Input输入Data provided to a software system.用户或其他系统提供给软件的数据。
Output输出Information produced by a software system.软件处理后产生的结果。

What to Remember

  1. A client is the side of a system that interacts with a server.
  2. Clients usually send requests and receive responses.
  3. Browsers, mobile apps, and desktop applications can all act as clients.
