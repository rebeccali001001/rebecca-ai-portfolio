01

Package

A package is reusable Python code that can be installed and imported.

requests
pandas
numpy
fastapi
openpyxl
02–09

pip

pip installs Python packages.

pip install requests
python -m pip install requests
pip list
pip show requests
pip uninstall requests
pip install requests==2.32.0

python -m pip tells the currently selected Python interpreter to run pip. This helps reduce confusion when multiple Python installations exist.

Possible output

Package     Version
requests    2.x.x
pandas      2.x.x

== means install exactly this version.

10–11

requirements.txt

requirements.txt stores packages needed by a project.

requests==2.32.0
pandas==2.2.0
openpyxl==3.1.0

pip install -r requirements.txt
pip freeze
pip freeze > requirements.txt

pip freeze shows installed packages in requirements format.

12–13

Virtual Environment

A virtual environment creates an isolated Python environment for one project.

Project A
↓
its own Python packages

Project B
↓
its own Python packages

The projects do not have to use the same package versions.

Why Use a Virtual Environment

  • keep project dependencies separate
  • avoid package conflicts
  • make projects easier to reproduce
  • avoid changing global Python packages
14

Create venv

python -m venv .venv

Creates a virtual environment folder named .venv.

15–18

Activate and Deactivate

macOS / Linux

source .venv/bin/activate

After activation, the terminal may show:

(.venv)

Windows PowerShell

.venv\Scripts\Activate.ps1

Windows cmd

.venv\Scripts\activate

Activation command depends on the shell.

Deactivate

deactivate

Leaves the current virtual environment.

Which Python Is Running?

which python
where python
import sys
print(sys.executable)

20

ModuleNotFoundError

ModuleNotFoundError:
No module named 'requests'

Common reasons

  • package is not installed
  • package was installed in another virtual environment
  • wrong Python interpreter is running
  • wrong environment is activated

Simple check

python -m pip show requests
