01 · Document Structure

The outer structure every complete HTML document needs.

What is it?

A document is the top-level container a browser parses into a page. Indentation makes nested parent and child elements easier for people to read.

Think of it like: a building envelope: the foundation, metadata room, and visible rooms each have a place.

Basic Syntax

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Example</title>
  </head>
  <body>
    <h1>Hello</h1>
  </body>
</html>

How it works

DOCTYPE enables standards mode. html is the root. head contains document information; body contains rendered content. The browser parses the nested markup and builds a DOM tree.

Common Mistakes

  • Putting visible page content in head.
  • Forgetting closing tags for non-void elements.
  • Using inconsistent indentation that hides nesting.

When to use it

Start every standalone HTML page with this structure. Related concepts: Metadata & Head and Elements & Tags.

Quick Reference

<!DOCTYPE html> · modern HTML; <html lang="en"> · root and page language; <body> · visible content.
