01 · Document Structure

See how HTML separates page information from visible page content.

Opening Tag vs Closing Tag

<p>Hello</p>
<p>Opening tagHelloContent</p>Closing tag

Most HTML elements use an opening tag and a closing tag.
The slash / means the element is closing.

Nested Tags

<head>
  <title>Trading Platform</title>
</head>

<head> → starts the head section
<title> → starts the title element
Trading Platform → content
</title> → closes the title element
</head> → closes the head section

The / in </title> and </head> means “close this element”.

Browser Result

The <title> appears in the browser tab. It is not visible page content.

Visual Structure

Each element has a place and a job inside the document.

HTML Document │ ├── <head> Page information │ └── <title> Browser tab title │ └── <body> Visible page content ├── <h1> Main heading └── <p> Paragraph
<head>Page information
<title>Browser tab title
<body>Visible page content
<h1>Main heading
<p>Paragraph

How it works

The browser reads the nested markup, keeps page information in <head>, and renders the content inside <body> as the page.

Common Mistakes

  • Putting visible page content in <head>.
  • Forgetting closing tags for non-void elements.
  • Using inconsistent indentation that hides nesting.
