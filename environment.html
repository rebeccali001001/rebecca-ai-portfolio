PART VIII · DEVELOPMENT & GIT

Environment

A specific setup in which software is developed, tested, built, or run.

01 · What is it?

An environment is the combination of software, configuration, dependencies, infrastructure, and settings in which an application runs.

Different environments may be used for development, testing, staging, and production.

Simple DefinitionAn environment is the setup where software runs.

02 · Think of it like...

Think of the same application moving through different rooms.

The code may be similar, but each room has different settings and purposes.

07 · Do Not Confuse

Environment

The complete setup where software runs.

Environment Variable

One configuration value supplied inside that environment.

Environment = Complete Setup    ·    Environment Variable = One Configuration Value

08 · Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Environment环境A setup in which software is developed or run.软件开发、测试或运行时所使用的一整套配置和资源。
Development Environment开发环境An environment used to build and change software.开发人员编写、修改和调试软件使用的环境。
Test Environment测试环境An environment used to verify software changes.用来执行测试并验证软件功能的环境。
Production Environment生产环境The live environment used by real users.真实用户实际使用的软件运行环境。
Runtime运行时The software context required to execute an application.程序真正执行时依赖的语言、库和系统环境。
Environment Variable环境变量A configuration value supplied by the environment.由运行环境提供给程序使用的一项配置值。

09 · What to Remember

An environment is the setup where software runs.

Different environments can have different configuration and dependencies.

Development environments should not be confused with production.
