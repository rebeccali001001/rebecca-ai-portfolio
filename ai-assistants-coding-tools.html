03 · The distinction

Assistant vs coding agent vs AI IDE

AI ASSISTANT

General-purpose help for writing, research, files, questions, and analysis.

Example: ChatGPT
CODING AGENT / TOOL

Repository context, file edits, commands, tests, and review.

Example: Codex or Claude Code
AI IDE / DEVELOPMENT ENVIRONMENT

A coding workspace with AI integrated into the editor workflow.

Example: Cursor or Windsurf

These are useful categories, not sealed boxes. Real products increasingly combine chat, autocomplete, agent loops, editors, terminals, and human approval.

05 · How to choose

Start with your work surface

I want general AI help→ Choose an AI assistant
I mainly work inside an editor→ Choose an AI development environment
I want terminal or repository workflows→ Choose a coding agent
I want lightweight coding suggestions→ Choose a coding assistant

There is no universal winner. Fit depends on your context, permissions, review habits, editor, repository, and comfort with automation.
