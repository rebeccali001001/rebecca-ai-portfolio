What Is an API?

An API is an interface that lets one software system request data or actions from another software system.

In AI systems, applications often use APIs to send model requests and receive responses.

Request and response

REQUEST may contain

model · prompt · messages · settings · tool definitions

RESPONSE may contain

text · structured data · tool request · error · usage metadata

Conceptual categories, not a specific vendor schema.

API vs Model

API

Communication interface.

MODEL

AI system component that performs inference.

App→API→Serving→Runtime→Model

Local API vs Cloud API

LOCAL API

Application talks to a locally hosted service, such as a localhost service.

CLOUD API

Application talks to a remote provider.

The interface concept is the same. The location differs.

API vs Tool Calling

API

General software interface.

Tool Calling

AI pattern where a model requests a tool or function.

A tool may itself use an API.

API vs MCP

API

Specific software interface.

MCP

Standardized protocol for connecting AI applications to tools and resources.

MCP may sit above or alongside APIs, but they are not interchangeable concepts.

Why APIs matter

Without an API, an AI service is isolated.

With an API, a Web App, Mobile App, Excel workflow, Agent, or Backend can all call the AI service.

Remember this

An API is the interface applications use to communicate with an AI service or other software system.
