PART I · HOW SOFTWARE WORKS

API

A way for different parts of software to communicate.

01 · What is it?

An API is a way for different parts of software to communicate.

It defines how one system can request data or actions from another.

Simple Definition：
API is a communication interface between software systems.

02 · Think of it like...

Think of an API like a waiter.

You send a request.

The waiter takes it to the kitchen.

The waiter brings the result back.

03 · What does it do?

An API lets one system request data or actions from another system.

Get Data
Send Data
Create Data
Update Data
Trigger Actions

04 · Where is it used?

APIs connect frontend and backend systems, mobile apps and servers, and different software services.

Frontend ↔ Backend
Mobile App ↔ Server
Service ↔ Service
System ↔ External System

05 · Example

GET /api/orders

asks the system for order data.

POST /api/orders

asks the system to create a new order.

06 · How it connects

Frontend→Request→API→Backend→Response→Frontend

The API sits between software components and defines how they communicate.

07 · Do Not Confuse

API

Provides a defined way to communicate with software.

Backend

Contains the logic that processes the request.

API is the access point.
Backend is the processing behind it.

09 · What to Remember

APIs allow software parts to communicate.

APIs receive requests and return responses.

APIs often connect frontend applications with backend services.
