Failure Modes

Reliable AI products make failure visible, classifiable, and recoverable instead of treating every wrong answer as a mysterious model problem.

Detail

FailureSignalResponse
Grounding missAnswer lacks supporting evidenceRetrieve again, cite sources, or abstain
Schema driftInvalid or incomplete structured outputValidate, repair once, then escalate
Tool errorTimeout, permission denial, bad argumentsRetry safely or return an actionable error
Context overloadLatency rises or instructions are ignoredSummarize, trim, or split the task

Sample

If a pricing assistant cannot retrieve the current policy, it should say what is missing and route the question to an operator—not invent a confident exception.

Operating principle

Every failure class needs an owner, a detector, and a safe next action.
