03 · Tokens, Context & Inference

What are tokens per second?

Tokens per second (TPS) is the rate at which a model produces output tokens after generation begins.

Definition

TPS is output throughput: the number of generated tokens divided by the time spent generating them.

In plain language

It is the robot’s writing speed after it has started. A fast writer can still feel slow if the café takes a long time before saying “Got it,” so TPS and latency should be measured separately.

Key points

  • TPS usually describes generation, not the initial prompt-reading wait.
  • Longer context, model size, hardware, batching, and sampling can change the rate.
  • Higher TPS is useful only if quality and correctness remain acceptable.
tokens per second = generated output tokens ÷ generation seconds

Sample: how fast can it write?

Once the robot acknowledges “one oat latte,” TPS describes how quickly it writes the rest of the confirmation. It does not tell you how long you waited before that first acknowledgement.

Where it matters

TPS matters for interactive chat, local model selection, voice or coding experiences, and capacity planning. Compare it under the same prompt, output length, hardware, and concurrency.

A benchmark number without its prompt, hardware, batch, and load is not a reliable product promise.
