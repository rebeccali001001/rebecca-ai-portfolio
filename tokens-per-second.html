What are Tokens per Second?

Tokens per second is a throughput measure: how many tokens a model generates in one second under a defined workload.

Topic detail

It is usually a decode-speed metric for output generation. Prompt processing speed, time to first token, and steady-state output speed are related but distinct. The exact number depends on model, hardware, context, batch size, sampling, and runtime.

A higher tokens-per-second number is useful only if quality and the full user experience still pass.

Why it matters

Throughput helps compare local runtimes, hardware choices, and concurrency plans. But it should be paired with first-token time, memory use, quality, and cost rather than treated as a single performance score.

generation rate = output tokens ÷ generation seconds

Sample

The same local model may generate 18 output tokens per second on a short prompt and 11 on a long context. That is a workload difference, not necessarily a model change.
