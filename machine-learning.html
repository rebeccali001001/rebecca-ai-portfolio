What is Machine Learning?

Machine Learning is a way to build systems that learn patterns from data and use those patterns to make predictions or decisions.

Detail

Instead of writing every rule by hand, we provide examples and a learning algorithm finds useful relationships.

Data → training → learned pattern → prediction

Key takeaway

Machine learning learns from examples, then applies learned patterns to new inputs.

Sample

Train on historical invoices labeled “valid” or “needs review,” then predict the label for a new invoice.

Input
Invoice data
Learn
Find patterns
Output
Risk score
