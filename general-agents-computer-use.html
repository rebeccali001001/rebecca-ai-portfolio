General Agents & Computer Use

General AI agents go beyond answering questions by planning steps, using tools, interacting with software, and carrying tasks through to completion.

Core: answer

→

These are useful mental models, not rigid categories. Real products often combine assistant and agent capabilities.

Product landscape

General agent products

A compact map of products that turn a broad request into a multi-step workflow. Product boundaries and features change over time.

OPENAI

ChatGPT Work

What it is: a work-oriented environment for longer, multi-step tasks and finished deliverables.

Typical workflow: give a goal → work across context and files → review the result.

Capability style: workspace orchestration, files, tools, and—when permitted—desktop context.

MANUS

Manus

What it is: a general-purpose agent product built around delegated tasks and deliverables.

Typical workflow: describe an outcome → agent researches, structures, and produces an artifact.

Capability style: multi-step task execution, web research, and artifact creation.

OPEN SOURCE / COMMUNITY

OpenClaw

What it is: an emerging general-agent project name used for an extensible, self-directed assistant pattern.

Typical workflow: configure an agent and tools → delegate a task → inspect actions and output.

Capability style: extensibility and tool-connected automation; exact packaging depends on the deployment.

TENCENT

WorkBuddy

What it is: an agentic AI product for office work and ready-to-use work outputs.

Typical workflow: issue a natural-language instruction → agent plans across office context → receive a document, sheet, or presentation.

Capability style: office tools, files, connectors, and multi-step output generation.

Capability, not a product category

What is Computer Use?

Computer Use is a capability where an AI system interacts with a graphical interface in a way similar to a user.

AGENT
↓
SEE SCREEN
↓
CLICK / TYPE / NAVIGATE
↓
OBSERVE RESULT
↓
CONTINUE

Computer Use can support a browser agent, a desktop agent, or another product depending on the environment and permissions. It is not one fixed company or app.

Two common environments

Browser Agent vs Desktop Agent

BROWSER AGENT

Web interfaces

Works mainly in websites and browser interfaces: open pages, navigate, enter information, and read results.

DESKTOP AGENT

Local GUI

Works across desktop software and local graphical interfaces, subject to the operating system and app permissions.

COMPUTER USE

Broader capability

A general interaction capability that may support either environment depending on the product.

Interfaces matter

Why control matters

More action capability requires more control.

PermissionsLimit what systems and data the agent can reach.
Human ApprovalPause before sensitive or irreversible actions.
ValidationCheck inputs, outputs, and state changes.
LoggingKeep a trace of actions and results.

Remember this

General AI agents use models, tools, and interaction capabilities to carry out multi-step tasks rather than only generating answers.

A product is the application. Computer Use is one capability that an application may provide.
