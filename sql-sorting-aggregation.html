01

Sorting

Sorting controls the order in which rows appear in a query result.

ORDER BY

ORDER BY sorts query results using one or more columns.

Syntax

SELECT columns
FROM table_name
ORDER BY column_name;

Example 1

SELECT order_id, product, price
FROM orders
ORDER BY price;

What it means

Sort the orders by price from low to high.

Output

1002 | Aluminum | 2450 1005 | Aluminum | 2500 1001 | Copper | 8500 1004 | Copper | 8700 1003 | Nickel | 16000

Explain

Ascending order is the default.

Example 2

SELECT customer, quantity
FROM orders
ORDER BY quantity;

Output

10 20 25 35 50

ASC

ASC means ascending order.

Numbers go from smaller to larger. Text goes in ascending alphabetical order.

Syntax

ORDER BY column_name ASC

Example

SELECT order_id, quantity
FROM orders
ORDER BY quantity ASC;

Output

1003 | 10 1001 | 20 1005 | 25 1004 | 35 1002 | 50

Key point

ASC is usually the default sorting direction.

DESC

DESC means descending order.

Example 1

SELECT order_id, price
FROM orders
ORDER BY price DESC;

Output

1003 | 16000 1004 | 8700 1001 | 8500 1005 | 2500 1002 | 2450

Example 2

SELECT order_id, quantity
FROM orders
ORDER BY quantity DESC;

Output

50 35 25 20 10

Multiple-Column Sorting

SQL can sort by more than one column.

Syntax

ORDER BY column1 ASC, column2 DESC

Example

SELECT product, order_id, quantity
FROM orders
ORDER BY product ASC, quantity DESC;

What it means

First sort by product. For rows with the same product, sort quantity from high to low.

Output

Aluminum | 1002 | 50 Aluminum | 1005 | 25 Copper | 1004 | 35 Copper | 1001 | 20 Nickel | 1003 | 10
02

Aggregate Functions

Aggregate functions calculate one summary value from multiple rows.

COUNT(*)

COUNT(*) counts rows.

Example

SELECT COUNT(*)
FROM orders;

Output

5

Explain

The orders table contains five rows.

COUNT(column)

COUNT(column) counts non-NULL values in a column.

Example

SELECT COUNT(delivery_date)
FROM orders;

If 3 rows have delivery dates:

3

Rows where delivery_date is NULL are not counted.

COUNT(DISTINCT ...)

COUNT(DISTINCT column) counts unique non-NULL values.

Example

SELECT COUNT(DISTINCT product)
FROM orders;

Products

Copper Aluminum Nickel

Output

3

SUM()

SUM adds numeric values together.

Example

SELECT SUM(quantity)
FROM orders;

Calculation

20 + 50 + 10 + 35 + 25

Output

140

The total quantity across all five orders is 140.

AVG()

AVG calculates the average of numeric values.

Example

SELECT AVG(quantity)
FROM orders;

Calculation

140 / 5

Output

28

MIN()

MIN returns the smallest value.

Example

SELECT MIN(price)
FROM orders;

Output

2450

MAX()

MAX returns the largest value.

Example

SELECT MAX(price)
FROM orders;

Output

16000
03

GROUP BY

GROUP BY combines rows that share the same value so aggregate calculations can be performed for each group.

GROUP BY

GROUP BY creates groups of rows that share the same value.

It is commonly used with aggregate functions such as COUNT, SUM, AVG, MIN, and MAX.

Syntax

SELECT group_column, aggregate_function(column)
FROM table_name
GROUP BY group_column;

Example 1

SELECT product,
       SUM(quantity) AS total_quantity
FROM orders
GROUP BY product;

What it means

Create one group for each product and calculate total quantity inside each group.

Output

producttotal_quantity
Aluminum75
Copper55
Nickel10

The five original rows become three grouped result rows.

Example 2

SELECT product,
       COUNT(*) AS order_count
FROM orders
GROUP BY product;

Output

Aluminum | 2 Copper | 2 Nickel | 1

Multiple GROUP BY Columns

SQL can group rows using more than one column.

Example

SELECT customer, product, COUNT(*) AS order_count
FROM orders
GROUP BY customer, product;

Rows are grouped by each unique customer + product combination.

Output

ABC Metals | Copper | 1 Global Trade | Aluminum | 1 Eastern Metals | Nickel | 1 Apple Resources | Copper | 1 Pacific Metals | Aluminum | 1

Aggregate with GROUP BY

Example

SELECT product,
       SUM(quantity) AS total_quantity,
       AVG(price) AS average_price
FROM orders
GROUP BY product;

Output

producttotal_quantityaverage_price
Aluminum752475
Copper558600
Nickel1016000

GROUP BY defines the groups. Aggregate functions calculate values for each group.

04

HAVING

HAVING filters grouped or aggregated results.

HAVING

HAVING applies a condition after GROUP BY has created groups.

Syntax

SELECT group_column,
       aggregate_function(column)
FROM table_name
GROUP BY group_column
HAVING aggregate_condition;

Example 1

SELECT product,
       SUM(quantity) AS total_quantity
FROM orders
GROUP BY product
HAVING SUM(quantity) > 50;

Output

Aluminum | 75 Copper | 55

Nickel is removed because its total quantity is only 10.

Example 2

SELECT product,
       COUNT(*) AS order_count
FROM orders
GROUP BY product
HAVING COUNT(*) >= 2;

Output

Aluminum | 2 Copper | 2

WHERE vs HAVING

WHERE

Filters individual rows before grouping.

WHERE status = 'Completed'

HAVING

Filters groups after aggregation.

HAVING SUM(quantity) > 50

Complete query

SELECT product,
       SUM(quantity) AS total_quantity
FROM orders
WHERE status = 'Completed'
GROUP BY product
HAVING SUM(quantity) > 30
ORDER BY total_quantity DESC;
WHERE → keeps only Completed rows GROUP BY → creates product groups SUM → calculates total quantity HAVING → removes groups below the threshold ORDER BY → sorts the final result

Output

Copper | 55
