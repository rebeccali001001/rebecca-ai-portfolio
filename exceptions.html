13 · Exceptions

Handle errors so Python programs can respond safely.

Exceptions are errors that happen while a Python program is running.

number = int("abc")

This causes:

ValueError

Exception handling lets the program respond to errors instead of stopping immediately.

1. try

Put code that may fail inside try.

try:
    code

A try block is normally followed by except.

2. except

except handles an error.

try:
    quantity = int("abc")
except:
    print("Invalid quantity")

Output:

Invalid quantity

3. Catch a Specific Exception

Only handles ValueError.

try:
    quantity = int("abc")
except ValueError:
    print("Invalid quantity")

This is better than catching every possible error.

4. ValueError

quantity = int("abc")

Error:

ValueError

Handling:

try:
    quantity = int("abc")
except ValueError:
    print("Quantity must be a number")

5. ZeroDivisionError

result = 10 / 0

Error:

ZeroDivisionError

Handling:

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")

6. KeyError

order = {
    "product": "Copper"
}

print(order["customer"])

Error:

KeyError

Safer option:

customer = order.get("customer")

Or handle it:

try:
    customer = order["customer"]
except KeyError:
    print("Customer not found")

7. IndexError

products = ["Copper", "Aluminum"]

print(products[5])

Error:

IndexError

8. FileNotFoundError

open("missing.txt", "r")

May cause:

FileNotFoundError

Handling:

try:
    with open("missing.txt", "r") as file:
        content = file.read()
except FileNotFoundError:
    print("File not found")

9. Multiple except Blocks

try:
    value = int(user_input)
    result = 100 / value

except ValueError:
    print("Please enter a number")

except ZeroDivisionError:
    print("Number cannot be zero")

Different errors can have different responses.

10. else

else runs when no exception occurs.

try:
    quantity = int("10")

except ValueError:
    print("Invalid quantity")

else:
    print("Quantity is valid")

Output:

Quantity is valid

11. finally

finally runs whether an error happens or not.

try:
    print("Processing order")

except Exception:
    print("Something went wrong")

finally:
    print("Finished")

Common uses:

  • cleanup
  • close resources
  • final logging

12. Get the Error Message

try:
    quantity = int("abc")

except ValueError as error:
    print(error)

error contains information about what went wrong.

13. Exception

Exception is a general exception type.

try:
    do_something()

except Exception as error:
    print(error)

Prefer specific exception types when you know which errors are expected.

14. raise

raise creates an exception intentionally.

quantity = -5

if quantity < 0:
    raise ValueError(
        "Quantity cannot be negative"
    )

15. raise Inside a Function

def calculate_total(price, quantity):

    if quantity < 0:
        raise ValueError(
            "Quantity cannot be negative"
        )

    return price * quantity

The function rejects invalid data.

16. Practical Example

def calculate_total(
    price_text,
    quantity_text
):

    try:
        price = float(price_text)
        quantity = int(quantity_text)

        return price * quantity

    except ValueError:
        return None

Call:

result = calculate_total(
    "8500",
    "10"
)

print(result)

Output:

85000.0

Invalid example:

result = calculate_total(
    "ABC",
    "10"
)

Result:

None

The function safely handles invalid numeric input.

17. Common Pattern

try:
    risky_operation()

except SpecificError as error:
    print(error)

else:
    print("Success")

finally:
    print("Finished")
