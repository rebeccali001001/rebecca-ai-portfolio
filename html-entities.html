15 · HTML Entities

Write reserved characters as text instead of accidental markup.

What is it?

An HTML entity is an escaped representation of a character. Think of it like: a safe spelling for characters the browser normally reads as syntax.

Basic Syntax

&lt;  displays <
&gt;  displays >
&amp; displays &
&quot; displays "
&nbsp; displays a non-breaking space

How it works

Characters such as < start HTML tags, so writing them as content needs an escape such as &lt;.

Common Mistakes

Do not use &nbsp; to force layout spacing; use CSS. Escape content correctly when displaying code examples.

Quick Reference

&lt; less-than · &gt; greater-than · &amp; ampersand · &quot; quote.
