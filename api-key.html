MODULE 06 · AUTHENTICATION & SECURITY

API Key

A credential that identifies a software client and helps control access to an API.

01 · What is it?

An API key is a value that a client sends with an API request so the API can identify the caller and decide whether to accept the request.

The server checks the key before it provides data or performs an action.

Simple Definition:
An API key is a credential used to identify and control an API caller.

02 · Think of it like...

Think of an API key like an access card for a building.

The card tells the entrance system which visitor is arriving.

The system checks the card before opening a door.

A valid card may still open only the doors that its access rules allow.

03 · What does it do?

An API key gives an API a practical way to recognize a client and apply access controls.

Identify the Caller

Associate a request with an application, project, or integration.

Control Access

Allow or reject requests based on the key and its rules.

Apply Limits

Connect usage quotas and rate limits to a client.

Revoke Access

Disable a key without changing the whole API.

04 · Where is it used?

API keys are common when a software client needs access to an API without an interactive user login.

Server to ServerBackend integrations

One service calls another service.

Developer ToolsCLI and SDK access

A developer tool calls a platform API.

External ServicesThird-party integrations

An application connects to a provider.

Public ClientsRestricted browser keys

A key may be exposed only when the provider limits its permissions and allowed origins.

05 · Example

GET /v1/weather
Host: api.example.com
X-API-Key: sk_live_example_key

The client includes the key in a request header. The API checks the key, applies its access rules, and then returns a response or an error.

The example key is fictional. Real keys should be stored securely and rotated when exposure is suspected.

06 · How it connects

Client→Request→API Key→API Gateway→Service→Response

The API key travels with the request; the API gateway or service validates it before access is granted.

07 · Do Not Confuse

API Key

Usually identifies a client, project, or integration when it calls an API.

Password

Usually helps a user prove knowledge of a secret during sign-in.

Access Token

Usually represents granted access for a user or service for a limited time or scope.

An API key is a credential, not proof that every caller or every action is allowed.

09 · What to Remember

An API key is a credential that helps an API identify a client and enforce access rules.

Keep API keys private, limit what they can access, and rotate or revoke them when needed.
