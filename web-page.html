PART II · FRONTEND & BROWSER

Web Page

A document displayed in a browser as part of a website or web application.

01 · What is it?

A web page is a document that a browser loads and displays.

It can contain text, images, forms, buttons, links, and interactive features.

Simple Definition: A web page is one screen of content shown in a browser.

02 · Think of it like...

Think of a website as a book.

A web page is one page inside that book.

Website │ ├─ Home Page ├─ Product Page ├─ Order Page └─ Contact Page

03 · What does it do?

A web page presents information and gives users ways to interact with a web application.

Show Content
Collect Input
Provide Navigation
Trigger Actions
Display Results

04 · Where is it used?

Web pages are used throughout websites and browser-based applications.

Home Page
Login Page
Search Page
Order Page
Dashboard
Settings Page

05 · Example

An Order Page

The page may contain:

Order Number

Browser→Order Page→User Action→Application

06 · How it connects

HTML→Page StructureCSS→Page StyleJavaScript→Page BehaviorAll three→Web Page

A web page combines structure, style, and behavior inside the browser.

07 · Do Not Confuse

Web Page

One document or screen.

Website

A collection of related web pages.

One page is part of a website.

08 · Topic Glossary

English Term中文Simple English中文小白理解
Web Page网页A document displayed in a browser.浏览器中显示的一张网页。
Website网站A collection of related web pages.由多张相关网页组成的网站。
Browser浏览器Software that displays web pages.用来打开和显示网页的软件。
HTML超文本标记语言The language used to define page structure.用来定义网页结构的语言。
CSS层叠样式表The language used to control page appearance.用来控制网页样式和布局的语言。
JavaScriptJavaScriptA language used to add interaction and behavior.用来给网页增加交互和行为的语言。
Link链接A clickable connection to another page or resource.点击后可以跳转到其他页面或资源的连接。
Form表单A group of controls used to collect user input.用来收集用户输入的一组控件。
Button按钮A control users click to trigger an action.用户点击后触发操作的控件。
Content内容Information displayed on a page.网页中展示给用户的信息。

09 · What to Remember

A web page is one document shown inside a browser.

HTML provides structure.

CSS controls appearance.

JavaScript adds interaction.

HTML + CSS + JavaScript→Web Page
