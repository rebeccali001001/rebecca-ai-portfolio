Python Language & Syntax

06 · Loops

Loops repeat code.

Common uses

process many orders · go through API results · read list items · repeat a task · process rows in data

1. for

for runs code once for each item in a collection.

for item in collection:
    code
products = ["Copper", "Aluminum", "Nickel"]

for product in products:
    print(product)

Output

Copper
Aluminum
Nickel

2. Loop Through a List

orders = [1001, 1002, 1003]

for order_id in orders:
    print(order_id)

Python processes one item at a time.

3. range()

range() creates a sequence of numbers.

for i in range(5):
    print(i)

Output

0
1
2
3
4

Important: range(5) starts at 0 and stops before 5.

4. range(start, stop)

for i in range(1, 6):
    print(i)

Output

1
2
3
4
5

5. range(start, stop, step)

for i in range(0, 10, 2):
    print(i)

Output

0
2
4
6
8

6. while

while keeps running while a condition is True.

while condition:
    code
count = 1

while count <= 3:
    print(count)
    count = count + 1

Output

1
2
3

Important: The condition must eventually become False. Otherwise the loop may continue forever.

7. break

break stops a loop immediately.

products = ["Copper", "Aluminum", "Nickel"]

for product in products:
    if product == "Aluminum":
        break

    print(product)

Output

Copper

8. continue

continue skips the current loop item and moves to the next one.

products = ["Copper", "Aluminum", "Nickel"]

for product in products:
    if product == "Aluminum":
        continue

    print(product)

Output

Copper
Nickel

9. pass

pass means: do nothing for now.

for product in products:
    if product == "Copper":
        pass

Common scenario: Temporary placeholder while writing code.

10. enumerate()

enumerate() gives both index and value.

products = ["Copper", "Aluminum", "Nickel"]

for index, product in enumerate(products):
    print(index, product)

Output

0 Copper
1 Aluminum
2 Nickel

11. enumerate(..., start=1)

for index, product in enumerate(products, start=1):
    print(index, product)

Output

1 Copper
2 Aluminum
3 Nickel

12. zip()

zip() combines items from multiple collections.

products = ["Copper", "Aluminum"]
prices = [8500, 2300]

for product, price in zip(products, prices):
    print(product, price)

Output

Copper 8500
Aluminum 2300

13. Loop Through Dictionary

order = {
    "customer": "Apple",
    "product": "Copper",
    "quantity": 10
}

for key, value in order.items():
    print(key, value)

.items() returns dictionary keys and values.

14. Nested Loop

products = ["Copper", "Aluminum"]
regions = ["US", "CN"]

for product in products:
    for region in regions:
        print(product, region)
