PART III · HTTP & APIs

API

A defined interface that allows software systems to exchange data and actions.

01 · What is it?

What is it?

API stands for Application Programming Interface.

An API defines how one software system can request data or actions from another.

Simple Definition：
An API is a defined way for software systems to communicate.

02 · Think of it like...

Think of it like...

Think of an API as a service menu.

The menu tells you:

What you can request
How to request it
What information you must provide
What result you can expect

Software version：

Client→API→Service
03 · What does it do?

What does it do?

An API can allow software to:

Get Data
Create Data
Update Data
Delete Data
Trigger Actions
Connect Systems
04 · Where is it used?

Where is it used?

APIs are used between:

Frontend and Backend
Mobile App and Server
Internal Services
Business Systems
External Platforms
Cloud Services
05 · Example

Example

GET /api/orders

Purpose：
Retrieve orders.

POST /api/orders

Purpose：
Create a new order.

The method describes the action.
The endpoint identifies the API resource.

06 · How it connects

How it connects

Client→HTTP Request→API Endpoint→Backend→HTTP Response→Client

The API defines the available interface.
HTTP commonly carries the request and response.

07 · Do Not Confuse

Do Not Confuse

API

A collection of defined functions or resources available to other software.

Endpoint

One specific access point inside an API.

API = The interface
Endpoint = One address inside the interface

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解

What to Remember

An API usually contains multiple endpoints.

Web APIs commonly use HTTP requests and responses.
