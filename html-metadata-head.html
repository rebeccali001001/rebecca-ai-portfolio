11 · Metadata & Head

Describe the document and attach resources without adding visible body content.

What is it?

The head holds information for browsers, search tools, and integrations. Think of it like: a cover sheet for a document.

Basic Syntax

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="description" content="A short page description.">
  <title>Page title</title>
  <link rel="icon" href="favicon.svg">
</head>

Key Syntax

title names the browser tab. meta provides charset, viewport, description, and social metadata. link attaches stylesheets and icons. script loads JavaScript. Open Graph metadata gives social previews basic title, image, and description information.

Common Mistakes

Head content usually does not appear in the page body. Do not forget the viewport meta tag on responsive pages.

Quick Reference

title tab label · meta charset encoding · meta viewport mobile layout · link resource.
