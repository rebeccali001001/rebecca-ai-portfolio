PART III · HTTP & APIs

REST API

A common way to design APIs around resources and HTTP methods.

01 · What is it?

A REST API is a common style for designing web APIs.

It usually represents business data as resources and uses HTTP methods to perform actions on those resources.

Simple Definition：
A REST API organizes API operations around resources.

02 · Think of it like...

Think of an API resource as a collection of business objects.

Orders

Customers

Products

Each resource has an address and common actions.

OrdersA collection of business objects
→
Common actions
  • Get Orders
  • Create Order
  • Update Order
  • Delete Order

03 · What does it do?

A REST API commonly uses these HTTP methods to work with resources.

GETRetrieve
POSTCreate
PUTReplace
PATCHPartially update
DELETERemove

04 · Where is it used?

REST APIs are commonly used in:

Web Applications
Mobile Applications
Business Systems
Cloud Services
System Integrations

05 · Example

GET /api/orders

Retrieve orders.

GET /api/orders/1001

Retrieve one order.

POST /api/orders

Create an order.

PATCH /api/orders/1001

Update part of an order.

DELETE /api/orders/1001

Delete an order.

These examples show the design pattern. They are not implementation code.

06 · How it connects

Resource→Endpoint→HTTP Method→Backend Action
Orders→/api/orders→POST→Create Order

REST APIs combine resource-oriented URLs with HTTP methods.

07 · Do Not Confuse

API

The broader concept of a software interface.

REST API

One common way to design a web API.

REST is an API design style.
Not every API is REST.

09 · What to Remember

REST API is one common API design style.

REST APIs organize operations around resources.

HTTP methods describe what action should be performed.

Final：
Resource + Endpoint + HTTP Method = REST API Operation
