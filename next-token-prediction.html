What Is Next-token Prediction?

During generation, a language model repeatedly estimates which token could come next.

It does not write the whole response at once.

On this pageWhat is it?Think of it like...How it worksPrediction vs SamplingTemperatureMini exampleWhat it is NOTRelated conceptsRemember thisVideo

What is it?

Next-token prediction is the model’s repeated estimate of what token could come next.

The model reads the available context, scores possible continuations, forms a probability distribution, and then selects one token. That new token becomes part of the context for the next step.

The final response emerges from many small prediction-and-selection steps.

Think of it like...

Autocomplete repeated many times.

Imagine writing: “I would like a cup of ...” Possible continuations might include coffee, tea, or water. The model selects one token, adds it to the text, and predicts again.

This analogy is simplified. A language model uses learned probability patterns across the full available context.

Five steps, one token at a time

01READ CONTEXTThe model reads the tokens currently available.
02CALCULATE SCORESIt evaluates possible next tokens.
03FORM PROBABILITIESScores become a next-token distribution.
04SELECT ONE TOKENA decoding rule chooses one token.
05ADD AND REPEATThe sequence grows and the loop starts again.

Prediction vs Sampling

PREDICTION

Which tokens are plausible next?

Output: scores or probabilities for many possible tokens.

SAMPLING

Which token is selected this time?

Output: one chosen token.

Core difference: Prediction scores possibilities. Sampling chooses one.

Temperature

Temperature changes the token-selection distribution.

LOWER TEMPERATUREMore conservative distributionMore predictable token choices
HIGHER TEMPERATURELower-probability choices can become more competitiveMore variation in selection

What it is NOT

Prediction ≠ Sampling

Prediction: scores possibilities.

Sampling: selects one token.

Prediction ≠ Training

Prediction: used during inference.

Training: updates model parameters.

One step ≠ Full answer

Next-token prediction: one step.

Final response: emerges from repeated generation.
