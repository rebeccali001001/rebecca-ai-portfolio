PART III · HTTP & APIs

Method

The part of an HTTP request that describes what action should be performed.

01 · What is it?

What is it?

An HTTP method tells the server what type of action the client wants to perform.

Common methods include GET, POST, PUT, PATCH, and DELETE.

Simple Definition: A method tells the API what kind of action you want.

02 · Think of it like...

Think of it like...

05 · Example

Example

GET /api/orders

Retrieve orders.

POST /api/orders

Create an order.

PATCH /api/orders/1001

Update part of an order.

DELETE /api/orders/1001

Delete an order.

The endpoint may stay similar while the method changes the requested action.

06 · How it connects

How it connects

Client→HTTP Method→Endpoint→Backend Route→Action→Response

The method and endpoint work together to describe an API request.

07 · Do Not Confuse

Do Not Confuse

Method

Describes the requested action.

Endpoint

Identifies where the request should go.

Method = What to do
Endpoint = Where to do it
