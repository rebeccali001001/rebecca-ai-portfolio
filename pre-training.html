What is Pre-training?

Pre-training is the broad first phase where a model learns language patterns from a large, diverse corpus before it is adapted to a specific use case.

Easy analogy

Pre-training is like reading a vast library and practicing missing-word prediction until broad language patterns emerge.

Analogy video

Definition

A language model sees many sequences and learns to predict a missing or next token. The error updates the parameters through repeated optimization.

broad data + next-token learning → a general-purpose base model

In plain English

Imagine a student reading many books and practicing fill-in-the-blank again and again. Each small exercise builds a wider sense of language.

Key points

Corpus
Curated and filtered text sequences
Objective
Predict the next token
Checkpoint
Reusable base model

Sample

Given “The trader closed the position because it was ___,” a pre-trained model learns to assign higher probability to plausible continuations such as “risky.” Repeated across many examples, this creates broad representations.

Where it shows up

Choosing a base model, understanding domain coverage, estimating adaptation work, and setting expectations for capability, cost, and context behavior.
