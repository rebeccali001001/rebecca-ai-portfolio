What Is Text Generation?

Text generation is the process of using an AI model to create new text from a prompt or other context. Modern language models usually generate text one token at a time.

Core idea

Text generation builds a response one selected token at a time.

PROMPT ↓ CONTEXT System instructions + User request + Other relevant information ↓ LANGUAGE MODEL → NEXT-TOKEN PREDICTION → TOKEN SELECTED ↓ ADD TO OUTPUT → REPEAT ↺ ↓ FINAL TEXT

This connects to Module 05’s Next-token Prediction concept without repeating that page: prediction is one step; generation is the repeated loop.

Think of it like...

Building a sentence one piece at a time.

“AI can help us ...”

Possible continuation: understand · analyze · create

Then the model selects one token and continues with the next part.

This analogy is simplified. Real generation depends on learned probabilities across the available context.

One simple example

INPUT

“Write one sentence about the ocean.”

MODEL GENERATION

The → ocean → covers → most → of → Earth → ...

FINAL OUTPUT

“The ocean covers most of Earth’s surface.”

The exact generated text can vary.

How text generation works

01Read prompt and context
02Run inference
03Predict possible next tokens
04Select a token
05Add it and repeat

This loop continues until the response ends.

Text Generation vs related concepts

Next-token Prediction

One internal generation step: What token could come next?

Text Generation: The full repeated process that produces a complete response.

LLM

LLM: A type of model focused on language.

Text Generation: A capability or task performed using a model.

Generative AI

Generative AI: A broad capability area that creates new content, including text, image, audio, video, or code.

Text Generation: One specific generative capability.

Code Generation

Text Generation: Natural-language text such as summaries, emails, and answers.

Code Generation: Source code or code-like output such as Python, JavaScript, or SQL.

Next-token Prediction = one step Text Generation = the whole repeated process LLM = model Text Generation = what the model can do

What changes the output?

SAME MODEL │ ├─ PROMPT ├─ CONTEXT ├─ SYSTEM INSTRUCTIONS ├─ SAMPLING SETTINGS ├─ TEMPERATURE └─ AVAILABLE INFORMATION

Sampling settings influence which token choices are selected; temperature is not simply “creativity.”

Why generated text can be wrong

Text generation produces likely continuations based on model learning and supplied context. It does not automatically verify every statement against reality.

Can be fluent, relevant, useful

The response may read naturally and fit the prompt.

But still unsupported, outdated, incorrect

Check evidence and use grounding or RAG when the task requires reliable facts.

What it is NOT

Generation vs Search

Generation: creates output. Search: finds existing information.

Generation vs Retrieval

Generation: produces language. Retrieval: finds source information.

Generation vs Training

Generation: happens during inference. Training: changes model parameters.

Fluent vs Correct

Fluent: reads naturally. Correct: matches reality or evidence.
