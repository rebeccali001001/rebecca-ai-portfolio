10 · MODEL SERVING & LOCAL AI

How Does a Model Become a Running AI Service?

A model file cannot serve users by itself. It needs a runtime, memory, hardware, and an interface that applications can call.

MODEL+RUNTIME+HARDWARE+SERVING INTERFACE=RUNNING AI SERVICE

THE PROBLEM THIS MODULE SOLVES

QUESTION

“I downloaded a Qwen model. Why can’t my app use it directly?”

BECAUSE A MODEL FILE IS NOT A SERVICE

A model file does not by itself:

  • listen for requests
  • manage memory
  • run inference
  • expose an API
  • handle concurrent users
  • return application responses

The serving stack turns model weights into a usable service.

DEPLOYMENT ENVIRONMENT

Local vs Cloud

LOCAL

Runs on your hardware.

Good fit when

Local control matters, hardware is available, or offline operation is useful.

Constraints

Memory, setup, and maintenance.

CLOUD

Runs on provider infrastructure.

Good fit when

Large managed infrastructure, scaling, or easy API access is preferred.

Constraints

Network, usage cost, and governance considerations.

Neither is universally better.

UNDERSTAND EACH LAYER

Four roles in a running AI service

ACCESS

API · Model Serving
Lets applications reach the running model. Example: an app sends a chat request.

RUN

Runtime · Ollama · vLLM
Executes inference using model weights.

RESOURCE

Quantization · GPU / VRAM
Determines what can fit and run.

PERFORMANCE

Latency · Tokens per Second
Describes waiting time and generation speed.

KEY DISTINCTIONS

What not to confuse

MODEL vs RUNTIME

MODELLearned weights.
RUNTIMESoftware that executes them.

RUNTIME vs MODEL SERVING

RUNTIMERuns inference.
SERVINGMakes it available to applications.

QUANTIZATION vs FINE-TUNING

QUANTIZATIONChanges numerical precision.
FINE-TUNINGChanges learned behavior through training.

LATENCY vs TPS

LATENCYHow long you wait.
TPSHow fast output is generated.

REMEMBER THIS

A model becomes usable when a runtime serves it through an API on real hardware, while memory, quantization, and performance constraints determine how well it runs.
