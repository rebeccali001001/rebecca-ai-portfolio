MODULE 06 · AUTHENTICATION & SECURITY

Login

A login lets a user prove their identity and start an authenticated session.

01 · What is it?

A login is the process a user follows to access an account.

The user provides credentials, such as an email address and password.

Simple Definition: Login is how a system checks a user's identity before granting account access.

02 · Think of it like...

Think of a login as showing an entry pass at a guarded door.

The guard checks the pass, then lets the person enter the area they are allowed to use.

03 · What does it do?

A login flow can:

Collect Credentials
Check Identity
Start a Session
Issue a Token
Return an Error
Open the Account

04 · Where is it used?

Login is used anywhere a product gives different users private or personalized access.

Admin Dashboards

05 · Example

A user enters an email address and password, then selects Sign in.

The server checks the credentials. If they are valid, the system creates an authenticated session and returns the account page.

07 · Do Not Confuse

Login

The user-facing process of signing in to an account.

Authentication

The broader process of checking who a user or system is.

Authorization

The separate decision about what an authenticated user is allowed to do.

Registration

The process of creating a new account before a user can log in.

Login = Sign in
Authorization = Allowed actions

09 · What to Remember

Login is the process of signing in to an existing account.

Credentials help a system check the user's identity.

A successful login can create a session or return a token for later requests.

Authentication checks identity; authorization checks allowed actions.
