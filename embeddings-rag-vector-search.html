08 · Embeddings, Search & RAG

How AI Finds External Information Before Answering

This module explains how documents can be prepared, searched, retrieved, and added to a model’s context so answers can use relevant external information.

Understand the full path from source documents to retrieved context.

The Big Picture · two information flows converge

Knowledge Map

Prepare → Find → Use

A · PREPARE

Chunking

Splits large content into retrievable pieces.

Embeddings

Represent meaning as vectors.

Vector Database

Stores and indexes vectors efficiently.

B · FIND

Semantic Search

Searches by meaning, not only exact words.

Vector Search

Finds mathematically similar vectors.

Retrieval

The broader process of finding useful source information.

Reranking

Reorders candidates by relevance.

C · USE

RAG

Adds retrieved information to model context before generation.

Grounding

Connects an answer to supplied external evidence.

Key Distinctions

Connected concepts, different layers

EmbeddingRepresentation≠Vector DatabaseStorage and indexing system
Semantic SearchSearch by meaning≠Vector SearchOne technical method
Vector SearchSearch method≠RetrievalBroader information-finding process
RetrievalFinds information≠RAGUses it during generation
RAGRuntime context≠Fine-tuningAdditional training
GroundingTies output to evidence≠Guaranteed correctnessStill requires evaluation
One Example

Answering a leave-policy question

KNOWLEDGE BASE

Employee handbook → chunk leave policy → index content

USER REQUEST

“How many annual leave days do employees receive?” → search / retrieval → relevant leave-policy chunk → add to LLM context → answer

The answer can reference the retrieved policy.

Remember the pipeline
Retrieval systems prepare and search external knowledge, while RAG supplies the most relevant information to a model before it generates an answer.
