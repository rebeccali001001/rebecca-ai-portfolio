08 · Strings

Strings are text values in Python.

On This Page CreateMultilineConcatenationf-stringMethodsSearchComparisonEscape Characters

Create a String

customer = "Apple"
product = "Copper"
status = "Pending"

name = "Rebecca"

Single quotes also work:

name = 'Rebecca'

Multiline String

message = """
Order created.
Waiting for approval.
"""

Triple quotes can store text across multiple lines.

String Concatenation

Use + to combine strings.

first_name = "Rebecca"
last_name = "Li"

full_name = first_name + " " + last_name

Result:

Rebecca Li

f-string

f-strings insert variables directly into text.

customer = "Apple"
product = "Copper"

message = f"{customer} ordered {product}"

Result:

Apple ordered Copper

This is usually easier to read than string concatenation.

String Methods

len()

Returns the number of characters in a string.

product = "Copper"
print(len(product))

Output: 6

lower()

status = "PENDING"
status = status.lower()

Result: pending

upper()

product = "copper"
product = product.upper()

Result: COPPER

title()

name = "rebecca li"
name = name.title()

Result: Rebecca Li

strip()

Removes spaces from the beginning and end of text.

name = "  Rebecca  "
name = name.strip()

Result: Rebecca

replace()

Replaces part of a string.

status = "Pending Approval"
status = status.replace("Pending", "Waiting")

Result: Waiting Approval

split()

Splits a string into a list.

products = "Copper,Aluminum,Nickel"
items = products.split(",")

Result: ["Copper", "Aluminum", "Nickel"]

join()

Combines list items into one string.

products = ["Copper", "Aluminum", "Nickel"]
text = ", ".join(products)

Result: Copper, Aluminum, Nickel

String Search

startswith()

order_id = "ORD-1001"
order_id.startswith("ORD-")

Result: True

endswith()

filename = "orders.csv"
filename.endswith(".csv")

Result: True

find()

Finds the position of text.

text = "Copper order"
text.find("order")

Result: 7

If the text is not found: -1

in with Strings

message = "Order completed"
"completed" in message

Result: True

String Comparison

status = "Completed"

if status == "Completed":
    print("Done")

Escape Characters

message = "Customer said: \"Approved\""

Common escape sequences:

\n   new line
\t   tab
\"   double quote
\'   single quote
\\   backslash
