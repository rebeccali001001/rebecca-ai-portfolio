PART VIII · DEVELOPMENT & GIT

GitHub

An online platform used to host Git repositories and support software collaboration.

01 · What is it?

GitHub is a cloud platform built around Git repositories.

It provides repository hosting and collaboration features such as pull requests, code review, issues, and automation.

GitHub is an online collaboration platform for Git projects.

02 · Think of it like...

Think of Git as the version-control engine.

GitHub is the shared online workspace where teams collaborate around those Git repositories.

Local Git Repository→GitHub→Team Collaboration

03 · What does it do?

GitHub can provide:

Remote Repository Hosting
Pull Requests
Code Review
Issues
Access Control
Automation

04 · Where is it used?

GitHub is used for:

Company Repositories
Open-source Projects
Team Collaboration
Code Review
CI/CD
Project Documentation

05 · Example

Developer→Local Commit→Push to GitHub→Pull Request→Code Review

06 · How it connects

Git→GitHub Repository→Branch→Pull Request→Review / Merge

07 · Do Not Confuse

GitHub

A platform that hosts and manages collaboration around repositories.

Git

The underlying version control system.

Git = Track Changes
GitHub = Share and Collaborate

08 · Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
GitHubGitHubAn online platform for hosting Git repositories.用于托管 Git 仓库并支持团队协作的在线平台。

Pull拉取Getting remote changes into a local repository.把远程仓库最新修改获取到本地。

09 · What to Remember

GitHub hosts Git repositories online.

It provides collaboration features around Git.

Pull requests and code reviews are common GitHub workflows.
