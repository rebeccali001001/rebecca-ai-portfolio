05 · Tokens, Context & Inference

How a Language Model Turns Your Input into an Answer

This module explains how text becomes tokens, enters the model’s context, and is processed during inference to generate an answer one token at a time.

Follow one request from raw text to generated output.

The Big Picture · inference timeline

From user text to final response

USER TEXTRaw input from a person or application
↓
TOKENIZATIONText is split into token units
↓
TOKENSUnits the model processes
↓
CONTEXT WINDOWInformation available for this run
↓
INFERENCEThe trained model processes the context
↓
NEXT-TOKEN PREDICTIONCalculate probabilities for possible next tokens
↓
SAMPLINGA generation method selects the next token
↓
GENERATED TOKEN ↺ REPEATAdd it to the sequence until a final response is complete
KV CACHEReuses information from earlier tokens during autoregressive generation.

It is an efficiency mechanism, not another mandatory step in the conceptual pipeline.

Token

The amount of information available during a run.

C · EXECUTION

Inference

Running the trained model on current input.

Next-token Prediction

Calculating probabilities for possible next tokens.

D · CONTROL

Sampling / Temperature

Controls how next-token choices are selected.

KV Cache

Reuses earlier attention information during generation.
