MODULE 05 · DATABASE & SQL

Field

One individual data value inside a record; sometimes, the same word is used for a column.

01

What is it?

A field usually means one individual data value in a record.

For example, status = "paid" is one field value in an order record. In database conversations, people sometimes also use “field” to mean a column.

Simple Definition: A field is one piece of data inside a record.

02

Think of it like…

Think of a record as one completed paper form.

Each labeled answer on that form is a field. If you place many forms side by side, the same question becomes a column.

03

What does it do?

Hold one valueStores one item of information for a record.
Label dataGives a value a name such as status or total.
Describe a recordCombines with other fields to describe one object.
Support operationsCan be read, filtered, sorted, updated, or validated.
04

Where is it used?

Fields appear wherever software stores or passes structured information.

Database tablesEach record contains values for named data fields.
Forms and APIsInputs and JSON objects carry named fields.
Filters and reportsQueries select fields to find or display useful data.
Application codeCode reads and changes fields while processing a record.

A field is the individual value; a column describes the same kind of field across many records. SQL can select or change either view.

07

Do Not Confuse

Field

One named piece of information in a record, or sometimes the value stored there.

Column

One category of information represented across every record in a table.

Record

The complete group of related field values for one item.

The word “field” is used loosely in some teams. Check whether the speaker means one value, one named data item, or a whole column.

09

What to Remember

A field is one individual piece of data in a record.

Across many records, the same kind of field forms a column.

When someone says “field,” confirm whether they mean a value, a named data item, or a column.
