What is Inference?

Inference is the process of running a trained model on an input to produce an output.

On this page What is it? Think of it like... How it works Real-world examples What it is NOT Related concepts Remember this Video

What is it?

Inference happens when a trained model is used to make a prediction or generate a result.

Training changes model parameters. Inference uses learned parameters on new input.

Think of it like...

Training is studying for an exam; inference is using what you learned to answer a new question.

How it works

1 · Input Receive new data A prompt, image, audio clip, or other input.
2 · Represent Convert the input Make it readable by the model.
3 · Compute Run the model Apply learned parameters.
4 · Predict Produce a result Calculate a prediction or likely next token.
5 · Return Generate output Return a label, transcription, or response.

Real-world examples

Image classification

An image becomes a category such as “dog.”

Language model

A prompt produces a response through repeated next-token predictions.

Speech recognition

An audio recording becomes a transcription.

What it is NOT

Inference ≠ Training

Inference uses learned parameters; training changes them.

Inference ≠ Next-token Prediction

Inference is the broader execution process; next-token prediction can repeat within it.

Inference ≠ Reasoning

Inference means model execution; reasoning describes possible problem-solving behavior.
