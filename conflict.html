Conflict

A situation where Git cannot automatically decide how to combine overlapping changes.

01

What is it?

A merge conflict happens when Git cannot automatically combine changes from different branches.

This often occurs when the same part of a file was changed in incompatible ways.

Simple Definition: A conflict means Git needs a person to decide which code should remain.

02

Think of it like...

Think of two people editing the same sentence differently.

A tool cannot safely guess which version is correct.

A person must decide.

03

What does it do?

Identify Conflicting Files
Compare Both Changes
Choose the Correct Result
Edit the File
Test the Result
Complete the Merge

09

What to Remember

Conflicts happen when Git cannot combine changes automatically.

Developers must inspect and resolve the final code.

Resolved code should be tested before completion.

Merge → Conflict → Resolve → Test
