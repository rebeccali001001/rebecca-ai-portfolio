What is an AI Agent?

An AI agent is a controlled loop around a model that can observe, decide, use tools, and continue toward a goal.

Detail

Agents need explicit tools, validation, permissions, stopping conditions, and recovery behavior.

Observe → reason → act → inspect → stop

Sample

A coding agent reads a file, proposes an edit, runs a restricted test, and reports the result.
