MODULE 06 · AUTHENTICATION & SECURITY

Hashing

A one-way transformation that turns input data into a fixed-length value.

01 · What is it?

Hashing transforms data into a hash value that is designed to be difficult to reverse.

Systems can compare hash values without keeping the original input in the same form.

02 · Think of it like...

Think of hashing like making a tamper-evident fingerprint for a document.

03 · What does it do?

Protects Password Storage

Systems can store a password hash instead of the password itself.

Checks Integrity

A changed input produces a different value.

Supports Lookup

Hash values help software compare known data efficiently.

04 · Where is it used?

Hashing is used for password storage, file integrity checks, and content identifiers.

05 · Example

A login system hashes the password entered by a user and compares it with the stored password hash.

A secure password system uses a password-specific hashing algorithm and a unique salt.

06 · How it connects

Password Input→Hash Function→Stored Hash→Comparison

07 · Do Not Confuse

Hashing

Designed as a one-way transformation.

Encryption

Designed to be reversed with a key.

Encoding

Changes representation for transport or storage.
