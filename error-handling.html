Error Handling

The logic used to detect, manage, and respond to problems safely.

01

What is it?

Error handling defines what the application should do when something goes wrong.

Good error handling prevents uncontrolled failures and returns useful results.

Simple Definition： Error handling tells the system what to do when an error happens.

02

Think of it like...

Think of an emergency procedure.

When a problem happens, the system follows a planned response instead of failing randomly.

07

Do Not Confuse

Error Handling

Decides what the system should do.

It may catch an exception, return a response, retry, recover, or stop safely.

Logging

Records information about what happened.

It supports diagnosis, but recording an error alone does not decide the system’s next action.
