PART III · HTTP & APIs

POST

An HTTP method commonly used to create or submit data.

01 · What is it?

What is it?

POST is an HTTP method commonly used to send data to a server.

It is often used to create a new resource or start an action.

Simple Definition: POST sends data to create or submit something.

02 · Think of it like...

Think of it like...

Think of POST as submitting a new form.

You provide information.

The system processes it and creates or starts something.

03 · What does it do?

What does it do?

POST is commonly used to:

Create RecordsAdd a new resource to a system.
Submit FormsSend collected form data for processing.
Create OrdersStart a new order or transaction.
Upload DataSend files or structured data.
Start ActionsAsk the backend to begin a process.
Send MessagesSubmit a message to a service.
04 · Where is it used?

Where is it used?

05 · Example

Example

POST /api/orders

Request Body:

{
  "customer_id": 2001,
  "quantity": 10
}

Meaning: Create a new order using the submitted data.

Flow

Frontend → POST /api/orders → Backend → Create Order → Response

06 · How it connects

How it connects

Client→POST→Endpoint→Request Body→Backend→Business Logic→Database→Response

POST often carries data in the request body for the backend to process.

07 · Do Not Confuse

Do Not Confuse

POST

Usually sends data to create or submit something.

GET

Usually retrieves existing data.

POST = Send / Create
GET = Retrieve
