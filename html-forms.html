09 · Forms

Forms collect values and submit them to a destination.

What is it?

A form groups controls that a user can fill in and submit. Think of it like: a paper form whose completed fields become an HTTP request.

Basic Syntax

<form action="/orders" method="post">
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>
  <button type="submit">Save</button>
</form>

How it works

HTML Form → user enters values → submit → HTTP request → backend receives data. action is the destination and method is commonly GET or POST.

Key Attributes / Syntax

Use input, label, textarea, select, option, and button. Input types include text, email, password, number, date, checkbox, radio, file, and submit. Useful attributes: name, value, placeholder, required, disabled, readonly, min, max, step.

GET vs POST

GET usually retrieves a resource and puts form values in the URL. POST usually submits data for processing or creation. The backend defines the actual behavior.

Common Mistakes

Every usable control needs a label and a meaningful name. Placeholder text is not a label.

Quick Reference

label[for] names a control · name sends a field key · required blocks empty submission.
