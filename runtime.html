PART I · HOW SOFTWARE WORKS

Runtime

The environment in which software is actually executing.

01

What is it?

Runtime is the environment in which a program is actually running.

It provides what the program needs while it executes.

Simple Definition: Runtime is where code becomes a running program.

02

Think of it like...

Think of code as a recipe.

Runtime is the kitchen where the recipe is actually used.

Recipe→Kitchen→Meal
Code→Runtime→Running Program
03

What does it do?

A runtime provides the environment needed to execute software.

It may provide:

Memory

Temporary space used while software is running.

Libraries

Reusable code that the program can use.

System Access

Ways for software to interact with files, devices, or services.

Execution Rules

The rules that determine how code is run.

04

Where is it used?

Different software runs in different runtimes.

Browser

Runs JavaScript.

Python Runtime

Runs Python code.

Server Environment

Runs backend applications.

Cloud Environment

Runs deployed software.

05

Example

JavaScript code is written in a file. When a browser loads the page, the browser executes that JavaScript.

JavaScript Code→Browser→Runtime→Running Behavior

The code exists before it runs.

Runtime is when and where the code is actually executed.

06

How it connects

Code→Runtime→Running Program→Process

Runtime connects written code with actual execution.

07

Do Not Confuse

Code

Written instructions.

Runtime

The environment where those instructions execute.

Code = Instructions    ·    Runtime = Execution Environment
