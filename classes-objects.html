14 · Classes & Objects

Classes are used to define reusable objects that contain data and behavior.

1. class

Use class to define a new type of object.

class ClassName:\n    pass\n\nclass Order:\n    pass

This creates a class called Order.

2. Create an Object

A class is a blueprint.

An object is an instance created from that class.

class Order:\n    pass\n\norder = Order()

Order is the class. order is an object.

3. __init__()

__init__() runs when a new object is created.

It is commonly used to set initial values.

class Order:\n\n    def __init__(self, order_id):\n        self.order_id = order_id\n\norder = Order(1001)

4. self

self refers to the current object.

class Order:\n\n    def __init__(self, order_id):\n        self.order_id = order_id

Store the passed order_id inside this object.

5. Attributes

Attributes are values stored inside an object.

class Order:\n\n    def __init__(self, order_id, product, quantity):\n        self.order_id = order_id\n        self.product = product\n        self.quantity = quantity\n\norder = Order(1001, "Copper", 10)\n\nprint(order.order_id)\nprint(order.product)\nprint(order.quantity)

Output

1001\nCopper\n10

6. Methods

Methods are functions defined inside a class.

class Order:\n\n    def __init__(self, product, quantity):\n        self.product = product\n        self.quantity = quantity\n\n    def show_summary(self):\n        print(self.product, self.quantity)\n\norder = Order("Copper", 10)\norder.show_summary()

Output

Copper 10

7. Method with Return Value

class Order:\n\n    def __init__(self, price, quantity):\n        self.price = price\n        self.quantity = quantity\n\n    def calculate_total(self):\n        return self.price * self.quantity\n\norder = Order(8500, 10)\ntotal = order.calculate_total()\nprint(total)

Output

85000

8. Change an Attribute

order.quantity = 20

Changes the object's quantity value.

9. Multiple Objects

order1 = Order("Copper", 10)\norder2 = Order("Aluminum", 20)

Both objects use the same class but store different values.

10. Class Example

class Order:\n\n    def __init__(self, order_id, customer, product, quantity, price):\n        self.order_id = order_id\n        self.customer = customer\n        self.product = product\n        self.quantity = quantity\n        self.price = price\n\n    def calculate_total(self):\n        return self.quantity * self.price\n\n    def show_summary(self):\n        print(self.order_id, self.customer, self.product)\n\norder = Order(1001, "Apple", "Copper", 10, 8500)\norder.show_summary()\ntotal = order.calculate_total()\nprint(total)

11. Inheritance

Inheritance lets one class reuse another class.

class Order:\n\n    def show_type(self):\n        print("Order")\n\nclass SalesOrder(Order):\n\n    def show_sales(self):\n        print("Sales Order")\n\norder = SalesOrder()\norder.show_type()\norder.show_sales()

SalesOrder can use methods from Order.

12. isinstance()

Checks whether an object belongs to a class.

order = Order()\n\nprint(isinstance(order, Order))

Output

True
