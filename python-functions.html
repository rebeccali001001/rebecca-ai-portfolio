1. def

Use def to create a function.

Syntax

def function_name(): ··· code

Example

def say_hello(): ··· print("Hello") ··· say_hello()

Output

Hello

2. Function Parameters

Parameters let you pass data into a function.

def function_name(parameter): ··· code ··· def greet(name): ··· print("Hello", name) ··· greet("Rebecca")

Output

Hello Rebecca

3. Multiple Parameters

def calculate_total(price, quantity): ··· total = price * quantity ··· print(total) ··· calculate_total(8500, 10)

Output

85000

4. return

return sends a value back from a function.

def calculate_total(price, quantity): ··· return price * quantity ··· total = calculate_total(8500, 10) ··· print(total)

Output

85000

print() displays a value. return sends a value back to the caller.

5. Default Parameter

A parameter can have a default value.

def greet(name="Guest"): ··· print("Hello", name) ··· greet() ··· greet("Rebecca")

Output

Hello Guest ··· Hello Rebecca

6. Keyword Arguments

def create_order(product, quantity): ··· print(product, quantity) ··· create_order(quantity=10, product="Copper")

Keyword arguments make it clear which value belongs to which parameter.

7. Local Variables

A variable created inside a function usually belongs to that function.

def calculate_total(): ··· price = 8500 ··· quantity = 10 ··· total = price * quantity ··· return total

total is created inside the function.

Keep scope explanation simple.

8. *args

*args allows a function to receive multiple positional values.

def show_products(*products): ··· for product in products: ······ print(product) ··· show_products("Copper", "Aluminum", "Nickel")

9. **kwargs

**kwargs allows a function to receive named values.

def show_order(**order): ··· print(order) ··· show_order(customer="Apple", product="Copper", quantity=10)

Result

{"customer": "Apple", "product": "Copper", "quantity": 10}

Inside the function, kwargs behaves like a dictionary.

10. lambda

lambda creates a small anonymous function.

Syntax

lambda arguments: expression

Example

double = lambda x: x * 2 ··· double(5)

Result

10

Keep this section simple.

11. Function Example

def calculate_order_amount(price, quantity, fee=0): ··· subtotal = price * quantity ··· total = subtotal + fee ··· return total ··· amount = calculate_order_amount(price=8500, quantity=10, fee=100) ··· print(amount)

Output

85100

The function receives data, performs a calculation, and returns the result.
