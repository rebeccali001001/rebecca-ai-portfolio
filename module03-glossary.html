PART III · HTTP & APIs

HTTP & APIs Glossary

English terms with simple explanations and beginner-friendly Chinese meaning.

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
HTTP超文本传输协议The protocol commonly used for web communication.浏览器、客户端和服务器在 Web 上交换数据时常用的基础协议。
HTTPS安全的 HTTPHTTP with encryption to protect data during communication.加密版 HTTP，用来保护数据在网络传输过程中的安全。
URLURL 地址The address used to locate a web resource.用来定位网页、接口或其他网络资源的地址。
API应用程序接口A collection of defined software functions or resources.对外提供一组功能或数据访问方式的软件接口。
REST APIREST APIAn API style that commonly organizes resources around URLs and HTTP methods.通常围绕 URL 和 HTTP 方法组织资源的一种 API 设计风格。
Endpoint接口地址A specific address that provides an API function.API 中提供某个具体功能的访问地址。
MethodHTTP 方法The action requested at an endpoint.在某个接口地址上希望执行的操作类型。
GET获取Usually used to retrieve data.通常用于获取数据。
POST创建 / 提交Usually used to send or create data.通常用于提交或创建数据。
PUT完整更新Usually used to replace a resource.通常用于完整替换或更新一个资源。
PATCH部分更新Usually used to update part of a resource.通常用于修改资源的一部分。
DELETE删除Usually used to remove a resource.通常用于删除一个资源。
Request请求A message sent to an endpoint.发送到某个接口地址的数据或操作请求。
Response响应The result returned after a request is processed.请求处理完成后返回的数据或结果。
Header请求头 / 响应头Extra information sent with a request or response.随请求或响应一起传递的附加信息。
Body请求体 / 响应体The main data carried inside a request or response.请求或响应中真正承载的主要数据内容。
Query Parameter查询参数Optional information added to a URL after a question mark.添加在 URL 问号后面的可选信息。
Path Parameter路径参数A value included inside a URL path.直接放在 URL 路径中的参数值。
Status Code状态码A number that shows the result of an HTTP request.用数字表示 HTTP 请求处理结果。
JSONJSON 数据格式A common text format for exchanging structured data.软件系统之间交换结构化数据时常用的文本格式。
API DocumentationAPI 文档Documentation listing endpoints and how to use them.说明有哪些接口、怎么调用以及返回什么的文档。
Webhook网络钩子A callback sent when an event happens.某个事件发生后由系统主动发送的回调通知。
Timeout超时A limit on how long a request can wait.请求等待结果的最长时间限制。
Retry重试Trying a failed request again.请求失败后再次尝试发送。
Rate Limit速率限制A rule limiting how often requests can be sent.限制一段时间内可以发送多少次请求的规则。
Idempotency幂等性Repeating an operation has the same intended effect.同一个操作重复执行时，预期结果不会继续产生额外变化。
