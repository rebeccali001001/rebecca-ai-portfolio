What is a Transformer?

A Transformer is a neural-network architecture that processes relationships between tokens.

KEY IDEA
Transformer = Attention + Stacked Neural Network Layers
It processes relationships between tokens before producing an output.
Core idea

Architecture first. Mechanism inside.

A Transformer is a neural-network architecture that processes relationships between tokens.

Its attention mechanism lets each token weigh information from other relevant tokens.

A useful analogy

Think of it like a reading group

Thebankapprovedit

Each word can look at the other words and decide which ones are most useful for understanding the current context.

Reading group → Transformer layer
Words → Tokens
Looking at other words → Attention
Repeated discussion → Layer stack

This analogy is for understanding only. A Transformer uses mathematical operations, not human discussion.

The processing story

How it works

STEP 01

Tokens enter the model

Text becomes token representations.

STEP 02

Attention compares relationships

Each position can weigh information from other relevant positions.

STEP 03

Representations are updated

Attention results are combined with additional neural-network processing.

STEP 04

Layers repeat the process

Stacked layers progressively transform the representation.

STEP 05

Output scores are produced

The final representation supports prediction or another model task.

Concept boundaries

What it is NOT

TRANSFORMER ≠ LLM

Architecture ≠ language model

An LLM is often built with Transformer architecture.

TRANSFORMER ≠ ATTENTION

Full architecture ≠ one mechanism

Attention is one important mechanism inside it.

TRANSFORMER ≠ CHATGPT

Architecture ≠ product

ChatGPT uses models plus other systems.
