What is a Transformer?

A Transformer is a neural-network architecture that uses attention to connect relationships between tokens in a sequence.

Detail

Attention lets the model weigh which parts of the input matter most for understanding or generating the next part.

Tokens + attention → contextual representations

Key takeaway

Transformers help models understand relationships across a sequence efficiently.

Sample

In “The trader closed the position because it was risky,” attention helps connect “it” with the relevant context.
