02 · LLMs & Transformers · Topic 2 of 5

What is a Transformer?

A Transformer is a neural-network architecture that uses attention to connect relationships between tokens in a sequence.

Definition

Attention lets each token weigh which other tokens matter most for understanding or generating the next part.

tokens + attention → contextual representations

In plain English

Imagine reading a sentence and quickly scanning back to the clues that explain a pronoun or an important detail. Attention is the model’s way of making those connections.

Key points

Sequence
The input is split into tokens
Attention
Relevant clues receive more weight
Layers
Repeated transformations build meaning

Sample

In “The trader closed the position because it was risky,” attention helps connect “it” with the relevant context. The model is not only reading left to right; it is weighing relationships across the sequence.

Where it shows up

Language models, translation, document understanding, code assistants, image-text systems, and other models that need to relate parts of a sequence.
