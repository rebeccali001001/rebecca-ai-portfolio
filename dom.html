PART II · FRONTEND & BROWSER

DOM

The browser's object representation of a web page.

01 · What is it?

DOM stands for Document Object Model.

When a browser reads HTML, it creates an object structure that JavaScript can access and change.

Simple Definition: The DOM is the browser's working version of the web page.

02 · Think of it like...

Think of HTML as the original document.

The DOM is the browser's live tree built from that document.

HTML→Browser→DOM Tree 
Document
└─ html
   └─ body
      ├─ h1
      ├─ p
      └─ button

03 · What does it do?

The DOM allows JavaScript to:

Find Elements
Read Content
Change Content
Change Classes
Change Styles
Add or Remove Elements

04 · Where is it used?

The DOM is used whenever JavaScript reads or changes a web page.

Update Text
Open a Menu
Show an Error
Hide a Panel
Add a New Row
Change a Button State

05 · Example

const button = document.querySelector(".save-button");

button.textContent = "Saved";
document represents the current page.
querySelector() finds an element in the DOM.
textContent changes the element's text.
HTML→DOM→JavaScript→DOM Change→Page Update

06 · How it connects

HTML→Browser→DOM→JavaScript→User Interface

HTML creates the original structure.

The browser turns that structure into the DOM.

JavaScript works with the DOM to change the page.

07 · Do Not Confuse

HTML

The markup written in the source file.

DOM

The live object structure created by the browser.

HTML is the source.

DOM is the browser's live representation.
