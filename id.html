ID

A name used to identify one specific HTML element.

01 · What is it?

What is it?

An ID is a value used to identify a specific element on a page.

An ID should normally be unique within that page.

Simple Definition: An ID identifies one specific element.

02 · Think of it like...

Think of it like...

Think of an ID as a unique employee number.

Many people may share the same job role.

But each person has a different employee number.

HTML version
│
├─ Class = shared category
└─ ID = unique identifier
03 · What does it do?

What does it do?

An ID can help:

Identify One Element
Link to a Page Section
Select an Element in CSS
Find an Element in JavaScript
Connect Labels and Form Fields

07 · Do Not Confuse

Do Not Confuse

ID

Usually identifies one specific element.

Class

Can be reused on multiple elements.

ID = specific
Class = reusable
