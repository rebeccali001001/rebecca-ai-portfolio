Agents & Agent Systems

Plain-English definitions for the concepts used to design, operate, and evaluate agent systems.

TermSimple EnglishProduct Manager question
AI AgentA system that uses a model, tools, and a loop to work toward a goal.What actions may it take, and when must a person review?
Agent HarnessThe runtime layer around a model that manages context, tools, permissions, memory, loops, and execution.Which capabilities, controls, and approvals surround the model?
Agent RoleThe job and boundaries assigned to one agent.What does this agent own, and what is outside its scope?
Agent HandoffPassing a task or result to another agent.What input and acceptance criteria make the handoff reliable?
Agent CommunicationThe messages, artifacts, events, or state agents exchange.Can we inspect what was communicated when something fails?
Agent CoordinationManaging dependencies, ordering, conflicts, and shared progress.Who resolves a conflict or a stalled subtask?
Agent OrchestrationThe control logic that routes work and decides what runs next.Is orchestration centralized, event-driven, or decentralized?
Shared MemoryCommon information multiple agents can read or update.Who can write it, and how do we prevent stale or unsafe state?
Task DelegationAssigning a well-defined subtask to a suitable agent.Does delegation improve the outcome enough to justify its cost?
Multi-Agent SystemMultiple agents coordinating toward one or more goals.Why is one agent not enough for this product outcome?
