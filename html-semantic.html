10 · Semantic HTML

Choose elements that say what a part of the page means.

What is it?

Semantic elements communicate purpose, not just structure. Think of it like: named rooms in a building instead of a floor plan made only of blank boxes.

Basic Syntax

<header>…</header>
<nav>…</nav>
<main><article>…</article></main>
<footer>…</footer>

Common Examples

header, nav, main, section, article, aside, and footer describe page landmarks and content roles.

div vs section

div is a generic grouping element. section represents a meaningful themed section, normally with a heading. Semantic HTML improves accessibility, SEO, and maintainability.

Common Mistakes

Do not use semantic elements only for styling. Do not add multiple competing main regions to one page.

Quick Reference

nav navigation · article independent content · aside supporting content · footer closing information.
