Attribute

Extra information added to an HTML element.

01 · What is it?

An extra detail on an element

An attribute provides extra information about an HTML element.

Attributes can control identity, behavior, links, input types, and other element settings.

Simple Definition: An attribute adds information to an element.

02 · Think of it like...

05 · Example

An input with attributes

<input
  id="quantity"
  class="form-input"
  type="number"
  required
>
id="quantity" gives the element a unique identifier.
class="form-input" assigns a reusable class.
type="number" defines the input type.
required marks the field as required.

07 · Do Not Confuse

Attribute ≠ Property

Attribute

Information written in HTML.

Property

A value available on the DOM object in JavaScript.
