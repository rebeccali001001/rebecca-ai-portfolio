What is Knowledge Distillation?

Knowledge distillation transfers useful knowledge from a large, powerful teacher model into a smaller, faster student model.

On this page What is it? Think of it like... How it works Examples Distillation vs... Related concepts Remember this

What is it?

Knowledge distillation teaches a smaller model to reproduce useful patterns from a larger model.

The large model acts as a teacher. Its outputs, probabilities, or demonstrations become learning signals for the student model. The goal is to keep useful behavior while reducing model size, memory needs, or response cost.

Think of it like...

Teacher Model = Senior Expert · Student Model = Junior Employee

Distillation is like asking a senior expert to demonstrate many tasks, then using those demonstrations to train a junior employee. The junior does not become the same person, but can learn a useful version of the expert’s approach.

Teacher ModelLarge and capable; generates helpful demonstrations or outputs.
Student ModelSmaller and faster; learns to imitate useful behavior.

How it works

A teacher produces learning signals, and a student is trained to match the useful parts of those signals.

Simple examples

Model size example

Large Model · 70B→Distillation→8B Model

A 70B teacher can generate examples that help an 8B student learn a smaller, more efficient version of selected behavior.

Precision example

FP16→Quantization→8-bit / 4-bit / Q4 / Q3

This is a representation change: the model’s weights are stored with lower numerical precision to reduce memory and compute needs.

Important: Distillation and quantization are not the same concept. Distillation transfers behavior between models; quantization changes how weights are represented.

Distillation vs Fine-Tuning vs Quantization

Fine-Tuning

Core idea: adjust model behavior or capability with additional training on focused examples.

Changes: what the model learns or how it responds.

Distillation

Core idea: transfer useful knowledge from a large model to a smaller model.

Changes: which model carries the behavior, often reducing size or cost.

Quantization

Core idea: represent model weights with lower numerical precision.

Changes: memory and compute requirements, with possible quality trade-offs.

Related concepts

Large Teacher → Knowledge / Outputs → Small Student Fine-Tuning = adjust behavior · Distillation = transfer knowledge · Quantization = lower precision
