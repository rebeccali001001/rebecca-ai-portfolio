Event Listener

Code that waits for an event and runs a response when it happens.

PreviousEvent CurrentEvent Listener ← active NextResponsive Design

01 · What is it?

An event listener waits for a specific event.

When that event occurs, the listener runs a function.

Simple Definition: An event listener waits for something to happen.

02 · Think of it like...

Think of an event listener as someone waiting for a signal.

When the signal appears, the person takes action.

Wait→Event Happens→Action Runs

03 · What does it do?

  • Wait for Clicks
  • Watch User Input
  • Detect Form Submission
  • React to Changes
  • Run Functions
  • Update the Interface

04 · Where is it used?

Event listeners are used in interactive web applications.

  • Buttons
  • Forms
  • Menus
  • Search Boxes
  • Dropdowns
  • Keyboard Shortcuts

05 · Example

button.addEventListener("click", () => {
  menu.classList.toggle("open");
});

button is the element being watched.

addEventListener() registers the listener.

"click" is the event.

The function runs after the click.

Button→Click→Event Listener→Function→Menu Changes

06 · How it connects

HTML Element→Event→Event Listener→JavaScript Function→DOM Change

Event listeners connect user actions with JavaScript behavior.

07 · Do Not Confuse

Event Listener ≠ Event

Event

Something that happens.

Event Listener

Code waiting for that event.

Event = What happened

Listener = What is waiting for it
