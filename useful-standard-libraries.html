20 · Useful Standard Libraries

Python includes many useful modules without installing extra packages.

These are part of the:

Python Standard Library

This page only covers commonly seen modules.

1. datetime

Dates and times.

from datetime import datetime
now = datetime.now()
print(now)

2. date

from datetime import date
today = date.today()
print(today)

3. timedelta

Adds or subtracts time.

from datetime import datetime, timedelta
now = datetime.now()
tomorrow = now + timedelta(days=1)

4. pathlib

File and folder paths.

from pathlib import Path
file_path = Path("data/orders.csv")

exists()
is_file()
is_dir()
mkdir()
glob()

5. os

Operating-system related functions and environment variables.

import os
api_key = os.getenv("API_KEY")

6. json

Read and write JSON.

import json
data = json.loads(json_text)

7. csv

Read and write CSV files.

import csv

8. math

Mathematical functions.

import math
result = math.sqrt(16)

4.0

sqrt()
ceil()
floor()

9. random

Generate random values.

import random
number = random.randint(1, 10)

10. re

Pattern matching with regular expressions.

import re
text = "Order 1001"
match = re.search(r"\d+", text)
print(match.group())

1001

11. collections

Provides additional collection tools.

from collections import Counter
products = ["Copper", "Copper", "Aluminum"]
counts = Counter(products)
print(counts)

Copper   → 2
Aluminum → 1

12. defaultdict

from collections import defaultdict
groups = defaultdict(list)
groups["Copper"].append(1001)
groups["Copper"].append(1002)

Automatically creates a default value when a key does not exist.

13. statistics

Basic statistics.

import statistics
prices = [8500, 8600, 8400]
average = statistics.mean(prices)

14. itertools

Provides tools for working with iterators.

from itertools import chain
a = [1, 2]
b = [3, 4]
combined = chain(a, b)
print(list(combined))

[1, 2, 3, 4]

15. sys

Information about the Python runtime.

import sys
print(sys.version)
print(sys.executable)

16. time

Basic time-related operations.

import time
time.sleep(2)

Pause the program for 2 seconds.

17. logging

Record information about what a program is doing.

import logging
logging.basicConfig(level=logging.INFO)
logging.info("Order processing started")

Real projects often use logging instead of many print() statements.
