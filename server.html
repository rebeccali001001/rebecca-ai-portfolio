PART IV · BACKEND

Server

A computer or software environment that receives requests and provides services to other systems.

01 · What is it?

What is it?

A server provides data, applications, or services to clients.

Backend applications commonly run on servers and listen for incoming requests.

Simple Definition:
A server is where backend software runs and responds to requests.

02 · Think of it like...

Think of it like...

Think of a service desk.

Clients send requests to the desk.

The server receives them and passes them to the correct application logic.

Flow:

Client→Server→Backend Application→Response
03 · What does it do?

What does it do?

A server can:

Receive Network Requests
Run Backend Applications
Host APIs
Access Databases
Serve Files
Connect to Other Services
04 · Where is it used?

Where is it used?

07 · Do Not Confuse

Do Not Confuse

Server

The computing environment.

Backend

The software logic running on that environment.

Server = Where it runs

Backend = What runs there

08 · Topic Glossary

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Server服务器A system that provides services to clients.接收其他系统请求并提供服务的计算环境。
Client客户端A system that sends requests to a server.向服务器发送请求的一端。
Backend Application后端应用Software running on the server.运行在服务器上、负责业务处理的程序。
Host主机A machine or environment running software.承载程序运行的计算机或运行环境。
Port端口A numbered network access point used by software.网络中程序对外提供服务时使用的编号入口。
Process进程A running instance of a program.程序真正运行起来后的执行实例。
Request请求A message sent by a client to a server.客户端发送给服务器的操作请求。
Response响应A result returned by the server.服务器处理请求后返回的结果。
09 · What to Remember

What to Remember

Servers provide computing environments for backend software.

Clients send requests to servers.

A backend application may run as one or more processes on a server.
