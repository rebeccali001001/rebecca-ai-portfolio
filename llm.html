What is an LLM?

A Large Language Model predicts and generates language by learning statistical patterns across very large text datasets.

Detail

An LLM reads context as tokens and predicts what token is likely to come next. Applications add instructions, retrieval, tools, and validation around the model.

Context → prediction → next token → repeat

Key takeaway

An LLM is a language prediction engine that becomes useful through an application layer.

Sample

A support assistant receives a customer question, uses policy context, and drafts a response for review.

Context
Question + policy
Model
Predict response
Review
Human approval
