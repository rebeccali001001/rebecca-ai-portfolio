02 · LLMs & Transformers · Topic 1 of 5

What is an LLM?

A Large Language Model predicts and generates language by learning patterns across very large collections of text.

Easy analogy

An LLM is a powerful autocomplete that uses context to predict the next useful piece of language.

Analogy video

Definition

An LLM reads context as tokens and predicts the next token. It repeats that small step to produce a sentence, answer, or draft.

context → prediction → next token → repeat

In plain English

Think of a very capable autocomplete. It does not pull a finished answer from a drawer; it builds a response one piece at a time from the clues it can see.

Key points

Input
Question, instructions, and context
Engine
Predicts likely next tokens
Application
Adds tools, policy, retrieval, and review

Sample

A support assistant receives a customer question and the relevant policy. It drafts a reply one piece at a time, then a human checks the result before it is sent.

Where it shows up

Chat assistants, summarization, drafting, classification, coding copilots, extraction, and any workflow where language is the interface.
