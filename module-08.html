Development & Git

Understand how code is versioned, reviewed, merged, built, and prepared for release.

How the module connects

The development path turns a requirement into code, a reviewed change, a build, and a release.

Requirement→Code→Git→Commit→Branch→Pull Request→Code Review→Merge→Build→Release

Module 08 Topics

Source CodeDeveloper-written instructions for software. RepositoryProject files and version history. GitTrack code changes over time. GitHubHost and collaborate on Git repositories. CommitRecord a set of code changes. BranchWork on an independent line of changes. MainThe primary project code line. Pull RequestRequest that changes be merged. Code ReviewInspect proposed code changes. MergeCombine changes from different branches. ConflictChanges Git cannot combine automatically. VersionA specific software state. ReleaseA version made available for use or delivery. BuildTurn source code into a runnable output. DependencyExternal code a project needs. PackageBundled code prepared for use. EnvironmentConfiguration and resources where software runs.
