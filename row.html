MODULE 05 · DATABASE & SQL

Row

A row is one complete record in a database table.

01 · What is it?

A row is one complete record in a database table.

Each row describes one item, person, event, or other stored thing. The values in that row belong together because they describe the same record.

In a users table, one row can represent one user.

02 · Think of it like...

Think of a row as one filled-out line on a form.

The labels across the top tell you what each piece of information means. One horizontal line then holds the complete information for one item.

03 · What does it do?

A row keeps the values for one record together so software can work with that record as a unit.

Represent One Thing

Store the information that describes one user, order, product, or event.

Keep Values Together

Group related values such as an ID, name, and email address.

Support Data Changes

Let software read, update, or delete one complete record.

Return a Result

Give a query a record that the application can display or process.

04 · Where is it used?

Rows appear in every table that stores multiple records of the same kind.

UsersOne account

A row can hold one user’s ID, name, email, and status.

OrdersOne purchase

A row can hold one order’s ID, customer, amount, and date.

ProductsOne item

A row can hold one product’s name, price, and inventory count.

LogsOne event

A row can hold one recorded event and the time it happened.

05 · Example

Suppose a users table has these columns:

idnameemailstatus
42Alexalex@example.comactive

The complete line with ID 42 is one row. Together, its four values describe one user.

A query can find that one row:

SELECT id, name, email, status
FROM users
WHERE id = 42;

The database returns the matching row as the query result.

07 · Do Not Confuse

Row

One complete record, such as one user or one order.

Column

One type of information shared by every row in a table.

Table

A collection of related rows organized by columns.

Record

Another common word for the complete data represented by one row.

A row is horizontal data for one item; a column is vertical data for one attribute.

09 · What to Remember

A row is one complete record in a database table.

Columns describe the kinds of values; a row holds the values for one item.

SQL queries can select, update, or delete rows.
