01

Filtering

Filtering lets you return only the rows that match a condition.

WHERE

WHERE filters rows based on a condition. Only rows where the condition is true remain in the query result.

Syntax
SELECT columns
FROM table_name
WHERE condition;

Example 1

SELECT order_id, customer, product
FROM orders
WHERE product = 'Copper';

What it means: Return only orders where the product is Copper.

Output
order_idcustomerproduct
1001ABC MetalsCopper
1004Apple ResourcesCopper

Only the two Copper orders remain.

Example 2

SELECT order_id, quantity
FROM orders
WHERE quantity > 20;

What it means: Return orders where quantity is greater than 20.

Output
order_idquantity
100250
100435
Key point: WHERE controls which rows appear in the result.

=

= checks whether two values are equal.

Example

SELECT order_id, status
FROM orders
WHERE status = 'Completed';
Output
order_idstatus
1001Completed
1004Completed

Only rows where status exactly equals Completed are returned.

<>

<> means “not equal to”.

Example

SELECT order_id, status
FROM orders
WHERE status <> 'Rejected';
Output
1001 Completed 1002 Pending 1004 Completed 1005 Cancelled

Order 1003 is excluded because its status is Rejected.

!=

!= is another commonly supported way to write “not equal to”.

Example

SELECT order_id
FROM orders
WHERE status != 'Rejected';
Output
1001 1002 1004 1005

This produces the same idea as:

status <> 'Rejected'

Note: <> is standard SQL. != is also supported by many database systems.

>

> means greater than.

Example

SELECT order_id, quantity
FROM orders
WHERE quantity > 20;
Output
1002 | 50 1004 | 35

<

< means less than.

Example

SELECT order_id, price
FROM orders
WHERE price < 3000;
Output
1002 | 2450 1005 | 2800

>=

>= means greater than or equal to.

Example

SELECT order_id, quantity
FROM orders
WHERE quantity >= 20;
Output
1001 | 20 1002 | 50 1004 | 35

Quantity 20 is included because the comparison includes the boundary value.

<=

<= means less than or equal to.

Example

SELECT order_id, quantity
FROM orders
WHERE quantity <= 10;
Output
1003 | 10 1005 | 8
02

Logical Conditions

Logical operators let you combine or reverse filtering conditions.

AND

AND requires all connected conditions to be true.

Syntax
WHERE condition1
  AND condition2

Example 1

SELECT order_id, product, quantity
FROM orders
WHERE product = 'Copper'
  AND quantity > 20;

What it means: Return Copper orders only when quantity is also greater than 20.

Output
order_idproductquantity
1004Copper35

Example 2

SELECT order_id, status, product
FROM orders
WHERE status = 'Completed'
  AND product = 'Copper';
Output
1001 | Completed | Copper 1004 | Completed | Copper
Key point: With AND, every condition must be true.

OR

OR keeps a row when at least one condition is true.

Example

SELECT order_id, product
FROM orders
WHERE product = 'Copper'
   OR product = 'Nickel';
Output
1001 | Copper 1003 | Nickel 1004 | Copper
Key point: With OR, one matching condition is enough.

NOT

NOT reverses a condition.

Example 1

SELECT order_id, status
FROM orders
WHERE NOT status = 'Rejected';

Return rows where status is anything other than Rejected.

Output
1001 | Completed 1002 | Pending 1004 | Completed 1005 | Cancelled

Example 2

SELECT order_id, product
FROM orders
WHERE NOT product = 'Copper';
Output
1002 | Aluminum 1003 | Nickel 1005 | Zinc

Parentheses ( )

Parentheses control how multiple logical conditions are grouped.

Example

SELECT order_id, product, status
FROM orders
WHERE (product = 'Copper' OR product = 'Nickel')
  AND status = 'Completed';

What it means: First allow Copper or Nickel. Then require the order to also be Completed.

Output
1001 | Copper | Completed 1004 | Copper | Completed

Parentheses make complex conditions easier to understand and prevent ambiguous logic.

03

NULL

NULL represents a missing or unknown value.

NULL

NULL means that a value is missing, unknown, or not available.

It is not the same as 0, an empty string, or the text 'NULL'.

In the sample data, rows 1002 and 1003 have delivery_date = NULL.

IS NULL

IS NULL checks whether a value is missing.

Syntax
WHERE column_name IS NULL

Example

SELECT order_id, customer
FROM orders
WHERE delivery_date IS NULL;
Output
order_idcustomer
1002Global Trade
1003Eastern Metals

These rows do not currently have a delivery date.

Important note: Do not write delivery_date = NULL. Use delivery_date IS NULL.

IS NOT NULL

IS NOT NULL returns rows where a value exists.

Example

SELECT order_id, delivery_date
FROM orders
WHERE delivery_date IS NOT NULL;
Output
1001 | 2026-09-20 1004 | 2026-09-25 1005 | 2026-09-28

COALESCE()

COALESCE returns the first non-NULL value.

Syntax
COALESCE(value1, value2, ...)

Example 1

SELECT order_id,
       COALESCE(status, 'Unknown') AS order_status
FROM orders;

If status is NULL, SQL returns Unknown instead.

Tiny example dataset: order_id 1006 has status NULL.

Output
1006 | Unknown

Example 2

SELECT order_id,
       COALESCE(delivery_date, 'Not scheduled') AS delivery
FROM orders;

Missing delivery dates are displayed as Not scheduled.

Output
1002 | Not scheduled 1003 | Not scheduled
Key point: COALESCE changes the query output. It does not update the stored database value.

NULLIF()

NULLIF compares two values. If they are equal, it returns NULL. Otherwise, it returns the first value.

Syntax
NULLIF(value1, value2)

Example 1

SELECT NULLIF(10, 10);
Output
NULL

Example 2

SELECT NULLIF(20, 0);
Output
20

Example 3

SELECT order_id,
       NULLIF(quantity, 0) AS quantity_value
FROM orders;

A quantity of 0 would be returned as NULL.

Output
1001 | 20 1002 | 50 1003 | 10 1004 | 35 1005 | 8
04

IN / BETWEEN / LIKE

These operators provide shorter ways to match lists, ranges, and text patterns.

IN

IN checks whether a value matches any value in a list.

Syntax
WHERE column_name IN (value1, value2, ...)

Example 1

SELECT order_id, product
FROM orders
WHERE product IN ('Copper', 'Nickel');
Output
1001 | Copper 1003 | Nickel 1004 | Copper

IN is easier to read than writing several OR conditions.

Compare:

product = 'Copper'
OR product = 'Nickel'

with:

product IN ('Copper', 'Nickel')

NOT IN

NOT IN excludes values listed inside the parentheses.

Example

SELECT order_id, status
FROM orders
WHERE status NOT IN ('Rejected', 'Cancelled');
Output
1001 | Completed 1002 | Pending 1004 | Completed

BETWEEN

BETWEEN checks whether a value falls inside a range. It includes both boundary values.

Syntax
WHERE column_name BETWEEN low_value AND high_value

Example 1

SELECT order_id, price
FROM orders
WHERE price BETWEEN 8000 AND 9000;
Output
1001 | 8500 1004 | 8700

Example 2

SELECT order_id, quantity
FROM orders
WHERE quantity BETWEEN 10 AND 20;
Output
1001 | 20 1003 | 10

10 and 20 are both included.

NOT BETWEEN

NOT BETWEEN returns values outside a range.

Example

SELECT order_id, price
FROM orders
WHERE price NOT BETWEEN 8000 AND 9000;
Output
1002 | 2450 1003 | 16000 1005 | 2800

LIKE

LIKE matches text using a pattern.

Example 1

SELECT customer
FROM orders
WHERE customer LIKE 'A%';

What it means: Return customers whose names begin with A.

Output
ABC Metals Apple Resources

% matches zero or more characters.

Example 2

SELECT customer
FROM orders
WHERE customer LIKE '%Metals';
Output
ABC Metals Eastern Metals Pacific Metals

The pattern means the value must end with Metals.

NOT LIKE

NOT LIKE excludes text that matches a pattern.

Example

SELECT customer
FROM orders
WHERE customer NOT LIKE 'A%';
Output
Global Trade Eastern Metals Pacific Metals

% Wildcard

% matches zero or more characters inside a LIKE pattern.

Examples

'A%' → starts with A '%Metals' → ends with Metals '%Trade%' → contains Trade

_ Wildcard

_ matches exactly one character.

Example

WHERE code LIKE 'A_'

Possible matches:

A1 AB AX

Not a match: A100, because _ matches only one character.
