PART II · FRONTEND & BROWSER

Event

An action or change that software can detect and respond to.

01 · What is it?

An event is something that happens in the browser or user interface.

JavaScript can detect events and run code in response.

A simple definition: an event tells software that something happened.

02 · Think of it like...

Think of an event as a signal.

Something happens. The signal is detected. Software responds.

Something Happens
→
Event
→
Software Response

03 · What does it do?

Events allow software to react to user and system actions.

Events are used throughout interactive web pages.

Click a Button

07 · Do Not Confuse

Event ≠ Event Listener

Event
Something that happens.

Event Listener

Code that waits for the event.

Event = Signal·Event Listener = Listener
