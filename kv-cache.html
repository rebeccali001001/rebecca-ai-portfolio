03 · Tokens, Context & Inference

What is a KV Cache?

A KV cache stores attention keys and values for tokens already processed, so generation can reuse them instead of recomputing the same history each step.

Topic detail

In a Transformer attention layer, a new query can attend to earlier keys and values. During autoregressive decoding, the runtime keeps those tensors for the existing sequence and computes only the new token's state.

The cache is temporary inference state. It is not the model's weights and it is not long-term memory.

Why it matters

Reusing K/V state can reduce repeated work and improve generation speed. The trade-off is memory: cache size grows with sequence length, layers, heads, batch size, and the precision used to store it.

cache pressure ∝ layers × sequence length × concurrent sequences

Sample

When a model has read tokens A, B, and C and is predicting D, the runtime can reuse K/V state for A–C while calculating the new state for D.

Easy analogy

Like keeping a page of notes after checking earlier facts, the cache lets the runtime reuse prior attention state. Unlike human notes, its format is numeric tensors and it is tied to a particular live request.
