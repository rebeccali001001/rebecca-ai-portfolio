03 · Tokens, Context & Inference

What is a KV cache?

A KV cache stores attention information for tokens the model has already processed, so it can reuse that work while generating the next tokens.

Definition

The key–value cache is temporary memory used during inference to avoid recomputing earlier attention states for every new output token.

In plain language

Imagine putting a coffee order ticket on a tray after reading it. When the robot writes the confirmation word by word, it can glance at the tray instead of rereading the whole ticket from scratch each time.

Key points

  • It can reduce repeated computation during generation.
  • It grows with the sequence and can consume memory.
  • It helps reuse work; it does not make the context window larger.

Sample: keep the ticket nearby

For “one oat latte, no sugar, table six,” the robot reads the order once, keeps the attention state on a tray, and uses it as it produces “Got it — one oat latte…”

1 · readOrder ticketEarlier tokens are processed.
2 · cacheAttention trayReusable key/value states stay nearby.
3 · generateWrite next tokenThe answer can continue without full rereading.

Where it matters

KV cache matters in streaming chat, long outputs, local model serving, concurrent requests, and memory planning. Measure cache growth alongside context length and batch size.

A cache can improve generation work, but it is not a second context window and it is not permanent memory.
