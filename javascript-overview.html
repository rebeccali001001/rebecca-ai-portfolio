WEB · JAVASCRIPT

JavaScript Overview

JavaScript adds behavior to web pages: it responds to users, changes the DOM, stores state, and calls APIs.

What JavaScript does

HTML

Defines what exists: headings, buttons, forms, and content.

CSS + JavaScript

CSS controls appearance; JavaScript controls behavior and data.

User clicks a button → JavaScript handles the click → Read and validate input → fetch() an API → Update the DOM

Learning path

Start with values and control flow, then learn functions, arrays, and objects. Next connect those skills to DOM, events, forms, and APIs. The final topics cover storage, classes, collections, and common modern syntax.

Because you already know Python, each topic includes a direct syntax comparison to make the mapping faster.

Browser mental model

HTML → browser parses → DOM tree → JavaScript reads / changes it → Events and API responses → Updated page
