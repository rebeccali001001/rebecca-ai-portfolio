What is a Foundation Model?

What is it?

A foundation model is a broadly trained AI model that can be reused for many different tasks.

People can adapt the same base model with prompts, retrieval, fine-tuning, or tools instead of training a separate model from zero for every task.

Think of it like...

Think of it like a broad school education. The person has a base of skills, then uses extra instructions or training for a particular job.

How it works

Broad pre-training creates a base model. Later application work adapts it for a task.

1 · Broad dataLearn general patternsThe model trains on large and varied data.
2 · Pre-trainingBuild a baseTraining produces a broadly capable model.
3 · AdaptationAdd a task layerPrompts, retrieval, fine-tuning, or tools provide specialization.
4 · ApplicationUse the modelA product sends task-specific input.
5 · EvaluationCheck the fitTests confirm quality and boundaries for the target use.

Real-world examples

Everyday example · Writing helper

Input: A request to rewrite a note

System: A general language model follows the requested style

Output: A clearer message

AI product example · Image creation

Input: A text description

System: A foundation model maps language to visual patterns

Output: A generated image

Business example · Support assistant

Input: A policy question

System: A base model plus approved context handles the task

Output: A cited draft answer

What it is NOT

Foundation Model ≠ Finished product

Foundation Model: A reusable base model

Finished product: A product also includes interface, data, rules, and operations

Foundation Model ≠ Fine-tuning

Foundation Model: The broadly trained starting point

Fine-tuning: Additional training for narrower behavior

Foundation Model ≠ Database

Foundation Model: Knowledge encoded as model parameters

Database: Explicit records stored for retrieval

Related concepts

Pre-training → Foundation Model → Prompting · RAG · Fine-tuning · Tools
These are related adaptation paths, not a strict parent-child tree.
