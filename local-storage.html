PART II · FRONTEND & BROWSER

Local Storage

Browser storage used to keep small amounts of data on a user's device.

01 · What is it?

Local Storage is a browser feature that allows a web application to save data on the user's device.

The data can remain available after the browser tab or window is closed.

Simple Definition: Local Storage saves small pieces of data in the browser.

02 · Think of it like...

Think of Local Storage as a small drawer inside the browser.

A web application can place information in the drawer and read it again later.

Web App
→
Save Data
→

03 · What does it do?

Local Storage can save:

User Preferences

Remember a person's choices in the browser.

Theme Settings

Keep a light or dark theme between visits.

Simple Draft Data

Keep small unfinished pieces of work.

Recently Viewed Items

Remember which items a user opened recently.

Small UI Settings

Preserve simple interface choices.

04 · Where is it used?

Local Storage is commonly used for browser-side data that does not need to be stored on the server.

Dark Mode
Language Preference
Collapsed Menu State
Draft Text
Recent Search

05 · Example

localStorage.setItem("theme", "dark");

const theme = localStorage.getItem("theme");
setItem()saves a value.
getItem()reads a saved value.
"theme"is the key.
"dark"is the value.

06 · How it connects

→

JavaScript can save and read Local Storage directly in the browser. No backend request is required for this basic operation.

07 · Do Not Confuse

Local Storage

Small browser-side storage for one user's browser.

Database

Server-side or system-level storage used by applications.

Local Storage = Browser
Database = Application Data System
