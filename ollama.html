07 · Model Serving & Local AI

What is Ollama?

Ollama is a local model runtime that gives an application a simple boundary for downloading, running, and talking to open models on your own machine.

Detail

The runtime abstracts model loading and exposes a local API. The deployment still owns memory limits, model files, context settings, concurrency, logging, and access control.

Local does not mean unconstrained.

Sample

A local assistant calls the runtime over localhost, streams tokens to the UI, and keeps sensitive source material on-device.

request → local runtime → model → streamed response
