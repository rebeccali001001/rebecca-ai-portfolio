07 · Model Serving & Local AI · Topic 01

What is Ollama?

Ollama is a local model runtime: it gives an application a simple boundary for loading a model, sending a request, and streaming the answer on your own machine.

Definition

A runtime is the software that turns a model file into a running service. Ollama handles common serving work such as model packaging, local process management, and a local API.

In plain language

Think of Ollama as the counter between your app and the cook. It accepts the order, gets the selected model ready, and returns the answer. It is not the model’s learned knowledge and it cannot create more memory.

Key points

  • Local boundary: prompts and responses can stay on-device.
  • Simple interface: an app can call a local endpoint instead of managing model internals.
  • Still a deployment: memory, context, access control, logging, and concurrency remain your responsibility.

Life-like Sample: a private notes assistant

You ask an assistant to summarize private trip notes. The app sends the request to localhost; Ollama loads the selected model; the model generates tokens; the answer streams back into the app. The notes do not need to leave the laptop.

your app → localhost / Ollama → selected model → streamed response

Where it is useful

  • Private prototypes and offline assistants
  • Local coding or document workflows
  • Testing model behavior before choosing hosted infrastructure
  • Applications that need a stable local serving boundary

What to measure

MemoryWeights + KV cache + runtime overhead
LatencyTime to first token and steady speed
StabilityMulti-turn behavior under real context
