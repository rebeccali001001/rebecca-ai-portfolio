05 · Embeddings, RAG & Vector Search

What is Vector Search?

Vector search finds the items closest to a query in embedding space, so retrieval can match intent instead of relying only on exact keywords.

Detail

A vector index stores embeddings and makes nearest-neighbor search efficient. At query time, the application embeds the question, retrieves the top-k candidates, then filters or reranks them using metadata, lexical signals, or a cross-encoder.

The best k is not universal: too few results can miss evidence, while too many can add noise and consume context.

Retrieve a small, relevant evidence set before generation.

Key takeaway

Vector search is a candidate-finding step. Treat ranking, access control, freshness, and source quality as part of retrieval—not as details to solve after the model answers.

Sample
