08 · Tables

Represent data that naturally belongs in rows and columns.

What is it?

A table communicates relationships between tabular values. Think of it like: a spreadsheet with a clear purpose and headers.

Basic Syntax

<table><caption>Orders</caption><thead><tr><th>ID</th><th>Status</th></tr></thead>
<tbody><tr><td>1001</td><td>Open</td></tr></tbody></table>

Key Syntax

Use table, caption, thead, tbody, tfoot, tr, th, and td. rowspan and colspan merge cells when truly necessary.

Common Mistakes

Tables are for tabular data, not page layout. Do not use a visual layout in place of a header structure.

Quick Reference

th header cell · td data cell · tr row · caption table title.
