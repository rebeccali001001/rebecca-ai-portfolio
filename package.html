MODULE 08 · DEVELOPMENT & GIT

Package

A distributable collection of software files and metadata that can be installed or reused.

01

What is it?

A package groups related code so it can be reused and distributed.

Backend projects often depend on packages created by other developers or teams.

Simple Definition: A package is reusable code bundled together.

02

Think of it like...

Think of a toolbox.

Instead of building every tool yourself, you install a package and use the tools it provides.

Reusable toolsbundled and ready to use
03

What does it do?

Packages can provide:

Frameworks

Database Drivers

HTTP Clients

Validation Tools

Logging Tools

Utility Functions

04

Where is it used?

Packages are used in:

Python ProjectsBackend ApplicationsAPIsAutomationData ProcessingTesting
05

Example

Python package: fastapi

Install

pip install fastapi

Use

from fastapi import FastAPI
06

How it connects

Package Repository→Install→Project Dependency→Import→Application

A package moves from a repository into the project environment, then becomes available to application code.

07

Do Not Confuse

Package

A collection of related code that may contain multiple modules.

Module

A single code file or logical unit.

Package ≠ Module
