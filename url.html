PART III · HTTP & APIs

URL

The address used to locate a resource on the web.

01 · What is it?

What is it?

URL stands for Uniform Resource Locator.

A URL tells software where a web resource is located.

Simple Definition:
A URL is the address of a web resource.

02 · Think of it like...

Think of it like...

Think of a URL as a street address.

The address tells you where to go.

A URL tells the browser or software where to find a resource.

03 · What does it do?

What does it do?

A URL can identify:

A Web PageA document shown in a browser.
An API EndpointA specific address for an API function.
An ImageA visual resource on the web.
A FileA resource that software can access.
A DownloadA resource offered for retrieval.
A Specific ResourceA precise item identified by its address.
04 · Where is it used?

Where is it used?

BrowsersLoad pages and other web resources.
LinksConnect one resource to another.
API RequestsTell software where to send a request.
ImagesPoint to visual files.
DownloadsLocate files for retrieval.
WebhooksIdentify where event data should be sent.
05 · Example

Example

Use:

https://example.com/api/orders/1001?status=completed

Break it into simple parts:

httpsProtocol
example.comDomain
/api/orders/1001Path
?status=completedQuery String

Different parts of the URL tell the system how and where to access the resource.

06 · How it connects

How it connects

Client→URL→HTTP Request→Server Resource

HTTP requests are sent to URLs.

API endpoints are usually represented by URLs or URL paths.

07 · Do Not Confuse

Do Not Confuse

URL

The complete address of a resource.

Example: https://example.com/api/orders

Domain

The main human-readable name of a website or service.

Example: example.com

08 · Topic Glossary

Topic Glossary

English Term中文Simple English中文小白理解
URL网址 / 资源地址The address used to locate a web resource.用来找到网页、接口或其他网络资源的地址。
Protocol协议The communication scheme at the beginning of a URL.URL 开头表示使用哪种通信方式的部分。
Domain域名The human-readable name of a website or service.用户容易阅读的网站或服务名称。
Path路径The part of a URL that identifies a specific resource.URL 中用来定位某个具体资源的路径部分。
Query String查询字符串Extra parameters added after ? in a URL.URL 中 ? 后面携带的一组查询参数。
Query Parameter查询参数A key-value value passed in the URL.通过 URL 传递的一组参数值。
Resource资源Something that can be accessed through a URL.可以通过 URL 访问的网页、数据、文件或接口资源。
Endpoint接口地址A URL used to access a specific API function.用来访问某个具体 API 功能的地址。
HTTPSHTTPSThe secure protocol commonly used at the start of web URLs.Web URL 开头常见的安全通信协议。
09 · What to Remember

What to Remember

A URL identifies where a web resource is located.

URLs can point to pages, files, or API endpoints.

A URL contains several parts such as protocol, domain, path, and parameters.

Final:
Protocol + Domain + Path + Parameters = URL
