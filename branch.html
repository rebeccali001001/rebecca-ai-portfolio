Branch

An independent line of development in a Git repository.

01

What is it?

A branch lets developers work on changes without directly changing another branch such as main.

Branches allow multiple lines of development to exist in the same repository.

Simple Definition:
A branch is a separate line of code development.

02

Think of it like...

Think of a branch as creating a side road from the main road.

You can work on the side road and later reconnect it.

Do Not Confuse

Branch

One line of development inside a repository.

Repository

The whole project containing branches and history.

Branch ≠ Repository

08

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Branch分支An independent line of development in Git.Git 中可以独立修改代码的一条开发线。
Feature Branch功能分支A branch used to develop a specific feature.专门用于开发某个新功能的分支。
Main Branch主分支The primary branch representing the main code line.通常代表项目主要稳定代码线的分支。
Checkout / Switch切换分支Changing the current working branch.让本地工作目录切换到另一个 Git 分支。
Branch Name分支名称The label used to identify a branch.用来区分不同开发分支的名称。
Merge合并Combining a branch's changes into another branch.把一个分支上的修改整合进另一个分支。

Feature work is often done outside main.
