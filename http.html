PART III · HTTP & APIs

HTTP

The basic communication protocol used by the web.

01 · What is it?

HTTP stands for HyperText Transfer Protocol.

It defines how clients and servers exchange requests and responses on the web.

Simple Definition：
HTTP is the basic communication language of the web.

02 · Think of it like...

Think of HTTP as a set of delivery rules.

One side sends a request.

The other side returns a response.

Both sides follow the same communication format.

Flow:

Client
→
HTTP Request
→
Server
→
HTTP Response
→
Client

03 · What does it do?

HTTP helps software:

Request Web Pages
Call APIs
Send Data
Receive Data
Return Status Information

04 · Where is it used?

HTTP is used between:

Browser and Server
Frontend and Backend
Mobile App and API
Service and Service
System and External API

05 · Example

GET /api/orders HTTP/1.1

GET
is the request method.

/api/orders
is the requested resource.

HTTP/1.1
shows the HTTP protocol version.

HTTP/1.1 200 OK

The client sends an HTTP request.

The server returns an HTTP response.

06 · How it connects

Frontend→HTTP Request→API→Backend→HTTP Response→Frontend

HTTP carries requests and responses between software systems.

APIs commonly use HTTP as their communication protocol.

07 · Do Not Confuse

HTTP

A communication protocol.

API

A defined interface that software uses to request data or actions.

HTTP = How the message travels
API = What software interface is being used

09 · What to Remember

HTTP is the basic communication protocol of the web.

HTTP connects clients and servers through requests and responses.

Many APIs use HTTP.
