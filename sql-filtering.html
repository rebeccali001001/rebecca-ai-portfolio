01

WHERE

WHERE filters rows based on a condition.

Explanation

It tells SQL which rows should remain in the result.

Common scenarios

  • show confirmed orders
  • find one metal
  • filter by value, date, or status

Syntax

SELECT column_name
FROM table_name
WHERE condition;

Example

SELECT order_id, customer_name, metal
FROM sales_orders
WHERE status = 'Confirmed';

What happens: Only confirmed rows are returned.

PM takeaway: WHERE controls which rows appear.

02

Comparison Operators

Use =, <>, !=, >, <, >=, and <= to compare values.

SELECT order_id, quantity_mt, price_usd
FROM sales_orders
WHERE quantity_mt >= 20
  AND price_usd < 9000;

PM takeaway: Comparison operators turn a business rule into a row-level test.

03

AND, OR, NOT, and Parentheses

AND requires both conditions. OR allows either. NOT reverses a condition. Parentheses make mixed logic explicit.

SELECT *
FROM sales_orders
WHERE (metal = 'Copper' OR metal = 'Aluminum')
  AND status = 'Confirmed';

PM takeaway: Use parentheses when combining alternatives and requirements.

04

NULL, IS NULL, IS NOT NULL, COALESCE, and NULLIF

NULL means missing or unknown. It is not zero or an empty string.

SELECT order_id, price_usd
FROM sales_orders
WHERE price_usd IS NULL;

SELECT order_id, price_usd
FROM sales_orders
WHERE price_usd IS NOT NULL;

Important: Use IS NULL or IS NOT NULL, never = NULL.

SELECT COALESCE(status, 'Unknown'), NULLIF(quantity_mt, 0)
FROM sales_orders;

COALESCE() returns the first non-NULL value. NULLIF() returns NULL when two values are equal.

PM takeaway: Missing-value checks use special NULL syntax.

05

IN and NOT IN

IN matches one value from a list and is easier to read than repeated OR conditions.

SELECT order_id, metal, status
FROM sales_orders
WHERE metal IN ('Copper', 'Aluminum');

NOT IN excludes the listed values.

PM takeaway: Use IN for a clear set of allowed values.

06

BETWEEN and NOT BETWEEN

BETWEEN checks an inclusive range.

SELECT order_id, price_usd
FROM sales_orders
WHERE price_usd BETWEEN 8000 AND 9000;

BETWEEN includes both boundary values. NOT BETWEEN excludes the range.

PM takeaway: Use it when both endpoints belong in the result.

07

LIKE, NOT LIKE, %, and _

LIKE matches text patterns. % matches zero or more characters; _ matches exactly one.

SELECT order_id, customer_name
FROM sales_orders
WHERE customer_name LIKE 'A%';

NOT LIKE excludes matching text.

PM takeaway: Wildcards find text when only part of the value is known.

08

Putting It Together

SELECT order_id, customer_name, metal, quantity_mt
FROM sales_orders
WHERE metal IN ('Copper', 'Aluminum')
  AND status = 'Confirmed'
  AND quantity_mt >= 20;
  • FROM → source table
  • WHERE → starts filtering
  • IN → checks allowed values
  • AND → requires all conditions
  • >= → checks minimum quantity
