05 · Embeddings, RAG & Vector Search

What are Embeddings?

Embeddings turn text, images, or other content into vectors that preserve useful relationships in a machine-readable space.

Detail

An embedding model maps an input to a list of numbers. Inputs with similar meaning tend to land closer together, which makes semantic search possible even when the wording is different.

Good retrieval still depends on the embedding model, chunking strategy, metadata, distance metric, and the domain represented in the source data.

Meaning becomes searchable when it has a location in vector space.

Key takeaway

Embeddings are representations, not answers. They help an application find relevant content; a model or downstream system still has to use and validate that content.

Sample

A user asks, “Can I cancel after the vessel sails?” The query and policy chunks are embedded separately. The closest chunk is selected because it discusses post-departure cancellation, even though it never uses the exact word “sails.”
