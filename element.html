Element

A single building block of a web page.

01 · What is it?

An element is one part of an HTML page.

Headings, paragraphs, buttons, images, forms, and links are all elements.

Simple Definition: An element is one piece of a web page.

02 · Think of it like...

Think of a web page as a structure made from blocks.

Each element is one block.

Web Page
│
├─ Heading
├─ Paragraph
├─ Image
├─ Input
└─ Button

03 · What does it do?

Elements give a web page structure and meaning.

They can:

  • Display Content
  • Collect Input
  • Create Links
  • Show Images
  • Trigger Actions
  • Group Content

04 · Where is it used?

Elements appear everywhere in HTML pages and the DOM.

  • <h1>
  • <p>
  • <a>
  • <img>
  • <input>
  • <button>
  • <div>

05 · Example

<button class="save-button">Save</button>
buttonis the element type.
classis an attribute.
save-buttonis the class value.
Saveis the visible text.

06 · How it connects

HTML→Element→DOM→JavaScript / CSS

HTML creates elements.

The browser represents those elements in the DOM.

CSS styles them.

JavaScript can read or change them.

07 · Do Not Confuse

Element

The actual page component.

Attribute

Extra information attached to the element.

<button class="save-button">

button = Element
class = Attribute
