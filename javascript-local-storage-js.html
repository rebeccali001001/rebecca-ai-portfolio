26 · Local Storage

Local Storage saves small string values in one browser.

What is it?

Local Storage

How it works

JavaScript evaluates this feature when the code reaches it. The result can be stored, returned, displayed, or used to decide what happens next.

Simple Example

# browser-specific
localStorage.setItem("theme", "dark");
