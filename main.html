Main

The primary branch that usually represents the main shared code line in a Git repository.

01

What is it?

Main is the primary branch that usually represents the main shared code line in a Git repository.

Main is the shared branch that represents the project’s central line of development.

02

Think of it like...

Think of a repository as a project with several working paths. Main is the shared path that the team returns to when work is ready to be combined.

MainThe shared path
Other branchesSeparate paths for changes
03

What does it do?

Main gives a team a shared place for the central version of the project.

Shared BaseProvides a common starting point.
Combined WorkReceives changes that are ready to join the project.
Team ReferenceShows the version the team treats as central.
Release Starting PointCan provide code for a release or deployment workflow.
04

Where is it used?

Main is used in Git repositories, team development workflows, code review, continuous integration, and release workflows.

Git Repositories
Team Development
Code Review
Release Workflows
05

Example

A team is building a website. A developer creates a separate branch for a change, commits the work, and opens a pull request. After review, the change is merged into main.

Starting point

The developer starts from main.

Separate work

The developer makes changes on another branch.

Review

The team checks the proposed change.

Combine

The approved change is merged into main.

06

How it connects

Repository→Main→Feature Branch→Commit→Pull Request→Code Review→Merge to Main

Main connects shared code with the branch, review, and merge workflow.

07

Do Not Confuse

Main ≠ Every Branch

Main is one branch with a special shared role. Other branches are usually used for separate work.

Main ≠ GitHub

Main is a branch. GitHub is a platform that can host and collaborate on repositories.

Main ≠ Production

Main may be connected to deployment, but it is not automatically the live production environment.

Main is a branch with a shared role, not a separate version-control system.
