PART IV · BACKEND

External API

An API provided by another system that the backend calls to use external data or capabilities.

01 · What is it?

What is it?

An external API is an interface owned or operated by another system.

A backend can call it to retrieve data or trigger actions outside the current application.

Simple DefinitionAn external API lets your backend use another system’s service.

02 · Think of it like...

Think of it like...

Think of outsourcing a task.

Your backend needs something another system provides. It sends an API request and waits for a response.

Backend→External API→External System→Response
03 · What does it do?

What does it do?

External APIs let a backend use capabilities that are not built into the current application.

Market PricesRead current or historical pricing data.
PaymentsStart or confirm a payment.
ShippingCreate labels or track deliveries.
Identity ServicesVerify an identity or account.
EmailSend transactional messages.
AI ServicesUse an external model or capability.

How it connects

07 · Do Not Confuse

Do Not Confuse

External API

Provided by another system or organization. The current backend calls it as a dependency.

Internal API

Provided within the same organization or platform. It connects parts of the same system boundary.

External API = another system’s interface.
Internal API = an interface inside the same organization or platform.

09 · What to Remember

What to Remember

External APIs provide capabilities from other systems.

Backend services often call them through HTTP clients.

Timeouts, retries, authentication, and error handling are important when using external APIs.
