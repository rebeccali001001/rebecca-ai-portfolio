02 · Elements & Tags

Elements are the named building blocks that describe page content.

What is it?

An element usually has an opening tag, content, and a closing tag. Think of it like: a labeled box that tells the browser what its content is.

Basic Syntax

<p>A paragraph element</p>
<div><span>Nested text</span></div>
<br>
<hr>

br and hr are void elements: they have no closing tag or content.

Common Examples

div is a general structural container; span is a small inline text container; p marks a paragraph; h1–h6 mark headings.

Common Mistakes

Do not close void elements like <img>, or use div when a more meaningful element fits. “Block” and “inline” are CSS display behavior, so keep that separate from HTML meaning.

When to use it

Use an element that best describes the content. Related: Semantic HTML, Attributes.

Quick Reference

<div> group structure · <span> annotate text · <hr> thematic break.
