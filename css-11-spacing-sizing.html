01 · What is it?

Set an element’s outer space, inner space, and dimensions.

02 · Think of it like...

This is the tape measure for a component.

03 · Basic Syntax

.content { width: 100%; max-width: 70rem; margin: 0 auto; padding: 24px; aspect-ratio: 16 / 9; }

04 · Visual Model

11 · Spacing & Sizing

05 · How it works

width:100% lets a box fill its parent; max-width stops it becoming too wide. Horizontal margin:auto centers a constrained block.

08 · Common Patterns
