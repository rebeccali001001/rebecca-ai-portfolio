CSS Overview

CSS is the language that turns HTML structure into a readable, responsive visual interface.

01 · What is CSS?

CSS means Cascading Style Sheets. It controls layout, colors, spacing, typography, responsive behavior, animation, and visual presentation.

LayoutColorsSpacingTypographyResponsive behaviorAnimation

02 · Structure, presentation, behavior

Three browser languages

HTML → structure
CSS → presentation
JavaScript → behavior

HTML says that a button exists. CSS decides its size, color, and position. JavaScript can make it respond to a click.

03 · A CSS rule

selector {
  property: value;
}
selector — what to styleproperty — settingvalue — chosen setting

The property and value together are a declaration.

04 · How the browser draws a page

Rendering path

HTML ↓ DOM
CSS ↓ CSSOM
DOM + CSSOM ↓ Render Tree ↓ Layout ↓ Paint

The browser combines structure and styles, calculates where things go, then paints pixels on screen.
