PART II · FRONTEND & BROWSER

CSS

The language used to control the appearance and layout of web pages.

01 · What is it?

CSS stands for Cascading Style Sheets.

It controls how HTML elements look and how they are arranged on the screen.

Simple Definition: CSS controls how a web page looks.

02 · Think of it like...

Think of HTML as the structure of a room. CSS is the interior design.

HTMLDecides what exists.
CSSDecides how it looks.
PageCombines structure and style.

03 · What does it do?

CSS controls:

Colors
Fonts
Spacing
Sizes
Borders
Positions
Layouts
Responsive Behavior

04 · Where is it used?

CSS is used to style web pages and frontend interfaces.

It can control both individual elements and the overall page layout.

Web Pages
Frontend Interfaces
Individual Elements
Page Layouts

05 · Example

.button {
  background: black;
  color: white;
  padding: 12px;
}
.button

selects elements with the class "button".

background

sets the background.

color

sets the text color.

padding

adds space inside the element.

07 · Do Not Confuse

HTML

Defines what exists on the page.

CSS

Controls how those elements look and are arranged.

HTML = Structure
CSS = Style

08 · Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
CSS层叠样式表The language used to style web pages.用来控制网页样式和布局的语言。
Selector选择器A pattern used to choose which elements to style.用来选择哪些页面元素需要应用样式的规则。
Property属性A style setting such as color or width.CSS 中需要设置的样式项目，例如颜色或宽度。
Value值The setting assigned to a CSS property.给某个 CSS 属性设置的具体值。
ClassClass 类名A reusable name used to select multiple elements.可以给多个元素使用并应用相同样式的名称。
Layout布局The arrangement of elements on a page.页面中不同元素的位置和排列方式。
Margin外边距Space outside an element.元素外部与其他元素之间的空间。
Padding内边距Space inside an element around its content.元素内容与边框之间的内部空间。
Flexbox弹性布局A CSS layout system for arranging items.用来灵活排列页面元素的一种 CSS 布局方式。
Grid网格布局A CSS system for arranging content in rows and columns.按行和列组织页面元素的一种 CSS 布局方式。
Responsive Design响应式设计A design that adapts to different screen sizes.页面根据不同屏幕尺寸自动调整布局。

09 · What to Remember

CSS controls the visual appearance of web pages.

CSS works with HTML.

CSS also controls layout and responsive behavior.
