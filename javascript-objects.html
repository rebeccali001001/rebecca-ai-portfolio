09 · Objects

Objects group named properties that describe one thing.

What is it?

Objects

Think of it like...

A profile card with labeled fields.

Basic Syntax

A profile card with labeled fields.

How it works

JavaScript evaluates this feature when the code reaches it. The result can be stored, returned, displayed, or used to decide what happens next.

Simple Example

user = {"name": "Rebecca"}
const user = { name: "Rebecca", role: "PM" };

Real Web Example

// Objects in a web page
console.log("Objects is running");

Common Mistakes

Do not confuse a similar-looking syntax with the same behavior. Read errors carefully and test with a small value first.

Python Comparison

Python

user = {"name": "Rebecca"}

JavaScript

const user = { name: "Rebecca", role: "PM" };

When to use

Use Objects when it makes the intent of your code clearer and smaller.
