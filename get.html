PART III · HTTP & APIs

GET

An HTTP method commonly used to retrieve data.

01 · What is it?

What is it?

GET is an HTTP method commonly used to request existing data.

It asks the server to return information.

Simple Definition: GET asks the system to give you data.

02 · Think of it like...

Think of it like...

Think of GET as asking:

“Show me the information.”

Client→GET Request→Server→Data→Client
03 · What does it do?

What does it do?

GET is commonly used to:

Load a Page
Retrieve a List
Retrieve One Record
Search Data
Read Existing Information
04 · Where is it used?

Where is it used?

GET requests are commonly used in:

Web Pages
APIs
Search
Dashboards
Reports
Data Lookups
05 · Example

Example

GET /api/orders

Retrieve a list of orders.

GET /api/orders/1001

Retrieve order 1001.

GET /api/orders?status=completed

Retrieve orders filtered by status.

06 · How it connects

How it connects

Client→GET→Endpoint→Backend→Read Data→Response

GET requests usually read existing data and return it to the client.

07 · Do Not Confuse

Do Not Confuse

GET

Usually retrieves existing data.

POST

Usually creates or submits data.

GET = Read
POST = Create / Submit
08 · Topic Glossary

Topic Glossary

English Term中文Simple English中文小白理解
GET获取An HTTP method commonly used to retrieve data.通常用于获取已有数据的 HTTP 方法。
Read读取Getting existing information without creating new data.获取系统中已经存在的数据。
Endpoint接口地址The API address a GET request is sent to.GET 请求发送到的具体 API 地址。
Resource资源The data being requested.GET 请求想获取的数据或业务对象。
Query Parameter查询参数A value added to a URL to filter or control a request.加在 URL 中用来筛选或控制请求的参数。
Path Parameter路径参数A value placed inside the URL path.放在 URL 路径中用来标识具体资源的参数。
Response响应Data returned after the GET request is processed.GET 请求处理后返回的数据。
Status Code状态码A number showing the result of the request.表示 GET 请求处理结果的数字。
Client客户端The side that sends the GET request.发起 GET 请求的一端。
Server服务器The side that receives the request and returns data.接收 GET 请求并返回数据的一端。
09 · What to Remember

What to Remember

GET is commonly used to retrieve data.

GET usually reads existing resources.

A GET request returns data in the response.
