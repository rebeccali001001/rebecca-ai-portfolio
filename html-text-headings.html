04 · Text & Headings

Use text elements to express both content and meaning.

What is it?

Text tags describe headings, paragraphs, emphasis, quotations, and code. Think of it like: editorial markup that explains a document’s hierarchy and intent.

Basic Syntax

<h1>Page title</h1>
<p>A paragraph with <strong>importance</strong>.</p>
<blockquote>A quoted source.</blockquote>

Key Syntax

h1–h6 are hierarchical headings; p is a paragraph; strong and em add importance and emphasis. b and i are visual alternatives. Also use small, mark, sub, sup, code, and pre when their meaning fits.

strong vs b

strong communicates importance; b draws visual attention without necessarily adding importance. Prefer semantic meaning first.

Common Mistakes

Do not choose a heading merely for its size or skip hierarchy to style text. Use CSS to change appearance.

When to use it

Use headings to outline a page and paragraphs for prose. Related: Semantic HTML.

Quick Reference

h1 page topic · p paragraph · code inline code · pre preformatted content.
