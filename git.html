PART VIII · DEVELOPMENT & GIT

Git

A distributed version control system used to track changes in source code.

01

What is it?

Git is a version control system that records changes to files over time.

It helps developers create commits, work on branches, compare changes, merge work, and return to earlier versions.

Git tracks how code changes.

02

Think of it like...

Think of Git as a timeline for a software project.

Every important change can be recorded so the team can see what changed and when.

Do Not Confuse

Git ≠ GitHub

Git

The version control system.

GitHub

An online platform for hosting and collaborating on Git repositories.

Git = Version Control Tool

GitHub = Collaboration Platform
