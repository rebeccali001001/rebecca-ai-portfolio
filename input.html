Input

A control used to collect data from users.

01 · What is it?

What is it?

An input is a form control that lets users enter or select data.

Inputs can collect text, numbers, dates, files, choices, and other values.

Simple Definition: An input collects one piece of user data.

02 · Think of it like...

Think of it like...

Think of an input as one blank field on a form.

Each field asks the user for one specific value.

Form
│
├─ Name Input
├─ Quantity Input
├─ Date Input
└─ File Input
03 · What does it do?

What does it do?

Inputs can collect:

TextWords and short messages
NumbersNumeric values and quantities
DatesCalendar dates
PasswordsHidden password text
FilesSelected files for upload
SelectionsChoices from available options
04 · Where is it used?

Where is it used?

Inputs are commonly used in:

Login Forms
Search Boxes
Order Forms
Registration Forms
Settings
File Uploads
05 · Example

Example

<label for="quantity">Quantity</label>
<input id="quantity" type="number" value="10">
input creates the control.
type="number" defines the type of data expected.
value="10" sets the current value.
06 · How it connects

How it connects

User→Input→Value→Form→Submit→Application

Inputs collect the values that forms and JavaScript can use.

07 · Do Not Confuse

Do Not Confuse

Input

One control used to collect a value.

Form

A group of controls used to collect related data.

One form can contain many inputs.

Topic Glossary

English Term中文Simple English中文小白理解
Input输入控件A control used to collect user data.用来收集用户输入数据的页面控件。
Value值The data currently stored in an input.输入控件中当前保存的数据。
type类型An attribute that defines what kind of input it is.用来指定输入控件类型的属性。
text文本输入An input type used to enter text.用来输入普通文字的输入类型。

file文件输入An input type used to select files.用来选择并上传文件的输入类型。
placeholder占位提示Hint text shown inside an empty input.输入框为空时显示的提示文字。
required必填An attribute that requires a value.要求该输入控件必须填写的属性。
Form表单A group of controls used to collect related data.用来收集一组相关数据的页面区域。
Event事件An action such as typing or changing an input.输入或修改控件时产生的事件。
