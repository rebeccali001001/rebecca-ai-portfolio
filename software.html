PART I · HOW SOFTWARE WORKS

Software

The programs and instructions that make computers perform useful tasks.

01

What is it?

Software is the programs and data that make computers perform useful tasks.

It can be a website, mobile app, desktop application, or backend system.

Software tells a computer what to do.

02

Think of it like...

Think of hardware as the machine and software as the instructions that tell the machine what to do.

Hardware

The machine

Software

The instructions

Computer │ ├─ Hardware │ Physical parts │ └─ Software Instructions and programs
03

What does it do?

Software receives input, processes information, follows rules, and produces results.

Different software is built for different tasks.

Input→Software→Process→Output

Input

User enters order information.

Process

The software checks and processes the data.

Output

The system shows the result.

04

Where is it used?

Software runs on phones, computers, servers, browsers, cloud platforms, and many other devices.

PhoneComputerBrowserServerCloud
05

Example

An Order System

An order system lets users create orders, save data, check status, and view results.

All of these functions are provided by software.

User→Create Order→Software processes the action→Save Data→Show Result

06

How it connects

User ↓ Software ↓ Application ↓ Frontend / Backend ↓ Data
Software │ ┌───────────┴───────────┐ │ │ Application System │ ┌─────┴─────┐ │ │ Frontend Backend │ │ └───── Data ┘

Software is the broad concept.

Applications are software built for specific tasks.

Frontend and backend are different parts of many software applications.

Software works with data to perform useful actions.

07

Do Not Confuse

Software ≠ Hardware

Hardware

The physical parts of a computer or device.

Examples:

  • Screen
  • Keyboard
  • CPU
  • Memory
  • Storage

Software

The programs and instructions running on the hardware.

Examples:

  • Browser
  • Mobile App
  • Website
  • Operating System
  • Business Application

Hardware is the physical machine.

Software is the programs and instructions running on it.

Hardware + Software = A working computer system
