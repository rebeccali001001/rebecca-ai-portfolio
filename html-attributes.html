03 · Attributes

Attributes add settings and extra information to an element.

What is it?

An attribute appears in the opening tag. Think of it like: a label on a box that adds an instruction or identity.

Basic Syntax

<a href="/about.html" title="About us">About</a>
<input type="text" required>

Most attributes use name="value". Boolean attributes are enabled by being present: disabled, checked, required.

Key Attributes / Syntax

Common global attributes include id, class, title, lang, hidden, and style. Use CSS rather than inline style for reusable visual rules.

Common Mistakes

Do not repeat an id on a page. Do not use a value such as required="false" to turn a boolean attribute off—the attribute’s presence means true.

When to use it

Use attributes for links, labels, form validation, language, identifiers, and behavior hooks. Related: IDs & Classes.

Quick Reference

href destination · src resource · alt image replacement text · required validation.
