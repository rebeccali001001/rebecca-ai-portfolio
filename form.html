Part II · Frontend & Browser

Form

A group of controls used to collect and submit user input.

01 · What is it?

What is it?

A form is a section of a page used to collect information from users.

Forms can contain inputs, labels, buttons, checkboxes, dropdowns, and other controls.

Simple Definition: A form collects user data.

02 · Think of it like...

Think of it like...

Think of a form as a digital paper form.

The user fills in fields and submits the completed information.

User→Fill Fields→Submit→Software
03 · What does it do?

What does it do?

Forms help software:

Collect Text
Collect Numbers
Choose Options
Upload Files
Validate Input
Submit Data
04 · Where is it used?

Where is it used?

Forms are used in:

Login
Registration
Search
Create Order
Edit Profile
Payment
Contact Forms
05 · Example

Example

<form>
  <label for="quantity">Quantity</label>
  <input id="quantity" type="number">
  <button type="submit">Create Order</button>
</form>
form groups the controls.
label describes the input.
input collects the value.
button submits the action.
06 · How it connects

How it connects

User→Form→Input→Submit Event→JavaScript→API Request→Backend

Forms collect user data and often start a request to the backend.

07 · Do Not Confuse

Do Not Confuse

Form

A container for collecting related user data.

Input

One individual control inside a form.

A form can contain many inputs.

08 · Topic Glossary

Topic Glossary

English Term中文Simple English中文小白理解
Form表单A group of controls used to collect user input.用来收集用户输入的一组页面控件。
Input输入框 / 输入控件A control used to enter or select data.用户输入或选择数据的页面控件。
Label标签说明Text that describes a form control.用来说明某个输入控件含义的文字。
Button按钮A control used to trigger an action.用户点击后触发某项操作的控件。
Submit提交Sending form data for processing.将表单数据发送出去进行处理。
Validation校验Checking whether entered data follows required rules.检查用户输入的数据是否符合要求。
Field字段One piece of information collected by a form.表单中需要收集的一项具体信息。
Value值The data entered or selected in a control.用户在某个控件中输入或选择的数据。
required必填An attribute that requires a field to have a value.要求某个表单字段必须填写的属性。
Submit Event提交事件An event triggered when a form is submitted.用户提交表单时触发的事件。
API RequestAPI 请求A request that may carry submitted form data.可能携带表单数据发送给后端的请求。
