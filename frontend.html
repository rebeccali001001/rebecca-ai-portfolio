Part II · Frontend & Browser

Frontend

The part of software that users see, interact with, and use directly.

01 · What is it?

What is it?

The frontend is the part of software that users see and interact with.

In web applications, frontend code usually runs inside a browser.

Simple Definition: Frontend is the user-facing part of software.

02 · Think of it like...

Think of it like...

Think of the frontend as the customer-facing area of a store.

Users can see information, enter data, click buttons, and perform actions.

User→Frontend→Software System
03 · What does it do?

What does it do?

The frontend turns software functions into an interface people can actually use.

Display Content
Collect Input
Handle User Actions
Send Requests
Show Results

Where is it used?

Frontend software appears in websites, web applications, mobile apps, and desktop applications.

05 · Example

An Order Form

A user enters an order quantity and clicks Submit.

The frontend reads the input and starts the next software action.

User→Order Form→Submit Button→Frontend→Request
06 · How it connects

How it connects

User→Browser→Frontend→API→Backend→Response→Frontend

The frontend sits between the user and the rest of the software system.

In a web application, HTML defines the structure, CSS controls the appearance, and JavaScript adds behavior.

07 · Do Not Confuse

Do Not Confuse

User Interface

The visible screens and controls users interact with.

Frontend

The broader software layer that builds and controls that interface.

UI is part of the frontend.

Frontend includes both the interface and its behavior.

08 · Topic Glossary

Topic Glossary

English Term中文Simple English中文小白理解
Frontend前端The part of software users see and interact with.用户能够看到并直接操作的软件部分。
User Interface (UI)用户界面The screens and controls users interact with.用户看到并操作的页面、按钮和控件。
Browser浏览器Software that loads and runs web pages.用来打开、显示并运行网页的软件。
HTML超文本标记语言The language used to define web page structure.用来定义网页结构的语言。
CSS层叠样式表The language used to control web page appearance.用来控制网页样式和布局的语言。
JavaScriptJavaScriptA language used to add behavior to web pages.用来给网页增加交互行为的语言。
Input输入Data entered by a user or system.用户或其他系统输入的数据。
Event事件An action software can detect and respond to.软件可以检测并响应的操作，例如点击。
Request请求A message sent to ask another system for data or an action.向另一个系统发送的数据或操作请求。
Response响应The result returned after a request is processed.请求处理后返回的数据或结果。
DOM文档对象模型The browser's object representation of a web page.浏览器把网页结构转换成可被 JavaScript 操作的对象结构。
