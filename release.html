Release

A selected software version made available for use, delivery, or deployment.

01 · What is it?

What is it?

A release is a selected software version made available for users or another environment.

It is the point where a version is intentionally prepared for delivery, deployment, or use.

A release is a version prepared for users.

02 · Think of it like...

Think of it like...

Think of a release as opening a finished edition of a product to customers.

A version may exist internally, but a release marks the point when that version is intentionally made available.

Version→Release→Users / Environment

06 · How it connects

How it connects

Source Code→Build→Version→Release→Deployment

A release identifies the version that is ready to be made available; deployment moves it into a running environment.

07 · Do Not Confuse

Do Not Confuse

Release

A selected software version prepared for users or delivery.

Deploy

Move software into an environment where it can run.

Version

A specific state of software at a point in time.

Release

A version intentionally made available for use or delivery.

Release ≠ Deploy
