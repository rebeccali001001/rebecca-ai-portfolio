Responsive Design

A design approach that adapts a page to different screen sizes.

01 · What is it?

One page, different screens

Responsive design allows a web page to adjust its layout for different screen sizes.

The same page can work on desktop, tablet, and mobile devices.

Simple Definition: Responsive design makes one page fit different screens.

02 · Think of it like...

Furniture that rearranges itself

Think of responsive design as furniture that rearranges itself to fit the room.

Large spaceMore items can sit side by side.
Small spaceItems may stack vertically.

07 · Do Not Confuse

Responsive Design ≠ Mobile Website

Responsive Design

One interface adapts to different screen sizes.

Separate Mobile Website

A different site or page designed specifically for mobile.

Responsive = Same page, different layout.

08 · Topic Glossary
English Term中文Simple English中文小白理解
Responsive Design响应式设计A design that adapts to different screen sizes.页面根据不同屏幕尺寸自动调整布局。
Breakpoint断点A screen width where layout rules change.页面布局开始切换的一种屏幕宽度条件。
Media Query媒体查询A CSS rule used to apply styles at certain screen sizes.CSS 中根据屏幕尺寸应用不同样式的规则。
Viewport视口The visible area of a web page.用户当前能够看到的网页显示区域。
Desktop桌面端A layout designed for larger screens.面向较大电脑屏幕的页面布局。
Mobile移动端A layout designed for smaller screens.面向手机等小屏设备的页面布局。
Flexbox弹性布局A CSS layout system that can adapt item positions.可以灵活调整元素排列方式的 CSS 布局系统。
Grid网格布局A CSS system for arranging content in rows and columns.按行和列组织页面元素的 CSS 布局系统。
max-width最大宽度A rule that limits how wide an element can become.用来限制元素最大宽度的 CSS 属性。
Stack堆叠Arranging elements vertically instead of side by side.将原本横向排列的元素改成纵向排列。
Flow Direction流程方向The direction in which steps are visually arranged.流程节点在页面中的排列方向。
