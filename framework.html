PART IV · BACKEND

Framework

A structured set of tools and conventions used to build software applications.

01

What is it?

A framework provides a reusable structure for building applications.

Instead of creating every technical piece from scratch, developers follow the framework's patterns and use its built-in capabilities.

Simple Definition：
A framework gives developers a ready-made structure for building software.

02

Think of it like...

Think of building a house.

A programming language gives you the raw materials.

A framework gives you a building structure and common construction rules.

Programming Language→Framework→Application
03

What does it do?

Backend frameworks can provide:

Routing

Connect incoming requests to application logic.

Request Handling

Receive and process requests consistently.

Validation

Check whether input follows required rules.

Error Handling

Respond safely when something goes wrong.

Dependency Management

Organize software components the application needs.

Application Structure

Keep code organized in a repeatable way.

04

Where is it used?

Frameworks are used in:

Web ApplicationsAPIsBackend ServicesEnterprise SystemsMicroservices
05

Example

Python＋FastAPI Framework→API Application

Text：

Python provides the language.

FastAPI provides the structure for defining API routes and handling requests.

06

How it connects

Flow：

Programming Language→Framework→Application Structure→Backend Service
07

Do Not Confuse

Framework

Provides the overall structure and calls application code.

Library

Provides reusable functionality that application code calls.

Framework = Application Structure
Library = Reusable Capability

What to Remember

Frameworks provide structure.

They reduce repeated technical setup.

A framework is not the same as the programming language.
