MODULE 05 · DATABASE & SQL

Column

A column is a named attribute that defines one type of data stored for every row in a table.

01 · What is it?

A column is a named attribute that defines one type of data stored for every row in a table.

In a table of customers, for example, customer_id, name, and email can each be columns. Every row has a value for each column, unless the value is allowed to be missing.

02 · Think of it like…

Think of a spreadsheet. A column is one vertical category, such as Name, Email, or Status. The heading tells you what the values below it mean.

customer_idnamestatus
101Adaactive
102Linpending

The headers are columns. Each horizontal line beneath them is a row.

03 · What does it do?

A column gives a table structure and makes its data easier to understand and use.

Names the data

A clear name explains what each stored value represents.

Defines a type

A column can expect text, numbers, dates, identifiers, or another data type.

Supports queries

SQL uses column names to select, filter, sort, and change values.

04 · Where is it used?

Columns appear in every structured table that stores records for an application.

Users

user_id, email, created_at

Orders

order_id, total, order_status

Products

sku, name, price

05 · Example

This table definition creates three named columns with different data types.

CREATE TABLE customers (
  customer_id INTEGER,
  name TEXT,
  email TEXT
);

A query can then choose specific columns instead of returning every value.

SELECT name, email
FROM customers;

07 · Do Not Confuse

Column

A named category of data shared by every row in a table.

Row

One complete record containing values across the table’s columns.

Field

A named data item in a record; people often use “field” and “column” interchangeably.

09 · What to Remember

A column names one kind of data in a table.

Every row can provide a value for that column.

SQL uses column names to work with stored data.
