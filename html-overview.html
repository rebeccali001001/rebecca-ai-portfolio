HTML Overview

HTML gives a web page its structure and meaning.

What is HTML?

HTML means HyperText Markup Language. It describes the content and structure a browser should put on a page.

HTML is not styling and it is not programming logic: HTML → structure, CSS → presentation, JavaScript → behavior.

How a browser uses HTML

Browser requests HTML↓HTML arrives↓Browser parses HTML↓DOM is created↓CSS styles the DOM↓JavaScript interacts with it↓Page appears and becomes interactive

A page starts with a document

<!DOCTYPE html>
<html>
  <head></head>
  <body></body>
</html>

DOCTYPE tells the browser to use modern HTML. html wraps the document. head holds metadata; body holds visible page content.

Core vocabulary

An element is a complete building block such as <p>Hello</p>. Tags mark its beginning and end; an attribute adds information. Text between tags is content. Nested elements form parent, child, and sibling relationships.
