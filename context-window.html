What is a Context Window?

The context window is the amount of text a model can consider in one request.

Detail

It includes instructions, tools, conversation history, retrieved content, the current task, and the output budget.

More context is not automatically better; relevant, compact context is better.

Sample

A coding agent can fail after many tool calls because tool outputs consume the available context.
