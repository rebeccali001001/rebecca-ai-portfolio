03 · Tokens, Context & Inference

What is a context window?

The context window is the amount of text a model can consider in one request.

Definition

A context window is the model’s working space for the current input and the output it is allowed to produce.

In plain language

Think of it as the order board behind a café counter. It holds the instructions, conversation history, retrieved notes, current question, tool descriptions, and room reserved for the answer. If the board is full, something must be shortened, removed, or summarized.

Key points

  • A context window is measured in tokens, not pages.
  • Longer context can help, but irrelevant context adds load.
  • Output space is part of the same request budget.
usable room = window size − instructions − history − tools − retrieved text − output budget

Sample: the coffee order board

The robot needs the recipe rules, the customer’s order, the table number, and enough blank space to write the confirmation. A long stack of old tickets can crowd out today’s order.

1 · keepRecipe rulesStable instructions stay on the board.
2 · addToday’s orderRelevant current details join the request.
3 · reserveAnswer spaceLeave room for the response.

Where it matters

Context planning matters in chat history, coding agents, retrieval systems, tool calling, and any workflow that accumulates documents or previous turns.

More context is not automatically better. Relevant, compact context is usually easier to process and easier to debug.
