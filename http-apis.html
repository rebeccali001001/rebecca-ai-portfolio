02

Big Picture

Client→HTTP Request→API Endpoint→Backend→HTTP Response

HTTP is the communication protocol; an API defines the available way to ask a system for data or actions.

03

Core Concepts

HTTP

The protocol used to exchange messages on the web.

URL

The address that identifies a page, resource, or API endpoint.

API

A defined interface for software-to-software communication.

Request

The message asking for data or an action.

Response

The result returned after a request is processed.

Query Parameter

A URL value that filters, searches, sorts, or controls results.

04

How Everything Connects

Method+URL+Headers / Body→Request→Response

A request combines an action with an address and optional information. The response reports what happened and can return data.
