PART II · FRONTEND & BROWSER

Browser

Software that loads, displays, and runs web pages.

01 · What is it?

What is it?

A browser is software used to open and interact with websites and web applications.

It downloads web files, interprets them, and displays the result.

Simple Definition: A browser turns web code into a page you can use.

02 · Think of it like...

Think of it like...

Think of a browser as a reader and renderer.

It receives HTML, CSS, and JavaScript and turns them into an interactive web page.

HTML + CSS + JavaScript→Browser→Web Page
03 · What does it do?

What does it do?

A browser can:

Load Web Pages
Read HTML
Apply CSS
Run JavaScript
Send Network Requests
Store Browser Data
04 · Where is it used?

Where is it used?

Browsers are used to access websites and web applications.

Chrome
Safari
Edge
Firefox
05 · Example

Opening a Web Page

Step 1→User enters a URL
Step 2→Browser sends a request
Step 3→Server returns web files
Step 4→Browser reads HTML
Step 5→Browser applies CSS
Step 6→Browser runs JavaScript
Step 7→Page appears

The browser combines different web technologies into the page the user sees.

06 · How it connects

How it connects

User→Browser→HTML / CSS / JavaScript→Frontend→HTTP Request→Server

The browser is the runtime environment for many frontend web applications.

07 · Do Not Confuse

Do Not Confuse

Browser

Software used to access web content.

Internet

The global network that connects computers and services.

The browser uses the internet.
The browser is not the internet.

08 · Topic Glossary
ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Browser浏览器Software that loads and runs web pages.用来打开、显示并运行网页的软件。
Web Page网页A document displayed inside a browser.浏览器中显示的一张网页。
HTML超文本标记语言The language used to define page structure.用来定义网页结构的语言。
CSS层叠样式表The language used to control page appearance.用来控制网页样式和布局的语言。
JavaScriptJavaScriptA language used to add behavior to web pages.用来给网页增加交互行为的语言。
URL网址 / 资源地址The address of a resource on the web.用来定位网页或其他网络资源的地址。
Render渲染Turning web code into what users see on the screen.把网页代码转换成用户实际看到的页面。
Runtime运行环境The environment where software actually runs.软件真正执行时所在的环境。
Request请求A message sent to ask for web data or resources.向服务器请求网页数据或资源的信息。
Developer Tools浏览器开发者工具Tools used to inspect and debug web pages.用来查看和调试网页结构、请求和错误的工具。
