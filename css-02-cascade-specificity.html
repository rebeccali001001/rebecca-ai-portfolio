08 · Common Patterns

Keep a small, reusable rule close to the component it styles. Prefer clear class names and values that support responsive layouts.

09 · Common Mistakes

Do not reach for !important first. Inspect the competing rule and its specificity.

10 · When to use

Use cascade & specificity whenever this is the clearest way to express a visual decision in CSS.
