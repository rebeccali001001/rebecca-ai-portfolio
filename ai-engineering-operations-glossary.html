AI Engineering & Operations Glossary

Simple definitions for the signals and system parts used to understand AI behavior in production.

On this pageCore signalsAI system dataOperations language

01 · Core signals

English term中文Simple English中文小白理解
Logs日志Records of events that happened.记录系统刚刚做了什么。
Metrics指标Numbers that summarize behavior over time.用数字观察数量、速度、错误率或成本。
Traces链路追踪A connected view of one request across its steps.把一次请求经过的各个步骤串起来看。
Observability可观测性The ability to understand what is happening inside a system from its emitted data.通过系统留下的数据，推断内部发生了什么。
Monitoring监控Ongoing checking of known signals and conditions.持续看系统是否正常、是否超出预设范围。

02 · AI system data

English term中文Simple English中文小白理解
Prompt提示词The instructions and input sent to a model.发给模型的任务说明和输入内容。
Context Size上下文大小How much text or information the model receives for a request.一次请求中模型需要处理的信息量。
Token UsageToken 使用量The amount of tokenized input and output used.这次请求消耗了多少模型计费单位。
Model Call模型调用One request from an application to a model.应用向模型发起的一次请求。
Latency延迟The time it takes to produce a result.从开始请求到得到结果花了多久。
Retrieval检索Finding relevant information for the request.从知识库或数据库找相关内容。
Tool Call工具调用An action that asks another tool or service to do work.让外部工具或服务执行一个动作。
Agent StepAgent 步骤One observable action or decision in an agent workflow.智能体工作流中的一次决定、行动或观察。
Cost成本The money or resource use associated with a request or workflow.一次请求或整个流程消耗的钱和计算资源。

03 · Operations language

English term中文Simple English中文小白理解
Error错误A problem that prevents the expected result.系统没有按预期完成任务。
Root Cause根因The underlying reason an issue happened.导致问题真正发生的原因，而不只是表面现象。
Debugging调试 / 排错Investigating a system to find and fix a problem.根据证据一步步定位并修复问题。
Evaluation评测Structured measurement against quality criteria.按明确标准检查结果好不好。
Incident事故 / 事件A production problem that needs attention.线上影响用户或业务、需要处理的问题。

Remember: Logs tell you what happened, metrics show patterns, and traces explain how one request moved through the system.
