01
CASE

CASE

CASE adds conditional logic to a SQL query.

It lets SQL return different values depending on which condition is true.

Syntax

CASE
    WHEN condition THEN result
    ELSE result
END

Example 1

SELECT
    order_id,
    quantity,
    CASE
        WHEN quantity >= 40 THEN 'Large'
        ELSE 'Standard'
    END AS order_size
FROM orders;
Output
1001 | 20 | Standard
1002 | 50 | Large
1003 | 10 | Standard

Key point: SQL checks the condition for every row.

Example 2

SELECT
    order_id,
    quantity,
    CASE
        WHEN quantity >= 40 THEN 'Large'
        WHEN quantity >= 20 THEN 'Medium'
        ELSE 'Small'
    END AS order_size
FROM orders;
Output
1001 | 20 | Medium
1002 | 50 | Large
1003 | 10 | Small

Key point: SQL evaluates WHEN conditions from top to bottom. The first matching condition determines the result.

WHEN

WHEN defines a condition that SQL should check.

Example

WHEN quantity >= 40
Meaning
Check whether quantity is at least 40.

THEN

THEN defines the result returned when a WHEN condition is true.

Example

WHEN quantity >= 40 THEN 'Large'

ELSE

ELSE provides a fallback result when no previous WHEN condition matches.

Example

ELSE 'Small'

END

END closes the CASE expression.

Example

END AS order_size

Key point: The alias order_size gives the CASE result a readable column name.

02
String Functions

String functions transform or inspect text values.

UPPER()

UPPER converts text to uppercase.

Example

SELECT UPPER(customer)
FROM orders;
Output
ABC METALS
GLOBAL TRADE
EASTERN METALS

LOWER()

LOWER converts text to lowercase.

Example

SELECT LOWER(customer)
FROM orders;
Output
abc metals
global trade
eastern metals

TRIM()

TRIM removes spaces from the beginning and end of text.

Sample

'  ABC Metals  '

Query

SELECT TRIM('  ABC Metals  ');
Output
ABC Metals

Key point: Spaces inside the text are not removed.

LENGTH()

LENGTH returns the number of characters in a text value.

Example

SELECT LENGTH('Copper');
Output
6

Key point: Some database systems use functions such as LEN instead.

CONCAT()

CONCAT joins text values together.

Example 1

SELECT CONCAT(customer, ' - ', product)
FROM orders;
For order 1001
ABC Metals - Copper

Example 2

SELECT CONCAT('Order ', order_id)
FROM orders;
Output example
Order 1001

SUBSTRING()

SUBSTRING extracts part of a text value.

Example

SELECT SUBSTRING(order_id, 1, 3)
FROM orders;

If order_id is represented as text such as ORD1001:

Output
ORD

Key point: Exact function syntax can vary slightly between database systems.

REPLACE()

REPLACE substitutes one piece of text with another.

Example

SELECT REPLACE('Pending Order', 'Pending', 'Waiting');
Output
Waiting Order

03
Numeric Functions

ROUND()

ROUND rounds a numeric value to a specified number of decimal places.

Example 1

SELECT ROUND(8500.456, 2);
Output
8500.46

Example 2

SELECT order_id,
       ROUND(price, 2) AS rounded_price
FROM orders;
Output
1001 | 8500.46
1002 | 2450.79
1003 | 16000.13

ABS()

ABS returns the absolute value of a number.

Example 1

SELECT ABS(-250);
Output
250

Example 2

SELECT ABS(100);
Output
100

CEILING() / CEIL()

CEILING or CEIL rounds a number upward to the next whole number.

Example

SELECT CEIL(8500.1);
Output
8501

Key point: Function naming can vary by database.

FLOOR()

FLOOR rounds a number downward to the previous whole number.

Example

SELECT FLOOR(8500.9);
Output
8500

04
Date / Time

SQL can return current dates and compare stored date values.

CURRENT_DATE

CURRENT_DATE returns the current date according to the database system.

Syntax

SELECT CURRENT_DATE;
Output format example
2026-09-18

Key point: The real value depends on when the query runs.

CURRENT_TIMESTAMP

CURRENT_TIMESTAMP returns the current date and time.

Example

SELECT CURRENT_TIMESTAMP;
Example format
2026-09-18 10:30:00

Key point: The actual result depends on the database system and execution time.

DATE

DATE represents a calendar date.

Example

SELECT DATE '2026-09-12';
Output
2026-09-12

Key point: Date literal syntax differs between database systems.

Date Comparison

Date values can be used in filtering conditions.

Example 1

SELECT order_id, trade_date
FROM orders
WHERE trade_date >= '2026-09-02';
Output
1002 | 2026-09-02
1003 | 2026-09-03

Example 2

SELECT order_id
FROM orders
WHERE trade_date = '2026-09-01';
Output
1001

Key point: Date functions differ significantly across SQL databases.

05
CAST / CONVERT

Type conversion changes how SQL treats a value.

CAST()

CAST converts a value from one data type to another.

Syntax

CAST(value AS data_type)

Example 1

SELECT CAST(quantity AS DECIMAL(10,2))
FROM orders;
For quantity 20
20.00

Example 2

SELECT CAST('100' AS INT);
Output
100

Key point: The text value '100' becomes a numeric value.

CONVERT()

CONVERT is another type-conversion function supported by some database systems.

Example

SELECT CONVERT(VARCHAR, order_id)
FROM orders;
Output
1001
1002
1003

Key point: The numeric or typed order_id is returned as text. CONVERT syntax is database-specific; CAST is generally more portable across SQL systems.

06
Conditional NULL Functions

COALESCE()

COALESCE returns the first value that is not NULL.

Syntax

COALESCE(value1, value2, value3, ...)

Sample Data

customerphonemobile
ABC MetalsNULL91234567
Global Trade6123456792345678
Eastern MetalsNULLNULL

Example

SELECT
    customer,
    COALESCE(phone, mobile, 'N/A') AS contact_number
FROM customers;
Output
ABC Metals | 91234567
Global Trade | 61234567
Eastern Metals | N/A

Key point: SQL checks values from left to right and returns the first non-NULL value.

FROM orders;

Key point: If quantity is 0, the result becomes NULL.

NULLIF()

NULLIF returns NULL when two values are equal. Otherwise, it returns the first value.

Example 1

SELECT NULLIF(10, 10);
Output
NULL

Example 2

SELECT NULLIF(20, 0);
Output
20

Example 3

SELECT NULLIF(quantity, 0)
FROM orders;
Output for the sample data
20
50
10

Key point: If quantity is 0, the result becomes NULL.

FROM orders;

Key point: If quantity is 0, the result becomes NULL.

Database-Specific NULL Functions

Some databases provide additional functions such as NVL and ISNULL. These are not universal SQL syntax. Keep COALESCE as the more portable concept taught here.
