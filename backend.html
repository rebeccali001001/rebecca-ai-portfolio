PART IV · BACKEND

Backend

The part of a software system that processes requests, applies logic, and works with data behind the interface.

01

What is it?

The backend is the part of a software system that runs behind the user interface.

It receives requests, applies business logic, works with databases or external services, and returns results.

Simple Definition：
The backend is where the system processes work behind the screen.

02

Think of it like...

Think of a restaurant.

The frontend is the dining area where customers place orders.

The backend is the kitchen where the work is processed.

Flow:

Frontend→Backend→Database / Services→Response
03

What does it do?

The backend can:

Receive Requests

Validate Data

Apply Business Logic

Read and Write Data

Call External Services

Return Responses

04

Where is it used?

Backend systems are used in:

Web Applications

Mobile Applications

APIs

Trading Platforms

Payment Systems

Enterprise Systems

05

Example

Scenario:

A user creates an order.

Flow:

Frontend→POST /api/orders→Backend→Validate Data→Apply Business Rules→Save Order→Return Response
06

How it connects

Flow:

Frontend→API→Backend→Business Logic→Database→Response

The backend connects user actions with system rules, data, and other services.

07

Do Not Confuse

Backend

Processes requests and data behind the interface.

Frontend

Displays information and interacts directly with users.

Frontend = What users interact with
Backend = What processes the work

08

09

What to Remember

The backend processes work behind the user interface.

It connects APIs, business logic, databases, and external services.

The frontend sends requests; the backend processes them and returns responses.

Final:

Frontend→Backend→Data / Logic→Response
