What Is Prompt Design?

Prompt design is the practice of structuring instructions so a model understands the task, relevant context, constraints, and expected result.

On this pageCore ideaFour useful partsReal exampleKey distinctionsCommon problemsWhat it does not guaranteeRelated conceptsRemember thisVideo

Core idea

WEAK REQUEST

“Check this.”

BETTER DESIGNED REQUEST

TASK
Check the invoice.

CONTEXT
Use the attached invoice.

CONSTRAINTS
Do not invent missing fields.

OUTPUT
Return status and issues.

Prompt design makes the task explicit.

Four useful parts

TASKWhat should the model do?
CONTEXTWhat information matters?
CONSTRAINTSWhat rules should it follow?
OUTPUTWhat should the answer look like?

Not every prompt needs all four parts explicitly.

One real example

BAD

“Review this invoice.”

BETTER

TASK
Review the invoice for missing required fields.

CONTEXT
Use only the provided invoice.

RULES
Do not invent missing values.

OUTPUT
Return: status, missing_fields, notes.

Why better?

Clear goal
Clear evidence
Clear boundary
Clear output

Prompt Design vs System Prompt

PROMPT DESIGNA design practiceCan apply to system instructions, user prompts, examples, and task structure.
SYSTEM PROMPTOne type of instructionSupplied by an application to guide the model.

Prompt design is broader than system prompts.

Prompt Design vs Context Engineering

PROMPT DESIGNHow instructions are written
CONTEXT ENGINEERINGWhat complete set of information the model receivesThis may include system prompt, user prompt, history, retrieved documents, tool results, state, and examples.

Prompt design is one part of the broader context-design problem.

Common prompt problems

VAGUE TASK“Analyze this.”
MISSING CONTEXTRequired information is unavailable.
UNCLEAR CONSTRAINTSThe model may make unwanted assumptions.
UNCLEAR OUTPUTThe result is hard for an application to use.

What good prompt design does not guarantee

Good prompt ≠ correct answer

A clear prompt can improve task clarity, but does not guarantee correctness.

Good prompt ≠ current knowledge

Prompt wording does not automatically provide fresh information.

Good prompt ≠ tool access

Instructions do not automatically give the model permission or external capabilities.
