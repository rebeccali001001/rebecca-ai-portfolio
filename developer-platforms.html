First, the basic ideas

GIT

Version control technology that records changes to files over time.

REPOSITORY

A project folder plus its history, branches, and related files.

DEVELOPER PLATFORM

A service built around repositories for teamwork and delivery.

Code is usually placed on these platforms so teams can share it, review it, protect it, and ship it together.

Git vs GitHub

GIT

Version control technology.

Runs on a computer or server and tracks file changes.

GITHUB

Cloud developer platform built around Git repositories.

Adds collaboration, review, issues, permissions, and automation.

Git≠GitHub

Major platforms

GitHub

What it is: A widely used platform for Git repositories and software collaboration.

Main ecosystem: Open source, developer tools, Actions, and a large public community.

Typical fit: Teams that want broad ecosystem reach and familiar workflows.

Strength: Network and integrations. Trade-off: Some enterprise controls may require higher tiers.

GitLab

What it is: A developer platform that combines repositories, planning, security, and delivery.

Main ecosystem: Integrated DevSecOps and CI/CD, with self-managed options.

Typical fit: Teams wanting one connected delivery platform.

Strength: End-to-end workflow. Trade-off: Can feel broader and heavier for simple projects.

Bitbucket

What it is: A Git-based code hosting and collaboration platform from Atlassian.

Main ecosystem: Jira, Confluence, and other Atlassian tools.

Typical fit: Organizations already centered on Atlassian workflows.

Strength: Atlassian integration. Trade-off: Smaller public ecosystem than GitHub.
