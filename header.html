PART III · HTTP & APIs

Header

Extra information sent with an HTTP request or response.

01 · What is it?

What is it?

An HTTP header carries additional information about a request or response.

Headers describe how the message should be handled or interpreted.

Simple Definition： Headers are extra information attached to an HTTP message.

02 · Think of it like...

Think of it like...

Think of a package.

The package contains the main item. The label outside the package contains extra information.

HeadersInformation about the message
BodyThe main item or data

Visual： HTTP Message = Headers + Body

03 · What does it do?

What does it do?

Headers can describe:

Content TypeWhat format the body uses.
AuthenticationWho or what is allowed access.
Accepted FormatsWhat response formats the client can use.
LanguageWhich language is preferred.
CachingHow a response may be stored and reused.
Browser InformationDetails about the client software.
04 · Where is it used?

Where is it used?

Headers appear in:

HTTP Requests
HTTP Responses
API Calls
Authentication
File Downloads
Browser Communication
05 · Example

Example

Use:

Content-Type: application/json

Meaning: The message body contains JSON.

Second example:

Authorization: Bearer <token>

Meaning: The request includes authentication information. The token shown here is only a placeholder, not a real token.

06 · How it connects

How it connects

Request├─ Method ├─ URL ├─ Header └─ Body
Response├─ Status Code ├─ Header └─ Body

Headers provide metadata about the HTTP message.

07 · Do Not Confuse

Do Not Confuse

Header ≠ Body

Header

Contains metadata about the message.

Body

Contains the main data being sent or returned.

Header = Information about the message
Body = Main message data

09 · What to Remember

What to Remember

Headers contain extra information about HTTP messages.

Headers are separate from the main body.

Authentication and content type are commonly carried in headers.
