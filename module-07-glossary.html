MODULE 07 · GLOSSARY

System Architecture Glossary

Simple English and Chinese explanations for the components, paths, and operating ideas that shape a software system.

Topic Glossary

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
CDN内容分发网络A network that delivers cached content from locations close to users.把缓存内容放到离用户更近的网络节点来提供。
Object Storage对象存储Durable API-accessed storage for file-like objects.通过接口保存大量文件类对象的耐久存储。
File Storage文件存储Storage that exposes files and folders through shared paths.通过文件夹和路径共享文件的存储方式。
Cache缓存Fast temporary storage for data used again.把还会再用的数据暂时放在更快的地方。
Architecture架构The way a system's parts are arranged and connected.系统各个部分如何分工、连接和一起工作的方式。
Component组件A distinct part of a system with a clear responsibility.系统中负责一件明确工作的独立部分。
Service服务A component that provides a focused capability.提供某一种具体能力的系统部分。
Monolith单体应用An application whose major features are built and deployed together.主要功能放在一起开发和部署的应用。
Microservices微服务An architecture made of independently deployable services.把系统拆成多个可以独立发布的小服务。
API GatewayAPI 网关A managed entry point between clients and backend services.位于客户端和后端服务之间、统一管理请求入口的组件。
Load Balancer负载均衡器A component that distributes traffic across healthy instances.把请求分配给健康服务器或服务实例的组件。
Cache缓存Fast temporary storage for data used often.把常用数据暂时放在更快的地方。
RedisRedisA fast in-memory data store often used for temporary state.一种速度很快、常用来保存临时状态的数据工具。
Message Queue消息队列A temporary holding place between message producers and consumers.生产者和消费者之间暂存消息、让双方不用同时工作的地方。
Producer生产者A component that sends a message to a queue.把消息放进队列的系统部分。
Consumer消费者A component that receives and processes a message.从队列取出消息并处理它的系统部分。
Event事件A record or signal that something happened.表示某件事已经发生的一条记录或信号。
Event-driven事件驱动A system style where components react to facts about what happened.系统围绕“发生了什么”来让不同部分做出反应。
Synchronous同步The caller waits for the work to finish before continuing.调用方要等工作完成后才能继续。
Asynchronous异步The caller can continue while the work finishes separately.调用方可以先继续，工作在另一边完成。
Scaling扩展Changing capacity to handle changing demand.根据需求变化调整系统能处理的工作量。
Horizontal Scaling水平扩展Adding more machines or instances to share work.增加更多机器或实例，一起分担工作。
Vertical Scaling垂直扩展Making one machine more powerful.给同一台机器增加资源，让它变得更强。
Instance实例One running copy of an application or service.正在运行的一份应用或服务副本。
Fault Tolerance容错The ability to keep useful service when part of a system fails.系统某一部分出问题时，整体仍尽量继续提供服务。
High Availability高可用性Keeping a service usable most of the time through redundancy, health checks, and failover.通过冗余、健康检查和故障转移，让服务大部分时间保持可用。
Redundancy冗余An extra component or path ready to help when another fails.多准备一个可以在另一个出问题时接替工作的部件或路径。
Health Check健康检查A test that decides whether a target is ready to receive work.用来判断某个实例现在能不能接收请求的测试。
Failover故障转移Moving work from a failed path to a healthy replacement.把工作从坏掉的路径转到健康的备用路径。
