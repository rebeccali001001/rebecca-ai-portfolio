What is Grounding?

Grounding connects a model’s response to trusted, task-relevant evidence so the answer can be checked against a source.

Detail

A grounded workflow retrieves evidence, places it clearly in the model’s context, and instructs the model to answer within that evidence. The application can then preserve citations, confidence signals, and the retrieved source IDs.

Grounding reduces unsupported claims, but it does not guarantee correctness: the source may be stale, incomplete, or misinterpreted.

A citation makes an answer inspectable; it does not make it automatically true.

Key takeaway

Grounding is an evidence contract. Define what sources are trusted, how they are selected, how answers cite them, and when the system should abstain.

Sample

An operations assistant answers a question about a settlement exception. It passes the current policy excerpt into the prompt, cites the policy section, and says it cannot confirm the exception when no approved source is retrieved.

Evidence
Policy v4.2 · §3.1
Answer
Exception applies after approval
Trace
Source ID + timestamp
