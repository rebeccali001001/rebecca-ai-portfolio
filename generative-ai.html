Generative AI

Generative AI creates new text, code, images, audio, or structured outputs from learned patterns. The useful unit is the complete workflow around generation.

Detail

Input
Model
Grounding
Validation
Human / system action

A production feature constrains the model with instructions, context, schemas, policy checks, and a clear handoff. Fluency is not the same as correctness.

Sample

A meeting assistant turns a transcript into action items, validates the output shape, links each item to evidence, and lets the owner confirm before sending.

Questions I ask

  • What must be factual?
  • What can be creative?
  • Where is evidence required?
  • What happens when confidence is low?
