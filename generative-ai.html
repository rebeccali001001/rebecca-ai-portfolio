What is it?

Generative AI creates new content from a prompt or other input.

It can generate text, images, audio, video, code, or structured content by using patterns learned during training.

Think of it like...

Think of it like a studio that turns a brief into a draft. The studio has learned styles and patterns, but the result still needs checking.

How it works

A prompt is transformed into a generated result one piece at a time.

1 · PromptDescribe a goalA user or system provides instructions and source material.
2 · RepresentationProcess the inputThe model converts the input into internal numerical patterns.
3 · GenerationPredict the next partIt produces tokens, pixels, audio units, or other output pieces.
4 · RepeatBuild the resultGeneration continues until a stopping condition.
5 · ReviewCheck the outputA person or system verifies quality, safety, and fit.

Real-world examples

Everyday example · Drafting

Input: A short email request

System: The model generates likely text from the prompt

Output: A draft email

AI product example · Image generation

Input: A scene description

System: The model generates visual content

Output: An image

Business example · Document extraction

Input: An invoice

System: The model maps content to a requested schema

Output: Structured fields for review

What it is NOT

Generative AI ≠ Artificial Intelligence

Generative AI: A category focused on creating content

Artificial Intelligence: The broader field of intelligent computer systems

Generative AI ≠ Search engine

Generative AI: Generates a response from learned patterns

Search engine: Retrieves existing pages or records

Generative AI ≠ Human creativity

Generative AI: Can produce novel-looking combinations

Human creativity: Does not create with human experience or intent

Related concepts

Input → Generative model → New content
Generative AI describes what the system does. Deep Learning describes a common way it is built.
