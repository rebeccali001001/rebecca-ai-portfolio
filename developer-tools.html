PART II · FRONTEND & BROWSER

Developer Tools

Built-in browser tools used to inspect, debug, and understand web pages.

01 · What is it?

Developer Tools are built into modern browsers.

They help you inspect page structure, styles, JavaScript, network requests, storage, logs, and errors.

Simple Definition: Developer Tools let you see what is happening inside a web page.

02 · Think of it like...

Think of Developer Tools as an inspection panel for a web page.

The normal browser view shows the result.

Developer Tools show how that result is built and what the page is doing.

Web Page

03 · What does it do?

Developer Tools can help you inspect:

HTML

CSS

JavaScript Errors

Network Requests

API Responses

Browser Storage

04 · Where is it used?

Developer Tools are commonly used when:

A page layout looks wrong
A button does not work
An API request fails
Data is missing
A JavaScript error occurs
A browser value needs to be checked

05 · Example

A Save Button Does Not Work

Developer Tools
User clicks Save
  → Nothing happens
  → Open Developer Tools
  → Check Console
  → Check Network
  → Find the problem

Developer Tools help identify which layer may be failing.

06 · How it connects

Use a simple 4-part inspection map:

ConsoleJavaScript / Errors
NetworkHTTP / API
ApplicationCookies / Local Storage

Different Developer Tools panels help inspect different parts of the frontend system.

09 · What to Remember

Developer Tools help you inspect a running web page.

Elements shows HTML and CSS.

Console shows JavaScript messages and errors.

Network shows requests and responses.
