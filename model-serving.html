10 · Model Serving & Local AI

What Is Model Serving?

Model serving is the system that makes a trained model available to applications for inference.

It turns model weights running on hardware into a service that can receive requests and return results.

01 · The serving stack

Why is a model file not enough?

A model file contains learned behavior, but it does not by itself receive requests, manage resources, or return results to an application.

04 · Keep the layers distinct

Runtime vs Serving

RUNTIME

Executes inference.

MODEL SERVING

Makes inference available as a usable service.

May also manage requests, models, resources, queues, batching, and access.

Runtime is one layer inside serving.

05 · Another important distinction

Model vs Model Server

MODEL

Learned weights.

MODEL SERVER

Software / system exposing the model to applications.

Model ≠ service

06 · The practical reason

Why Serving Matters

Without serving

Model exists, but applications cannot easily use it.

With serving

Applications → requests → model → responses

07 · Scope changes with the workload

Local vs Production Serving

LOCAL SINGLE USER

Example: Ollama on a laptop.

PRODUCTION SERVING

May require multiple requests, resource scheduling, scaling, monitoring, and availability.

The core idea is the same; the operational demands grow with the number of users and requests.
