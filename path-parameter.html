Path Parameter

A value placed inside a URL path to identify a specific resource.

01 · What is it?

What is it?

A path parameter is a value placed directly inside a URL path.

It is commonly used to identify one specific resource.

Simple Definition：
A path parameter tells the API exactly which resource you want.

02 · Think of it like...

Think of it like...

Think of an address inside a building.

The endpoint identifies the area.

The path parameter identifies the exact item.

Orders→Order 1001
03 · What does it do?

What does it do?

Path parameters commonly identify:

Order IDOne specific order.
Customer IDOne specific customer.
Product IDOne specific product.
User IDOne specific user.
File IDOne specific file.
Other Specific ResourcesAny uniquely identified object.
04 · Where is it used?

Where is it used?

Path parameters are commonly used in REST APIs.

Retrieve One RecordGet one specific resource.
Update One RecordChange one specific resource.
Delete One RecordRemove one specific resource.
View One ResourceOpen the details of one object.
05 · Example

Example

Use：

GET /api/orders/1001

Break down：

/api/orders
Resource path

1001
Path parameter

Meaning： Retrieve order 1001.

Second example：

DELETE /api/orders/1001

Meaning：Delete order 1001.

06 · How it connects

How it connects

Resource Endpoint→Path Parameter→Specific Resource

Example：

/api/orders→1001→Order 1001
07 · Do Not Confuse

Do Not Confuse

Path Parameter ≠ Query Parameter

Path Parameter

Usually identifies a specific resource.

/api/orders/1001

Query Parameter

Usually filters or controls a request.

/api/orders?status=completed
Path Parameter = Which resource
Query Parameter = How to filter or control the request

09 · What to Remember

What to Remember

Path parameters identify specific resources.

They are part of the URL path.

Path parameters and query parameters serve different purposes.

Final：
Resource Path + Path Parameter = Specific Resource
