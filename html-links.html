05 · Links

Links connect people to pages, sections, files, and contact actions.

What is it?

The a element creates a hyperlink. Think of it like: a signpost with a destination.

Basic Syntax

<a href="/about.html">About</a>
<a href="#pricing">Pricing</a>
<a href="https://example.com">External site</a>

Key Attributes / Syntax

href sets the destination. A relative URL stays within a site; an absolute URL includes the full address. Use target="_blank" only when a new tab is useful, download for a download, mailto: for email, and tel: for a phone link.

Common Mistakes

Avoid vague link text such as “click here.” If you use target="_blank", add rel="noopener" for safety.

When to use it

Use links for navigation and destinations. Use a button for an in-page action instead.

Quick Reference

/about.html relative path · #pricing fragment link · https://… absolute URL.
