PART II · FRONTEND & BROWSER

HTML

The language used to define the structure and content of a web page.

01 · What is it?

HTML stands for HyperText Markup Language.

It defines the structure and content of a web page.

Simple Definition: HTML describes what is on the page.

02 · Think of it like...

Think of HTML as the structure of a building.

It defines where the major parts belong.

Web Page ├─ Heading ├─ Paragraph ├─ Image ├─ Form └─ Button

03 · What does it do?

HTML defines page elements such as:

HeadingsPage and section titles
ParagraphsBlocks of normal text
LinksConnections to resources
ImagesVisual content
FormsUser input areas
ButtonsClickable controls
TablesRows and columns of data

04 · Where is it used?

HTML is used in almost every web page.

Browsers read HTML and build a structured representation of the page.

Web PagesDocuments shown in a browser
Web AppsInterfaces users interact with
FormsFields that collect input
Content StructureMeaningful page organization

05 · Example

<h1>Order Details</h1>
<p>Order number: 1001</p>
<button>Save</button>
<h1>

creates a heading.

<p>

creates a paragraph.

<button>

creates a button.

06 · How it connects

HTML→Structure CSS→Style JavaScript→Behavior Together→Web Page

HTML provides the structure that CSS styles and JavaScript interacts with.

07 · Do Not Confuse

HTML ≠ CSS ≠ JavaScript

HTML

Defines structure.

CSS

Controls appearance.

JavaScript

Controls behavior.

HTML = Structure   ·   CSS = Style   ·   JavaScript = Behavior

09 · What to Remember

HTML defines the structure of a web page.

HTML uses elements to represent content and controls.

Browsers read HTML and turn it into a page structure.
