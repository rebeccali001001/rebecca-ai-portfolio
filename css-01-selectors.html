08 · Common Patterns

Keep a small, reusable rule close to the component it styles. Prefer clear class names and values that support responsive layouts.

09 · Common Mistakes

Avoid overly deep selectors and relying on #id for ordinary component styling.

10 · When to use

Use selectors whenever this is the clearest way to express a visual decision in CSS.
