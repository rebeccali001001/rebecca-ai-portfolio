Query Parameter

A value added to a URL to filter, search, sort, or control a request.

01

What is it?

A query parameter is information added to the end of a URL.

It helps control what data the request asks for.

Simple Definition：
A query parameter changes or filters a request.

02

Think of it like...

Think of a search form.

The endpoint identifies what type of data you want.

The query parameters describe how you want that data filtered.

Orders→Filter by Status→Completed Orders
03

What does it do?

Query parameters commonly help with:

Filtering
Searching
Sorting
Pagination
Optional Settings
04

Query parameters are commonly used in:

05

Example

GET /api/orders?status=completed

Break down:

/api/ordersEndpoint
statusParameter Name
completedParameter Value
GET /api/orders?status=completed&page=2

Multiple query parameters are usually separated with &.

07

Do Not Confuse

Query Parameter

Usually controls filtering or optional request behavior.

Example:
/api/orders?status=completed

Path Parameter

Usually identifies a specific resource inside the URL path.

Example:
/api/orders/1001

What to Remember

Query parameters are added after the URL path.

They commonly filter, search, sort, or control results.

Query parameters are usually optional.

Endpoint + Query Parameter = Controlled Request
