MODULE 06 · AUTHENTICATION & SECURITY

Password

A secret that a user provides to help prove their identity during sign-in.

01 · What is it?

A password is a secret value that a user knows and provides during authentication.

The application compares a protected representation of the submitted password with the stored representation. It should not store the original password as readable text.

Simple Definition:
A password is a user-held secret used to prove identity.

02 · Think of it like...

Think of a password like a secret phrase for a locked room.

The person says the phrase at the entrance. The entrance system checks it without displaying the protected secret. If the check succeeds, the person can continue.

03 · What does it do?

A password supports the sign-in part of an authentication flow.

Accept a Secret

The sign-in form receives the password over a protected connection.

Check Identity

The server checks whether the secret matches the account record.

Allow or Reject

A successful check continues the login flow; a failed check returns an error.

04 · Where is it used?

Passwords are commonly used when an application needs a user to sign in with an account.

Account Sign-inReturning users

A user enters a known email or username and password.

Account CreationNew accounts

A user chooses a password that the application can protect.

Password ChangeCredential updates

An authenticated user replaces an old password with a new one.

Password ResetAccount recovery

A recovery flow helps a user create a new password after forgetting the old one.

05 · Example

A user signs in to a web application.

What the user does

The user enters an email address and password, then submits the sign-in form.

What the system does

The server finds the account, checks the password securely, and continues the login flow only when the check succeeds.

The password should travel over HTTPS and should never be exposed in the page URL or returned in a response.

07 · Do Not Confuse

Password

A secret that a user provides to prove knowledge during sign-in.

Password Hash

A one-way derived value used by the server to verify a password without storing the original.

Session

State that helps the application remember a successful login across later requests.

A password is the secret used during authentication; it is not the same thing as the session that follows a successful login.

09 · What to Remember

A password is a user-held secret used to authenticate an account.

Applications should protect passwords with secure transport, one-way password hashing, and careful recovery flows.
