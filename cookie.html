MODULE 06 · AUTHENTICATION & SECURITY

Cookie

A small piece of data stored by the browser and associated with a website.

01 · What is it?

A cookie is a small piece of data that a website stores in the browser.

Cookies can be sent back to the server with later requests.

Simple Definition: A cookie helps a website remember information between requests.

02 · Think of it like...

Think of a cookie as a small note the website gives to the browser.

The browser keeps the note and may send it back when the user returns.

03 · What does it do?

Cookies can help websites remember:

Login Sessions
User Preferences
Language Settings
Tracking Information
Temporary Identifiers

04 · Where is it used?

Cookies are commonly used in web applications for:

Login
Sessions
Preferences
Analytics
Authentication Flows

07 · Do Not Confuse

Cookie

Small browser data that can be sent automatically with HTTP requests.

Local Storage

Browser data that JavaScript reads and writes directly.

Cookie = Browser + Request
Local Storage = Browser only
