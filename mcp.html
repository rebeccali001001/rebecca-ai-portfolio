What is MCP?

MCP is a protocol that lets AI applications connect to external tools and data through a standardized interface.

What is it?

Model Context Protocol (MCP) defines a standard way for AI applications to discover and interact with external capabilities and context.

It gives AI applications a common protocol for connecting to supported servers, which can expose tools, resources, and other useful context. MCP is not an agent, a model, or a tool itself.

Think of it like...

Think of MCP like USB for AI connections.

A USB standard does not define the device itself. It defines a common way devices connect. Similarly, MCP does not become the database or tool. It standardizes how an AI application can connect to supported servers and capabilities.

How it works

1 · HostRun the AI applicationA host application provides the user experience and coordinates the connection.
2 · ClientOpen an MCP connectionAn MCP client inside the host communicates with a server.
3 · ProtocolUse shared rulesThe protocol defines how capabilities and context are discovered and exchanged.
4 · ServerExpose capabilitiesAn MCP server makes approved tools, resources, or prompts available.
5 · SystemReach an external systemThe server connects to files, databases, developer tools, or business systems.

Real-world examples

Everyday example · Access files

Input: a request about documents in an approved folder

AI / System: the application connects through an MCP server that exposes file resources

Output: relevant file content is available as context

Business example · Connect systems

Input: a request to query a database or use a developer tool

AI / System: an MCP server exposes the allowed capability and applies its own access rules

Output: a result the AI application can use or present for review

What it is NOT

MCP ≠ AI Agent

MCP: a protocol for connecting an AI application to external capabilities and context.

AI agent: an application system that can decide and take actions toward a goal.

MCP ≠ Tool Calling

MCP: standardizes how capabilities can be discovered and exchanged between applications and servers.

Tool calling: a model or application mechanism for requesting a specific tool action.

MCP ≠ API

API: an interface provided by a service.

MCP: a standard protocol that can expose capabilities to AI applications.
