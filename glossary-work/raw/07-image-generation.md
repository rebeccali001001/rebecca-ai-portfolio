## Do Not Confuse Candidates

- Image Generation vs Image Search: image generation creates new visual content; image search retrieves images that already exist.
- Image Generation vs Computer Vision: image generation produces or transforms images; computer vision interprets or understands images.
- Image Generation vs Diffusion Model: image generation is a capability; diffusion is one model family that can implement it.
- Image Generation vs Generative AI: image generation is one visual capability within the broader category of generative AI.
- Image Generation vs Multimodal AI: image generation focuses on visual output; multimodal AI spans multiple data modalities.
- Image Generation vs Image Editing: generation can create a fresh image; editing changes an existing image, although both can be supported by one system.
- Image Generation vs Image Synthesis: image synthesis is a closely related technical term for producing an image, but “image generation” is the page’s broader capability label.
- Image Search vs Image Retrieval: search or retrieval finds existing content; neither necessarily creates a new image.
- Computer Vision vs Image Generation: computer vision may classify, detect, segment, or describe an image; image generation creates or modifies visual content.
- Image Understanding vs Image Generation: understanding extracts meaning from an image; generation produces a visual result.
- Prompt vs Condition: a prompt is one common type of condition; a condition can also be an image, mask, layout, or other signal.
- Text Prompt vs Image Condition: a text prompt describes a desired result in language; an image condition supplies visual guidance.
- Input vs Condition: an input is anything supplied to the model; a condition is input specifically used to guide or constrain the output.
- Input vs Representation: input is the external information supplied to the system; representation is the internal form used by the model.
- Representation vs Pixels: representation is an internal or abstract form; pixels are the concrete visual values returned in an image.
- Encode vs Decode: encoding turns input into a model-usable representation; decoding turns a representation into pixels or output.
- Encoder vs Decoder: an encoder builds an internal representation; a decoder turns a representation into an image or other output.
- Generative Model vs Image Generator: a generative model is the learned model component; an image generator may include the model, interface, preprocessing, safety controls, and output handling.
- Model vs System: a model is one learned component; a system includes the surrounding workflow and operational components.
- Model vs Product: a model produces or transforms content; a product also includes interface, controls, integrations, rules, and operations.
- Model Family vs Capability: a model family describes an implementation approach; a capability describes what the system can do.
- Generation vs Transformation: generation emphasizes producing a new result; transformation emphasizes changing an existing input.
- Create vs Edit: create starts a new visual result; edit modifies existing content.
- New Image vs Edited Image: a new image is generated as a fresh output; an edited image has an existing image as its starting point.
- Mask vs Layout: a mask marks where to edit or fill; a layout describes how visual elements are arranged.
- Image Mask vs Reference Image: a mask identifies editable regions; a reference image provides visual guidance.
- Inpainting vs Outpainting: inpainting fills or replaces an interior region; outpainting extends content beyond the original boundary.
- Inpainting vs Object Removal: inpainting is a general masked-generation technique; object removal is one use case that may use inpainting.
- Object Removal vs Image Search: object removal changes an image; image search only looks for existing images.
- Replacement vs Generation: replacement inserts new content in place of existing content; generation may produce a complete image without a source region.
- Consistent Replacement vs Copy-Paste: consistent replacement is generated to fit context; simple copy-paste may not match lighting, perspective, or texture.
- Mockup vs Final Asset: a mockup explores a product idea; a final asset is approved for real use.
- Concept Image vs Production Asset: a concept image supports exploration; a production asset is prepared for deployment or publication.
- Product Scene vs Product Image: a product scene includes context and environment; a product image may focus on the product itself.
- Visual Artist vs Image Generation Model: an artist is a human creator; the model is a learned computational mechanism.
- Learned Mathematical Pattern vs Explicit Rule: a learned pattern is inferred from data; an explicit rule is written in advance.
- Learned Pattern vs Representation: a pattern is a regularity captured by the model; a representation is the form in which information is encoded.
- Pixel vs Image: a pixel is one small visual unit; an image is the organized collection of pixels.
- Latent Space vs Pixel Space: latent space contains abstract internal representations; pixel space contains the visible image values.
- Latent Diffusion vs Pixel Diffusion: latent diffusion denoises a compact representation; pixel diffusion operates directly on pixels.
- Diffusion Model vs GAN: diffusion generates through iterative denoising; GANs use competing generator and discriminator networks.
- Diffusion Model vs VAE: diffusion iteratively denoises; a VAE encodes and decodes through a probabilistic latent representation.
- Diffusion Model vs Transformer: diffusion is a generative process or model family; Transformer is a neural architecture that may be used within a generator.
- Architecture vs Parameters: architecture describes the structure; parameters are the learned numerical values inside that structure.
- Encoder vs Text Encoder: an encoder is a general component; a text encoder specifically encodes language prompts.
- Vision Encoder vs Image Decoder: a vision encoder turns an image into a representation; an image decoder turns a representation into pixels.
- Attention vs Conditioning: attention is a mechanism for weighting information; conditioning is the information or control used to guide generation.
- Cross-Attention vs Self-Attention: cross-attention relates different sources such as text and image features; self-attention relates positions within one sequence or representation.
- Guidance vs Prompt: guidance is the mechanism or strength used to steer generation; a prompt is the condition being followed.
- Classifier-Free Guidance vs Guidance Scale: classifier-free guidance is a method; guidance scale is a setting controlling its strength.
