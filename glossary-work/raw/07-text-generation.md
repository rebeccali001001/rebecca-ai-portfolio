## Do Not Confuse Candidates

- Text generation ≠ next-token prediction: next-token prediction is one internal step; text generation is the repeated process that builds a complete response.
- Text generation ≠ an LLM: an LLM is a model type; text generation is a capability or task performed using a model.
- Text generation ≠ Generative AI: Generative AI is the broad area; text generation is one specific capability within it.
- Text generation ≠ code generation: ordinary text generation includes summaries, emails, and answers; code generation produces source code or code-like output.
- Generation ≠ search: generation creates new output; search finds existing information.
- Generation ≠ retrieval: generation produces language; retrieval finds source information.
- Generation ≠ training: generation happens during inference; training changes model parameters.
- Inference ≠ training: inference uses a trained model at runtime; training updates learned parameters.
- Prompt ≠ context window: a prompt can become part of context, but the context can also contain system instructions, other information, and generated tokens.
- Context ≠ model parameters: context is information available for one run; parameters are learned internal values.
- Context ≠ long-term memory: current context is runtime information, while durable memory may be a separate system.
- Context window ≠ output length: the context window covers usable context; output length is only one part of the total sequence.
- Token ≠ word: a token can be a word, subword, punctuation mark, whitespace, or another text fragment.
- Token ≠ character: one token can contain multiple characters, and a character can belong to a larger token.
- Token ≠ semantic unit: token boundaries are model-processing units, not guaranteed meaning boundaries.
- One token ≠ one sentence: a sentence normally requires many tokens.
- One generation step ≠ a full answer: one selected token is only one small part of a final response.
- Prediction ≠ selection: prediction estimates candidates; selection chooses which candidate to add.
- Prediction ≠ generation: prediction is one operation; generation repeats operations to produce a response.
- Candidate continuation ≠ final response: a candidate is one possible continuation; the final response is built across many decisions.
- Probability ≠ certainty: a model probability is an estimate, not a guarantee of truth.
- Likely ≠ correct: a likely continuation can be unsupported, outdated, or incorrect.
- Fluent ≠ correct: natural wording does not prove factual accuracy.
- Relevant ≠ supported: text can fit the question without having evidence.
- Useful ≠ true: useful-sounding wording still needs checking when facts matter.
- Sampling ≠ unstructured randomness: sampling follows a probability distribution even when outputs vary.
- Temperature ≠ creativity switch: temperature changes token-selection behavior; it does not add knowledge or reasoning ability.
- Temperature ≠ model retraining: temperature changes runtime selection and does not update parameters.
- Lower temperature ≠ always better: it can increase predictability but may reduce variation or encourage repetition.
- Higher temperature ≠ always random: it increases variation while remaining guided by the model distribution.
- Sampling ≠ training: sampling selects output tokens; training changes the model.
- Generated output ≠ retrieved source: generated text is produced by the model; retrieved information comes from a source.
- Grounding ≠ generation itself: grounding supplies or connects evidence; generation turns context into language.
- RAG ≠ retrieval only: RAG combines retrieval with generation.
- Structured text ≠ strict structured output: JSON-like text may resemble a format without being schema-valid or machine-validated.
- Code generation ≠ general text generation: code has programming-language syntax and execution semantics that ordinary prose does not.
- Translation ≠ copying: translation generates equivalent meaning in another language rather than simply repeating the input.
- Summarization ≠ truncation: summarization condenses content; truncation merely cuts content shorter.
- Rewriting ≠ summarization: rewriting changes tone or structure; summarization reduces content to key points.
- Exact generated text ≠ guaranteed output: the page notes that output can vary.
- Same model ≠ same output under all conditions: prompt, context, system instructions, sampling settings, temperature, and available information can change results.
- Model capability ≠ model identity: text generation describes what a system does, not necessarily which model it is.
- Model output ≠ model parameter: output is a runtime result; a parameter is learned internal state.
- Response ending ≠ successful factual completion: a response can end while still being wrong or unsupported.
