## Do Not Confuse Candidates

- **AI agent vs chatbot**：AI agent 可以规划并执行获准动作；chatbot 主要与用户交换消息。
- **AI agent vs LLM**：AI agent 是围绕模型、工具、上下文、记忆和控制机制构建的系统；LLM 是生成模型本身。
- **AI agent vs fully autonomous system**：AI agent 在定义好的工具、权限、限制和复核机制内运行；完全自主系统被描述为没有有意义的人或系统控制。
- **AI agent vs human**：agent 的导航员类比只描述控制循环，不表示它具有人类心智、经验、意图或真实理解。
- **Agent vs model**：model 负责基于输入上下文产生判断或输出；agent 还要管理工具、动作、观察和任务结束。
- **Model decision vs system action**：模型可以选择下一步，但通常由应用执行获准动作；选择和真正执行不是同一件事。
- **Tool vs model**：模型负责决定或生成；工具提供搜索、账户查询或其他外部操作能力。
- **Tool calling vs tool output**：tool calling 是请求工具执行；tool output 是工具执行后返回的结果。
- **Control loop vs one-shot response**：control loop 会根据观察继续决策；一次性回答只生成一次结果，不一定执行动作。
- **Goal vs plan**：goal 是想达到的结果；plan 是到达目标的步骤或路线。
- **Task vs action**：task 是整体工作要求；action 是完成任务过程中的一个具体步骤。
- **Context vs memory**：context 是当前提供给模型的信息；memory 是可以被保留下来、以后再次使用的信息。
- **Approved action vs arbitrary action**：approved action 在系统允许范围内；任意动作没有这样的边界。
- **Human review vs human handoff**：review 是人检查结果；handoff 是把整个案件或任务交给人继续处理。
- **Human review vs human approval**：review 可能只是检查；approval 是明确允许下一步执行。
- **Human-in-the-loop vs fully autonomous**：前者在关键步骤保留人参与；后者按定义不依赖有意义的人或系统控制。
- **Observation vs result**：observation 是循环中的返回信息；result 也可以指最终交付给用户的结果。
- **Tool output vs final output**：工具输出通常是中间信息；最终输出是整个 agent workflow 返回的结果。
- **Continue vs retry**：continue 是正常进入下一步；retry 是因失败或异常再次尝试同一动作。
- **Stop vs finish**：finish 通常意味着达到可交付状态；stop 也可能表示被中止、被限制或交给人工。
- **Research assistant vs search engine**：research assistant 可以组织目标、检索获准来源并收集证据；搜索引擎主要返回检索结果。
- **Evidence vs answer**：evidence 用来支持结论；answer 是对用户请求的最终回应。
- **Resolution vs handoff**：resolution 是问题得到处理的结果；handoff 是处理责任转交给人。
- **Support workflow vs chatbot conversation**：support workflow 可以查询账户、执行获准动作并转人工；chatbot conversation 主要是对话交换。
- **System control vs model capability**：system control 规定边界；model capability 只是模型能够生成或选择的能力。
- **Safety vs quality**：safety 关注伤害和风险；quality 关注结果是否正确、有用、完整。
- **MCP vs tool calling**：MCP 是页面所属主题组中的缩写，正文没有定义协议细节；tool calling 是页面明确关联的工具机制。
- **Structured outputs vs ordinary output**：structured output 需要符合指定结构；普通 output 不一定有固定格式。
- **Navigator analogy vs literal navigator**：navigator 是帮助理解控制循环的类比，不是页面声称存在的真实组件。
- **Human-like understanding vs useful behavior**：agent 可以产生有用行为，但这不等于像人一样真正理解。
- **Autonomy vs capability**：capability 是系统能做什么；autonomy 是系统在多大程度上可以自行决定和行动。
- **External capability vs external source**：capability 是可执行的能力；source 是提供研究信息的来源。
- **Input vs context**：input 是当前交给系统的输入；context 是模型做决定时可用的更广背景信息。
- **Source material vs output**：source material 用来支持任务；output 是系统处理后返回的结果。
