## Do Not Confuse Candidates

- **Planning vs plan**：planning 是决定步骤或动作的过程；plan 是这个过程产生的步骤安排。
- **Goal vs objective**：页面语境中两者都表示想达成的结果，但 goal 更像智能体要推进的目标，objective 更像需要明确理解和完成的任务目标。
- **Goal vs step**：goal 是最终想要的结果；step 是通往结果的一小步。
- **Plan vs sequence**：plan 是为目标提出的安排；sequence 强调动作的有序排列。
- **Action vs step**：action 是执行的动作；step 可以是计划中的抽象步骤，也可以指一个动作。
- **Action vs outcome**：action 是系统做什么；outcome 是做完后发生什么。
- **Current state vs observation**：current state 是做决定前的当前情况；observation 是动作后新返回的情况。
- **Observation vs result**：observation 强调循环中看到的新信息；result 可以是动作结果，也可以是研究或最终输出。
- **Result vs output**：result 是某个动作或步骤产生的结果；output 是系统对外返回的产出。
- **Context vs current state**：context 是决策时可用的背景信息；current state 是任务或环境此刻的状态。
- **Current state vs memory**：current state 描述现在；memory 是可以保留下来供以后使用的信息。
- **Revise vs retry**：revise 是改变计划或下一步；retry 是重新尝试相同或近似动作，页面没有展开 retry。
- **Continue vs finish**：continue 表示还有后续工作；finish 表示达到预期终点。
- **Stop vs finish**：finish 通常因为目标完成而结束；stop 也可能只是停止，不代表目标一定完成。
- **Plan vs fixed workflow**：plan 可以随状态和结果调整；fixed workflow 按预定义序列执行。
- **Planning vs reasoning**：planning 决定动作或动作顺序；reasoning 处理信息以得出结论。
- **Planning vs agent loop**：planning 是决定做什么的一部分；agent loop 还包括行动、观察、继续或停止。
- **Planning vs tool calling**：planning 选择要做的动作或计划；tool calling 是调用具体工具的机制。
- **Plan vs action sequence**：plan 可以包含目标、条件和多个步骤；action sequence 只强调动作的先后序列。
- **Plan revision vs course correction**：plan revision 是更新计划；course correction 强调把行动方向改到另一条路线。
- **Adaptive planning vs autonomous system**：adaptive planning 描述能否按新信息调整计划；autonomy 描述系统能否自行决定和行动。
- **Adaptability vs autonomy**：适应变化不等于完全自主；系统可以在严格规则或人工监督下调整计划。
- **Travel assistant vs research agent**：travel assistant 是到机场的日常类比；research agent 是比较产品、搜索信息和收集证据的 AI 产品实例。
- **Route vs plan**：route 通常是通往地点的路径；plan 可以是更广的任务步骤安排。
- **Traffic vs current state**：traffic 是影响旅行计划的一类条件；current state 是包含各种已知条件的整体状态。
- **Terminal vs destination**：terminal 是机场内的具体航站楼；destination 是要到达的地点，在类比中是机场。
- **Search vs query**：search 是查找信息的行为；query 是提交给搜索系统的请求或查询内容。
- **Evidence vs source**：source 是信息来自哪里；evidence 是用来支持结论的信息。
- **Sourced comparison vs ordinary comparison**：sourced comparison 标明支持信息的来源；普通 comparison 不一定有来源。
- **Human input vs human review**：human input 是人提供信息或判断；human review 是人检查已有结果。
- **Human review vs human approval**：review 是检查；approval 是明确允许继续执行。
- **Human input vs human handoff**：input 只是补充信息或意见；handoff 是把任务转交给人继续处理。
- **Chatbot vs AI agent**：chatbot 主要交换消息；AI agent 还会围绕目标选择和采取行动。
- **LLM vs AI agent**：LLM 根据上下文生成模型输出；AI agent 可以使用模型决定并执行行动。
- **Fully autonomous system vs agent**：agent 不必完全自主，页面强调它可能受人或系统控制。
- **Meaningful control vs no control**：meaningful control 是实际约束或引导系统的控制；不是泛指任何存在的控制。
- **System control vs human control**：system control 来自软件和规则；human control 来自人的监督、输入或批准。
- **Tool vs tool calling**：tool 是被使用的外部能力；tool calling 是调用它的机制或动作。
- **Approved tool vs available tool**：available tool 表示可用；approved tool 还强调得到系统允许。
- **Tool action vs action**：tool action 是通过工具执行的动作；action 也可以是不使用工具的下一步。
- **Memory vs state**：memory 是保留下来的信息；state 是某一时刻的当前条件。
- **Module vs topic**：module 是包含多个相关页面的较大学习单元；topic 是其中的一个具体主题。
- **Page title vs topic title**：页面 title 是网页名称；topic title 是学习内容的主题名称，两者可能相近但用途不同。
- **Video section vs process section**：video section 是媒体占位内容；process section 才是页面解释规划机制的正文。
- **Page navigation vs planning process**：页面导航帮助读者跳转；planning process 帮助智能体决定并执行任务步骤。
