## Do Not Confuse Candidates

- Multimodal AI vs Generative AI: Multimodal asks what information types a system can work with; generative asks whether it creates new content.
- Multimodal AI vs multimodal model: Multimodal AI is the broader capability or application; a multimodal model is one model designed or trained to handle multiple modalities.
- Multimodal AI vs computer vision: Computer vision focuses primarily on visual understanding; multimodal AI combines multiple information types.
- Modality vs input: A modality is a type of information; an input is a concrete piece of information received by the system.
- Modality vs output: A modality is a category; an output is the particular result returned in that category.
- Input modality vs output modality: Input modality describes what the system receives; output modality describes what it returns.
- Text vs text input: Text is a modality; text input is a specific text item supplied to a system.
- Image vs image input: Image is a modality; image input is a particular image received by the system.
- Audio vs speech: Audio includes sound generally; speech is spoken language and is one kind of audio.
- Audio vs music: Audio is the broad sound category; music is one kind of organized sound.
- Video vs frame: Video is a time-ordered medium; a frame is one image within a video.
- Video vs motion: Video can contain motion; motion is change over time within video or other input.
- Image vs diagram: An image is broad; a diagram is a kind of image used to explain structure or relationships.
- Text vs code: Code is written text with computer instructions; not every text is code.
- Structured data vs tables: A table is one common structured-data format; structured data can also use other formats.
- Understand vs generate: Understanding interprets received information; generation creates new output.
- Combine vs generate: Combining uses existing information together; generating creates new information.
- Representation vs raw input: Raw input is supplied data; a representation is a transformed internal form used for processing.
- Representation vs output: A representation is usually an internal processing form; an output is returned to a user or another system.
- Connect information vs reason across information: Connecting links information; reasoning uses linked information to reach a conclusion.
- Receive input vs return output: Receiving is the beginning of the flow; returning is the result stage.
- Input → system → output vs a model: The arrow describes a workflow; a model is one technical component that may implement part of it.
- One model vs several components: A multimodal product can use one unified model or several cooperating components.
- Multiple modalities vs multiple models: Handling multiple modalities does not require multiple models.
- Multimodal model vs product: A model is a model artifact or component; a product can add tools, interface, and application logic.
- Model vs application: A model maps or transforms information; an application is a user-facing use of models and other components.
- Product vs application logic: A product is the complete system; application logic is the rules and code organizing its behavior.
- Tools vs models: Tools are callable capabilities; a model may decide to use tools but is not identical to a tool.
- Image input vs image generation: Receiving or inspecting an image does not mean the system can create an image.
- Image inspection vs image generation: Inspection analyzes existing visual input; generation creates new visual output.
- Text → image vs image → text: Text-to-image produces a picture from text; image-to-text produces text from an image.
- Audio → text vs text → audio: Audio-to-text transcribes sound; text-to-audio generates or speaks sound from text.
- Video + text → text vs video generation: Understanding or summarizing video with text is not the same as creating new video.
- Text output vs text input: Text input is supplied to the system; text output is returned by it.
- Image output vs image input: Image input is received; image output is produced.
- Output modality vs output format: Modality is the information type; format is the specific representation or encoding.
- Generative AI vs generation: Generative AI is a category of systems; generation is the act or capability of creating output.
- Multimodal only vs both multimodal and generative: A system may handle several modalities without creating new content; another may do both.
- Computer vision vs visual understanding: Computer vision is a field or system family; visual understanding is a capability within it.
- Visual understanding vs multimodal understanding: Visual understanding focuses on visual input; multimodal understanding uses multiple information types.
- Speech model vs audio model: Speech models focus on spoken language; audio models can cover speech, sound, or music more broadly.
- Video understanding vs video generation: Video understanding interprets existing video; video generation creates new video.
- Image generation vs audio generation: Image generation creates pictures; audio generation creates sound.
- Audio generation vs speech-to-text: Audio generation produces sound; speech-to-text converts spoken sound into text.
- Transcription vs summarization: Transcription preserves spoken content as text; summarization condenses main points.
- Chart understanding vs trend generation: Understanding a chart interprets existing data; generation would create a new chart or description.
- Robot-in-a-library prompt vs generated image: The prompt is the request or description; the image is the generated result.
- High-level workflow vs exact implementation: The page’s four steps are an overview; actual architecture may differ.
- Architecture vs workflow: Architecture describes system structure; workflow describes the sequence of processing stages.
- Useful representation vs final output: A useful representation supports internal processing; a final output is returned externally.
- Shared representation vs modality: A shared representation would connect modalities internally; a modality is the information type itself.
- Cross-modal work vs single-modality work: Cross-modal work uses multiple information types; single-modality work uses one.
- Multiple inputs vs simultaneous inputs: A system may support multiple input types without receiving every type at the same time.
- Multiple outputs vs simultaneous outputs: A system may support multiple output types without returning every type in one response.
- “Multimodal” vs “all modalities”: Multimodal means more than one modality, not necessarily every possible modality.
- “Image” vs “visual information”: An image is one visual representation; visual information can also include video frames and diagrams.
- “Audio over time” vs a single sound: Audio over time emphasizes temporal change, especially within video.
- Foundation model vs multimodal model: A foundation model describes broad pretraining and reuse; a multimodal model describes supported modalities. A model can be both.
- Related concept vs definition: A related concept is connected to the topic; it is not automatically part of the core definition.
- Coming soon vs available: “Coming soon” means the visual explainer is not currently available.
- “AI” vs “multimodal AI”: AI is broad; multimodal AI is the subset or capability involving multiple information types.
