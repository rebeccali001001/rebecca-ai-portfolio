## Do Not Confuse Candidates

- AI integration vs model training: integration connects a model to systems and workflows; training changes learned parameters.
- AI integration vs model serving: serving makes a model available for requests; integration connects that capability to data, tools, controls, and business workflow.
- AI integration vs API connection: an API connection is one technical link; integration includes inputs, identity, permissions, validation, monitoring, workflow, and ownership.
- API vs AI integration: an API is an interface; integration is the larger system and process built around one or more interfaces.
- model vs AI system: a model generates or computes an output; an AI system includes the model plus data, tools, interfaces, controls, and workflow.
- model call vs working system: a model call is one invocation; a working system makes the result usable in an operational process.
- data source vs data: a data source is where information comes from; data is the information itself.
- input vs context: input is the broad supplied material; context is the relevant background included to help interpret the task.
- output vs business action: output is what the AI produces; a business action is what a person or downstream system does with it.
- tool vs API: a tool is a callable capability in a workflow; an API is a software interface that may implement or expose that capability.
- tool calling vs integration: tool calling is a model behavior or request pattern; integration is the end-to-end connection that makes the tool usable and controlled.
- validation vs monitoring: validation checks a particular result or action; monitoring observes system behavior over time.
- policy check vs safety check: a policy check tests compliance with a rule; a safety check focuses on preventing harmful or unsafe behavior. They can overlap.
- authentication vs authorization: authentication establishes identity; authorization determines permitted access or actions.
- permissions vs ownership: permissions control what a requester can do; ownership identifies who is responsible for the system or outcome.
- human review vs uncontrolled automation: human review adds a judgment or approval point; uncontrolled automation can act without required checks.
- exception vs error: an exception is a case routed outside the normal path; an error is a failed or invalid condition. An exception may be intentional to review.
- review queue vs business system: a review queue holds items for checking; the business system is where validated data or approved action is used.
- draft reply vs approved ticket action: a draft reply is proposed text; an approved ticket action is an authorized operation on the ticket.
- extracted fields vs validated data: extracted fields are identified values; validated data has also passed required checks for business use.
- workflow discovery vs technical scoping: workflow discovery maps users, systems, data, and handoffs; technical scoping defines technical boundaries and implementation scope.
- evaluation vs validation: evaluation judges broader system performance; validation checks whether a specific result or action meets requirements.
- adoption vs integration: integration makes a capability usable in a system; adoption is whether people and teams actually use it.
- business workflow vs business action: a workflow is the sequence; an action is one operation within or resulting from that sequence.
- live behavior vs test behavior: live behavior occurs in operation; test behavior is observed under a planned test case.
- monitoring vs observability: monitoring watches known conditions; observability is the broader ability to understand internal behavior from system signals.
- queue vs workflow: a queue holds waiting work; a workflow defines the steps and decisions for completing work.
- factory analogy vs technical specification: the factory comparison is a teaching analogy and does not define an actual integration architecture.
- AI integration vs automation without review: integration may automate steps, but it defines controls and human review where needed.
