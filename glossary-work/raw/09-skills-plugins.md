## Do Not Confuse Candidates

- Skill / Plugin vs Tool：Skill / Plugin 是可复用的打包能力；Tool 是执行一个具体动作的单项能力。
- Skill / Plugin vs MCP：Skill / Plugin 讲“能力如何被打包”；MCP 讲 AI 应用如何按标准连接外部工具和资源。
- Skill / Plugin vs Agent：Agent 决定为达成目标采取哪些动作；Skill / Plugin 提供 Agent 可以使用的能力。
- Skill / Plugin vs Model：Model 生成或选择输出；Skill / Plugin 在模型外围增加可复用能力。
- Tool vs Tool Calling：Tool 是被调用的能力；Tool Calling 是选择和调用工具的过程。
- MCP vs Tool：MCP 是连接标准；Tool 是通过某种机制被使用的具体动作。
- MCP vs Skill：MCP 不等于技能内容；它可以成为技能连接工具和资源的一种标准方式。
- Agent vs Model：Agent 是面向目标进行决策和行动的系统；Model 是生成或选择输出的模型组件。
- App vs Plugin：页面用 App 作类比，但 app、plugin、skill 的严格含义由具体平台决定。
- Action vs Tool：有的平台把 Action 当作可执行能力名称；在一般语境中 action 也可能只是一次动作。
- Resource vs Tool：Resource 提供能力所需的信息；Tool 执行一个动作，二者不是同一种对象。
- Workflow vs Tool：Workflow 是多个步骤的组织方式；Tool 通常是其中执行单个动作的组件。
- Permission vs Configuration：Permission 是允许或禁止的范围；Configuration 是更广义的运行设置。
- Orchestration vs Execution：Orchestration 负责安排和协调；Execution 是实际执行动作。
- Search function vs Search result：search_web() 是可调用的动作；搜索结果是执行后得到的输出。
- Database query vs Database：query 是请求；database 是存放数据的系统或资源。
- Human in the Loop vs Agent：人可以控制或审批动作；Agent 负责根据目标决定动作，二者角色不同。
- Standardized connection vs packaged capability：连接标准化描述“如何接入”；能力打包描述“提供什么能力”。
