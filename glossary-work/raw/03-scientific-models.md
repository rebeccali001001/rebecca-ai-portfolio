## Do Not Confuse Candidates

- Scientific foundation model vs scientific database: a model produces predictions or representations from learned patterns; a database stores explicit records for lookup.
- Scientific model vs scientific proof: a model offers a prediction, representation, or candidate; proof requires scientific reasoning and evidence.
- Scientific model vs experiment: a model computes or represents a result; an experiment tests a claim through observation or measurement.
- Scientific model vs scientific fact: a model output is not automatically an established fact.
- Scientific model vs LLM: a scientific model may operate on sequences, molecules, structures, materials, measurements, or scientific text; an LLM primarily models language tokens.
- Foundation model vs scientific foundation model: a foundation model is the broad category; a scientific foundation model is shaped around scientific data or tasks.
- Scientific data vs scientific evidence: scientific data is recorded input or observation; evidence is data or reasoning used to support a claim.
- Training data vs scientific literature: literature can be a source of training data, but not all training data is literature.
- Protein sequence vs protein structure: a sequence is an ordered chain of units; a structure is the spatial arrangement of the protein.
- Molecule vs material: a molecule is a chemical structure; a material may be a larger substance or system with composition, structure, and properties.
- Molecule generation vs drug discovery: generated molecules are candidates; drug discovery includes screening, synthesis, testing, and scientific judgment.
- Candidate structure vs validated structure: a candidate is proposed for review; validation requires additional evidence or experiment.
- Prediction vs generation: prediction estimates an outcome or property; generation proposes a new structure, representation, or content.
- Scientific prediction vs scientific proof: a prediction can be useful without proving that it is true.
- Statistical pattern vs causal mechanism: a learned association does not by itself explain why something happens.
- General representation vs scientific understanding: a reusable internal representation is not the same as human-understandable scientific theory.
- Adaptation vs pre-training: pre-training builds broad capability; adaptation specializes it for a task.
- Prompting vs fine-tuning: prompting changes the instructions or context; fine-tuning changes model parameters through additional training.
- Validation vs evaluation: validation checks a result or claim against evidence; evaluation measures model performance using planned tests.
- Benchmark vs experiment: a benchmark is a standardized comparison; an experiment tests a scientific claim or real-world behavior.
- Expert review vs proof: expert review is a human quality check; it is not by itself experimental proof.
- Reliability vs correctness: a system can be consistently wrong, so reliability is broader than correctness.
- Scientific model vs scientific database vs scientific proof: these are respectively a learned predictor or representation, an explicit record store, and evidence or reasoning supporting a claim.
- LLM vs language model: LLM is a large-scale language model; language model is the broader category.
- Vision model vs scientific model: a vision model is organized around visual input; a scientific model is organized around scientific data or tasks, and the categories can overlap.
- Multimodal model vs scientific model: multimodal describes the number or types of modalities; scientific describes the domain and tasks.
- Measurement vs property: a measurement is an observed value; a property is the characteristic being measured or predicted.
- Structure prediction vs structure generation: prediction estimates an existing or implied structure; generation proposes a new possible structure.
- Data analysis vs model inference: analysis is the broader activity; inference is applying a learned model to data.
- Scientific literature summary vs scientific conclusion: a summary reports source content; a conclusion requires evidence and interpretation.
- Internal values vs explicit records: internal model values encode learned behavior and are not a searchable database of source facts.
- Broad training vs broad scientific knowledge: broad training can improve capability but does not guarantee complete or correct scientific knowledge.
- Model output vs experimental result: a model output is computational; an experimental result comes from observation or measurement.
