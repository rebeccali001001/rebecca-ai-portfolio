## Do Not Confuse Candidates

- Artificial Intelligence vs Machine Learning: AI is the broad field; Machine Learning is one major approach within it.
- Machine Learning vs Deep Learning: Machine Learning is the broader family; Deep Learning is an approach inside it.
- Deep Learning vs Neural Network: Deep Learning usually refers to networks with many layers; a neural network can be small or shallow.
- Deep Learning vs Generative AI: Deep Learning is a method for learning patterns; Generative AI is a goal or application category that often uses it.
- Deep Learning vs Foundation Model: Deep Learning is a learning approach; a foundation model is a broadly trained reusable model, usually built with deep learning.
- Deep Learning vs Computer Vision: Deep Learning is a method; Computer Vision is a field that may use it for visual tasks.
- Model vs Algorithm: A model is the learned structure or artifact; an algorithm is a procedure used to train or apply it.
- Model vs Architecture: A model is a particular learned instance; architecture is the structural design shared by model instances.
- Architecture vs Parameters: Architecture describes connections and components; parameters are the learned numeric values inside that structure.
- Parameters vs Hyperparameters: Parameters are learned from data; hyperparameters control training and are selected outside the learned values.
- Weights vs Biases: Weights scale incoming signals; biases provide learned offsets. Both are usually parameters.
- Layer vs Neuron: A layer is a group or stage of units; a neuron is one computational unit within a layer.
- Representation vs Pattern: A representation is the encoded form; a pattern is a regularity captured within or across representations.
- Raw Data vs Input: Raw data is unprocessed source material; input is whatever representation is actually supplied to the model.
- Feature vs Sample: A feature is one property; a sample is one complete data example containing many features.
- Image vs Pixel: An image is the whole visual input; a pixel is one small numeric element of it.
- Audio vs Audio Sample: Audio is the signal or recording; an audio sample is one measured value in that signal.
- Speech vs Audio: Speech is human language conveyed by sound; audio includes speech and all other sounds.
- Token vs Word: A token is a model-processing unit and may be a word, part of a word, character, or symbol.
- Input vs Output: Input enters the network; output is produced after the network transforms it.
- Training vs Inference: Training learns or updates parameters; inference applies the learned model to new inputs.
- Training Data vs New Input: Training data teaches the model; new input is handled after or outside the training examples.
- Feedback vs Ground Truth: Feedback is information guiding improvement; ground truth is a trusted reference answer.
- Loss vs Error: Error is a discrepancy for an example; loss is a formal quantity used to optimize model behavior.
- Gradient vs Gradient Descent: A gradient describes how a quantity changes; gradient descent uses it to reduce loss.
- Epoch vs Batch: An epoch covers the entire training dataset once; a batch is only one group processed at a time.
- Pretraining vs Fine-tuning: Pretraining builds broad capabilities; fine-tuning adapts an existing model to a specific task.
- Supervised vs Self-supervised Learning: Supervised learning uses externally provided labels; self-supervised learning derives targets from the data.
- Unsupervised vs Reinforcement Learning: Unsupervised learning finds data structure; reinforcement learning learns actions through rewards and environment interaction.
- Classification vs Regression: Classification predicts categories; regression predicts numerical values.
- Classification vs Generation: Classification selects or predicts a category; generation creates new content.
- Prediction vs Generation: A prediction estimates an answer or value; generation produces a new sequence or artifact.
- Probability vs Confidence: Probability has a formal likelihood interpretation; confidence may be an informal score unless calibrated.
- Accuracy vs Precision vs Recall: Accuracy counts all correct predictions; precision focuses on predicted positives; recall focuses on finding actual positives.
- Validation Set vs Test Set: Validation helps tune or compare models; test data is reserved for a final check.
- Generalization vs Memorization: Generalization works on new cases; memorization mainly repeats training examples.
- Overfitting vs Underfitting: Overfitting learns too specifically; underfitting fails to learn enough useful structure.
- Data Drift vs Concept Drift: Data drift changes input characteristics; concept drift changes input-outcome relationships.
- Data Leakage vs Distribution Shift: Leakage exposes forbidden information during training; distribution shift changes the data encountered later.
- Bias vs Variance: Bias is systematic error from overly simple assumptions; variance is sensitivity to particular training data.
- Robustness vs Reliability: Robustness concerns performance under variation or noise; reliability concerns consistent operation over time.
- Interpretability vs Explainability: Interpretability concerns how understandable a model is; explainability concerns communicating reasons for outputs.
- Safety vs Security: Safety concerns harmful behavior; security concerns protection from attack, misuse, or unauthorized access.
- Privacy vs Security: Privacy concerns proper handling of personal information; security concerns protecting systems and data.
- Model vs Product: A model is one component; a product also includes interfaces, data, rules, integrations, and operations.
- Model Serving vs Training: Serving handles live requests; training learns or updates the model.
- Latency vs Throughput: Latency is time per response; throughput is work completed per unit time.
- Monitoring vs Evaluation: Evaluation is a planned measurement; monitoring watches a deployed system continuously or periodically.
- Model Update vs Retraining: An update may replace or modify a model; retraining is one way to create that update from data.
- Rollback vs Versioning: Versioning records alternatives; rollback returns production to an earlier version.
- CNN vs RNN: CNNs emphasize local spatial patterns; RNNs model ordered sequences with recurrent state.
- RNN vs Transformer: RNNs process sequence state recurrently; Transformers use attention to relate positions.
- Encoder vs Decoder: An encoder builds an internal representation; a decoder turns a representation into an output.
- Embedding vs One-hot Encoding: An embedding is a learned dense vector; one-hot encoding is a sparse fixed indicator representation.
- Convolution vs Attention: Convolution combines local neighborhoods; attention can weight relationships across positions more flexibly.
- Filter vs Kernel: A filter is the pattern detector or operation; a kernel is often the small matrix used to implement it.
- Image Filter vs Learned Filter: An image filter may be hand-designed; a learned filter is adjusted from training data.
- Model Size vs Parameter Count: Model size is storage or footprint; parameter count is the number of learned values and does not alone determine file size.
- GPU vs CPU: A GPU is optimized for parallel numeric workloads; a CPU is a general-purpose processor.
- Quantization vs Compression: Quantization reduces numerical precision; compression reduces storage or representation size, sometimes using quantization.
