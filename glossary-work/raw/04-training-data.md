## Do Not Confuse Candidates

- **Training data vs prompt**: Training data shapes learned parameters; a prompt is supplied during one use of an already trained model.
- **Training data vs context**: Training data is used to learn; context is information available during inference.
- **Training data vs fine-tuning data**: Training data is the broad category; fine-tuning data is used specifically for additional adaptation.
- **Training vs inference**: Training changes or fits the model; inference applies the fitted model to an input.
- **Training data vs model parameters**: Data is the learning material; parameters are internal values changed by learning.
- **Example vs label**: An example is the case or input; a label is the attached answer or category.
- **Label vs target**: A label is often categorical or descriptive; a target is the desired output more generally and may be numeric.
- **Label vs feature**: A label is what the model predicts; a feature is information used to make the prediction.
- **Target vs prediction**: The target is the known or desired answer; the prediction is what the model produces.
- **Training data vs validation data**: Training data fits the model; validation data supports development choices and tuning.
- **Validation data vs test data**: Validation data helps choose a model; test data should provide a more independent final check.
- **Held-out data vs unused data**: Held-out data is deliberately reserved for evaluation; unused data may simply have no planned role.
- **Generalization vs memorization**: Generalization works on new cases; memorization mainly repeats training examples.
- **Data quality vs model quality**: Good data helps learning but does not guarantee a good or perfect model.
- **Coverage vs balance**: Coverage asks whether important cases are present; balance asks whether some cases dominate the distribution.
- **Noise vs bias**: Noise is often random or irrelevant variation; bias is a systematic tendency or distortion.
- **Data bias vs model bias**: Data bias comes from the examples; model bias can come from the model, objective, or training choices.
- **Fair representation vs perfect representation**: Representative data covers important real cases; no finite dataset is automatically perfect.
- **Classification vs regression**: Classification predicts categories; regression predicts numerical values.
- **Binary classification vs multiclass classification**: Binary classification has two classes; multiclass classification has more than two possible classes.
- **Multiclass vs multilabel classification**: Multiclass normally selects one class; multilabel can assign several labels to one example.
- **Probability vs confidence score**: Probability has a defined likelihood interpretation; confidence may be an uncalibrated score.
- **Score vs decision**: A score is often continuous; a decision applies a threshold or policy to choose an action.
- **Accuracy vs precision**: Accuracy counts all correct predictions; precision focuses on whether predicted positives are truly positive.
- **Precision vs recall**: Precision asks how trustworthy positive predictions are; recall asks how many real positives were found.
- **False positive vs false negative**: A false positive is an incorrect alert; a false negative is a missed positive case.
- **Parameter vs hyperparameter**: Parameters are learned from data; hyperparameters are selected as training controls.
- **Error vs loss**: Error can mean an individual mistake or difference; loss is the formal quantity used by optimization.
- **Optimizer vs objective function**: The objective says what should improve; the optimizer decides how to update parameters.
- **Epoch vs iteration**: An epoch passes through the full training set; an iteration is one update step.
- **Pre-training vs fine-tuning**: Pre-training builds broad capability; fine-tuning adapts an existing model to a narrower purpose.
- **Fine-tuning vs prompt**: Fine-tuning changes model parameters; prompting changes the current input or instruction.
- **Supervised learning vs unsupervised learning**: Supervised learning uses known answers; unsupervised learning searches for structure without supplied labels.
- **Supervised learning vs reinforcement learning**: Supervised learning learns from labeled examples; reinforcement learning learns through actions and rewards or feedback.
- **Supervised learning vs deep learning**: Supervised learning describes the learning signal; deep learning describes a model approach that can use different signals.
- **Machine learning vs artificial intelligence**: Machine learning is a field within the broader AI field.
- **Deep learning vs neural network**: Deep learning generally uses many-layer networks; a neural network can be shallow or deep.
- **Prediction vs explanation**: A model may predict well without explaining why a relationship exists.
- **Correlation vs causation**: A predictive pattern may help forecast an outcome without causing it.
- **Evaluation vs monitoring**: Evaluation is a planned measurement; monitoring is ongoing observation, often after deployment.
- **Human review vs guaranteed correctness**: Human review is a safeguard, not a guarantee that every result is correct.
- **Risk score vs risk decision**: A risk score estimates risk; a person or policy still decides what action to take.
- **Model performance vs business outcome**: A metric can improve without improving the real decision or business result.
- **Data drift vs concept drift**: Data drift changes the input distribution; concept drift changes the relationship between input and outcome.
- **Training pipeline vs inference pipeline**: Training prepares or updates a model; inference serves predictions from the current model.
- **Online evaluation vs offline evaluation**: Offline evaluation uses prepared datasets; online evaluation measures behavior in live use.
- **AI vs ML**: AI is the broad field; ML is one major way to build AI systems.
- **RLHF vs preference learning**: RLHF is one named workflow for using human preferences; preference learning is the broader concept.
