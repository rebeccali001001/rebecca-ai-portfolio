## Do Not Confuse Candidates

- Neural Network vs Human Brain: the page explicitly describes a neural network as a mathematical model/system, not a biological mind.
- Neural Network vs Deep Learning: deep learning usually uses neural networks with many layers, but the page says the terms are related and not identical.
- Neural Network vs One Neuron: a network connects many computational units and layers; one neuron is a single unit.
- Artificial neural network vs biological neuron: biological neurons are an inspiration, while artificial neural networks are mathematical systems.
- Neural network vs digital brain: “digital brain” is a rejected metaphor, not the definition of the model.
- Layer vs neuron/unit: a layer is a structural grouping; a computational unit/neuron is an element within a network.
- First layer vs hidden layer vs output layer: these are distinct positions/roles in the page’s process flow.
- Hidden layer vs output layer: hidden layers build representations; the output layer produces a result.
- Input vs output: input is received data; output is the transformed result or prediction.
- Prediction vs training feedback: prediction returns an estimate; training feedback adjusts parameters.
- Estimate vs label: an estimate is a numeric or model output; a label is a categorical output such as “cat,” “road,” or “defect.”
- Classification vs price prediction: image/text classification maps to labels or categories; price prediction maps features to a numeric value.
- Image classification vs text classification: they operate on different input modalities and pattern types.
- Label vs category: a label is the assigned output token/class; a category is the class grouping or type.
- Feature vs representation: a feature is relevant input information; a representation is a learned/intermediate form built by hidden layers.
- CNN vs RNN vs Transformer: these are different architecture/model-family candidates listed together, not interchangeable names.
- CNN vs convolutional neural network: CNN is the abbreviation; the page does not expand it, so preserve both forms.
- RNN vs recurrent neural network: RNN is the abbreviation; the page does not expand it, so preserve both forms.
- Transformer vs transformer architecture: Transformer is the page’s model-family label; “transformer architecture” is a normalized expansion.
- Machine learning vs deep learning: machine learning is the broader parent concept in the page’s concept tree; deep learning is a related child concept.
- Neural network vs model architecture: a neural network is a model; architecture describes its organization/design.
- Parameter vs hyperparameter: the source names learned parameters but does not discuss hyperparameters; do not merge them.
- Training vs inference: the page names training and prediction but does not use the word inference; preserve the distinction as an expansion candidate.
- Numeric value vs categorical label: numeric output and class-label output represent different prediction types.
- Biological neuron vs computational unit: the page uses biological neurons as inspiration but computational units as the network’s mathematical components.
