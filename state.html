PART I · HOW SOFTWARE WORKS

State

Information that describes the current condition of a system, page, or process.

01 · What is it?

State is information that describes the current condition of an application, page, or process.

Simple Definition:

State answers: “What is happening right now?”

02 · Think of it like...

Think of state as the current position of something in a process.

Draft
→
Submitted
→
Approved
→
Completed

Each step represents a different state.

03 · What does it do?

State helps software remember current values and conditions.

It can tell the system:

What the user selected
Whether the user is logged in
What step a workflow is on
What status an order has

07 · Do Not Confuse

State ≠ Data

Data
The broader information used by a system.

State

Information describing the current condition at a specific moment.

Data can exist for a long time. State describes what is true now.

09 · What to Remember

State describes the current condition of a system.

State can change when users or software perform actions.

State helps determine what the system should show or do next.
