02 · Data Types

A data type tells Python what kind of value is being stored.

On This PageSummaryintfloatstrboolNonetype()Type Conversion

Data Types

int     → whole number
float   → decimal number
str     → text
bool    → True / False
None    → no value
01

int

int stores whole numbers without decimals.

Common scenarios:

quantityageyearpage numbercountID when stored as a number
count = 99
age = 20
page = 5
quantity = 100
02

float

float stores numbers with decimals.

Common scenarios:

priceweightexchange ratepercentage
price = 8500.50
weight = 12.75
rate = 7.18
03

str

str stores text. Text is usually written inside quotes.

customer = "Apple"
product = "Copper"
status = "Pending"

customer = 'Apple'

Single quotes also work.

04

bool

bool stores only two values:

True
False

Common scenarios:

enabled / disabledcompleted / not completedapproved / rejected
is_active = True
is_completed = False
05

None

None means there is currently no value.

delivery_date = None

Common scenario: A value has not been assigned yet.

06

type()

type() checks the data type of a value.

price = 8500
print(type(price))

Output:

<class 'int'>
customer = "Apple"
print(type(customer))

Output:

<class 'str'>
07–11

Type Conversion

int()

int() converts a compatible value into an integer.

quantity = "10"
quantity = int(quantity)

Before: "10" is text. After: 10 is an integer.

float()

price = "8500.50"
price = float(price)

Converts text into a decimal number.

str()

order_id = 1001
text = str(order_id)

Converts a value into text.

bool()

is_active = bool(1)

Result: True

Type Conversion Example

price = "8500"
quantity = "10"

total = int(price) * int(quantity)

print(total)

Output:

85000

The values originally arrive as strings. int() converts them into numbers before calculation.
