01

Software Basics

软件、程序、数据与运行的基础概念。

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Software软件Programs and data that help a computer perform useful tasks.让计算机完成各种实际任务的程序和相关数据。
Application应用程序Software designed to help users perform specific tasks.为用户完成某种具体任务而设计的软件，例如浏览器、聊天工具或订单系统。
System系统A group of connected parts that work together for a purpose.多个相互连接的部分一起工作，共同完成某个目标。
Program程序A set of instructions that tells a computer what to do.一组告诉计算机应该执行什么操作的指令。
Code代码Instructions written in a programming language for a computer to execute.使用编程语言写出的指令，告诉计算机具体要做什么。
User用户A person or another system that uses a software application.使用软件的人，也可以是调用这个软件的其他系统。
Data数据Information that software stores, reads, changes, or sends.软件保存、读取、修改或传递的信息。
State状态Information that describes the current condition of an application or process.用来表示应用或流程当前处于什么情况的信息。
Process进程A running instance of a program on a computer.一个程序真正运行起来后的执行实例。
Runtime运行时 / 运行环境The environment in which a program is actually running.程序真正执行时所处的环境。
02

Client & Frontend

用户看到、操作以及客户端中运行的软件部分。

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Client客户端The part of a system that sends requests to a server.系统中向服务器发送请求的一端，例如浏览器、手机 App 或桌面应用。
Browser浏览器Software that loads, displays, and runs web pages.用来打开、显示并运行网页的软件，例如 Chrome、Safari 和 Edge。
App应用 / AppA software application designed for users to perform tasks.用户直接使用的软件应用，例如手机 App、桌面程序或 Web App。
Frontend前端The part of software that users see and interact with.用户能够看到并直接操作的软件部分。
User Interface (UI)用户界面The screens, buttons, forms, and other elements users interact with.用户在软件中看到和操作的页面、按钮、表单等界面元素。
Page页面A screen or document shown to the user in an application or website.网站或应用中展示给用户的一张具体页面。
HTML超文本标记语言The language used to define the structure of a web page.用来定义网页结构，例如标题、文字、图片、表格和按钮。
CSS层叠样式表The language used to control the appearance and layout of a web page.用来控制网页的颜色、字体、间距、位置和整体布局。
JavaScriptJavaScriptThe language commonly used to add behavior and interaction to web pages.用来给网页增加点击、输入、切换、请求数据等交互行为。
Event事件An action or change that software can detect and respond to.软件可以检测并做出响应的操作，例如点击、输入或提交。
Input输入Data or information provided to a software system.用户或其他系统输入给软件的数据，例如文字、数字或文件。
Output输出Information or results produced by a software system.软件处理后提供给用户或其他系统的结果。
03

Communication

客户端、服务器和不同软件之间如何交换信息。

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Network网络A connection that allows computers and devices to exchange data.让计算机和设备之间能够传递数据的连接体系。
Internet互联网A global network that connects computers and services around the world.把全球大量计算机、网站和服务连接起来的网络。
URL网址 / 资源地址The address used to locate a page or resource on the web.用来找到网页、接口或其他网络资源的地址。
HTTP超文本传输协议The basic protocol used to exchange data on the web.浏览器、客户端和服务器在 Web 上交换数据时常用的基础协议。
HTTPS安全的 HTTPHTTP with encryption to protect data during communication.加密版 HTTP，用来保护数据在网络传输过程中的安全。
API应用程序接口A way for different parts of software to communicate.让不同软件组件或系统之间交换数据和调用功能的接口。
Endpoint接口地址A specific address where an API provides a function or resource.API 中提供某个具体功能或数据的访问地址。
Request请求A message sent to ask another system for data or an action.向另一个系统发送的取数或执行操作请求。
Response响应A message returned after a request has been processed.系统处理请求后返回的数据或结果。
Header请求头 / 响应头Extra information sent with a request or response.随请求或响应一起传递的附加信息，例如内容类型或身份信息。
Body请求体 / 响应体The main data carried inside a request or response.请求或响应中真正承载的主要数据内容。
Status Code状态码A number that shows the result of an HTTP request.用一个数字表示 HTTP 请求成功、失败或其他处理结果。
JSONJSON 数据格式A common text format for exchanging structured data.软件系统之间交换结构化数据时常用的文本格式。
04

Server & Backend

服务器如何接收请求、执行逻辑并处理业务。

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Server服务器A computer or service that receives requests and provides data or functions.接收客户端请求，并提供数据或功能的计算机或服务。
Backend后端The part of software that processes data and business rules.用户通常看不到，负责处理数据、规则和业务逻辑的软件部分。
Route路由A rule that connects a request path to backend code.把某个接口地址连接到对应后端处理代码的规则。
Function函数A reusable block of code that performs a specific task.封装某项具体操作、可以重复执行的一段代码。
Validation校验Checking whether incoming data follows the required rules.检查输入的数据是否完整、正确并符合系统要求。
Business Logic业务逻辑Rules that decide how the system handles business actions.决定系统如何处理订单、付款、审批等业务操作的规则。
Service服务A software component that provides a specific capability.在系统中负责提供某一类功能的软件组件。
External Service外部服务A service provided by another system or company.由其他系统或公司提供、当前系统需要调用的服务。
Dependency依赖Software or code that another program needs in order to work.当前程序运行时需要依赖的其他代码、软件包或组件。
Configuration配置Settings that control how software behaves in an environment.用来控制软件在不同环境下如何运行的一组设置。
Error错误A problem that prevents software from working as expected.导致软件没有按照预期工作的异常情况。
Exception异常An event raised by a program when something goes wrong during execution.程序执行过程中发生问题时产生的一种异常事件。
Log日志A record of events and actions that happen while software is running.记录系统运行过程中发生了什么，便于排查和分析问题。
05

Data & Database

软件如何组织、查询、保存和修改业务数据。

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Database数据库A system used to store and organize application data.用来长期保存和组织用户、订单、商品等应用数据的系统。
Table表A structure that stores one type of data in rows and columns.数据库中按行和列保存某一类数据的结构。
Row行One complete record in a database table.数据表中的一条完整记录。
Column列One type of information stored for every record in a table.数据表中的一个字段类别，例如名称、金额或状态。
Record记录A collection of related data about one item or event.描述一个用户、订单或其他对象的一组完整数据。
Field字段A named piece of information within a record.一条记录中的某个具体数据项，例如 customer_id 或 status。
SQL结构化查询语言A language used to read and change data in relational databases.用来查询、增加、修改和删除关系型数据库数据的语言。
Query查询A request to read or change data in a database.向数据库发出的查询或数据操作指令。
Read读取Getting existing data from a system or database.从系统或数据库中获取已经存在的数据。
Write写入Saving or changing data in a system or database.将新数据保存到系统中，或修改已有数据。
Create创建Adding new data or a new resource to a system.在系统中新增一条数据或一个新的业务对象。
Update更新Changing data that already exists.修改系统中已经存在的数据。
Delete删除Removing existing data or a resource.从系统中删除已有的数据或对象。
CRUD增删改查The four basic data operations: Create, Read, Update, and Delete.数据处理中最基础的四种操作：创建、读取、更新和删除。
Primary Key主键A value that uniquely identifies each record in a table.在数据表中唯一标识一条记录的字段。
Relationship关系A connection between data stored in different tables.不同数据表之间通过字段建立的数据关联。
Transaction事务A group of database operations treated as one complete unit.一组需要作为一个整体完成的数据库操作，通常要求一起成功或一起失败。
06

Environment & Delivery

代码如何从开发阶段变成真正可供用户使用的软件。

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Environment环境A set of systems and settings where software runs.软件运行所依赖的一组服务器、配置和资源。
Development开发环境The environment where software is created and changed.开发人员编写和修改软件时使用的环境。
Test测试环境An environment used to check whether software works correctly.用来验证功能和检查问题的测试环境。
UAT用户验收测试环境An environment where users verify that the system meets business needs.让业务用户在正式上线前确认功能是否符合需求的环境。
Production生产环境The live environment used by real users.真实用户正式使用的软件运行环境。
Build构建Turning source code into a form that can be run or deployed.把源代码处理成可以运行或部署的软件版本。
Release发布版本A version of software prepared for users or deployment.已经准备好用于上线或交付的软件版本。
Deployment部署Moving software into an environment where it can run.把软件发布到目标环境中并让它真正运行起来。
Cloud云计算Computing resources provided over the internet.通过互联网提供服务器、存储和计算能力的服务方式。
Hosting托管Running a website or application on a server or cloud platform.把网站或应用放在服务器或云平台上持续运行。
07

Reliability & Operations

系统上线后如何发现问题、观察运行状态并保持稳定。

ENGLISH TERM中文SIMPLE ENGLISH中文小白理解
Bug缺陷 / BugA problem in software that causes incorrect or unexpected behavior.软件中的缺陷，会导致功能结果错误或出现非预期行为。
Error错误A problem that occurs while software is running.软件运行过程中出现的错误情况。
Log日志A record of events that happen while a system is running.记录系统运行过程中发生了什么，常用于排查问题。
Metric指标A number used to measure how a system is performing.用数字表示系统运行情况，例如请求量、响应时间或错误率。
Monitoring监控Continuously checking whether a system is running correctly.持续观察系统是否正常运行以及性能是否出现异常。
Alert告警A notification sent when a system problem or unusual condition is detected.系统发现异常或达到预设条件后发出的提醒。
Observability可观测性The ability to understand what is happening inside a system using its data.通过日志、指标等信息了解系统内部正在发生什么。
