What is Fine-tuning?

Fine-tuning adapts a pre-trained model with focused examples so it follows a task, format, style, or domain behavior more consistently.

Easy analogy

Fine-tuning is focused coaching: a broadly trained model studies a smaller workbook of expert examples for one job.

Analogy video

Definition

Fine-tuning continues training from an existing checkpoint with a smaller, curated dataset. Teams may use supervised examples, preference data, or parameter-efficient adapters.

start with a capable base; specialize with evidence

In plain English

Imagine a general athlete working with a coach to practice one position. The goal is more consistent behavior for a particular job.

Key points

Base model
General language ability
Curated examples
Task + ideal output
Evaluation
Accuracy + edge cases

Sample

A company wants consistent JSON for support triage. It collects high-quality examples, labels edge cases, adapts a base model, and tests ambiguous tickets and policy-sensitive cases.

Where it shows up

Format adherence, tone, task consistency, domain conventions, and other stable behaviors. Use retrieval or tools for facts that change and actions that need current systems.
